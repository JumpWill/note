# 交换机 (Network Switch)

## 一、交换机概述

### 什么是交换机

**交换机 (Switch)**:**数据链路层 (Layer 2)** 的网络设备,根据 **MAC 地址**转发以太网帧。

- 替代了旧的集线器 (Hub)
- 多个端口独立冲突域
- 智能学习 MAC 表,精准转发
- 现代交换机也支持三层 (路由) / 四层功能

### 交换机 vs 集线器 vs 路由器

| 设备 | 工作层 | 转发依据 | 冲突域 | 适用 |
| ---- | ------ | -------- | ------ | ---- |
| **集线器 (Hub)** | 物理层 | 无 | 所有端口共享 | 已淘汰 |
| **交换机 (Switch)** | 数据链路 | MAC 地址 | 每端口独立 | 局域网 |
| **路由器 (Router)** | 网络层 | IP 地址 | 每端口独立 | 跨网段 |
| **三层交换机 (L3 Switch)** | 链路 + 网络 | MAC + IP | 每端口独立 | 大型园区 |
| **网关 (Gateway)** | 应用层 (概念) | 协议 | - | 协议转换 |

## 二、交换机工作原理

### 1. 核心机制:MAC 地址学习

**MAC 表 (CAM Table / MAC Address Table)**:

| MAC 地址 | 端口 | VLAN | 老化时间 |
| -------- | ---- | ---- | -------- |
| AA:BB:CC:11:22:33 | 1 | 10 | 300s |
| AA:BB:CC:44:55:66 | 5 | 20 | 280s |
| ... | ... | ... | ... |

### 2. 转发过程 (3 步骤)

```text
1. 学习 (Learning)
   - 收到帧,记录源 MAC + 进入端口到 MAC 表
   - 自动学习,无需配置

2. 泛洪 / 转发 (Flooding / Forwarding)
   - 查目的 MAC 是否在 MAC 表
   ├─ 找到 → 只从对应端口转发(精准)
   └─ 没找到 → 向所有端口泛洪(广播)
   (除进入端口外)

3. 老化 (Aging)
   - MAC 表项 300 秒未使用则删除
   - 适应拓扑变化
```

### 3. 工作示例

```text
主机 A → 主机 B 通信:

A 发送帧
  → 交换机收到,源 MAC = A,学习到 MAC 表
  → 查目的 MAC = B
  ├─ 找到了 → 只从 B 所在端口转发
  └─ 没找到 → 泛洪(除 A 端口外)

之后 A 发送别的帧
  → 交换机已经知道 A 在哪,正常转发
```

## 三、交换机类型

### 1. 按管理方式

| 类型 | 特点 | 适用 |
| ---- | ---- | ---- |
| **非管理型 (Unmanaged)** | 插电即用,无配置 | 家用、小办公室 |
| **智能型 (Smart)** | 基础 Web 管理 | 小企业 |
| **管理型 (Managed)** | 完整 CLI / Web / SNMP | 企业、机房 |

### 2. 按网络层

| 类型 | 层 | 能力 |
| ---- | -- | ---- |
| **二层交换机** | 数据链路 | MAC 转发、VLAN、STP |
| **三层交换机** | 链路 + 网络 | 上述 + IP 路由、ACL、VRRP |
| **四层交换机** | + 传输 | 上述 + 端口号匹配、负载均衡 |
| **七层交换机** | + 应用 | 上述 + URL/Host 匹配 |

### 3. 按外形

- **固定端口**: 8/16/24/48 口,1U 高度
- **模块化**: 插槽,可换板卡,核心机房
- **盒式**: 普通企业
- **机箱式**: 数据中心核心

### 4. 按速率

| 速率 | 用途 |
| ---- | ---- |
| 100 Mbps | 边缘接入(已少) |
| 1 Gbps | 桌面接入、服务器接入 |
| 10 Gbps | 服务器上行、汇聚 |
| 25 Gbps | 服务器上行(新) |
| 40 Gbps | 汇聚 |
| 100 Gbps | 核心、数据中心 |
| 400 Gbps | 超大规模数据中心 |
| 800 Gbps | 下一代 |

## 四、VLAN (虚拟局域网)

### 1. 什么是 VLAN

**VLAN**:**逻辑**上把一个物理交换机分成**多个独立的广播域**

- 跨物理位置
- 隔离广播
- 提高安全
- 灵活组网

### 2. VLAN 类型

| 类型 | 标识 | 范围 |
| ---- | ---- | ---- |
| **基于端口** | VLAN ID (1-4094) | 静态 |
| **基于 MAC** | 动态 | 灵活 |
| **基于协议** | IP 子网 | 协议 |
| **基于 802.1Q** | Trunk 上的标签 | 跨交换机 |

### 3. 802.1Q 标签

```text
┌─────────┬─────┬──────┬──────┬──────┐
│ Dest MAC │ Src │ 802.1Q│ Type │ 载荷 │
│ 6B       │ 6B  │ 4B   │ 2B   │ ...  │
└─────────┴─────┴──────┴──────┴──────┘
              ↑ VLAN Tag
              - TPID (0x8100)
              - TCI (VLAN ID + 优先级)
```

### 4. 端口类型

| 类型 | 模式 | 说明 |
| ---- | ---- | ---- |
| **Access** | 单 VLAN | 接入终端,不打标签 |
| **Trunk** | 多 VLAN | 交换机之间,打标签 |
| **Hybrid** | 灵活 | 国产交换机常用 |
| **Access (trunk allowed)** | 限制 | Trunk 允许的 VLAN |

### 5. VLAN 间通信

- **同一 VLAN**:直接通信
- **不同 VLAN**:需要**三层设备**(路由器或三层交换机)
- **单臂路由 (Router-on-a-Stick)**:用 Trunk + 子接口
- **SVI (Switch Virtual Interface)**:三层交换机的 VLAN 接口

### 6. VLAN 配置示例

```text
# Cisco
vlan 10
  name Sales
vlan 20
  name Engineering
!
interface GigabitEthernet0/1
  switchport mode access
  switchport access vlan 10
!
interface GigabitEthernet0/2
  switchport mode access
  switchport access vlan 20
!
interface GigabitEthernet0/48
  switchport mode trunk
  switchport trunk allowed vlan 10,20
```

## 五、STP (生成树协议)

### 1. 为什么需要 STP

**问题**:交换机冗余链路会形成**网络环路**,导致:

- **广播风暴**:广播帧无限循环
- **MAC 表震荡**:MAC 地址表项不稳定
- **网络不可用**

**STP 作用**:**逻辑上断开环路**,提供冗余

### 2. STP 演进

| 标准 | 名称 | 特点 |
| ---- | ---- | ---- |
| 802.1D | STP | 经典,收敛慢 (30-50s) |
| 802.1w | RSTP | 快速收敛 (< 6s) |
| 802.1s | MSTP | 多实例,多 VLAN |
| 802.1Q-2014 | (含 RSTP) | 当前主流 |

### 3. STP 概念

- **根桥 (Root Bridge)**: 选举出来,作为参考点,BID 最小
- **BPDU**: Bridge Protocol Data Unit,交换机之间交换
- **Bridge ID (BID)**: Bridge Priority (高 16 位) + MAC (低 48 位)
- **路径开销 (Path Cost)**: 与链路带宽成反比
- **根端口 (Root Port)**: 离根桥最近的端口
- **指定端口 (Designated Port)**: 每网段朝向根桥的端口
- **阻塞端口**: 既不是根端口也不是指定端口 → 阻塞

### 4. STP 选举步骤

```text
1. 选举根桥 (Root Bridge)
   - BID 最小的交换机
   - 默认 Priority = 32768

2. 每个非根交换机选举根端口
   - 根路径开销最小
   - 上游 BID 最小
   - 上游端口 ID 最小

3. 每个网段选举指定端口
   - 根路径开销最小
   - BID 最小
   - 端口 ID 最小

4. 阻塞剩余端口 → 逻辑无环
```

### 5. STP 端口状态

| 状态 | 作用 | 时间 |
| ---- | ---- | ---- |
| Disabled | 关闭 | - |
| Blocking | 接收 BPDU,不发数据 | 20s |
| Listening | 收发 BPDU,不学 MAC | 15s |
| Learning | 收发 BPDU,学 MAC | 15s |
| Forwarding | 正常转发 | - |

总收敛:30-50s (传统 STP)
RSTP: 几秒内

### 6. STP 端口角色

- **Root Port** (根端口): 每交换机一个
- **Designated Port** (指定端口): 每网段一个
- **Alternate Port** (替代): STP 备份根端口
- **Backup Port** (备份): STP 备份指定端口

### 7. STP 防护

- **BPDU Guard**: 接入端口收到 BPDU 时关闭端口
- **Root Guard**: 阻止非期望的根桥选举
- **Loop Guard**: 防止单向链路误判
- **UDLD**: 检测单向链路

### 8. RSTP 优势

- 收敛时间 < 6 秒
- 端口角色简化
- 兼容 STP

### 9. 多生成树 (MSTP)

- 多 VLAN 共享一个生成树实例
- 负载均衡
- 不同 VLAN 走不同路径

## 六、链路聚合 (Link Aggregation)

### 1. 概念

**链路聚合 (Link Aggregation)**:把多条物理链路捆绑成**一条逻辑链路**

- 增大带宽
- 提供冗余
- 负载均衡
- 不阻塞 STP

### 2. 协议

| 协议 | 标准 | 模式 |
| ---- | ---- | ---- |
| **LACP** | IEEE 802.3ad / 802.1AX | 动态协商 (推荐) |
| **LACP (active/passive)** | 802.3ad | 主动 / 被动 |
| **Static LAG** | - | 手动 (无协议) |

### 3. LACP 模式

- **Active**: 主动发送 LACP 报文
- **Passive**: 被动(对方 Active 才能协商成功)

**推荐**: 一端 Active,另一端 Active 或 Passive

### 4. 配置示例

```text
# Cisco LACP
interface range GigabitEthernet0/1-2
  channel-group 1 mode active
!
interface Port-channel1
  switchport mode trunk
  switchport trunk allowed vlan 10,20
```

### 5. 负载均衡

- **src-mac**: 基于源 MAC
- **dst-mac**: 基于目的 MAC
- **src-dst-mac**: 基于两者
- **src-ip / dst-ip / src-dst-ip**: 基于 IP
- **L4 port**: 基于端口

## 七、交换机高级特性

### 1. 端口安全 (Port Security)

```text
# Cisco
interface GigabitEthernet0/1
  switchport port-security
  switchport port-security maximum 2
  switchport port-security violation restrict
  switchport port-security aging time 5
  switchport port-security aging type inactivity
```

- 限制端口 MAC 数量
- 违反时动作: protect / restrict / shutdown

### 2. DHCP Snooping

- 防止非法 DHCP 服务器
- 交换机只信任 trusted 端口
- 建立 **DHCP Snooping Binding 表**

### 3. DAI (Dynamic ARP Inspection)

- 防止 ARP 欺骗
- 基于 DHCP Snooping 表验证 ARP
- 配合 DCHP Snooping 使用

### 4. 端口镜像 (SPAN / Mirror)

```text
# Cisco
monitor session 1 source interface Gi0/1 both
monitor session 1 destination interface Gi0/48
```

- 把一个/多个端口流量复制到另一个端口
- 抓包分析
- 入侵检测

### 5. ACL (访问控制列表)

```text
# 拒绝 192.168.1.0/24 访问服务器
access-list 100 deny ip 192.168.1.0 0.0.0.255 host 10.0.0.100
access-list 100 permit ip any any
!
interface GigabitEthernet0/1
  ip access-group 100 in
```

- **标准 ACL**: 基于源 IP
- **扩展 ACL**: 基于源/目的 IP、端口、协议

### 6. QoS (服务质量)

- 队列管理
- 流量分类
- 拥塞避免
- 语音/视频优先

### 7. IGMP Snooping

- 抑制组播泛洪
- 只向有成员的端口转发
- 默认 Cisco 启用

### 8. LLDP (链路层发现协议)

- 自动发现邻居
- 显示设备信息
- 802.1AB 标准

## 八、交换机堆叠 (Stacking)

### 1. 概念

**堆叠**:把多台物理交换机**虚拟成一台**逻辑交换机

- 统一管理
- 端口总和
- 冗余

### 2. 堆叠方式

- **专用堆叠线 / 模块**: 如 Cisco StackWise
- **普通网线 + 协议**: 如 Huawei iStack、H3C IRF
- **虚拟化**: Cisco vSwitch、VMware vDS

### 3. 堆叠优势

- 简化管理
- 跨设备端口聚合
- 减少 STP

### 1. 管理方式

### 2. 常用配置

```text
# Cisco IOS
enable
configure terminal
hostname SW1
!
ip domain-name example.com
!
username admin privilege 15 secret strongpassword
!
interface vlan 1
  ip address 192.168.1.1 255.255.255.0
!
ip default-gateway 192.168.1.254
!
line vty 0 15
  login local
  transport input ssh
!
end

```

### 3. 监控命令

```text
# 看 MAC 表
show mac address-table

# 看 ARP 表
show arp

# 看 CDP / LLDP 邻居
show cdp neighbors
show lldp neighbors

# 看接口状态
show interfaces status
show ip interface brief

# 看 STP
show spanning-tree
show spanning-tree vlan 10

# 看 MAC 地址漂移 (环路)
show mac address-table move

# 看 CPU / 内存

show processes memory
```

### 4. 备份与恢复

```text
# Cisco
copy running-config startup-config
write memory

# 备份到 TFTP
copy running-config tftp://192.168.1.100/sw1-confg

# 恢复
copy tftp://192.168.1.100/sw1-confg running-config
```

## 十一、交换机 vs 路由器

| 维度 | 交换机 | 路由器 |
| ---- | ------ | ------ |
| 工作层 | 数据链路 | 网络层 |
| 转发依据 | MAC | IP |
| 隔离广播域 | 部分(用 VLAN) | 完整 |
| 速度 | 快 | 较慢 |
| 适合 | 局域网内 | 跨网段 |
| 路由功能 | 无/简单 | 强 |
| 防火墙 | 无 | 通常有 |
| NAT | 无 | 通常有 |
| 协议 | STP/VLAN | OSPF/BGP |

### 何时用交换机 vs 路由器

- **同一网段内部**:用交换机
- **跨网段**:用路由器
- **大型园区**:三层交换机
- **WAN/Internet**:路由器
- **企业出口**:路由器 + 防火墙

## 十二、交换机常见问题与故障排查

### 1. 常见问题

| 问题 | 原因 | 排查 |
| ---- | ---- | ---- |
| 端口不通 | 物理/配置 | show interface, 检查 VLAN |
| 慢 | 环路 / 拥塞 | check STP, 查广播 |
| MAC 表满 | 攻击 / 漂移 | show mac, 查漂移 |
| CPU 高 | 攻击 / 环路 | show proc cpu |
| VLAN 间不通 | Trunk 没放 | show vlan, show trunk |
| 路由不通 | 三层配置错 | show ip route, ping |

### 2. 排查工具

- **show**: Cisco/H3C/Huawei 的标准命令
- **Wireshark**: 抓包
- **ping / traceroute**: 连通性
- **NMS**: Zabbix, Prometheus
- **Console**: 救命稻草

### 3. 经典故障:环路

**症状**:

- 网络极慢
- 交换机 CPU 100%
- MAC 表不断变化

**解决**:

- 启用 STP
- 检查冗余链路
- 关闭未用端口
- 启用 Loop Guard
