# 计算机网络的层次结构

## 一、网络分层概述

### 为什么需要分层

- **复杂问题分解**:每层只关注自己的功能
- **各层独立**:一层变化不影响其他层
- **标准化接口**:不同厂商设备可互操作
- **易于学习**:可逐层深入

### 两大主流模型

| 模型 | 层数 | 特点 |
| ---- | ---- | ---- |
| **OSI 七层模型** | 7 层 | 理论参考,概念清晰 |
| **TCP/IP 四层模型** | 4 层 | 实际使用,工业标准 |

---

## 二、OSI 七层模型

OSI (Open Systems Interconnection) 是 ISO 制定的**理论参考模型**。

```text
┌────────────────────┐
│ 7. 应用层 (Application) │  HTTP, FTP, DNS, SMTP, SSH, SNMP
├────────────────────┤
│ 6. 表示层 (Presentation) │  SSL/TLS, MIME, ASCII, JPEG
├────────────────────┤
│ 5. 会话层 (Session)     │  NetBIOS, RPC, SQL session
├────────────────────┤
│ 4. 传输层 (Transport)   │  TCP, UDP, SCTP
├────────────────────┤
│ 3. 网络层 (Network)     │  IP, ICMP, OSPF, BGP, ARP
├────────────────────┤
│ 2. 数据链路层 (Data Link) │  Ethernet, PPP, WiFi (802.11)
├────────────────────┤
│ 1. 物理层 (Physical)    │  电/光/无线信号, 集线器, 中继器
└────────────────────┘
```

### 各层职责

#### 7. 应用层 (Application)

- **作用**:用户与网络的接口
- **协议**:HTTP/HTTPS、FTP、SFTP、SMTP/POP3/IMAP、DNS、SSH、Telnet、SNMP、LDAP、DHCP、NTP、TFTP
- **数据单元**:消息 (Message)

#### 6. 表示层 (Presentation)

- **作用**:数据表示、安全(加密)、压缩
- **协议/标准**:SSL/TLS、MIME、XDR、JPEG、MPEG、ASCII、Unicode (UTF-8)
- **数据单元**:数据 (Data)

#### 5. 会话层 (Session)

- **作用**:建立、管理、终止**会话**
- **协议/标准**:NetBIOS、RPC、SIP、PPTP、SQL*Net
- **数据单元**:数据 (Data)

#### 4. 传输层 (Transport)

- **作用**:**端到端**的可靠传输、流量控制、错误恢复
- **协议**:TCP、UDP、SCTP、DCCP
- **端口号**:0-65535,标识应用
- **数据单元**:段 (Segment)

#### 3. 网络层 (Network)

- **作用**:**路由**、**逻辑寻址** (IP)
- **协议**:IP (IPv4/IPv6)、ICMP、IGMP、ARP、RARP、OSPF、BGP、RIP、IS-IS
- **数据单元**:包 (Packet)
- **设备**:路由器 (Router)、三层交换机

#### 2. 数据链路层 (Data Link)

- **作用**:**物理寻址** (MAC)、**错误检测**、**流量控制**
- **协议/标准**:Ethernet (802.3)、WiFi (802.11)、PPP、HDLC、Frame Relay、MPLS、ARP(部分)
- **子层**:
  - **LLC** (Logical Link Control, 802.2)
  - **MAC** (Media Access Control, 802.3)
- **数据单元**:帧 (Frame)
- **设备**:交换机 (Switch)、网桥 (Bridge)、网卡 (NIC)

#### 1. 物理层 (Physical)

- **作用**:**比特流**传输,定义电/光/无线规格
- **标准**:Ethernet (10/100/1000/10G/100G)、USB、HDMI、RS-232、光纤、WiFi 物理层
- **设备**:网卡、集线器 (Hub)、中继器 (Repeater)、光纤、电缆

### OSI 数据封装

```text
应用层: [HTTP 请求]
         ↓ 加 TCP 头
传输层: [TCP][HTTP 请求]            ← 段
         ↓ 加 IP 头
网络层: [IP][TCP][HTTP 请求]        ← 包
         ↓ 加 Ethernet 头/尾
链路层: [Eth][IP][TCP][HTTP][FCS]  ← 帧
         ↓
物理层: ...1010101...               ← 比特
```

## 三、TCP/IP 四层模型

TCP/IP 模型是**实际工程标准**,源自 ARPANET。

```text
┌────────────────────┐
│ 4. 应用层              │  HTTP, DNS, FTP, SMTP, SSH, TLS
│ (Application)         │
├────────────────────┤
│ 3. 传输层              │  TCP, UDP, SCTP
│ (Transport)            │
├────────────────────┤
│ 2. 网络层              │  IP, ICMP, IGMP, ARP
│ (Internet)             │
├────────────────────┤
│ 1. 网络接口层          │  Ethernet, WiFi, PPP, 物理层
│ (Network Access / Link) │
└────────────────────┘
```

### 各层职责

#### 4. 应用层

等同于 OSI 的 **应用 + 表示 + 会话** 三层。

- **职责**:用户程序、协议交互、数据表示
- **协议**:
  - **Web**: HTTP/HTTPS/3、QUIC
  - **文件**: FTP、SFTP、TFTP、SMB
  - **邮件**: SMTP、POP3、IMAP
  - **域名**: DNS、mDNS
  - **远程**: SSH、Telnet、RDP、VNC
  - **配置**: DHCP、NTP
  - **Web 框架**: gRPC、GraphQL、REST
  - **安全**: TLS/SSL、Kerberos、LDAP
- **数据单元**:消息 / 数据流

#### 3. 传输层

等同于 OSI **传输层**。

- **职责**:端到端连接、可靠传输、流量控制、拥塞控制
- **协议**:
  - **TCP** (Transmission Control Protocol):面向连接,可靠,字节流
  - **UDP** (User Datagram Protocol):无连接,不可靠,数据报
  - **SCTP** (Stream Control Transmission Protocol):多流
  - **DCCP** (Datagram Congestion Control Protocol)
  - **QUIC** (基于 UDP,HTTP/3 底层)
- **端口**:
  - 0-1023:特权端口 (well-known)
  - 1024-49151:注册端口
  - 49152-65535:动态/临时端口
- **数据单元**:**段 (Segment)** (TCP) / **数据报 (Datagram)** (UDP)

#### 2. 网络层 (Internet)

等同于 OSI **网络层**。

- **职责**:**主机间路由**、逻辑寻址 (IP)
- **协议**:
  - **IP**: IPv4、IPv6
  - **ICMP / ICMPv6**:控制消息 (ping, traceroute)
  - **IGMP**:组播管理
  - **ARP / NDP**:IP↔MAC 解析
  - **路由**: OSPF、RIP、IS-IS (内部),BGP (外部)
  - **隧道**: GRE、IPIP
- **数据单元**:**包 (Packet) / 数据报 (Datagram)**

#### 1. 网络接口层

等同于 OSI **数据链路 + 物理层**。

- **职责**:相邻节点帧传输、MAC 寻址、介质接入
- **协议/标准**:
  - **Ethernet** (802.3): 主流有线
  - **WiFi** (802.11): 主流无线
  - **PPP / HDLC**: 串口、拨号
  - **LTE / 5G NR**: 移动
  - **光纤**: PON
  - **蓝牙** (802.15.1)
- **数据单元**:**帧 (Frame)** / **比特 (Bit)**

## 四、TCP/IP 协议栈数据封装

```text
应用层: [HTTP 数据]
            ↓ 加 TCP 头
传输层: [TCP 头 | HTTP 数据]            ← 段 (Segment)
            ↓ 加 IP 头
网络层: [IP 头 | TCP 头 | HTTP 数据]    ← 包 (Packet)
            ↓ 加 Ethernet 头尾
链路层: [Eth 头 | IP | TCP | HTTP | FCS]  ← 帧 (Frame)
            ↓
物理层: ...010100110...                ← 比特 (Bit)
```

## 五、OSI vs TCP/IP 对比

| 维度 | OSI 七层 | TCP/IP 四层 |
| ---- | -------- | ----------- |
| 起源 | ISO 理论 | ARPANET 实践 |
| 层数 | 7 | 4 |
| 标准化 | 完整 | 实用主义 |
| 会话/表示层 | 有 | 合并到应用层 |
| 采用 | 教学 | 工程 |
| 模型 | 完整 | 灵活 |

### 对应关系

```text
OSI              TCP/IP
─────            ──────
7. 应用层  ─┐
6. 表示层  ─┼─→ 4. 应用层
5. 会话层  ─┘
4. 传输层  ────→ 3. 传输层
3. 网络层  ────→ 2. 网络层
2. 数据链路 ─┐
1. 物理层  ─┴─→ 1. 网络接口层
```

## 八、TCP/IP 报文格式概览

### Ethernet 帧 (链路层)

```text
┌────────┬────────┬────────┬───────────┬─────┬────┐
│ Dest MAC │ Src MAC │ EtherType │ Payload  │ FCS │   │
│ 6B       │ 6B      │ 2B        │ 46-1500B  │ 4B  │   │
└────────┴────────┴────────┴───────────┴─────┴────┘
                                              ↑
                                         CRC 校验
```

### IP 包 (网络层)

```text
┌──────────────────────────────────┐
│ Version | IHL | DSCP | Total Length │
│ Identification | Flags | Offset     │
│ TTL | Protocol | Header Checksum   │
│ Source Address (32/128 bit)         │
│ Destination Address                │
│ Options (可选)                       │
└──────────────────────────────────┘
```

### TCP 段 (传输层)

```text
┌─────────────────────────────┐
│ Source Port | Dest Port        │
│ Sequence Number               │
│ Acknowledgment Number         │
│ Offset | Flags | Window       │
│ Checksum | Urgent Pointer     │
└─────────────────────────────┘
```

### UDP 数据报 (传输层)

```text
┌────────┬────────┐
│ Src Port │ Dst Port │
│ Length   │ Checksum │
└────────┴────────┘
```

### HTTP 请求 (应用层)

```text
GET /index.html HTTP/1.1
Host: example.com
User-Agent: curl/8.0
Accept: */*

```

## 十、关键概念

| 概念 | 含义 |
| ---- | ---- |
| **封装 (Encapsulation)** | 上层数据加下层头部 |
| **解封装 (Decapsulation)** | 接收方反向剥头部 |
| **多路复用 (Multiplexing)** | 多应用共享一个连接 (端口区分) |
| **多路分解 (Demultiplexing)** | 接收方按端口分发 |
| **对等通信 (Peer-to-Peer)** | 同层协议对等交互 |
| **MTU (Maximum Transmission Unit)** | 帧最大长度,通常 1500B |
| **MSS (Maximum Segment Size)** | TCP 段最大数据,通常 1460B |
| **TTL (Time To Live)** | 跳数限制,防环路 |
| **MTU / MSS 关系** | MSS = MTU - IP 头 - TCP 头 ≈ 1460 |

## 十一、面试常考

### 1. OSI 七层模型与 TCP/IP 四层

> OSI 7 层:应用/表示/会话/传输/网络/数据链路/物理
> TCP/IP 4 层:应用/传输/网络/网络接口

### 2. TCP 三次握手

```text
Client → Server: SYN, seq=x
Server → Client: SYN+ACK, seq=y, ack=x+1
Client → Server: ACK, ack=y+1
```

### 3. TCP 四次挥手

```text
Client → Server: FIN
Server → Client: ACK
Server → Client: FIN
Client → Server: ACK
```

### 4. TCP vs UDP

> TCP 可靠、面向连接、字节流、慢
> UDP 不可靠、无连接、数据报、快

### 5. HTTP vs HTTPS

> HTTP 明文,80
> HTTPS = HTTP + TLS,443,加密

### 6. IP 地址分类

> A 1.0.0.0/8, B 128.0.0.0/16, C 192.0.0.0/24
> D 224-239 多播, E 240-255 保留

### 7. ARP 作用

> IP → MAC 解析,广播询问

### 8. 为什么需要分层

> 复杂分解、独立、标准化、易学习

## 十二、核心要点速记

- **OSI 七层**:应用、表示、会话、传输、网络、数据链路、物理
- **TCP/IP 四层**:应用、传输、网络、网络接口
- **TCP/IP = 实际标准**
- **每层只管自己**
- **每层为上层提供服务**
- **下三层 = 主机到主机**
- **上四层 = 端到端**
- **TCP = 可靠、面向连接**
- **UDP = 不可靠、无连接**
- **IP = 尽力而为**
- **HTTP = Web**
- **DNS = 域名**
- **ARP = IP→MAC**
- **ICMP = 错误报告**
- **TCP 80 = HTTP**
- **TCP 443 = HTTPS**
- **MTU = 1500 字节**
- **数据封装**:每层加头部
- **每层 PDU 不同**:Message/Segment/Packet/Frame/Bit
- **设备**:物理层 Hub,链路层 Switch,网络层 Router
- **三 / 四次握手** = TCP 建立/关闭
- **2MSL** = TIME_WAIT 等待
