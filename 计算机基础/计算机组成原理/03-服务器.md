# 服务器 (Server)

## 一、服务器概述

**服务器**:在网络环境中为客户端(PC、手机、其他服务器)提供**计算、存储、网络、应用**等服务的专用计算机。

### 服务器 vs 普通 PC

| 维度           | 服务器                            | 普通 PC                          |
|----------------|-----------------------------------|----------------------------------|
| 稳定性         | 7×24 不间断运行,MTBF 数万小时     | 偶尔开关,无严格稳定性要求        |
| 性能           | 强调多 CPU、大内存、高 IO         | 强调单核/单卡游戏性能            |
| 扩展性         | 多内存槽、多硬盘位、多 PCIe       | 槽位少,扩展有限                  |
| 冗余           | 电源、风扇、硬盘、网卡冗余        | 一般无冗余                       |
| 散热           | 多冗余风扇,智能调速               | 1-2 个风扇                       |
| 管理           | 带 IPMI/iLO/BMC,远程管理          | 本地管理                         |
| 操作系统       | Linux / Windows Server / Unix     | Windows / macOS / 桌面 Linux     |
| 成本           | 几千到几十万元                    | 几千到几万元                     |
| 设计目标       | 可靠性、可用性、服务能力 (RAS)    | 体验、性能、便携                 |

### 服务器的核心设计目标:RAS

- **R (Reliability) 可靠性**:平均无故障时间长
- **A (Availability) 可用性**:故障能快速恢复
- **S (Serviceability) 可服务性**:易维护、热插拔

## 三、服务器硬件组成

### 1. CPU

- **多路服务器**:支持 2/4/8 个 CPU 共存,共享内存/IO
  - 2 路(2P):中小企业主流
  - 4 路(4P):大型数据库/虚拟化
  - 8 路(8P):高端关键业务
- **NUMA 架构**:多 CPU 下,每 CPU 访问本地内存快,跨 CPU 慢
  - 软件要绑核、绑内存才能发挥性能
- **服务器 CPU 特性**:
  - 更多核心/线程 (几十核,几百线程)
  - 更多 PCIe 通道 (64-128 条)
  - 更多内存通道 (6/8 通道)
  - 支持 ECC 内存
  - RAS 特性 (机器检查架构 MCA、错误纠正等)
- **代表型号**:
  - Intel Xeon Scalable (Sapphire Rapids / Emerald Rapids)
  - AMD EPYC (Genoa / Bergamo)
  - 华为鲲鹏 920
  - 海光 7285

### 2. 内存

- **类型**:DDR4 ECC、DDR5 ECC(主流)
- **形态**:DIMM(台式)、RDIMM(带寄存,服务器主流)、LRDIMM(低负载)
- **特性**:
  - **ECC (Error-Correcting Code)**:自动纠正单位错误,检测多位错误
  - **Memory Mirroring**:镜像,内存一半用于备份
  - **Memory Sparing**:备用内存,故障时自动启用
  - **Memory Lockstep**:成对内存同步,检测错误
- **容量**:单服务器 256GB ~ 几 TB
- **通道**:8 通道内存,插满才能达到最大带宽

### 3. 硬盘 / 存储

- **类型**:
  - **SAS HDD**:企业级机械盘,容量大、可靠性高 (2.4TB~24TB)
  - **SATA SSD**:性价比高
  - **SAS SSD**:企业级 SSD
  - **NVMe SSD**:性能最高 (PCIe 4.0/5.0,可达 14GB/s)
- **形态**:2.5 寸、3.5 寸、M.2、U.2、E1.S、E3.S
- **RAID 控制器**:独立 RAID 卡(LSI、PMC)
- **后端**:
  - **DAS**:直连存储(本地硬盘)
  - **NAS**:网络文件存储
  - **SAN**:块级存储(FC-SAN、IP-SAN)
  - **对象存储**:S3 兼容(MinIO、Ceph RGW)

### 4. 电源

- **冗余电源**:1+1、2+1、2+2,一路坏不影响运行
- **热插拔**:支持不关机更换
- **效率**:80 PLUS 金牌/铂金/钛金(越高越省电)
- **市电双路**:两路市电接入,任何一路停电不中断
- **UPS**:不间断电源,过渡到柴油发电机
- **柴油发电机**:长时间断电时供电

### 5. 散热

- **风扇**:多冗余,N+1 配置,智能调速
- **热插拔**:故障风扇可在线更换
- **液冷**:
  - **冷板式**:CPU/GPU 装冷板,水冷
  - **浸没式**:整服务器泡在绝缘冷却液里
  - **喷淋式**:冷却液直接喷到发热元件
- **风液混合**:低负载风冷,高负载切换液冷

### 6. 主板 / 机箱

- **主板**:
  - 多 CPU 插槽
  - 几十条 DIMM 槽
  - 多 PCIe 槽
  - 板载 BMC/IPMI 管理芯片
  - 板载 10G/25G/100G 网口
- **机箱**:
  - 1U/2U 高度
  - 大量硬盘托架(前置、后方)
  - 冗余电源、风扇模块
  - 滑轨、免工具维护

### 7. 网络

- **板载网卡**:1G/10G/25G
- **PCIe 网卡**:
  - 10G/25G/100G/200G/400G
  - **智能网卡 (SmartNIC)**:DPU 卸载网络/存储 (Mellanox、Broadcom)
- **HBA 卡**:连接 FC SAN
- **InfiniBand**:HPC 集群用,低延迟高带宽

## 四、关键特性深入

### 1. 可靠性指标

| 指标                          | 说明                                              |
|-------------------------------|---------------------------------------------------|
| MTBF                          | 平均故障间隔时间,越长越好                         |
| MTTR                          | 平均修复时间,越短越好                             |
| 可用性 = MTBF / (MTBF + MTTR) | 百分比,4 个 9 = 99.99%,5 个 9 = 99.999%           |
| 4 个 9                        | 一年宕机 ≤ 52 分钟                                |
| 5 个 9                        | 一年宕机 ≤ 5 分钟(银行、电信)                     |
| 6 个 9                        | 一年宕机 ≤ 31 秒(几乎不可能,需双活多活)           |

### 2. 远程管理 (BMC/IPMI)

- **BMC (Baseboard Management Controller)**:独立的小处理器,有自己的网口、IP、固件
- **IPMI (Intelligent Platform Management Interface)**:BMC 通信协议标准
- **常见品牌实现**:
  - Dell: iDRAC
  - HPE: iLO
  - Lenovo: XClarity Controller (XCC)
  - Huawei: iBMC
  - 浪潮: ISM
- **功能**:
  - 远程开关机、重启
  - 远程控制台 (KVM over IP,虚拟光驱)
  - 监控温度、电压、风扇、电源
  - 告警 (邮件、SNMP、短信)
  - 远程安装系统
- **Redfish**:新一代 RESTful API,逐步替代 IPMI

### 3. 虚拟化

- **裸金属虚拟化** (Type 1):直接装在硬件上
  - VMware ESXi、Citrix XenServer、Microsoft Hyper-V、KVM(可视为)
- **寄居虚拟化** (Type 2):装在 OS 上
  - VirtualBox、VMware Workstation
- **关键概念**:
  - **VM (虚拟机)**:完整 OS + 应用的虚拟实例
  - **Hypervisor**:虚拟化管理层
  - **vCPU、vRAM、vDisk**:虚拟资源
  - **过载使用 (Overcommit)**:虚拟资源 > 物理资源
  - **实时迁移 (vMotion)**:VM 不停机从一台物理机迁到另一台
  - **容器** (Docker):更轻量,共享 OS 内核
  - **K8s**:容器编排

### 4. 高可用 (HA) 与集群

- **主备模式 (Active-Standby)**:平时备机不服务,故障时切换
- **双主模式 (Active-Active)**:两台同时服务,互为备份
- **负载均衡**:多台服务器分担请求
  - L4 负载均衡 (基于 IP/端口,性能高)
  - L7 负载均衡 (基于 HTTP 内容,功能强)
- **集群**:
  - **HPC 集群**:高性能计算,GPU 集群
  - **数据库集群**:主从、主主、PXC、MGR
  - **分布式集群**:Hadoop、Kafka、ES
- **脑裂 (Split-Brain)**:集群失去通信后,双方都以为自己是主
  - 解决:心跳线、Quorum、STONITH
- **Fencing**:故障节点隔离(STONITH:爆头,强制断电)

### 5. 监控与运维

- **监控指标**:
  - CPU 使用率、负载(load average)
  - 内存使用率、Swap
  - 磁盘 IO、容量、延迟
  - 网络流量、丢包、错误
  - 应用进程、端口、连接数
- **告警**:阈值告警、异常告警、AI 告警
- **工具**:
  - **Prometheus + Grafana**:指标监控主流
  - **Zabbix**:传统企业级监控
  - **ELK / Loki**:日志
  - **Jaeger / SkyWalking**:链路追踪
  - **Ansible / SaltStack / Puppet**:自动化运维

## 六、服务器性能指标

### 1. CPU 性能

- 主频、核心数、IPC
- SPEC CPU 2017(行业基准)
- 实际业务:QPS、TPS、响应时间

### 2. 内存性能

- 容量、带宽、延迟
- STREAM(带宽基准)

### 3. 存储性能

- **IOPS**:每秒读写次数 (随机 4K)
- **吞吐量 (Throughput)**:MB/s (顺序读写)
- **延迟 (Latency)**:μs
- **FIO**:常用测试工具

### 4. 网络性能

- **带宽**:Gbps
- **PPS**:每秒包数
- **延迟**:μs
- **抖动**:ms

## 八、服务器选型要点

### 1. 业务需求分析

- **CPU 密集型**:编译、计算、AI 训练 → 高主频 / 多核
- **内存密集型**:数据库、缓存 → 大内存、内存带宽
- **IO 密集型**:数据库、视频、备份 → NVMe SSD、RAID 卡
- **网络密集型**:网关、负载均衡 → 高带宽网卡

### 2. 选型清单

- CPU:型号、核心数、主频
- 内存:容量、类型、通道数
- 硬盘:数量、容量、类型、RAID 级别
- 电源:冗余方式、功率
- 网络:网卡数量、速率
- 扩展:PCIe 槽位、硬盘位
- 管理:BMC/iLO/iDRAC
- 售后:保修年限、响应时间

### 3. 部署方式

- **单机**:小业务
- **主备**:核心业务
- **集群**:高可用 / 高性能
- **分布式**:大数据、互联网架构
- **云**:弹性伸缩

## 九、关键概念速记

- **RAS**:Reliability、Availability、Serviceability
- **BMC/IPMI/iDRAC/iLO**:服务器远程管理
- **ECC 内存**:服务器必备,自动纠错
- **冗余电源**:1+1 或 2+1,N+1 配置
- **NUMA**:多 CPU 内存访问本地 vs 远程
- **RAID**:数据冗余与性能(详见 RAID 笔记)
- **可用性**:4 个 9 (99.99%) 是企业级入门
- **热插拔**:电源/风扇/硬盘/PCIe 都应支持
- **虚拟化**:VMware ESXi、KVM、Hyper-V
- **容器**:Docker、K8s
- **智能网卡 (DPU)**:卸载网络/存储,降低 CPU 负担
- **液冷**:高密度数据中心标配
