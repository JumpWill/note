# Linux 安全 (Linux Security)

## 一、安全概述

### 安全的重要性

- **数据保护**:防止数据泄露、损坏
- **业务连续性**:防止服务中断
- **合规要求**:GDPR、个保法、PCI-DSS、HIPAA
- **声誉保护**:安全事件影响品牌
- **法律责任**:可能面临诉讼

### 安全的基本原则

- **最小特权 (Least Privilege)**:只给必要的权限
- **纵深防御 (Defense in Depth)**:多层防护
- **零信任 (Zero Trust)**:从不信任,始终验证
- **失效安全 (Fail Safe)**:失败时进入安全状态
- **默认拒绝 (Default Deny)**:默认拒绝所有
- **纵深防御**:多层防御

### 攻击类型

- **被动攻击**:嗅探、扫描
- **主动攻击**:DoS/DDoS、注入
- **本地攻击**:提权、密码破解
- **社会工程学**:钓鱼、伪装
- **供应链**:软件后门
- **零日漏洞**:未知漏洞
- **APT**:高级持续威胁

### 攻击面

- **网络层**:端口、服务、协议
- **应用层**:Web 漏洞、API
- **系统层**:内核、驱动
- **物理层**:机房、U 盘
- **人**:员工、内部威胁

## 二、认证与授权

### 1. PAM (Pluggable Authentication Modules)

**PAM**:Linux 认证框架

**配置位置**:
- `/etc/pam.d/` 各种服务的 PAM 配置
- `/etc/pam.d/login`、`sshd`、`sudo` 等

**配置结构**:
```
类型  控制标志  模块  参数
auth  required   pam_unix.so
```

**类型 (Type)**:
- `auth`: 认证 (验证你是谁)
- `account`: 账户 (账号是否过期)
- `password`: 密码 (修改密码)
- `session`: 会话 (登录/登出时操作)

**控制标志 (Control)**:
- `required`: 必须成功,失败继续但最终失败
- `requisite`: 必须成功,失败立即失败
- `sufficient`: 成功则 OK,失败忽略
- `optional`: 仅供参考
- `include`: 包含其他文件
- `substack`: 子栈

**示例 - /etc/pam.d/sshd**:
```
auth       required   pam_env.so
auth       sufficient   pam_unix.so
auth       required   pam_deny.so
account    required   pam_unix.so
password   required   pam_cracklib.so
session    required   pam_limits.so
```

**常用 PAM 模块**:
- `pam_unix.so`:传统 Unix 认证
- `pam_cracklib.so`:密码强度检查
- `pam_pwquality.so`:密码质量
- `pam_limits.so`:资源限制
- `pam_tally2.so` / `pam_faillock.so`:登录失败锁定
- `pam_google_authenticator.so`:2FA
- `pam_yubico.so`:Yubikey
- `pam_ssh_agent_auth.so`:SSH agent

### 2. /etc/shadow

```bash
# 字段:用户名:密码哈希:最后修改天数:最小间隔:最大间隔:警告:不活动:过期:保留
# 例: user:$6$salt$hash:19000:0:99999:7:::
# $1$ = MD5, $5$ = SHA-256, $6$ = SHA-512

# 命令
passwd user                    # 改密码
chage -l user                  # 看
chage -d 0 user                 # 强制下次登录改密码
chage -M 90 user                # 90 天过期
chage -W 7 user                 # 提前 7 天警告
chage -I 30 user                # 不活动 30 天后过期
passwd -l user                 # 锁定
passwd -u user                 # 解锁
usermod -L user                # 锁定(改 shadow)
usermod -U user                # 解锁
```

## 三、SSH 安全

### 1. /etc/ssh/sshd_config 关键配置

```bash
# 端口
Port 22                       # 可改非标准

# 协议
Protocol 2                    # 禁用 1

# 禁用 root
PermitRootLogin no            # 禁止 root 登录
# 或:PermitRootLogin prohibit-password  # 仅密钥

# 密码登录
PasswordAuthentication no    # 禁用密码,仅密钥
PermitEmptyPasswords no

# 密钥登录
PubkeyAuthentication yes
AuthorizedKeysFile .ssh/authorized_keys

# 认证尝试
MaxAuthTries 3
MaxSessions 5
LoginGraceTime 30

# 限制用户
AllowUsers alice bob
AllowGroups sshusers

# 超时
ClientAliveInterval 300
ClientAliveCountMax 0
TCPKeepAlive no

# 日志
LogLevel VERBOSE

# 安全
X11Forwarding no
PermitTunnel no
AllowTcpForwarding local      # 仅本地
AllowAgentForwarding no
AllowStreamLocalForwarding no

# 禁用弱加密
Ciphers -chacha20-poly1305@openssh.com,aes256-gcm@openssh.com,aes128-gcm@openssh.com,aes256-ctr,aes192-ctr,aes128-ctr
MACs -hmac-sha2-512-etm@openssh.com,hmac-sha2-256-etm@openssh.com,umac-128-etm@openssh.com
KexAlgorithms curve25519-sha256,curve25519-sha256@libssh.org,diffie-hellman-group16-sha512,diffie-hellman-group18-sha512

# 协议版本
Subsystem sftp internal-sftp
```

### 2. 重启 SSH

```bash
# 测试配置

# 重启
systemctl restart sshd
```

### 3. SSH 安全技巧

```bash
# 跳板机
ssh -J jumphost user@target

# 代理
ssh -D 1080 user@host          # SOCKS 代理
ssh -L 8080:localhost:80 user@host  # 本地转发

# 代理命令

# 配置文件 ~/.ssh/config

    HostName 1.2.3.4
    User alice
    Port 2222
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60

# 跳板

    ProxyCommand ssh -W %h:%p jumphost
```

### 4. SSH 端口敲门

```bash

# /etc/knockd.conf

sequence = 7000,8000,9000
seq_timeout = 5
command = /sbin/iptables -A INPUT -s %IP% -p tcp --dport 22 -j ACCEPT

[closeSSH]

seq_timeout = 5
command = /sbin/iptables -D INPUT -s %IP% -p tcp --dport 22 -j ACCEPT
```

### 3. 文件权限

```bash
# 基础
chmod 755 file
chmod u+x file
chmod -R 644 dir/

# ACL
getfacl file
setfacl -m u:user:rw file
setfacl -m g:group:r file
setfacl -x u:user file
setfacl -b file                 # 全部移除
setfacl -d -m u:user:rx dir/    # 默认 ACL(目录)

# SUID/SGID/Sticky
chmod u+s file                  # SUID
chmod g+s dir                   # SGID (目录继承组)
chmod +t dir                    # Sticky (仅属主可删)
chmod 4755 file                 # SUID + 755
```

### 4. 特殊权限 (隐藏的危险)

- **SUID root 文件** = 任何用户可 root 权限执行
- **SGID** = 临时提升组权限
- **找出 SUID**:
```bash
find / -perm -u+s -type f 2>/dev/null
find / -perm -g+s -type f 2>/dev/null
```

### 5. 默认权限 (umask)

```bash

umask 022                      # 文件 644, 目录 755

# 持久化
echo "umask 027" >> /etc/profile
```

### 1. nftables 安全模板

```bash
# 默认拒绝,白名单
nft add table inet filter
nft add chain inet filter input { type filter hook input priority 0 ; policy drop ; }

# 允许本地回环
nft add rule inet filter input iif lo accept

# 允许已建立/相关
nft add rule inet filter input ct state established,related accept

# 允许 SSH (限速防爆破)
nft add rule inet filter input tcp dport 22 ct state new limit rate 4/minute accept

# 允许 HTTP/HTTPS
nft add rule inet filter input tcp dport { 80, 443 } accept

# 允许 ICMP (ping)
nft add rule inet filter input icmp type echo-request accept

# 记录丢弃
nft add rule inet filter input log prefix "nft-drop: " level warn
```

## 六、SELinux 与 AppArmor

### 1. SELinux (Security-Enhanced Linux)

**SELinux**:Linux 内核的强制访问控制 (MAC) 机制

- 由 NSA 开发
- 标签化 (Label)
- 策略 (Policy)
- 强制 (Enforcing) / 许可 (Permissive) / 禁用 (Disabled)

**状态**:

```bash
getenforce                    # 当前模式
sestatus                      # 详细
setenforce 0                  # 临时切 Permissive
setenforce 1                  # 切回 Enforcing
```

**配置** (/etc/selinux/config):
```
SELINUX=enforcing
SELINUXTYPE=targeted
```

**文件上下文**:

```bash
# 看
ls -Z file
ps auxZ
id -Z

# 改
chcon -t httpd_sys_content_t file
restorecon -R dir/              # 恢复默认
semanage fcontext -a -t httpd_sys_content_t '/mydir(/.*)?'
```

**布尔值**:

```bash
getsebool -a | grep httpd
setsebool -P httpd_can_network_connect on
```

**SELinux 故障排查**:

```bash
# 安装
yum install setroubleshoot
# 看拒绝日志
sealert -a /var/log/audit/audit.log
ausearch -m avc,user_avc -ts recent
audit2allow -M mymodule < /var/log/audit/audit.log
semodule -i mymodule.pp
```

### 2. AppArmor (Ubuntu/Debian 默认)

**AppArmor**:Ubuntu 的 MAC 机制,比 SELinux 简单

```bash
# 状态
aa-status

# 模式
/etc/apparmor.d/                # 配置文件
enforce                         # 强制
complain                        # 警告
disable                         # 禁用

# 工具
apt install apparmor-utils
aa-genprof program
aa-complain program
aa-enforce program
```

**示例** (/etc/apparmor.d/usr.bin.nginx):
```
#include <tunables/global>

/usr/sbin/nginx {
  #include <abstractions/base>
  #include <abstractions/nginx>

  capability dac_override,
  capability setuid,
  capability setgid,

  /etc/nginx/** r,
  /var/log/nginx/** w,
  /var/www/** r,
  /run/nginx.pid w,

  deny /etc/shadow r,
}
```

## 七、内核安全加固

### 1. 内核参数

```bash
# /etc/sysctl.conf

# IP 转发 (路由器开,其他关)
net.ipv4.ip_forward = 0
net.ipv6.conf.all.forwarding = 0

# SYN 攻击防护
net.ipv4.tcp_syncookies = 1
net.ipv4.tcp_max_syn_backlog = 4096

# ICMP 重定向(防中间人)
net.ipv4.conf.all.send_redirects = 0
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.all.secure_redirects = 0
net.ipv6.conf.all.accept_redirects = 0

# 源路由(防 IP 欺骗)
net.ipv4.conf.all.accept_source_route = 0
net.ipv6.conf.all.accept_source_route = 0

# 反 IP 欺骗
net.ipv4.conf.all.rp_filter = 1
net.ipv4.conf.default.rp_filter = 1

# ICMP 忽略广播
net.ipv4.icmp_echo_ignore_broadcasts = 1

# 启用 BPF JIT
net.core.bpf_jit_enable = 1

# kptr 限制(防内核地址泄露)
kernel.kptr_restrict = 2

# dmesg 限制
kernel.dmesg_restrict = 1

# usermodehelper
kernel.usermodehelper.bset = 0

# modules 自动加载限制
# 阻止未授权模块
# /etc/modprobe.d/blacklist.conf 加黑名单
```

### 2. 内核模块安全

```bash
# 加载模块
modprobe module_name

# 黑名单
echo "blacklist module" >> /etc/modprobe.d/blacklist.conf

# 禁用自动加载
echo "install module /bin/false" >> /etc/modprobe.d/disable.conf

# 列出已加载
lsmod
```

### 3. Secure Boot

```bash
mokutil --sb-state            # 看状态
mokutil --list-enrolled        # 列出已注册
```

### 4. 内核 lockdown (LSM)

```bash
# 5 = confidentiality
# 4 = integrity
# 1 = confidentiality + integrity
echo 5 > /sys/kernel/security/lockdown
# 持久化
# /etc/sysctl.d/10-lockdown.conf
kernel.lockdown_mode = 5
```

## 十九、Linux 加固清单 (CIS)

### 1. 初始加固

```bash
# 系统更新
yum update -y

# 启用防火墙
systemctl enable --now firewalld
firewall-cmd --add-service=ssh
firewall-cmd --reload

# 启用 SELinux
sed -i 's/^SELINUX=.*/SELINUX=enforcing/' /etc/selinux/config
setenforce 1

# 启用 auditd
yum install audit
systemctl enable --now auditd
```

### 2. SSH 加固

```bash
# /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no
MaxAuthTries 3
ClientAliveInterval 300
ClientAliveCountMax 0
X11Forwarding no
AllowTcpForwarding no
```

### 3. 用户与认证

```bash
# 锁定不需要的账号
for user in $(awk -F: '($3 < 1000) {print $1}' /etc/passwd); do
    if [ "$user" != "root" ]; then
        usermod -L $user
        usermod -s /sbin/nologin $user
    fi
done

# 设置密码策略
# /etc/security/pwquality.conf
minlen = 12
dcredit = -1
ucredit = -1
lcredit = -1
ocredit = -1

# 失败锁定
# /etc/pam.d/system-auth
auth required pam_faillock.so preauth deny=5 unlock_time=900
```

### 4. 文件权限

```bash
chmod 600 /etc/shadow
chmod 600 /etc/gshadow
chmod 644 /etc/passwd
chmod 644 /etc/group
chmod 600 /etc/ssh/ssh_host_*_key
chmod 644 /etc/ssh/ssh_host_*_key.pub
```

### 5. 内核参数

```bash
# /etc/sysctl.d/99-security.conf
net.ipv4.ip_forward = 0
net.ipv4.conf.all.send_redirects = 0
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.conf.all.rp_filter = 1
net.ipv4.tcp_syncookies = 1
kernel.kptr_restrict = 2
kernel.dmesg_restrict = 1
```

### 6. 日志和审计

```bash
# auditd 规则
-w /etc/passwd -p wa -k identity
-w /etc/shadow -p wa -k identity
-w /etc/sudoers -p wa -k identity
-w /var/log/audit/ -p wa -k audit
```

### 7. 服务最小化

```bash
# 禁用不需要的服务
for service in telnet rsh rlogin rexec ypbind; do
    systemctl disable $service
    systemctl stop $service
done
```

## 二十一、核心要点速记

- **最小特权** = 给必要的权限
- **纵深防御** = 多层防护
- **默认拒绝** = 防火墙默认 DROP
- **SSH**:禁 root、禁密码、用密钥、改端口
- **防火墙** = 必备,iptables/nftables/firewalld/ufw
- **SELinux** = 强制,关键服务器必开
- **PAM** = 认证框架,改密码策略
- **fail2ban** = 自动封禁暴力破解
- **AIDE** = 文件完整性监控
- **ClamAV** = 杀病毒
- **rkhunter/chkrootkit** = Rootkit 检测
- **审计**:auditd + ausearch + aureport
- **日志** = journalctl + ELK
- **密码**:12+ 字符、定期改、用密码管理器
- **MFA** = 多因素,必开
- **SSH 密钥** = ed25519, 4-8 KB 安全
- **更新** = 及时装安全更新
- **零信任** = 永不信任,持续验证
- **等保 2.0** = 中国合规必过
- **CIS Benchmarks** = 加固基线
- **/etc/shadow 600**,**/etc/passwd 644**
- **find -perm -u+s** = 找 SUID
- **kptr_restrict = 2** = 防内核地址泄露
- **rp_filter = 1** = 反 IP 欺骗
- **accept_source_route = 0** = 禁源路由
- **sshd_config:PermitRootLogin no**
- **PermitEmptyPasswords no**
- **PasswordAuthentication no**
- **MaxAuthTries 3**
- **ClientAliveInterval 300**
- **firewalld/nftables** 必备
- **Lynis audit system** = 系统自检
- **tcpdump -i any -w file.pcap** = 抓包
