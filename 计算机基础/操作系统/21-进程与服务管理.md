# 进程与服务管理 (Process & Service Management)

## 一、进程管理基础

### 进程与程序

- **程序**:静态的、磁盘上的可执行文件
- **进程**:动态的、内存中运行的程序实例
- 详见 [09-进程管理.md](09-进程管理.md)

### 进程的属性

```bash
# 进程 ID
ps -p 1234

# 父进程
ps -o ppid= -p 1234

# 用户
ps -o user= -p 1234

# 启动时间
ps -o lstart= -p 1234

# CPU 时间
ps -o time= -p 1234

# 状态
ps -o stat= -p 1234
```

## 二、ps 命令详解

### 1. 常用选项

```bash
# BSD 风格
ps aux
ps auxf                      # 树形
ps auxww                     # 完整命令行

# System V 风格
ps -ef
ps -eF                       # 多列

# 看所有进程
ps -e
ps -A

# 过滤器
ps -u user                    # 用户
ps -C nginx                   # 命令名
ps -p 1234                    # PID
ps -t pts/0                   # 终端
ps -P                         # 真实 PID(无 PID 命名空间)

# 自定义列
ps -o pid,user,comm,args
ps -eo pid,ppid,user,%cpu,%mem,stat,start,time,comm
```

### 2. 常用列

| 列      | 含义                              |
|---------|-----------------------------------|
| PID     | 进程 ID                           |
| PPID    | 父进程 ID                         |
| USER    | 用户                              |
| UID     | 用户 ID                           |
| GID     | 组 ID                             |
| %CPU    | CPU 占用率                        |
| %MEM    | 内存占用率                        |
| VSZ     | 虚拟内存 (KB)                     |
| RSS     | 物理内存 (KB)                     |
| TTY     | 终端                              |
| STAT    | 状态                              |
| START   | 启动时间                          |
| TIME    | 累计 CPU 时间                     |
| COMM    | 命令                              |
| ARGS    | 命令行                            |
| PPID    | 父 PID                            |
| NLWP    | 线程数                            |

### 3. 状态详解

| 状态 | 含义                              |
|------|-----------------------------------|
| R    | Running (运行)                    |
| S    | Sleep (可中断睡眠)                |
| D    | Disk sleep (不可中断)             |
| Z    | Zombie (僵尸)                     |
| T    | Stopped (停止)                    |
| t    | Traced (被调试)                   |
| I    | Idle (内核空闲)                   |
| X    | Dead                              |
| K    | Wakekill                          |
| W    | Waking                            |
| P    | Parked                            |

**附加标志**:
- `<` 高优先级
- `N` 低优先级
- `L` 锁内存
- `s` session leader
- `l` 多线程
- `+` 前台进程

### 4. 排序与筛选

```bash
# 排序
ps -eo pid,comm,%cpu --sort=-%cpu | head
ps -eo pid,comm,rss --sort=-rss | head
ps aux --sort=-%cpu | head
ps aux --sort=-rss | head

# 多级排序
ps -eo pid,user,pri,comm --sort=-pri,-pid
```

## 三、top / htop / atop

### 1. top

```bash
top                           # 实时
top -d 1                      # 1 秒刷新
top -p 1234                   # 特定 PID
top -u user                   # 特定用户
top -bn1                      # 批处理模式
top -bn1 > /tmp/top.txt       # 输出
```

**top 内部快捷键**:

| 键     | 作用                       |
|--------|----------------------------|
| P      | 按 CPU 排序                |
| M      | 按内存排序                 |
| T      | 按时间排序                 |
| N      | 按 PID 排序                |
| 1      | 各 CPU 核心分别显示        |
| m      | 切换内存显示               |
| t      | 切换进程/CPU 显示          |
| c      | 切换命令行/命令显示        |
| V      | 树形显示                   |
| H      | 显示线程                   |
| i      | 忽略空闲进程               |
| k      | 杀进程 (输入 PID)          |
| r      | 改优先级 (renice)          |
| q      | 退出                       |

### 2. htop (推荐)

```bash
htop
```

**优势**:
- 颜色
- 鼠标支持
- 滚动
- 进程树 (F5)
- 排序/筛选简单

### 3. atop

```bash
atop
atop -a                      # 活跃进程
atop -c                      # 命令行
atop -m                      # 内存
atop -d                      | 磁盘
atop -n                      | 网络
atop -1                      # 每秒
```

**atop 优势**:
- 历史数据回放
- 详细 IO/网络统计
- 进程资源使用

### 4. 工具对比

| 工具     | 优势                       | 适合           |
|----------|----------------------------|----------------|
| top      | 系统自带,简单              | 通用           |
| htop     | 易用,功能强                | 日常           |
| atop     | 历史,详细                  | 性能分析       |
| bpytop   | 美观,模块化                | 桌面           |
| gloustop | 美观                       | 桌面           |

## 五、进程控制

### 1. 启动

```bash
# 前台
command

# 后台
command &

# 永久后台
nohup command &

# 不挂起
setsid command

# 离开 shell
disown

# 优先级
nice -n -10 command
```

### 2. 暂停与继续

```bash
Ctrl+Z                        # 挂起
kill -STOP PID                # 停止
kill -CONT PID                # 继续

# jobs
jobs                           # 看
fg %1                          # 前台
bg %1                          # 后台
```

### 3. 终止

```bash
kill PID                       # SIGTERM (15)
kill -9 PID                    # SIGKILL
kill -HUP PID                  # 重新加载
kill -INT PID                  # SIGINT
kill -TERM PID                 # SIGTERM

# 按名
killall nginx
killall -9 nginx

# 按模式
pkill nginx
pkill -f "python.*"
pkill -u baduser               # 按用户
pkill -t pts/0                 # 按终端
pkill --signal TERM -f pattern
```

### 4. 优先级

```bash
# 启动时
nice -n -10 command             # -20~19
# 调整
renice -n 5 -p PID
renice -n -5 -u user           # 用户所有
# 实时
chrt -f -p 99 PID              # SCHED_FIFO 优先级 99
chrt -r -p 50 PID              # SCHED_RR
```

### 5. CPU 亲和性

```bash
taskset -c 0 command            # 启动时绑 CPU 0
taskset -p 0x3 1234             # 修改 (掩码 0,1)
taskset -p 0,2,4 1234
```

### 6. 资源限制

```bash
# ulimit
ulimit -a                      # 看所有
ulimit -n 1000000              # fd
ulimit -u 65535                # 进程数
ulimit -s 8192                  # 栈
ulimit -c unlimited            # core dump
ulimit -t 3600                  # CPU 时间 (秒)
ulimit -v 4194304              # 虚拟内存 (KB)

# /etc/security/limits.conf 永久
*   soft   nofile   1000000
*   hard   nofile   1000000
*   soft   nproc    65535
*   hard   nproc    65535

# cgroup (现代)
# /sys/fs/cgroup/system.slice/PID.service
# 限制 CPU/内存/IO
```

## 七、systemd 与服务管理

### 1. systemd 概述

**systemd**:现代 Linux 的**初始化系统和服务管理器**

- 替代了 **SysV init** 和 **Upstart**
- 并行启动(快)
- 按需启动
- 依赖管理
- 统一日志(`journald`)

### 2. systemd 单元 (Unit)

**Unit 类型**:

| 类型     | 扩展名    | 用途                |
|----------|-----------|---------------------|
| Service  | .service  | 系统服务            |
| Target   | .target   | 一组 unit 的集合    |
| Mount    | .mount    | 文件系统挂载        |
| Socket   | .socket   | Socket 监听         |
| Timer    | .timer    | 定时任务            |
| Path     | .path     | 路径监控            |
| Device   | .device   | 设备                |
| Swap     | .swap     | Swap 分区           |
| Scope    | .scope    | 外部进程            |
| Slice    | .slice    | cgroup 切片         |
| Snapshot | .snapshot | 系统快照            |

### 3. 单元文件位置

```bash
# 系统
/etc/systemd/system/         # 用户自定义
/lib/systemd/system/         # 软件包自带 (符号链接到 /usr/lib)

# 用户
~/.config/systemd/user/        # 用户级

# 运行时
/run/systemd/system/         # 运行时生成
```

### 4. systemctl 命令 (核心)

```bash
# 查看
systemctl list-units            # 全部
systemctl list-units --type=service
systemctl list-units --state=running
systemctl list-units --all
systemctl list-unit-files      # 所有 unit 文件
systemctl status nginx          # 详细状态
systemctl is-active nginx       # 是否在跑
systemctl is-enabled nginx      # 是否开机启动
systemctl is-failed nginx       # 是否失败
systemctl list-dependencies nginx  # 依赖

# 启动/停止
systemctl start nginx
systemctl stop nginx
systemctl restart nginx
systemctl reload nginx          # 重新加载配置(不重启进程)
systemctl reload-or-restart nginx

# 启用/禁用
systemctl enable nginx          # 开机启动
systemctl disable nginx         # 禁止开机启动
systemctl enable --now nginx    # 启用 + 立即启动
systemctl mask nginx            # 屏蔽(链接到 /dev/null)
systemctl unmask nginx          # 解除屏蔽

# 查看失败
systemctl --failed
systemctl reset-failed nginx   # 重置失败状态

# 重新加载
systemctl daemon-reload        # 改 unit 文件后必执行
```

### 5. journalctl (日志)

```bash
# 全部
journalctl

# 特定服务
journalctl -u nginx
journalctl -u nginx -f         # 跟踪

# 时间
journalctl --since "1 hour ago"
journalctl --since today
journalctl --since "2024-01-01" --until "2024-01-02"
journalctl --since -7d

# 优先级
journalctl -p err
journalctl -p warning
journalctl -p emerg
# 级别: emerg / alert / crit / err / warning / notice / info / debug

# 启动相关
journalctl -b                 # 本次启动
journalctl -b -1              # 上次启动
journalctl -b -2              # 上上次启动
journalctl -k                 # 内核日志
journalctl -u nginx -b        # 特定服务,本次启动

# 进程/用户
journalctl _PID=1234          # 特定 PID
journalctl _UID=1000           # 特定用户

# 输出格式
journalctl -o short            # 默认
journalctl -o json-pretty      # JSON
journalctl -o cat              # 简洁

# 大小限制
journalctl -n 100              # 100 行

# 清理
journalctl --disk-usage
journalctl --vacuum-time=2d   # 保留 2 天
journalctl --vacuum-size=500M # 保留 500M

# 导出
journalctl -u nginx --since today > /tmp/nginx.log
```

### 6. 单元文件结构

**Service unit 示例** (myapp.service):

```ini
[Unit]
Description=My Application
Documentation=https://example.com
After=network.target
Wants=redis.service

[Service]
Type=simple
User=appuser
Group=appgroup
WorkingDirectory=/opt/myapp
ExecStart=/usr/bin/python3 /opt/myapp/server.py
ExecReload=/bin/kill -HUP $MAINPID
Restart=on-failure
RestartSec=5

# 资源限制
LimitNOFILE=100000
LimitNPROC=65535
CPUQuota=200%              # 最多 2 核
MemoryMax=2G
MemoryHigh=1G

# 环境
Environment=NODE_ENV=production
EnvironmentFile=/etc/myapp.env

# 安全
NoNewPrivileges=yes
PrivateTmp=yes
ProtectSystem=strict
ProtectHome=yes
ReadOnlyPaths=/

[Install]
WantedBy=multi-user.target
```

**Type 详解**:

| Type            | 含义                            |
|-----------------|---------------------------------|
| simple          | 默认,ExecStart 是前台进程       |
| exec            | 同 simple,会 fork               |
| forking         | 后台 fork (传统 daemon)         |
| oneshot         | 一次性,执行后退出               |
| dbus            | 通过 D-Bus 启动                 |
| notify          | 启动后通过 sd_notify 通知       |
| idle            | 等其他任务结束再启动            |

**Restart**:

| 值             | 含义                            |
|----------------|---------------------------------|
| no             | 不自动重启                      |
| on-success     | 正常退出时重启                  |
| on-failure     | 异常退出时重启                  |
| on-abnormal    | 信号/SIGKILL 退出时重启         |
| on-abort       | 超时退出时重启                  |
| on-watchdog    | 监控超时                        |
| always         | 总是重启                        |

### 7. Target (目标)

**Target 是一组 Unit** 的集合。

```bash
# 看 target
systemctl list-units --type=target
systemctl get-default          # 当前默认
systemctl set-default multi-user.target   # 设置默认
systemctl isolate multi-user.target        # 切换

# 常见 target
# poweroff.target    - 关机
# rescue.target      - 救援
# multi-user.target  - 多用户(命令行)
# graphical.target   - 图形界面
# reboot.target      - 重启
```

**Target 关系**:

```text
graphical.target
└── multi-user.target
    └── basic.target
        └── sysinit.target
```

## 十、cron 定时任务

### 1. crontab 命令

```bash
crontab -e                     # 编辑
crontab -l                     # 列出
crontab -r                     # 清空 (慎用)
crontab -i                     # 交互式删除

# 用户级
crontab -u user -e

# 备份
crontab -l > /tmp/cron.bak
crontab /tmp/cron.bak          # 恢复
```

### 2. crontab 格式

```text
分 时 日 月 周 命令
0  0  0  0  0
```

| 字段 | 范围           |
|------|----------------|
| 分   | 0-59           |
| 时   | 0-23           |
| 日   | 1-31           |
| 月   | 1-12           |
| 周   | 0-7 (0/7=周日) |

**特殊字符**:
- `*`:任意
- `,`:列表 (1,3,5)
- `-`:范围 (1-5)
- `/`:步长 (*/5)
- `@`:特殊 (见下)

**特殊**:
- `@reboot`:启动时
- `@hourly`:每时
- `@daily`:每天
- `@weekly`:每周
- `@monthly`:每月
- `@yearly`:每年

**示例**:

```bash
# 每分钟
* * * * * command

# 每 5 分钟
*/5 * * * * command

# 每天凌晨 2 点
0 2 * * * /scripts/backup.sh

# 工作日 9 点
0 9 * * 1-5 command

# 周末
0 0 * * 0,6 command

# 每月 1 号
0 0 1 * * command

# 启动时
@reboot command
```

### 3. crontab 环境

**注意**:cron 任务的**环境变量很少**

```bash
# 在脚本里设置
PATH=/usr/local/bin:/usr/bin:/bin
export PATH

# 或在 crontab 顶部
PATH=/usr/local/bin:/usr/bin:/bin
```

### 4. /etc/crontab 系统级

```bash
cat /etc/crontab
SHELL=/bin/bash
PATH=/sbin:/bin:/usr/sbin:/usr/bin
MAILTO=root

# run-parts
01 * * * * root run-parts /etc/cron.hourly
02 4 * * * root run-parts /etc/cron.daily
```

## 十二、服务管理最佳实践

### 1. 服务设计原则

- **单一职责**:一个服务一个进程
- **优雅启动**:处理启动依赖
- **优雅停止**:处理 SIGTERM,清理资源
- **失败重试**:Restart=on-failure

- **日志到 journal**:StandardOutput=journal
- **安全加固**:PrivateTmp、ProtectSystem

### 2. 启动顺序

```ini

[Service]
Type=notify
ExecStart=/opt/myapp/bin/start
ExecStop=/opt/myapp/bin/stop
Restart=on-failure
RestartSec=5s
TimeoutStartSec=30
TimeoutStopSec=30

# 环境
EnvironmentFile=/etc/myapp.env

# 资源
CPUQuota=200%
MemoryMax=4G

# 安全
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=true

[Install]
WantedBy=multi-user.target
```

## 十四、进程信号详解

### 1. 常用信号

| 信号       | 编号 | 含义                  | 默认动作        |
|------------|------|-----------------------|-----------------|
| SIGHUP     | 1    | 终端挂起/重载配置     | Term            |
| SIGINT     | 2    | Ctrl+C                | Term            |
| SIGQUIT    | 3    | Ctrl+\                | Core            |
| SIGKILL    | 9    | 强制终止              | Term (不可捕获) |
| SIGUSR1    | 10   | 用户自定义            | Term            |
| SIGSEGV    | 11   | 段错误                | Core            |
| SIGUSR2    | 12   | 用户自定义            | Term            |
| SIGPIPE    | 13   | 写关闭的管道          | Term            |
| SIGALRM    | 14   | 定时器                | Term            |
| SIGTERM    | 15   | 优雅终止              | Term            |
| SIGCHLD    | 17   | 子进程退出            | Ign             |
| SIGCONT    | 18   | 继续                  | Cont            |
| SIGSTOP    | 19   | 暂停                  | Stop (不可捕获) |
| SIGTSTP    | 20   | Ctrl+Z                | Stop            |
| SIGIO      | 29   | I/O 就绪              | Term            |
| SIGPWR     | 30   | 电源故障              | Term            |
| SIGWINCH   | 28   | 终端大小变化          | Ign             |

### 2. 发信号

```bash
# 标准
kill -SIGTERM PID
kill -TERM PID                 # 同 -15
kill -15 PID
kill PID                       # 默认 SIGTERM

# 强制
kill -9 PID                    # SIGKILL

# 进程组
kill -- -PGID                  # 负号表示 PGID

# 按名
pkill -TERM nginx
killall -TERM nginx

# 通用
killall5                       # 给所有进程发 SIGTERM
```

### 3. 进程捕获信号

```c
#include <signal.h>

void handler(int sig) {
    printf("Caught %d\n", sig);
    // 优雅退出
    cleanup();
    exit(0);
}

int main() {
    signal(SIGTERM, handler);  // 或用 sigaction
    signal(SIGINT, handler);
    // 主循环
    while (1) {
        // do work
    }
}
```

### 4. 进程与信号的关系

- **不可捕获**:SIGKILL (9), SIGSTOP (19)
- **可阻塞**:除 SIGKILL/SIGSTOP 外都可
- **可自定义**:除了 SIGKILL/SIGSTOP/SIGCHLD 等少数

## 十九、cgroups 资源控制

### 1. 概念

**cgroups (Control Groups)**:Linux 内核的资源管理机制

- 限制资源 (CPU/内存/IO)
- 优先级
- 监控
- 隔离

### 2. cgroup v1 vs v2

- **cgroup v1**:每个资源独立挂载点
- **cgroup v2** (统一层次):所有资源在 /sys/fs/cgroup/

### 3. systemd slice

```bash
# 看
systemd-cgtop

# 创建
systemd-run --slice=myapp.slice \
    -p CPUQuota=100% \
    -p MemoryMax=1G \
    command

# 临时
systemctl set-property myapp.service \
    CPUQuota=200% \
    MemoryMax=2G
```

### 4. cgroup v2 直接操作

```bash
# 创 cgroup
mkdir /sys/fs/cgroup/myapp
echo "+cpu +memory" > /sys/fs/cgroup/myapp/cgroup.subtree_control

# 限制
echo 100000 > /sys/fs/cgroup/myapp/cpu.max
echo 1G > /sys/fs/cgroup/myapp/memory.max

# 加进程
echo 1234 > /sys/fs/cgroup/myapp/cgroup.procs
```

### 5. Docker / K8s 用 cgroup

- Docker 用 cgroup 限制容器
- K8s 用 cgroup 限制 Pod
