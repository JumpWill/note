# 磁盘分区 (Disk Partition)

## 一、分区概述

### 什么是分区

**分区 (Partition)** 是将一块**物理硬盘**在逻辑上划分为**多个独立的区域**,每个区域可以单独格式化为不同的文件系统,挂载为不同的挂载点。

**本质**:在硬盘上建立**逻辑边界**,告诉操作系统"这块区域是独立的"。

### 为什么需要分区

| 目的                       | 说明                                          |
|----------------------------|-----------------------------------------------|
| **隔离数据**               | 系统、用户、数据、备份分开,互不干扰           |
| **多系统共存**             | 一台机器装多个 OS(Linux + Windows)            |
| **多文件系统**             | 不同分区用不同文件系统 (Ext4、XFS、NTFS)      |
| **安全管理**        / 隔离 | 系统区只读挂载,数据区读写,降低攻击面          |
| **备份与恢复**             | 系统坏了,只重装系统分区,数据还在              |
| **性能优化**               | 不同分区用不同 IO 调度算法                    |
| **配额管理**               | 对单独分区设磁盘配额,限制用户占用             |
| **空间管理**               | 防止某个目录(如 /var) 撑爆整个磁盘            |

### 分区相关核心概念

- **MBR (Master Boot Record)**:传统分区表,**最多 4 个主分区**,最大 2TB
- **GPT (GUID Partition Table)**:现代分区表,**最多 128 个分区**,最大 9.4 ZB
- **主分区 (Primary Partition)**:可安装 OS 的"主"分区
- **扩展分区 (Extended Partition)**:MBR 专用,容器,内含逻辑分区
- **逻辑分区 (Logical Partition)**:扩展分区内创建的分区
- **活动分区 (Active Partition)**:MBR 启动时被加载的分区
- **ESP (EFI System Partition)**:UEFI 启动分区,FAT32 格式
- **挂载点 (Mount Point)**:Linux 中分区映射到目录树的目录
- **卷标 (Label)**:分区的"名字"
- **UUID**:分区的唯一标识符

## 二、分区表 (MBR vs GPT)

### 2.1 MBR (Master Boot Record)

**位置**:硬盘的**第 0 扇区 (LBA 0)**,共 **512 字节**。

**结构**:

```text
偏移    大小    内容
0       440    引导代码 (Bootstrap Code)
440     2      磁盘签名 (Disk Signature)
442     4      0x0000 (通常为 0)
446     64    分区表 (4 × 16 字节)
510     2      魔数 0x55AA
```

**分区表项结构 (16 字节)**:

| 偏移 | 大小 | 含义                            |
|------|------|---------------------------------|
| 0    | 1    | 启动标志 (0x80=活动)            |
| 1    | 3    | CHS 起始地址 (已废弃)           |
| 4    | 1    | 分区类型                        |
| 5    | 3    | CHS 结束地址                    |
| 8    | 4    | LBA 起始扇区                    |
| 12   | 4    | 分区扇区数                      |

**MBR 限制**:

- 最多 4 个**主分区** (或 3 主 + 1 扩展)
- 扩展分区内可分多个**逻辑分区**(理论无限制)
- 单分区最大 **2 TB**(LBA 32 位)
- 单个 MBR 磁盘理论最大 2.19 ZB
- 无备份分区表,损坏难恢复
- 分区类型代码有限(只用 1 字节)

### 2.2 GPT (GUID Partition Table)

**位置**:
- **LBA 0**:保护性 MBR (Protective MBR,防止旧工具误识别)
- **LBA 1**:GPT 主头 (Primary Header)
- **LBA 2~33**:分区条目 (128 个,默认 128 个)
- **LBA 34~**:用户数据
- **磁盘末尾**:备份 GPT 头 + 分区条目

**GPT 头结构**:

- 签名 "EFI PART"
- 修订版本
- 主/备份头位置
- 分区条目大小
- CRC32 校验

**GPT 优势**:

- 支持 **128 个分区**(默认,实际可更多)
- 分区大小 **9.4 ZB**(LBA 64 位)
- 分区有 **UUID** 唯一标识
- **备份分区表** 在磁盘末尾,可恢复
- **CRC32 校验**,损坏可检测
- 分区名最长 36 个字符 Unicode
- **MBR 兼容**:第 0 扇区是保护性 MBR,防止旧工具误操作

**GPT 分区类型 GUID 示例**:

| GUID 段                              | 类型                 |
|--------------------------------------|----------------------|
| 0FC63DAF-8483-4772-8E79-3D69D8477DE4 | Linux Filesystem     |
| 4F68BCD8-6F2D-4BC2-92C5-58E51A0B0E4A | Linux /home          |
| 933AC7E1-2EB4-4F13-B844-0E14E2AEF915 | Linux /usr           |
| C12A7328-F81F-11D2-BA4B-00A0C93EC93B | EFI System           |
| EBD0A0A2-B9E5-4433-87C0-68B6B72699C7 | Microsoft Basic Data |
| E3C9E316-0B5C-4DB8-817D-F92DF00215AE | Microsoft Reserved   |

### 2.3 MBR vs GPT 对比

| 维度         | MBR                | GPT                          |
|--------------|--------------------|------------------------------|
| 推出年代     | 1983 (IBM PC)      | 2010 前后(UEFI 推动)         |
| 最大磁盘     | 2 TB               | 9.4 ZB(理论)                 |
| 分区数       | 4 主 / N 逻辑      | 128+(实际无限制)             |
| 备份         | 无                 | 主+备,自动恢复               |
| 校验         | 无                 | CRC32                        |
| 唯一标识     | 无                 | UUID                         |
| 兼容性       | 老 OS 都支持       | UEFI 原生,Legacy BIOS 需 CSM |
| 启动方式     | BIOS + MBR         | UEFI + ESP + .efi            |
| 适用         | 老系统             | 现代系统(几乎所有)           |

## 三、Linux 分区方案

### 3.1 经典分区方案 (传统)

**最小化方案 (服务器)**:

| 挂载点       | 大小          | 文件系统      | 说明                |
|--------------|---------------|---------------|---------------------|
| `/boot`      | 500 MB ~ 1 GB | Ext4          | 内核、initramfs     |
| `/` (根)     | 50 GB+        | Ext4          | 系统                |
| `swap`       | 内存 1-2 倍   | swap          | 交换分区            |
| `/data`      | 剩余          | Ext4/XFS      | 数据                |

**标准方案 (服务器推荐)**:

| 挂载点       | 大小           | 文件系统      | 说明                |
|--------------|----------------|---------------|---------------------|
| `/boot`      | 1 GB           | Ext4          | 启动文件            |
| `/boot/efi`  | 200 MB         | FAT32 (ESP)   | UEFI 启动           |
| `swap`       | 4-16 GB        | swap          | 交换                |
| `/`          | 50-100 GB      | Ext4/XFS      | 系统                |
| `/home`      | 剩余           | Ext4/XFS      | 用户                |
| `/var`       | 20-100 GB      | Ext4/XFS      | 日志、缓存、邮件    |
| `/tmp`       | 5-20 GB        | Ext4          | 临时文件            |
| `/opt`       | 10-50 GB       | Ext4          | 第三方软件          |
| `/data`      | 剩余           | Ext4/XFS      | 业务数据            |

**桌面 / 个人用户方案**:

| 挂载点       | 大小       | 文件系统   | 说明                |
|--------------|------------|------------|---------------------|
| `/boot/efi`  | 512 MB     | FAT32      | UEFI 启动           |
| `swap`       | 与内存等大 | swap       | 休眠支持            |
| `/`          | 100 GB+    | Ext4/Btrfs | 系统+应用           |
| `/home`      | 剩余       | Ext4/Btrfs | 用户数据            |

**企业/高安全方案**:

| 挂载点       | 大小       | 文件系统      | 挂载选项 (options)        |
|--------------|------------|---------------|---------------------------|
| `/boot`      | 1 GB       | Ext4          | defaults                  |
| `/tmp`       | 5 GB       | Ext4          | nosuid,nodev,noexec       |
| `/var`       | 20 GB      | Ext4          | nosuid                    |
| `/var/log`   | 10 GB      | Ext4          | nosuid,nodev,noexec       |
| `/home`      | 用户       | Ext4/XFS      | nosuid,nodev              |
| `/srv`       | 业务       | Ext4/XFS      | nosuid,nodev              |
| `swap`       | 内存 × 1-2 | swap          | defaults                  |
| `/`          | 50 GB      | Ext4          | defaults,ro (可选)        |

### 3.2 关键挂载点的作用

| 挂载点        | 作用                                  | 为什么单分                |
|---------------|---------------------------------------|---------------------------|
| `/boot`       | 内核镜像、initramfs、GRUB 配置        | 不卸载升级,可用旧内核启动 |
| `/boot/efi`   | UEFI 启动分区(FAT32)                  | UEFI 强制要求             |
| `/` (根)      | 系统根目录,所有其他目录的祖先         | -                         |
| `/home`       | 用户数据                              | 重装系统不影响,备份简单   |
| `/var`        | 变化的数据 (日志、缓存、邮件、数据库) | 容易撑爆,需单独监控       |
| `/tmp`        | 临时文件                              | 可挂 tmpfs (内存)         |
| `/opt`        | 第三方应用 (商业软件)                 | 与系统分离                |
| `/usr`        | 用户程序(系统级)                      | 可只读挂载                |
| `/srv`        | 服务数据 (Web、FTP)                   | 业务数据隔离              |
| `swap`        | 虚拟内存交换                          | 可独立调优                |
| `/data`       | 自定义数据                            | 业务/数据分离             |

### 3.3 特殊分区

#### (1) ESP (EFI System Partition)

- **格式**:FAT32
- **大小**:100 MB ~ 1 GB
- **内容**:UEFI 固件、bootloader (`.efi`)
- **挂载点**:`/boot/efi` 或 `/efi`
- **必须**:
  - UEFI 启动的系统
  - FAT32 格式
  - 正确设置 boot 和 esp 标志

#### (2) BIOS Boot Partition

- **格式**:无文件系统(裸分区,1 MB)
- **大小**:1 MB
- **作用**:GPT + BIOS 启动需要(BIOS 引导代码存放)
- **标志**:`bios_grub`

#### (3) Swap 分区 / Swap 文件

- **本质**:模拟内存,把内存中不活跃的数据搬到磁盘
- **作用**:
  - 扩展虚拟内存
  - 支持休眠 (Hibernate)
  - 内存不足时缓冲
- **现代方式**:Swap **文件** 比 Swap 分区更灵活
- **建议大小**:
  - 内存 ≤ 2 GB:swap = 内存 × 2
  - 内存 2-8 GB:swap = 内存
  - 内存 8-64 GB:swap = 4-8 GB
  - 内存 > 64 GB:swap 可不要(可选 4 GB)

#### (4) LVM 分区

- **LVM (Logical Volume Manager)**:逻辑卷管理
- **好处**:可以**动态调整分区大小**,跨多盘
- **层次**:
  - **PV (Physical Volume)**:物理卷,LVM 的基础单位
  - **VG (Volume Group)**:卷组,一个或多个 PV 组成
  - **LV (Logical Volume)**:逻辑卷,实际使用的"分区"
  - **PE (Physical Extent)**:物理区块,LVM 分配单位
- **典型布局**:

```text
PV: /dev/sda2, /dev/sdb1
VG: vg_main (PVs 组成)
  LV: lv_root → / (Ext4)
  LV: lv_home → /home (Ext4)
  LV: lv_var  → /var (XFS)
  LV: lv_swap → swap
```

#### (5) LUKS 加密分区

- **LUKS (Linux Unified Key Setup)**:Linux 统一密钥设置
- **用途**:全盘加密,保护静态数据
- **流程**:
  1. 创建加密分区 `cryptsetup luksFormat /dev/sdX`
  2. 打开 `cryptsetup open /dev/sdX my_crypt`
  3. 映射为 `/dev/mapper/my_crypt`
  4. 在上面建 LVM / 文件系统
- **解锁**:
  - 启动时输入密码
  - 通过密钥文件(网络/TPM)
  - SSH 解锁(远程管理)

#### (6) RAID 分区

- **mdadm**:软 RAID
- **zfs/btrfs RAID**:文件系统级 RAID
- 详见 RAID 笔记

#### (7) ZFS / Btrfs 子卷

- **ZFS**:用 `zpool` + `zfs create` 创建子卷
- **Btrfs**:用 `btrfs subvolume create` 创建子卷
- 可挂载为不同的目录

## 四、Linux 分区操作命令

### 4.1 查看分区信息

```bash
# 列出块设备
lsblk
# 详细信息
lsblk -f
# 完整信息 (UUID、label、size)
lsblk -o NAME,FSTYPE,LABEL,UUID,SIZE,MOUNTPOINT

# 查看磁盘
fdisk -l /dev/sda
parted /dev/sda print
gdisk -l /dev/sda      # GPT

# 看挂载情况
df -h
mount | grep sda

# 看 UUID
blkid
# 看单个设备
blkid /dev/sda1

# 看 /etc/fstab
cat /etc/fstab
```

### 4.2 创建分区

**MBR 风格 (fdisk)**:

```bash
fdisk /dev/sdb
# 命令:n (new) → p (primary) → 1 → enter → +10G
# 命令:t (change type) → 83 (Linux) 或 8e (LVM)
# 命令:w (write)
```

**GPT 风格 (gdisk)**:

```bash
gdisk /dev/sdb
# 命令:n (new) → 1 → enter → +10G → 8300 (Linux)
# 命令:w (write)
```

**parted (推荐,支持 MBR/GPT)**:

```bash
parted /dev/sdb mklabel gpt
parted /dev/sdb mkpart primary ext4 1MiB 10GiB
parted /dev/sdb set 1 boot on
parted /dev/sdb print
```

### 4.3 格式化

```bash
# Ext4
mkfs.ext4 /dev/sda1

# XFS
mkfs.xfs /dev/sda1

# Btrfs
mkfs.btrfs /dev/sda1

# FAT32 (用于 ESP)
mkfs.fat -F32 /dev/sda1

# Swap
mkswap /dev/sda1
swapon /dev/sda1

# 加密
cryptsetup luksFormat /dev/sda1
```

### 4.4 挂载与卸载

```bash
# 临时挂载
mount /dev/sda1 /mnt
mount -t ext4 /dev/sda1 /mnt
mount -t ext4 -o rw,noexec,nosuid /dev/sda1 /mnt

# 临时卸载
umount /mnt
umount /dev/sda1

# 强制卸载
umount -f /mnt

# 重新挂载
mount -o remount,ro /mnt

# 看挂载的来源
findmnt /mnt
```

### 4.5 自动挂载 (/etc/fstab)

**文件格式**:

```text
<设备>          <挂载点>  <文件系统> <选项>     <dump> <fsck>
UUID=xxxx       /         ext4       defaults   0      1
UUID=yyyy       /home     ext4       defaults   0      2
UUID=zzzz       swap      swap       defaults   0      0
UUID=wwww       /boot/efi vfat       umask=0077 0      1
tmpfs           /tmp      tmpfs      defaults,size=2G 0 0
```

**字段说明**:

- `<设备>`:UUID、LABEL、`/dev/sda1` 三种方式
- `<挂载点>`:目录,swap 是 `swap`
- `<文件系统>`:ext4、xfs、vfat、tmpfs 等
- `<选项>`:`defaults`、`ro`、`rw`、`noexec`、`nosuid`、`nodev` 等
- `<dump>`:0/1,是否被 dump 备份
- `<fsck>`:0/1/2,fsck 检查顺序,根分区=1,其他=2,swap=0

**测试 fstab**:

```bash
# 模拟挂载,检查配置
mount -fav
# -f: 模拟挂载
# -a: 挂载所有
# -v: 详细

# 或
findmnt --verify
```

**生成 fstab 工具**:

- 手动写
- `genfstab` (Arch 安装时用)
- `fstabgen` / 各种发行版安装器自动生成

### 4.6 分区调整

**growpart / parted (扩大)**:

```bash
# 扩大分区
parted /dev/sda resizepart 1 100%
# 扩大文件系统
resize2fs /dev/sda1   # Ext4
xfs_growfs /home      # XFS
```

**缩小**:

- 不容易,风险大
- 必须先缩文件系统,再缩分区
- 备份后操作

**LVM 调整 (动态)**:

```bash
# 添加新物理卷
pvcreate /dev/sdc
vgextend vg_main /dev/sdc

# 扩大逻辑卷
lvextend -L +10G /dev/vg_main/lv_home
# 或占满
lvextend -l +100%FREE /dev/vg_main/lv_home

# 扩大文件系统
resize2fs /dev/vg_main/lv_home
```

## 五、常见场景的分区方案

### 5.1 桌面 Linux (Ubuntu/Fedora)

| 挂载点      | 大小      | 文件系统     | 备注              |
|-------------|-----------|--------------|-------------------|
| `/boot/efi` | 512 MB    | FAT32        | UEFI              |
| `swap`      | 内存等大  | swap         | 休眠              |
| `/`         | 剩余      | Ext4/Btrfs   | 根,包含 /home     |

简单直接,一个根分区搞定。

### 5.2 Linux 服务器 (数据库)

| 挂载点           | 大小        | 文件系统 | 备注            |
|------------------|-------------|----------|-----------------|
| `/boot/efi`      | 512 MB      | FAT32    | UEFI            |
| `/boot`          | 1 GB        | Ext4     | 内核            |
| `swap`           | 内存 1-2 倍 | swap     |                 |
| `/`              | 50 GB       | Ext4     | 系统            |
| `/var`           | 20 GB       | Ext4     | 日志            |
| `/var/lib/mysql` | 100 GB+     | XFS      | 数据库单独挂载  |
| `/data`          | 剩余        | XFS      | 业务数据        |

数据库单独分区,**重要数据**和**系统**分开。

### 5.3 邮件/文件服务器

| 挂载点        | 大小        | 文件系统 | 备注            |
|---------------|-------------|----------|-----------------|
| `/boot/efi`   | 512 MB      | FAT32    | UEFI            |
| `/boot`       | 1 GB        | Ext4     | 内核            |
| `swap`        | 内存 1-2 倍 | swap     |                 |
| `/`           | 50 GB       | Ext4     | 系统            |
| `/var/mail`   | 100 GB+     | XFS      | 邮件            |
| `/srv`        | 1 TB+       | XFS      | 共享文件        |

### 5.4 虚拟化服务器

| 挂载点             | 大小        | 文件系统 | 备注              |
|--------------------|-------------|----------|-------------------|
| `/boot/efi`        | 512 MB      | FAT32    | UEFI              |
| `swap`             | 内存 1-2 倍 | swap     |                   |
| `/`                | 100 GB      | Ext4     | 系统 + hypervisor |
| `/var/lib/libvirt` | 剩余        | XFS      | 虚拟机镜像存放    |

### 5.5 Docker / K8s 主机

| 挂载点                | 大小       | 文件系统 | 备注            |
|-----------------------|------------|----------|-----------------|
| `/boot/efi`           | 512 MB     | FAT32    | UEFI            |
| `swap`                | 4-8 GB     | swap     | 容器主机可少    |
| `/`                   | 50 GB      | Ext4     | 系统            |
| `/var/lib/docker`     | 100 GB+    | XFS      | Docker 数据     |
| `/var/lib/containerd` | 100 GB+    | XFS      | containerd 数据 |

### 5.6 嵌入式 Linux

- **/boot**:小,几 MB
- **/**:小,几十 MB(只读)
- **/data**:用户数据,可写
- **swap**:一般没有
- **特殊**:OverlayFS,UBI (NAND)

### 5.7 国产化部署 (信创)

- 同企业方案
- 强调**自主可控**:用国产文件系统 (XFS、Ext4 都行)
- **国产加密**:TCM (TPM 中国标准)
- **审计要求**:`/var/log` 单独分区,留存日志

### 5.8 加密 + LVM 综合方案

- 一个加密分区 (LUKS) 包含整个根
- 在 LUKS 之上建 LVM
- 在 LVM 上建多个 LV
- 启动时输密码解锁

```text
/dev/sda2 (LUKS 加密)
  └─ VG vg_main
      ├─ LV root → / (Ext4)
      ├─ LV home → /home (Ext4)
      ├─ LV var  → /var (Ext4)
      └─ LV swap → swap
```

## 六、文件系统详解

### 6.1 主流 Linux 文件系统

| 文件系统      | 类型     | 特点                                       |
|---------------|----------|--------------------------------------------|
| **Ext4**      | 经典     | 默认,稳定,日志,最大 1EB(理论)              |
| **Ext3**      | 经典     | 老,带日志的 Ext2                           |
| **Ext2**      | 经典     | 无日志,嵌入式 / 启动分区                   |
| **XFS**       | 高性能   | 大文件,RHEL 默认                           |
| **Btrfs**     | 写时复制 | 快照,压缩,subvolume                        |
| **ZFS**       | 写时复制 | 池化,快照,校验和                           |
| **F2FS**      | 闪存     | 移动端,SSD                                 |
| **NTFS**      | 兼容     | Windows 文件系统,Linux 读写                |
| **FAT32**     | 兼容     | U 盘/SD 卡,兼容性最好                      |
| **exFAT**     | 兼容     | 大文件(微软)                               |
| **swap**      | 交换     | Linux 交换分区                             |
| **tmpfs**     | 内存     | 内存文件系统                               |
| **proc**      | 虚拟     | 内核信息                                   |
| **sysfs**     | 虚拟     | 内核对象                                   |
| **overlayfs** | 容器     | Docker / K8s 层叠文件系统                  |
| **NFS**       | 网络     | 网络文件系统                               |
| **CIFS**      | 网络     | Windows 网络共享                           |
| **9p**        | 网络     | virtio 共享文件夹                          |
| **Btrfs**     | 现代     | Oracle/SUSE 推崇                           |

### 6.2 文件系统选择建议

| 场景               | 推荐            | 原因                |
|--------------------|-----------------|---------------------|
| 系统根分区         | **Ext4** 或 XFS | 稳定,兼容           |
| 大文件             | XFS             | 高性能              |
| 数据库             | XFS             | 稳定,适合随机写     |
| 容器               | Ext4 或 XFS     | 通用                |
| 大容量存储         | XFS             | 几乎无限制          |
| 快照需求           | Btrfs / ZFS     | 原生快照            |
| 启动分区           | Ext2 / FAT32    | 小,稳定,无日志      |
| ESP                | **FAT32**       | UEFI 强制           |
| U 盘               | exFAT/FAT32     | 跨平台              |
| 交换               | swap            | 专用                |

## 七、UUID 与 Label

### 7.1 UUID

- **UUID (Universally Unique Identifier)**:全球唯一标识符
- 128 位,几乎不重复
- **优先用 UUID 标识分区**(设备名会变,UUID 不变)

```bash
# 查看 UUID
blkid
lsblk -f
# 改 UUID
tune2fs -U <新UUID> /dev/sda1
xfs_admin -U generate /dev/sda1
```

### 7.2 Label

- **Label**:分区的"名字",人类可读
- 缺点:可能重复

```bash
# 查看 label
e2label /dev/sda1
blkid -s LABEL

# 设置 label
e2label /dev/sda1 "DATA"
xfs_admin -L "DATA" /dev/sda1
fatlabel /dev/sda1 "EFI"
```

### 7.3 fstab 中使用

```text
# 用 UUID
UUID=abc-123 /data ext4 defaults 0 2

# 用 LABEL
LABEL=DATA /data ext4 defaults 0 2

# 用设备名(不推荐)
/dev/sda1 /data ext4 defaults 0 2
```

## 十、分区表备份与恢复

### 10.1 备份

```bash
# MBR
dd if=/dev/sda of=mbr.bin bs=512 count=1
sfdisk -d /dev/sda > mbr.sf

# GPT
sgdisk --backup=table.gpt /dev/sda
sgdisk --backup=table2.gpt /dev/sda   # 主+备
```

### 10.2 恢复

```bash
# MBR
dd if=mbr.bin of=/dev/sda bs=512 count=1
sfdisk /dev/sda < mbr.sf

# GPT
sgdisk --restore-backup=table.gpt /dev/sda
# 或从备份恢复
sgdisk -Z /dev/sda    # 危险!清空
```

### 10.3 修复

```bash
# 自动检测
gdisk /dev/sda
# 主+备 GPT 头,自动修复

# 强制重建
gdisk /dev/sda
# 命令:r → f (load backup MBR) 或其他
```

## 十二、分区与启动的关系

### 12.1 BIOS + MBR 启动

```text
硬盘 0 扇区 (MBR) - 446 字节引导代码 + 64 字节分区表
  → 引导代码找到活动分区
  → 加载活动分区的 VBR
  → VBR 加载 OS Bootloader (GRUB、BOOTMGR)
  → Bootloader 加载内核
```

### 12.2 UEFI + GPT 启动

```text
ESP 分区 (FAT32)
  → EFI/boot/bootx64.efi 或 EFI/ubuntu/grubx64.efi
  → Bootloader 加载内核
  → 启动
```

### 12.3 启动相关分区

- **ESP**:必须,UEFI 启动
- **/boot**:大部分 Linux 需要,放内核和 initramfs
- **/boot/efi**:同 ESP,只是挂载点
- **BIOS Boot**:GPT + BIOS 模式,1MB 裸分区

## 十三、最佳实践

### 13.1 物理服务器

- 至少做 **RAID** (硬件优先)
- 单独分 `/var`、`/home`、swap
- **LVM** 方便扩容
- **备份分区表**

### 13.2 虚拟机

- 一个根分区 + swap 即可
- 用 `growpart` 动态扩
- 选对虚拟磁盘类型 (qcow2 稀疏)

### 13.3 容器主机

- 简单分区,容器有自己的文件系统
- `/var/lib/docker` (或 containerd) 可单独挂载

### 13.4 桌面

- 一个根 + swap
- 用 Btrfs 体验快照

### 13.5 总体原则

- **重要数据单独分区**
- **/var 单独分区**(日志、缓存)
- **swap 大小合适**
- **不用设备名,用 UUID**
- **LVM 灵活扩容**
- **生产系统不直接用 root**

## 十四、核心要点速记

- **MBR**:老,2TB,4 主分区
- **GPT**:新,9.4 ZB,128 分区,带备份和 CRC
- **ESP** = FAT32,UEFI 启动必备
- **swap** 建议:内存 1-2 倍,或 4-8 GB 固定
- **UUID** 比设备名稳定,**fstab 必用 UUID**
- **/var 单分**:日志和缓存容易爆
- **/home 单分**:重装系统不丢数据
- **LVM** 灵活:动态扩,跨盘
- **LUKS** 加密:全盘保护
- **分区对齐**很重要(SSD 必须 4K 对齐)
- **现代 Linux** 大多用 GPT + EFI
- **fstab 测试**:`mount -fav` 或 `findmnt --verify`
- **mkfs** 后才能 mount
- **growpart + resize2fs / xfs_growfs** 扩文件系统
- **e2fsck / xfs_repair** 修复文件系统
- **blkid / lsblk -f** 看分区
- **parted / fdisk / gdisk** 创建分区
- **mount -o remount** 不卸载改挂载选项
