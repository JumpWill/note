# 网卡

Linux 网卡（Network Interface Card / NIC）从硬件到驱动再到 IP 协议栈有多个抽象层级。这篇解释命名规则、查看工具、配置、bond / bridge / VLAN、性能调优与排错。

## 1. 网卡命名规则

### 1.1 旧规则

| 前缀 | 设备类型 |
| --- | --- |
| `eth0` | 通用以太网 |
| `wlan0` | 无线 |
| `lo` | Loopback |
| `ppp0` | 点对点协议 |
| `bond0` | 多网卡绑定 |
| `br0` | 网桥 |
| `vlan0` | VLAN |
| `tun0` | 隧道（VPN） |
| `veth*` | 虚拟对（容器） |
| `dummy0` | Dummy |

### 1.2 systemd 命名（v197+）

按固件 / 总线 / 拓扑命名（`enp0s3` / `wlp2s0`），禁用"传统命名"：

```bash
# 关闭
net.ifnames=0 biosdevname=0
```

### 1.3 现代命名

```text
en + 设备类型 + 端口位置 + slot + func
enp3s0f1   = PCIe 端口 3 slot 0 function 1
wlp4s0     = Wireless
o<idx>     = Onboard
s<slot>    = Slot
```

每种类型：

```text
en   ethernet
ib   InfiniBand
sl   serial line
wl   wireless
ww   wwan
```

## 2. 查看网卡

### 2.1 传统

```bash
ifconfig -a
ifconfig eth0
```

### 2.2 iproute2（新）

```bash
ip addr
ip addr show dev eth0
ip -s link                  # 流量统计
ip -br addr                 # 简洁
ip -stats                   # 详细信息
ip -d link show eth0         # 驱动信息
ip -details addr show eth0
```

### 2.3 /sys/class/net/

```bash
ls /sys/class/net/
cat /sys/class/net/eth0/address         # MAC
cat /sys/class/net/eth0/speed          # 速率
cat /sys/class/net/eth0/stat/...
ethtool eth0
```

### 2.4 ethtool

```bash
ethtool eth0             # 通用
ethtool -i eth0          # 驱动
ethtool -S eth0          # 详细统计
ethtool -k eth0          # 功能开关
ethtool -p eth0          # 物理指示灯
ethtool --identify eth0
ethtool --show-time-stamping
```

常用：

```bash
ethtool -s eth0 speed 1000 duplex full autoneg on
ethtool -s eth0 wol g            # Wake on LAN
```

### 2.5 lspci / lshw

```bash
lspci | grep -i eth          # 列出以太网卡 PCI 设备
lshw -C network -short
lshw -C network -businfo
```

## 3. 配置 IP

### 3.1 临时

```bash
ip addr add 10.0.0.10/24 dev eth0
ip addr del 10.0.0.10/24 dev eth0
ip link set eth0 up
ip link set eth0 down
```

### 3.2 永久（Debian）

```text
# /etc/network/interfaces
auto eth0
iface eth0 inet static
  address 10.0.0.10
  netmask 255.255.255.0
  gateway 10.0.0.1
  dns-nameservers 8.8.8.8
```

### 3.3 永久（RHEL）

```bash
cd /etc/sysconfig/network-scripts/
cat > ifcfg-eth0 <<'EOF'
DEVICE=eth0
BOOTPROTO=static
IPADDR=10.0.0.10
NETMASK=255.255.255.0
GATEWAY=10.0.0.1
ONBOOT=yes
EOF

nmcli connection add ...
nmtui
```

### 3.4 NetworkManager / systemd-networkd

```bash
nmcli conn show
nmcli dev status
nmcli dev show eth0
nmcli con add con-name eth0 ifname eth0 type ethernet ip4 10.0.0.10/24 gw4 10.0.0.1
```

```text
# /etc/systemd/network/20-wired.network
[Match]
Name=eth0

[Network]
Address=10.0.0.10/24
Gateway=10.0.0.1
DNS=8.8.8.8
```

```bash
systemctl restart systemd-networkd
networkctl status
```

## 5. VLAN

### 5.1 802.1Q

```bash
ip link add link eth0 name eth0.10 type vlan id 10
ip addr add 10.0.10.1/24 dev eth0.10
ip link set eth0.10 up
```

### 5.2 VLAN 桥接

```bash
ip link add br0 type bridge
ip link set br0 up
ip link set eth0 master br0
ip link set eth0.10 master br0
```

### 5.3 VLAN 配置 (nmcli)

```bash
nmcli con add type vlan ifname eth0.100 dev eth0 id 100 \
  ip4 10.0.100.1/24 gw4 10.0.100.254
```

## 6. 网桥 (Bridge)

```bash
ip link add br0 type bridge
ip link set br0 up
ip link set eth0 master br0

# 启用 STP
ip link set br0 type bridge stp_state 1
bridge link show
bridge fdb show
```

container / K8s 内部 CNI 用到 bridge：

```bash
brctl show         # 老工具
ip link show master br0
```

## 7. Bond / Team（多网卡绑定）

```bash
# 创建 bond
ip link add bond0 type bond mode 802.3ad
ip link set eth0 master bond0
ip link set eth1 master bond0
ip link set bond0 up

# 模式
# balance-rr 0
# active-backup 1
# balance-xor 2
# broadcast 3
# 802.3ad 4  (LACP)
# balance-tlb 5
# balance-alb 6

# Team (替代方案)
ip link add team0 type team
ip link set eth0 master team0
ip link set eth1 master team0
```

nmcli 写法：

```bash
nmcli con add type bond ifname bond0 mode 802.3ad
nmcli con add type ethernet ifname eth0 master bond0
nmcli con add type ethernet ifname eth1 master bond0
nmcli con up bond0
```

## 8. 网桥 + VLAN + Bond 组合（生产常见）

```text
                 bond0 (LACP)
                /       \
             eth0        eth1
                |
           br0 (网桥)
            /  |  \
       br0.10 br0.20 br0.30
        VLAN10 VLAN20 VLAN30
```

```bash
ip link add bond0 type bond mode 802.3ad
ip link add br0 type bridge
ip link set eth0 master bond0
ip link set eth1 master bond0
ip link set bond0 master br0
ip link add link br0 name br0.10 type vlan id 10
ip addr add 10.0.10.1/24 dev br0.10
```

## 9. MTU 与 Jumbo Frame

```bash
ip link set eth0 mtu 9000          # 巨型帧
ip link show eth0                 # 看 MTU
```

MTU 选择：

- 默认：1500
- VLAN：1496
- 巨型帧：9000（数据中心）
- GRE/VXLAN：要看隧道包头开销

## 10. Offload 特性

```bash
ethtool -k eth0                  # 看
ethtool -K eth0 tso on           # 大包卸载
ethtool -K eth0 gso on
ethtool -K eth0 gro on
ethtool -K eth0 lro on
ethtool -K eth0 rx off           # 关闭 LRO
```

| Offload | 含义 |
| --- | --- |
| TSO | TCP Segment Offload，TCP 拆包给网卡 |
| GSO | Generic SO，内核层 |
| GRO | Generic Receive Offload，TCP 合包 |
| LRO | Large Receive Offload，网卡合包 |
| RSS | 多队列哈希分到多个 CPU |
| RPS | 软件版 RSS，内核处理 |
| RFS | 配合 RPS，根据应用 CPU 选择队列 |
| XDP | eXpress Data Path，内核旁路 |
| checksum offload | 网卡算 TCP/UDP 校验和 |

XDP（eXpress Data Path）：

```bash
ip link set eth0 xdp off
ip link set eth0 xdpdrv off
ip link set eth0 xdpgeneric off
```

## 11. 多队列（RSS / IRQ 亲和）

```bash
cat /proc/interrupts | grep eth0
ethtool -l eth0               # 队列
ethtool -x eth0               # 哈希
```

绑定 IRQ 到 CPU：

```bash
echo 0 > /proc/irq/32/smp_affinity       # CPU 0
echo f > /proc/irq/32/smp_affinity       # CPU 0-3
```

```bash
ethtool -g eth0                # 看

```

## 13. TCP / IP 调优

```bash
sysctl -w net.core.rmem_max=16777216
sysctl -w net.core.wmem_max=16777216
sysctl -w net.ipv4.tcp_rmem='4096 87380 16777216'
sysctl -w net.ipv4.tcp_wmem='4096 65536 16777216'
sysctl -w net.ipv4.tcp_congestion_control=bbr
sysctl -w net.core.default_qdisc=fq
sysctl -w net.ipv4.tcp_fastopen=3
```

MTU 调整：

```bash
sysctl -w net.ipv4.tcp_mtu_probing=1
```

## 15. 常见故障排查

### 15.1 网卡 down

```bash
ip link show eth0
dmesg | grep eth0
ethtool eth0
```

### 15.2 半双工 / 速度不对

```bash
ethtool eth0 | grep -i speed
# Auto-Negotiation: on / Speed: 1000Mb/s / Duplex: Full
```

两端双工模式必须一致。

### 15.3 IP 冲突

```bash
arping -I eth0 10.0.0.10
```

### 15.4 桥 / VLAN 不通

```bash
bridge link show
ip link show type vlan
brctl showmacs br0
tcpdump -i eth0 -n -e vlan
```

### 15.5 bond 失败

```bash
cat /proc/net/bonding/bond0
# 看 slave 状态 / lacp rate
```

### 15.6 大包丢 / 巨型帧

```bash
ip link show eth0
ethtool -g eth0
```

### 15.7 软中断 / CPU 占用

```bash
top -d 1
watch -n 1 "cat /proc/softirqs"
mpstat -P ALL 1 5
```

### 15.8 网卡驱动 bug

```bash
dmesg | grep -i eth0
ethtool -d eth0
rmmod <driver>; modprobe <driver>
```

## 16. SR-IOV / 虚拟化

```bash
# 启用 SR-IOV
echo 4 > /sys/class/net/eth0/device/sriov_numvfs

# 容器 / K8s 使用 VF
ip link set eth0 vf 0 mac aa:bb:cc:dd:ee:ff vlan 10
```

K8s：`networking.k8s.io/v1` Device Plugin：`k8s.io/sriov-net`
