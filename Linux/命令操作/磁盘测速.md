# 磁盘 I/O 性能测试

磁盘 / 内存 / 存储设备的速率与健康度检测。覆盖顺序读写、IOPS、随机 IO、性能对比与排错。

## 1. 简单测速工具

### 1.1 hdparm（机械 / SATA 硬盘）

测裸盘顺序读，不经过文件系统：

```bash
sudo hdparm -tT /dev/sda
```

- `-T`：缓存读（纯 CPU / kernel page cache）
- `-t`：磁盘读（绕过 page cache）

输出关键字段：`Timing buffered disk reads` 的 `MB/sec` 值。

### 1.2 dd（顺序读写）

只测最粗粒度的顺序读写，注意 `oflag=direct` 才能绕过 cache：

```bash
# 写 4GB
dd if=/dev/zero of=/tmp/test bs=1M count=4096 oflag=direct status=progress

# 读 4GB
dd if=/tmp/test of=/dev/null bs=1M count=4096 iflag=direct status=progress
```

注意：

- `oflag=direct` / `iflag=direct` 关键，否则命中 OS cache 测的是 RAM
- 测完先 `sync && rm /tmp/test`
- 适合验证基础 IO

### 1.3 dd 之日志

```text
4096+0 records in
4096+0 records out
4294967296 bytes (4.3 GB) copied, 3.21 s, 1.3 GB/s
```

## 2. 专业性能工具：fio

`fio`（Flexible I/O Tester）是 Linux 块设备性能测试的事实标准，能精确控制：

- 块大小（4K / 64K / 1M）
- 队列深度（iodepth）
- 读写模式（read / write / randread / randwrite / randrw）
- 同步 / 异步
- 直接 / 缓冲 IO

### 2.1 顺序读

```bash
fio --name=seq-read \
    --filename=/data/test.fio \
    --rw=read --bs=1M --size=4G \
    --direct=1 --numjobs=1 \
    --runtime=60 --time_based \
    --group_reporting
```

### 2.2 顺序写

```bash
fio --name=seq-write \
    --filename=/data/test.fio \
    --rw=write --bs=1M --size=4G \
    --direct=1 --numjobs=1 \
    --runtime=60 --time_based \
    --group_reporting
```

### 2.3 4K 随机读 IOPS

模拟数据库典型场景：

```bash
fio --name=rand-read-4k \
    --filename=/data/test.fio \
    --rw=randread --bs=4k --size=4G \
    --direct=1 --numjobs=4 \
    --iodepth=32 --runtime=60 --time_based \
    --group_reporting
```

### 2.4 混合读写

```bash
fio --name=mixed \
    --filename=/data/test.fio \
    --rw=randrw --rwmixread=70 \
    --bs=4k --size=4G \
    --direct=1 --iodepth=32 \
    --numjobs=4 --runtime=60 --time_based
```

### 2.5 关注输出

| 指标 | 含义 |
| ---- | ---- |
| `IOPS` | 每秒 IO 操作数 |
| `Bandwidth (KB/s)` | 吞吐 |
| `Latency (usec)` | 平均 / P95 / P99 |
| `Latency distribution` | 50 / 75 / 90 / 95 / 99 / 99.9 |
| `clat` | completion latency |
| `clat percentiles` | 分位数延迟 |

### 2.6 制品数据 JSON / CSV

```bash
fio --rw=randread --bs=4k --size=2G --output-format=json --output=result.json ...
fio ... --output-format=csv --output=result.csv
```

适合 `gnuplot` / `perfparse` / `fio-plot` 可视化。

## 3. sysbench 文件 IO

`sysbench` 提供简化版 IO 基准：

```bash
sysbench fileio prepare \
  --file-total-size=4G \
  --file-num=128

sysbench fileio run \
  --file-total-size=4G \
  --file-test-mode=rndrw \
  --file-num=128 \
  --file-block-size=4K \
  --threads=4 \
  --time=60
sysbench fileio cleanup
```

适合相对比较，无需详细参数。

## 4. 内存 / 处理器 / 总线测速

### 4.1 dmidecode（看内存规格）

```bash
sudo dmidecode -t memory
```

输出：内存条型号 / 频率 / 时序 / 插槽数量。不是测速而是识别。

### 4.2 stream（内存带宽）

```bash
# 安装 stream benchmark
stream -v 4
```

返回每数组访问能跑到的 MB/s，配合`Copy / Scale / Add / Triad`典型 MB/s。

### 4.3 iperf3 / nuttcp（网络）

不是磁盘，但放一起便于完整测速：

```bash
iperf3 -s                       # server
iperf3 -c 10.0.0.5 -t 30        # client
```

### 4.4 sysbench CPU

```bash
sysbench cpu --cpu-max-prime=20000 --threads=4 run
```

## 5. NVMe / SSD 健康度

### 5.1 smartctl（SMART 信息）

```bash
sudo apt install smartmontools
sudo smartctl -a /dev/nvme0n1
```

关注：

| 字段 | 含义 |
| ---- | ---- |
| `Reallocated_Sector_Ct` | 重映射扇区 |
| `Current_Pending_Sector` | 待修复扇区 |
| `Offline_Uncorrectable` | 不可纠正扇区 |
| `Wear_Leveling_Count` | NVMe 寿命 |
| `Percentage Used` | 寿命百分比 |
| `Temperature_Celsius` | 温度 |
| `Media_and_Integrity_Errors` | 介质错误数 |

### 5.2 NVMe 详细信息

```bash
sudo nvme smart-log /dev/nvme0n1
sudo nvme list
```

### 5.3 smartctl 自测

```bash
sudo smartctl -t short /dev/sda       # short self-test
sudo smartctl -l selftest /dev/sda    # 读取自测日志
sudo smartctl -t long /dev/sda        # 长自测
```

## 6. 文件系统层测速

### 6.1 bonnie++ / iozone

- `bonnie++` 测试文件元数据 + 顺序读写
- `iozone` 多场景：`read / write / random-read / random-write / mix`

```bash
iozone -a -g 4G -n 64k -i 0 -i 1 -i 2 \
  -f /mnt/data/test
```

适合对比不同文件系统（ext4 / xfs / zfs / btrfs）。

### 6.2 perf / sar

`perf record -e block:*` + `perf report`：

```bash
sudo perf stat -e block:*,block_rq_* dd if=/dev/sda of=/dev/null bs=1M count=1024
```

按 tracepoint 看块 IO 详细。

## 9. 常见排错与决策

| 现象 | 怀疑 |
| ---- | ---- |
| 顺序读慢，4K 随机更慢 | 文件系统 / 块大小未调 |
| 4K 随机 IOPS 低 | SSD 寿命 / Q 过深 / queue 不调 |
| NVMe 与 SATA 差异不大 | 没走 direct / 队列深度不够 |
| 写延迟 P99 抖动大 | GC / Wear leveling |
| tcp 高丢包率 | 不是磁盘问题，是网络 / iowait |
| CPU %iowait 高 | 块设备跟不上 |

## 10. 综合示例

```bash
# 看块设备
lsblk
cat /sys/block/nvme0n1/queue/scheduler
cat /sys/block/nvme0n1/queue/rotational    # 0 = SSD

# SMART
sudo smartctl -H /dev/nvme0n1

# fio 完整测
sudo fio --directory=/data \
  --name=stdtest \
  --rw=mix --rwmixwrite=30 \
  --bs=4k --size=4G --numjobs=4 --iodepth=32 \
  --direct=1 --sync=1 --time_based --runtime=120 \
  --group_reporting --output-format=json \
  --output=fio-result.json
```

## 11. 一句话总结

```text
块设备性能 = 顺序（hdparm / dd / fio bs=1M）+ 随机（fio bs=4K iodepth>=16）+ 健康度（smartctl）
```

按需选择：

- **粗测**：hdparm / dd
- **标准测**：fio
- **健康 / 寿命**：smartctl / nvme smart-log
- **内存**：stream benchmark
- **网络**：iperf3
- **进程级 IO**：iotop
