# 自定义 Shell 登陆显示信息

登陆 Linux 后控制台 / SSH / TTY 看到的"欢迎语"通常来自 `/etc/issue`（本地）、`/etc/issue.net`（远程 telnet/SSH）以及 `/etc/motd`（Message Of The Day）。可以自定义它们显示系统信息、负载、IP 等"自助信息"。

## 1. 三种登陆显示源

| 文件 | 作用 | 何时显示 |
| --- | --- | --- |
| **/etc/issue** | 本地控制台 tty 登陆前 | 本地物理 / 虚拟终端 |
| **/etc/issue.net** | 网络登陆前 | SSH / telnet / 远程登陆（看 PAM 配置） |
| **/etc/motd** | Message Of The Day | 登陆之后（ssh 看到的 banner） |
| **/etc/profile.d/\*.sh** | 登录后 bash 配置 | 每次 bash 启动 |

注：

- `issue.net` 在 sshd 中默认关闭（`Banner /etc/issue.net`）
- motd 是 ssh 后 cat 给用户看
- CentOS 7+ 默认无 motd（被 cloud-init 取代）

## 2. /etc/issue 转义符

`/etc/issue` 支持多个 \` 转义符：

| 转义符 | 含义 |
| --- | --- |
| `\d` | 当前日期（local time） |
| `\t` | 当前时间（hour:minute:second） |
| `\l` | 当前终端名（tty1, ttyS0） |
| `\n` | 主机名 |
| `\s` | 操作系统 |
| `\r` | 内核版本 |
| `\v` | 内核 build 时间 |
| `\m` | 硬件架构（x86_64） |
| `\b` | 总线频率（基本无意义） |
| `\U` | 登陆的 N 用户（用户数） |
| `\u` | 当前用户名 |
| `\D{format}` | 自定义 date 格式（如 `\D{%Y-%m-%d}`） |
| `\e` | ANSI 转义（如 `\e[31m`） |

例：

```text
Welcome to \n \r \m
System: \s \r
Time: \t \d
User: \u on \l
```

## 3. 修改 /etc/issue

```bash
# 看默认
cat /etc/issue
# Ubuntu 通常：\d \t \l \n \m
# CentOS: \S Kernel \r on \m
```

```bash
cat > /etc/issue <<'EOF'
================================================
  🐧 Welcome to \n
  OS:        \s \r (\m)
  Date:      \d \t
  User:      \u from \l
  Uptime:    \U user(s) online
================================================
EOF
```

> 注意：motd / issue 不走 ssh；sshd 看 `Banner` 配置。

## 4. /etc/motd（ssh 后显示）

```bash
cat > /etc/motd <<'EOF'
================================================
  ⚠️  This system is for authorized use only.
  All activity may be monitored and reported.
================================================
EOF
```

CentOS / Ubuntu 大多没 motd，但 sshd 默认登录后输出。

## 5. /etc/issue.net（ssh 前 Banner）

需要在 sshd_config 中启用：

```text
# /etc/ssh/sshd_config
Banner /etc/issue.net
```

```bash
systemctl reload sshd
```

`/etc/issue.net` 与 `/etc/issue` 区别：

- `issue.net` 不解释 `\d` 等转义
- 推荐纯文本（公司名 / 警告语）

## 6. motd.d / profile.d 机制

现代 Linux 倾向于：

```bash
# /etc/motd.d/  按片段拼装
/etc/motd.d/00-header
/etc/motd.d/10-help-text
/etc/motd.d/90-footer
```

```bash
# SSH 触发一次
run-parts /etc/motd.d/
```

```bash
# /etc/profile.d/*.sh  登录 bash 时执行
cat > /etc/profile.d/welcome.sh <<'EOF'
echo "============================="
echo " Welcome to $(hostname)"
echo " $(date '+%Y-%m-%d %H:%M:%S')"
echo "============================="
EOF
chmod +x /etc/profile.d/welcome.sh
```

## 7. 动态信息（脚本生成 motd）

Linux 动态 banner 常用：

```bash
#!/bin/bash
# /usr/local/bin/gen-motd.sh
UPTIME=$(uptime -p)
LOAD=$(cat /proc/loadavg | awk '{print $1, $2, $3}')
IP=$(hostname -I | awk '{print $1}')
MEM=$(free -m | awk '/Mem/{print $3"/"$2"MB"}')
DISK=$(df -h / | awk 'NR==2 {print $3" / "$2}')

cat <<EOF
================================================
  Host:    $(hostname)
  IP:      $IP
  Uptime:  $UPTIME
  Load:    $LOAD
  Memory:  $MEM
  Disk /:  $DISK
================================================
EOF
```

加进 cron：

```bash
chmod +x /usr/local/bin/gen-motd.sh
echo "@reboot root /usr/local/bin/gen-motd.sh > /etc/motd" > /etc/cron.d/gen-motd
```

## 8. 实用方案：landscape / motd + 动态

### 8.1 Ubuntu /etc/update-motd.d/

```bash
ls /etc/update-motd.d/
# 00-header  10-help-text  50-landscape-sysinfo  90-updates-available  91-release-upgrade  95-hwe-eol  98-cloud-guest-utils  98-fsck-at-reboot  99-esm
```

工作流：

```text
pam_motd ─► run-parts /etc/update-motd.d/ ─► /etc/motd ─► ssh 显示
```

每条脚本独立：

```bash
cat > /etc/update-motd.d/99-custom <<'EOF'
#!/bin/sh
echo "==================="
echo "Welcome to $(hostname)"
echo "IP: $(hostname -I | awk '{print $1}')"
EOF
chmod +x /etc/update-motd.d/99-custom
```

### 8.2 CentOS / RHEL cloud-init

`/etc/cloud/cloud.cfg`：

```yaml
cloud_init_modules:
  - update_hostname
  - update_etc_hosts
motd:
  info: |
    Welcome to {hostname}!
    IP: {ip4}
```

### 8.3 自定义彩色 banner（figlet / toilet）

```bash
apt install -y figlet toilet
figlet "Welcome"
toilet -f mono12 "Corp Linux"
```

输出 ASCII 大字，可作为 `/etc/motd` 内容。

### 8.4 给所有用户显示公司 / 警告

```bash
cat > /etc/profile.d/legal-notice.sh <<'EOF'
cat <<MSG
=========================
  This system is for authorized use only.
  All activities are logged.
=========================
MSG
EOF
```

## 9. 不同登陆场景下的显示

| 方式 | /etc/issue | /etc/issue.net | /etc/motd | /etc/profile.d |
| --- | --- | --- | --- | --- |
| 物理 tty 登陆 | ✔ | ✘ | ✔ | ✔ |
| ssh（默认） | ✘ | 配置后 ✔ | ✔ | ✔ |
| telnet | ✔ | ✔ | ✔ | ✔ |
| `su -` | ✘ | ✘ | ✔ | ✔ |
| bash 内 interactive 启动 | ✘ | ✘ | ✘ | ✔ |

## 10. SSH Banner 行为

`Banner /etc/issue.net` 在 ssh 用户认证前显示，常用作"法律声明"。

```text
Banner /etc/issue.net
```

注意：

- 在用户输入密码前
- 不能有 ANSI 转义
- 如果写 issue 类型转义符，反 ssh 客户端不解析

## 11. 跨发行版兼容

| 发行版 | motd 路径 | 动态机制 |
| --- | --- | --- |
| Debian / Ubuntu | `/etc/motd` + `/etc/update-motd.d/` | pam_motd |
| CentOS / RHEL | `/etc/motd`（旧） | cloud-init |
| Alpine | 无 motd | /etc/profile |
| Amazon Linux | `/etc/motd` | cloud-init |

## 12. 实战：完整自定义

```bash
# 1. issue（本地 tty）
cat > /etc/issue <<'EOF'
╔════════════════════════════════════╗
║  🐧 \n \r                             
║  \l @ \t                             
║  Welcome to $(cat /etc/os-release | head -1) 
╚════════════════════════════════════╝
EOF

# 2. issue.net（远程 ssh banner）
cat > /etc/issue.net <<'EOF'
================================================
  ⚠️  AUTHORIZED ACCESS ONLY
  All activity is monitored and reported.
================================================
EOF

# 3. 配置 sshd
echo "Banner /etc/issue.net" >> /etc/ssh/sshd_config
systemctl reload sshd

# 4. motd（登陆后）
cat > /etc/motd <<'EOF'
Welcome to $(hostname)
$(( uptime -p 2>/dev/null )) || uptime -p
EOF

# 5. 动态信息
cat > /etc/update-motd.d/90-status <<'EOF'
#!/bin/sh
echo "Users:    $(users | wc -w)"
echo "Load:     $(cut -d' ' -f1-3 /proc/loadavg)"
echo "Memory:   $(free -h | awk '/Mem/{print $3"/"$2}')"
EOF
chmod +x /etc/update-motd.d/90-status

# 6. 退出提醒
cat > /etc/profile.d/logout-notice.sh <<'EOF'
cat <<MSG
================================================
  Session will close in 30 seconds if idle
================================================
MSG
EOF
```

## 13. SSH 二次确认 / 双 banner

sshd_config 支持多个 banner：

```text
Banner /etc/issue.net
```

仅一条生效。

## 14. 调试

```bash
# 看是否被覆盖
cat /etc/issue
cat /etc/motd
ls -la /etc/update-motd.d/

# 确认 PAM 配置
grep pam_motd /etc/pam.d/sshd /etc/pam.d/login

# 测 ssh
ssh user@host
```

## 15. 一句话总结

```text
登陆显示 = /etc/issue + /etc/issue.net + /etc/motd + /etc/profile.d/*
本地 tty  → /etc/issue（带转义符）
远程 ssh → sshd Banner → /etc/issue.net
登陆后   → /etc/motd（动态推荐 update-motd.d）
bash 内   → /etc/profile.d/*.sh
推荐路径：update-motd.d/ + figlet + 动态脚本
```
