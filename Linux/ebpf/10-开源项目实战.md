# 10 - eBPF 开源项目实战

> 读优秀的开源项目是掌握 eBPF 的最佳路径。本章精选 8 个核心项目，每个都给出关键代码片段分析。

## 1. Cilium

> **地址**：https://github.com/cilium/cilium
> **语言**：C + Go
> **规模**：20+ 万行 C 代码
> **核心**：用 eBPF 完全替代 iptables/ipvs 做 k8s 网络

### 架构

```
┌──────────────────────────────────────────────────────┐
│  Cilium Agent (Go)                                     │
│    ├─ API Server 监听 k8s service/endpoints           │
│    ├─ 规则编译：将 k8s 网络策略 → eBPF 程序           │
│    └─ map 管理：endpoint map, identity map, ...       │
├──────────────────────────────────────────────────────┤
│  BPF 程序集 (C)  由 bpf2go 嵌入 Go 二进制             │
│    ├─ bpf_xdp.c      XDP 入口（包处理）              │
│    ├─ bpf_lxc.c      容器内入口（service 接入）       │
│    ├─ bpf_host.c     节点入口                        │
│    ├─ bpf_overlay.c  overlay 网络                    │
│    ├─ bpf_sock.c     socket LB                       │
│    └─ bpf_lb.c       负载均衡核心                    │
├──────────────────────────────────────────────────────┤
│  bpf/lib/                                              │
│  ├─ conntrack.c      状态机跟踪                       │
│  ├─ nat.c           NAT                              │
│  ├─ lb.c            负载均衡                          │
│  └─ policy.c        网络策略                          │
└──────────────────────────────────────────────────────┘
```

### 关键文件：`bpf_lxc.c`（容器入口）

```c
// cilium/bpf/bpf_lxc.c
__section_entry
int cil_from_container(struct __ctx_buff *ctx)
{
    __u16 proto;
    int ret;

    /* 包必须先经过 conntrack */
    ret = ctx_check_protocol(ctx, &proto);
    if (IS_ERR(ret))
        return ret;

    /* 解析身份标识 */
    __u32 src_id = ctx_get_identity(ctx);
    validate_ethertype(ctx, proto);

    /* 1. SNAT / 负载均衡 */
    ret = handle_nat_fwd(ctx, src_id, proto);
    if (IS_ERR(ret))
        return send_drop_notify(ctx, src_id, ret, METRIC_INGRESS);

    /* 2. 网络策略检查（CIDR、L3/L4、L7）*/
    ret = policy_can_egress(ctx, src_id, proto);
    if (IS_ERR(ret))
        return send_drop_notify(ctx, src_id, ret, METRIC_INGRESS);

    /* 3. 发送到物理设备 / 转发 */
    ret = ctx_redirect(ctx, HOST_IFINDEX, BPF_F_INGRESS);
    if (IS_ERR(ret))
        return send_drop_notify(ctx, src_id, ret, METRIC_INGRESS);

    return ret;
}
```

## 2. Facebook Katran

> **地址**：https://github.com/facebookincubator/katran
> **类型**：XDP L4 负载均衡

### 核心代码：XDP 主程序

```c
// katran/decap_acl.bpf.c
SEC("xdp")
int xdp_lb_balancer(struct xdp_md *ctx)
{
    struct ethhdr *eth = data;
    struct iphdr *iph;
    struct udphdr *udp;
    u64 csum_flags = 0;
    u32 key = 0;
    struct packet_description pckt = {};
    int cpu = bpf_get_smp_processor_id();
    struct real_definition *dst;
    int action = XDP_PASS;

    /* 1. 解析包 */
    if (!(parse_packet(ctx, &pckt, &csum_flags))) {
        return XDP_PASS;
    }

    /* 2. 查一致性哈希 → 真实服务器 */
    if (pckt.flow.proto == IPPROTO_TCP) {
        dst = bpf_map_lookup_elem(&tcp_mapping, &pckt.flow);
    } else {
        dst = bpf_map_lookup_elem(&udp_mapping, &pckt.flow);
    }

    if (!dst) return XDP_PASS;

    /* 3. 替换目的 MAC/IP */
    action = xdp_adjust_data(ctx, &pckt, dst, &csum_flags);

    if (action == XDP_TX) {
        /* 4. 统计 */
        u64 *stats = bpf_map_lookup_elem(&stats_map, &key);
        if (stats) {
            if (pckt.flags & F_SYN) stats[__pcpu_stats_TOTAL_SYN]++;
        }
    }

    return action;
}
```

### 关键技巧

1. **CPU 亲和性**：real server 哈希到特定 CPU
2. **封装/解封装**：TPR/TPR+IPIP 模式
3. **一致性哈希**：用 V-IPMRoute 实现会话保持

```bash

```

```c
int trace_execve(struct trace_event_raw_sys_enter *ctx) {
    u32 pid = bpf_get_current_pid_tgid() >> 32;
    struct event_t event = { .pid = pid };
    bpf_get_current_comm(event.comm, sizeof(event.comm));
```

### biolatency.c（块设备延迟）

```c
// 生物延迟直方图
BPF_HISTOGRAM(biolatency);

SEC("kprobe/blk_mq_start_request")
int trace_start(struct pt_regs *ctx) {
    u64 pid_tgid = bpf_get_current_pid_tgid();
    u64 ts = bpf_ktime_get_ns();
    bpf_map_update_elem(&start_map, &pid_tgid, &ts, BPF_ANY);
    return 0;
}

SEC("kretprobe/blk_mq_start_request")
int trace_end(struct pt_regs *ctx) {
    u64 pid_tgid = bpf_get_current_pid_tgid();
    u64 *start_ts = bpf_map_lookup_elem(&start_map, &pid_tgid);
    if (!start_ts) return 0;
    u64 delta = bpf_ktime_get_ns() - *start_ts;
    bpf_map_delete_elem(&start_map, &pid_tgid);

    // 转换为 us 并触发直方图
    u64 lat_us = delta / 1000;
    u64 slot = log2l(lat_us);
    biolatency.increment(bpf_log2l(lat_us));
    return 0;
}
```

## 4. bpftrace（高级追踪 DSL）

> **地址**：https://github.com/iovisor/bpftrace
> **使用**：单行脚本，9000+ 内置工具

### 单行例子

```bash
# 谁在系统调用最多？
sudo bpftrace -e 't:syscalls:sys_enter_* { @[comm] = count(); }'

# TCP 连接的 RTT
sudo bpftrace -e '
    t:tcp::connect /retval == 0/ {
        @start[tid] = nsecs;
    }
    t:tcp::tcp_set_state /args->newstate == TCP_CLOSE/ {
        if (@start[tid]) {
            @usecs = hist((nsecs - @start[tid]) / 1000);
            delete(@start[tid]);
        }
    }
'

# 调度延迟直方图
sudo bpftrace -e '
    kprobe:pick_next_task { @start[tid] = nsecs; }
    kretprobe:pick_next_task /@start[tid]/ {
        @latency_us = hist((nsecs - @start[tid]) / 1000);
        delete(@start[tid]);
    }
'
```

### 进阶脚本：追踪进程 dns 查询

```bash
sudo bpftrace -e '
uprobe:/lib/x86_64-linux-gnu/libc.so.6:sendto
    /comm == "curl" || comm == "wget"/
{
    printf("PID %d sends to fd %d\n", pid, arg0);
}
'
```

### 内部实现：bpftrace 编译为 eBPF

bpftrace 把脚本编译为 LLVM IR，再编译为 eBPF 字节码，加载到内核。

```c
// 检测到恶意行为 → bpf_override_return 阻断
SEC("tracepoint/raw_syscalls/sys_enter")
int block_openat(struct trace_event_raw_sys_enter *ctx) {
    int syscall_nr = ctx->args[0];
    if (syscall_nr != __NR_openat)
        return 0;

    // 进程名是 'crypto_miner'
    char comm[16];
    bpf_get_current_comm(comm, sizeof(comm));
    if (bpf_strncmp(comm, 14, "crypto_miner") != 0)
        return 0;

    // 阻断！
    bpf_override_return(ctx, -EPERM);
    return 0;
}
```

## 7. Falco

> **地址**：https://github.com/falcosecurity/falco
> **类型**：运行时威胁检测

### 核心思路

```yaml
# /etc/falco/falco_rules.yaml
- rule: Detect crypto mining
  desc: Detect Bitcoin mining
  condition: >
    spawned_process and container and 
    proc.name in (cryptonight, xmr-stak)
  output: >
    Possible crypto mining (user=%user.name command=%proc.cmdline)
  priority: WARNING
```

### 工作原理

```
Falco 配置规则 → 翻译为 eBPF kprobe 集合 →
在主机或容器上加载 → kprobe 触发 → 事件写入
→ Falco 用户态评估 → 触发告警
```
