# 12 - 包管理与模块

## 一、go.mod

### 1. 初始化

```bash
cd myproject
go mod init github.com/user/myproject
```

生成 `go.mod`:

```go
module github.com/user/myproject

go 1.22
```

### 2. 添加依赖

```bash
# 直接 go get
go get github.com/gin-gonic/gin@v1.9.1
go get github.com/spf13/viper@latest

# 或 import 后 go mod tidy 自动添加
```

go.mod 更新为:

```go
module example.com/app

go 1.22

require (
    github.com/gin-gonic/gin v1.9.1
    github.com/spf13/viper v1.16.0
)
```

### 3. go.sum

锁定依赖的哈希,确保可重现构建。**应提交到版本控制**。

```
github.com/gin-gonic/gin v1.9.1 h1:wt0fKZ...
github.com/gin-gonic/gin v1.9.1/go.mod h1:yoGx8...
```

## 二、常用命令

### 1. 依赖管理

```bash
go mod tidy          # 整理依赖(添加缺失 + 删除未用)
go mod download      # 下载依赖到本地缓存
go mod verify        # 校验 go.sum
go mod vendor        # 复制依赖到 vendor/ 目录
go mod why pkg       # 为什么需要这个依赖
go mod graph         # 依赖图
```

### 2. 版本选择

```bash
go get pkg@latest
go get pkg@v1.2.3
go get pkg@commit_hash
go get pkg@branch_name
```

### 3. 升级 / 降级

```bash
go get -u                 # 升级所有 minor / patch
go get -u=patch           # 仅 patch
go get pkg@none           # 移除依赖
```

## 三、replace(本地覆盖)

```go
// go.mod
require github.com/lib/pq v1.10.9

replace github.com/lib/pq => ../lib-pq-fork
```

调试或使用 fork 时很有用。

## 四、workspace(Go 1.18+)

多模块本地开发。

```
myworkspace/
├── go.work
├── tools/
│   ├── go.mod
│   └── main.go
└── services/
    ├── api/
    │   ├── go.mod
    │   └── main.go
    └── worker/
        ├── go.mod
        └── main.go
```

```go
// go.work
go 1.22

use (
    ./tools
    ./services/api
    ./services/worker
)
```

```bash
go work init ./tools ./services/api   # 初始化
go work sync                          # 同步依赖
go work edit -dropuse=./services/api  # 移除
```

## 五、internal 包

`internal` 目录只能被其父目录访问。

```
myapp/
├── go.mod
├── main.go
└── internal/
    └── auth/
        └── auth.go    // 只有 myapp/ 下的代码能 import
```

## 六、版本与兼容性

### 1. 语义版本

```bash
go get pkg@v1.2.3    # 精确
go get pkg@v1        # 最新 v1.x.x
go get pkg@v1.2      # 最新 v1.2.x
```

### 2. major 版本升级

```go
// v1
import "github.com/foo/bar"

// v2(独立路径)
import "github.com/foo/bar/v2"
```

### 3. go.work 与 replace 的区别

| 场景 | 用 |
| --- | --- |
| 本地多模块开发 | `go.work` |
| 临时覆盖一个依赖 | `replace` in go.mod |
| CI 强制构建 | `vendor` |

## 八、发布模块

### 3. 语义化版本策略

| 版本 | 含义 |
| --- | --- |
| 0.x.x | 初始开发,API 可能变 |
| 1.0.0 | 稳定 API,后续向后兼容 |

| 2.0.0 | 不兼容变更 |

## 九、常用目录约定

```
myapp/
├── cmd/                  # 可执行程序入口(多 binary)
│   ├── myapp/
│   │   └── main.go
│   └── myapp-tool/
│       └── main.go
├── internal/             # 私有代码
│   ├── auth/
│   └── storage/
├── pkg/                  # 公开 API(供外部用)
│   └── api/
├── api/                  # API 定义(protobuf / OpenAPI)
├── web/                  # 静态资源 + 模板
├── configs/              # 配置文件
├── deployments/          # Docker / K8s manifests
├── docs/                 # 文档
├── test/                 # 额外的测试数据
├── go.mod
├── go.sum
└── README.md
```

**关键原则**:
- `cmd/` 放 main 函数,**简短**,实际逻辑放包中
- `internal/` 防止外部意外依赖
- `pkg/` 是允许外部使用的库代码

### 2. `go.mod`

### 3. `internal/task/task.go`

```go

    ID        int
    Title     string
    Done      bool
    CreatedAt time.Time
}

func New(id int, title string) *Task {
    return &Task{
        ID:        id,
        Title:     title,
        CreatedAt: time.Now(),
    }
}
```

### 4. `internal/store/store.go`

```go
package store

import "github.com/user/todo_cli/internal/task"

type Store interface {
    Add(t *task.Task) error
    List() ([]*task.Task, error)
    Complete(id int) error
}
```

### 5. `internal/store/memory.go`

```go
package store

import (
    "errors"
    "sync"

    "github.com/user/todo_cli/internal/task"
)

type Memory struct {
    mu     sync.Mutex
    tasks  map[int]*task.Task
    nextID int
}

func NewMemory() *Memory {
    return &Memory{tasks: make(map[int]*task.Task)}
}

func (m *Memory) Add(t *task.Task) error {
    m.mu.Lock()
    defer m.mu.Unlock()

    t.ID = m.nextID
    m.nextID++
    m.tasks[t.ID] = t
    return nil
}

func (m *Memory) List() ([]*task.Task, error) {
    m.mu.Lock()
    defer m.mu.Unlock()

    out := make([]*task.Task, 0, len(m.tasks))
    for _, t := range m.tasks {
        out = append(out, t)
    }
    return out, nil
}

func (m *Memory) Complete(id int) error {
    m.mu.Lock()
    defer m.mu.Unlock()

    t, ok := m.tasks[id]
    if !ok {
        return errors.New("task not found")
    }
    t.Done = true
    return nil
}
```

### 6. `internal/cli/cli.go`

```go
package cli

import (
    "fmt"
    "os"

    "github.com/user/todo_cli/internal/store"
)

type CLI struct {
    store store.Store
}

func New(s store.Store) *CLI {
    return &CLI{store: s}
}

func (c *CLI) Run() {
    if len(os.Args) < 2 {
        c.usage()
        return
    }

    switch os.Args[1] {
    case "add":
        if len(os.Args) < 3 {
            fmt.Println("用法: todo add <title>")
            return
        }
        // ... 实际 add 逻辑
    case "list":
        tasks, _ := c.store.List()
        for _, t := range tasks {
            mark := " "
            if t.Done {
                mark = "x"
            }
            fmt.Printf("[%s] %d: %s\n", mark, t.ID, t.Title)
        }
    default:
        c.usage()
    }
}

func (c *CLI) usage() {
    fmt.Println(`todo - 简单的任务管理工具

用法:
  todo add <title>   添加任务
  todo list          列出任务
  todo done <id>     完成任务`)
}
```

### 7. `cmd/todo/main.go`

```go

    "github.com/user/todo_cli/internal/store"
```

## 十一、要点速记

- **`go mod init` 初始化模块,生成 go.mod**
- **`go mod tidy` 整理依赖(添加缺失 + 删除未用)**
- **go.sum 应提交,确保可重现构建**
- **`internal/` 目录的代码只能被父目录引用**
- **`go.work` Go 1.18+ 多模块本地开发**
- **`replace` 临时覆盖依赖(常用于 fork)**
- **`vendor` 把依赖复制到 vendor/ 目录**
- **`go get pkg@version` 指定版本**
- **大版本(v2+)用独立 import path:`/v2`**
- **目录约定:`cmd/` + `internal/` + `pkg/`**
- **`cmd/<name>/main.go` 简短,逻辑放包中**
