# 01 - 快速开始

## 一、安装

### 1. macOS

```bash
brew install go
```

### 2. Linux

```bash
# Ubuntu/Debian
sudo apt install golang-go

# 或官方安装包
wget https://go.dev/dl/go1.22.x.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.22.x.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
```

### 3. Windows

下载 MSI 安装包:[go.dev/dl](https://go.dev/dl/)

### 4. 验证

```bash
go version
# go version go1.22.x ...
```

## 二、第一个程序

```bash
mkdir hello
cd hello
go mod init hello
```

```go
// main.go
package main

import "fmt"

func main() {
    fmt.Println("Hello, 世界!")
}
```

```bash
go run main.go
# Hello, 世界!
```

## 三、Go 命令速查

| 命令 | 作用 |
| --- | --- |
| `go run file.go` | 编译并运行 |
| `go build` | 编译当前包 |
| `go build -o app` | 指定输出 |
| `go install` | 编译并安装到 `$GOPATH/bin` |
| `go test` | 运行测试 |
| `go test -bench=.` | 基准测试 |
| `go test -race` | 竞态检测 |
| `go vet` | 静态分析 |
| `gofmt -w .` | 格式化 |
| `goimports -w .` | 格式化 + 自动 import |
| `go mod init` | 初始化模块 |
| `go mod tidy` | 清理依赖 |
| `go mod download` | 下载依赖 |
| `go get pkg@ver` | 添加依赖 |
| `go list -m all` | 列出所有模块 |
| `go env` | 查看环境变量 |
| `go doc fmt.Println` | 文档 |

## 四、模块与包

### 1. 模块 (Module)

```bash
# 初始化模块
go mod init github.com/user/project

# go.mod
module github.com/user/project

go 1.22

require (
    github.com/gin-gonic/gin v1.9.1
    golang.org/x/text v0.14.0
)
```

### 2. 包 (Package)

```
myapp/
├── go.mod
├── main.go              // package main
└── internal/            // 仅本模块可见
    └── auth/
        └── auth.go      // package auth
```

```go
// pkg/user/user.go
package user

// User 大写开头,跨包可见
type User struct {
    ID   int
    Name string
}

// Find 小写,仅包内可见
func Find(id int) (*User, error) {
    return nil, nil
}
```

### 3. 导入

```go
// 单个
import "fmt"

// 多个
import (
    "fmt"
    "os"
)

// 别名
import f "fmt"

// 仅副作用(不直接使用)
import _ "image/png"

// 点导入(不推荐)
import . "fmt"  // Println() 直接调用
```

## 五、注释

```go
// 单行注释

/*
   多行注释
   块注释
*/

// 文档注释(被 godoc 提取)
// Package main 是程序入口。
package main

// Add 返回 a + b。
//
// # Examples
//
//     Add(1, 2) // returns 3
func Add(a, b int) int {
    return a + b
}
```

## 七、变量命名规范

```go
// 推荐:驼峰式
var maxRetry = 3
var userName string

// 大写 = 导出(public)
// 小写 = 非导出(package private)

// 不要用 _ 或 __ 开头
// 不要用类型前缀(StringName / iCount)
```

## 十一、要点速记

- **Go 1.11+ 推荐 go.mod 管理依赖**
- **package main + func main() 是入口**
- **大写开头的标识符跨包可见,小写仅包内**
- **`go run` 编译并运行,`go build` 仅编译**
- **`go test` 运行测试,`go mod tidy` 清理依赖**
- **`gofmt` 必须跑,代码风格统一**
- **`go vet` 在 CI 必跑**
- **常用 import 别名:`import f "fmt"`、`import _ "pkg"`(副作用)**
