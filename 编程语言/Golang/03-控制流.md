# 03 - 控制流

## 一、if / else

### 1. 基本用法

```go
if x > 0 {
    fmt.Println("正数")
} else if x < 0 {
    fmt.Println("负数")
} else {
    fmt.Println("零")
}
```

### 2. if 初始化

```go
// if 短语句:在条件判断前执行
if v := compute(); v > 100 {
    fmt.Println("big:", v)
} else {
    fmt.Println("small:", v)
}
// v 在这里不可见,作用域仅限 if/else
```

### 3. 常用模式

```go
// 错误处理
if err := doSomething(); err != nil {
    return err
}

// 检查存在
if v, ok := m[key]; ok {
    fmt.Println(v)
}

// 类型断言
if x, ok := i.(*MyType); ok {
    fmt.Println(x)
}
```

## 二、for 循环

Go **只有 `for` 一种循环**,无 while / do-while。

### 1. 三种形式

```go
// 1. C 风格
for i := 0; i < 10; i++ {
    fmt.Println(i)
}

// 2. while 风格(省略 init 和 post)
sum := 0
for sum < 100 {
    sum++

// 3. 无限循环
for {
    // break 退出
    // continue 跳到下次
}
```

### 4. 跳出多层循环

```go
func main() {
outer:
    for i := 0; i < 3; i++ {
        for j := 0; j < 3; j++ {
            if i*j >= 4 {
                break outer    // 跳出外层循环
            }
            fmt.Println(i, j)
        }
    }
}
```

### 5. range 遍历

```go
// slice / 数组
for i, v := range []int{10, 20, 30} {
    fmt.Println(i, v)
}

// map
for k, v := range m {
    fmt.Println(k, v)
}

// string(按 rune 遍历)
for i, r := range "hello 你好" {
    fmt.Printf("位置 %d: %c\n", i, r)
}

// channel
for v := range ch {
    fmt.Println(v)
}

// 忽略索引或值
for _, v := range slice { ... }
for k := range m { ... }
```

### 6. range 的细节

```go
nums := []int{1, 2, 3, 4, 5}

// 值是副本
for _, v := range nums {
    v *= 2        // 不影响原 slice
}

// 想要修改原值,用索引
for i := range nums {
    nums[i] *= 2
}

// 遍历 map 顺序随机
m := map[string]int{"a": 1, "b": 2}
for k, v := range m {
    fmt.Println(k, v)  // 顺序不固定
}
```

## 三、switch

### 1. 基本用法

```go
switch day {
case "Monday":
    fmt.Println("周一")
case "Tuesday":
    fmt.Println("周二")
default:
    fmt.Println("其他")
}
```

### 2. 多值匹配

```go
switch n {
case 1, 3, 5, 7, 9:
    fmt.Println("奇数")
case 2, 4, 6, 8:
    fmt.Println("偶数")
}
```

### 3. 无表达式 switch

```go
// 等价于 if/else if 链
score := 85
switch {
case score >= 90:
    fmt.Println("A")
case score >= 80:
    fmt.Println("B")
case score >= 70:
    fmt.Println("C")
default:
    fmt.Println("D")
}
```

### 4. 类型 switch

```go
func describe(i interface{}) {
    switch v := i.(type) {
    case int:
        fmt.Printf("int: %d\n", v)
    case string:
        fmt.Printf("string: %s\n", v)
    case bool:
        fmt.Printf("bool: %v\n", v)
    default:
        fmt.Printf("unknown: %T\n", v)
    }
}

describe(42)
describe("hi")
```

### 5. fallthrough(不推荐)

```go
switch n {
case 1:
    fmt.Println("one")
    fallthrough    // 强制执行下一个 case
case 2:
    fmt.Println("two or one")
}
```

## 四、goto(谨慎使用)

```go
func main() {
    i := 0
loop:
    if i < 3 {
        fmt.Println(i)
        i++
        goto loop
    }
}
```

适用:跳出深层循环、错误处理集中跳到清理代码。**滥用会破坏可读性**。

## 五、break / continue

```go
// break:跳出当前循环或 switch
for i := 0; i < 10; i++ {
    if i == 5 {
        break
    }
}

// continue:跳过本次,继续下一次
for i := 0; i < 10; i++ {
    if i%2 == 0 {
        continue    // 跳过偶数
    }
    fmt.Println(i)  // 1 3 5 7 9
}
```

## 六、综合实战:猜数字

```go
package main

import (
    "fmt"
    "math/rand"
    "time"
)

func main() {
    rand.Seed(time.Now().UnixNano())
    target := rand.Intn(100) + 1

    fmt.Println("猜数字(1-100)")

    for {
        var guess int
        fmt.Print("你的猜测: ")
        _, err := fmt.Scanf("%d", &guess)
        if err != nil {
            fmt.Println("请输入数字")
            continue
        }

        switch {
        case guess < target:
            fmt.Println("小了")
        case guess > target:
            fmt.Println("大了")
        default:
            fmt.Println("恭喜!答对了")
            return
        }
    }
}
```

## 七、要点速记

- **Go 只有 `for` 一种循环**
- **`if`/`switch` 可在条件前执行初始化语句**
- **`switch` 默认不 fallthrough(不像 C)**
- **`switch v := x.(type)` 类型 switch**
- **空 `switch` (`switch {}`) 是 if/else 链的写法**
- **`range` 遍历 slice / map / string / channel**
- **`range` 给出的是副本,要修改原值用 `for i := range`**
- **`map` 的 range 顺序随机**
- **`break` 跳到循环外,`continue` 跳到下次**
- **带标签的 `break outer` 可跳出多层循环**
- **`goto` 仅在必要时使用,易破坏可读性**
