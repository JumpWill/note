# 09 - 接口

Go 的接口是**隐式实现**的一组方法集合,体现"鸭子类型"。

## 一、接口基础

### 1. 定义与实现

```go
// 定义接口
type Speaker interface {
    Speak() string
}

// 实现接口(隐式,无需 implements)
type Dog struct{ Name string }

func (d Dog) Speak() string {
    return d.Name + " barks"
}

// 使用
var s Speaker = Dog{Name: "Buddy"}
fmt.Println(s.Speak())  // "Buddy barks"
```

### 2. 多方法接口

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

// 组合接口
type ReadWriter interface {
    Reader
    Writer
}

// 实现需要全部方法
type File struct{ /* ... */ }

func (f *File) Read(p []byte) (int, error)  { /* ... */ }
func (f *File) Write(p []byte) (int, error) { /* ... */ }

// File 自动实现 ReadWriter
var rw ReadWriter = &File{}
```

### 3. 空接口

```go
// interface{} 或 any
var x any = 42
x = "hello"
x = []int{1, 2, 3}

// 用作 map 值(异构)
m := map[string]any{
    "name":   "alice",
    "age":    30,
    "tags":   []string{"a", "b"},
    "active": true,
}
```

### 4. 类型断言

```go
var i interface{} = "hello"

// 单返回值(失败 panic)
s := i.(string)             // "hello"

// 双返回值(推荐)
s, ok := i.(string)         // "hello", true
n, ok := i.(int)            // 0, false(失败不 panic)

// switch 类型断言
switch v := i.(type) {
case int:
    fmt.Println("int:", v)
case string:
    fmt.Println("string:", v)
default:
    fmt.Println("unknown")
}
```

## 二、接口设计原则

### 1. 接受接口,返回具体类型

```go
// ✅ 好
func NewUserStore(db *sql.DB) *UserStore {  // 返回具体类型
    return &UserStore{db: db}
}

func (s *UserStore) Find(id int) (*User, error) {
    // 内部实现可换
}

// 调用者可以再定义为接口
type UserFinder interface {
    Find(id int) (*User, error)
}

// ❌ 不推荐
func NewStore() Storage { ... }   // 返回接口,难以扩展
```

### 2. 接口小而精

```go
// ✅ 一个方法一个接口
type Reader interface {
    Read(p []byte) (int, error)
}

type Writer interface {
    Write(p []byte) (int, error)
}

type Closer interface {
    Close() error
}

// io.ReadWriteCloser = Reader + Writer + Closer
```

### 3. 定义在使用方

```go
// 在使用方定义接口,而不是实现方
package consumer

// 消费者需要"能打印的东西"
type Printer interface {
    Print() string
}

func PrintAll(items []Printer) {
    for _, p := range items {
        fmt.Println(p.Print())
    }
}

// 实现方(其它包)无需知道这个接口
type MyStruct struct{}
func (m MyStruct) Print() string { return "hi" }
```

## 四、综合实战:多存储后端

```go
package storage

import "errors"

// 抽象接口
type Store interface {
    Get(key string) ([]byte, error)
    Set(key string, value []byte) error
    Delete(key string) error
    List() (map[string][]byte, error)
}

// 错误
var (
    ErrNotFound = errors.New("key not found")
    ErrNoSpace  = errors.New("no space")
)

// 内存实现
type MemoryStore struct {
    data map[string][]byte
}

func NewMemoryStore() *MemoryStore {
    return &MemoryStore{data: make(map[string][]byte)}
}

func (m *MemoryStore) Get(key string) ([]byte, error) {
    v, ok := m.data[key]
    if !ok {
        return nil, ErrNotFound
    }
    return v, nil
}

func (m *MemoryStore) Set(key string, value []byte) error {
    m.data[key] = value
    return nil
}

func (m *MemoryStore) Delete(key string) error {
    delete(m.data, key)
    return nil
}

func (m *MemoryStore) List() (map[string][]byte, error) {
    out := make(map[string][]byte, len(m.data))
    for k, v := range m.data {
        out[k] = v
    }
    return out, nil
}

// 文件实现
type FileStore struct {
    path string
}

func NewFileStore(path string) *FileStore {
    return &FileStore{path: path}
}

func (f *FileStore) Get(key string) ([]byte, error) {
    return os.ReadFile(filepath.Join(f.path, key))
}

func (f *FileStore) Set(key string, value []byte) error {
    return os.WriteFile(filepath.Join(f.path, key), value, 0644)
}

func (f *FileStore) Delete(key string) error {
    return os.Remove(filepath.Join(f.path, key))
}

func (f *FileStore) List() (map[string][]byte, error) {
    out := make(map[string][]byte)
    entries, err := os.ReadDir(f.path)
    if err != nil {
        return nil, err
    }
    for _, e := range entries {
        data, err := os.ReadFile(filepath.Join(f.path, e.Name()))
        if err != nil {
            return nil, err
        }
        out[e.Name()] = data
    }
    return out, nil
}

// 使用:业务代码只依赖接口
type Cache struct {
    store Store
}

func NewCache(s Store) *Cache {
    return &Cache{store: s}
}

func (c *Cache) Get(key string) ([]byte, error) {
    return c.store.Get(key)
}

func main() {
    mem := NewMemoryStore()
    cache := NewCache(mem)              // 用内存实现
    // cache := NewCache(NewFileStore("/tmp"))   // 切换文件实现,业务代码不变
    _ = cache
}
```

## 五、接口与多态

```go
type Shape interface {
    Area() float64
}

type Circle struct{ Radius float64 }
type Rect struct{ W, H float64 }

func (c Circle) Area() float64 { return math.Pi * c.Radius * c.Radius }
func (r Rect) Area() float64   { return r.W * r.H }

func TotalArea(shapes []Shape) float64 {
    total := 0.0
    for _, s := range shapes {
        total += s.Area()
    }
    return total
}

shapes := []Shape{
    Circle{Radius: 1},
    Rect{W: 2, H: 3},
    Circle{Radius: 5},
}
fmt.Println(TotalArea(shapes))
```

## 六、要点速记

- **接口是隐式实现,无需 `implements` 关键字**
- **接口是一组方法签名(行为)**
- **小接口原则:接口方法越少越好(1-3 个)**
- **接受接口、返回具体类型**
- **`any`(Go 1.18+) = `interface{}`**
- **类型断言 `v, ok := i.(T)`,失败不 panic(双返回值)**
- **`switch v := i.(type)` 类型 switch**
- **空接口 + 类型断言 = 模拟泛型(Go 1.18 前)**
- **接口值 = (类型指针 + 数据指针),两指针相等才相等**
- **接口 nil 不等于 nil 接口(常见陷阱)**
