# 07 - 指针与内存

## 一、指针基础

### 1. 定义与使用

```go
x := 42
p := &x              // *int,指向 x
fmt.Println(*p)      // 42(解引用)
*p = 100             // 通过指针修改 x
fmt.Println(x)       // 100

// 零值 nil
var p *int
fmt.Println(p == nil)  // true
// *p                    // panic: nil pointer
```

### 2. 指针与函数

```go
// 传值(不影响外部)
func Double(v int) {
    v *= 2
}

// 传指针(可修改外部)
func DoublePtr(v *int) {
    *v *= 2
}

n := 10
Double(n)
fmt.Println(n)         // 10
DoublePtr(&n)
fmt.Println(n)         // 20

// Go 没有指针运算(p++ 这种)
// 但可以 unsafe.Pointer 转换
```

### 3. 指针接收者

```go
type Counter struct{ n int }

// 值接收者
func (c Counter) Value() int { return c.n }

// 指针接收者(可修改)
func (c *Counter) Increment() { c.n++ }

c := Counter{}
c.Increment()
c.Increment()
fmt.Println(c.Value())  // 2
```

### 4. 自动取址

```go
c := Counter{}

// 自动取址(&c)
c.Increment()

// 不可寻址的值不能取指针
// c.Increment() 中 c 自动转为 &c
```

### 5. new 与 make

```go
// new(T):分配零值 T,返回 *T(指针)
p := new(int)        // *int,指向 0
fmt.Println(*p)     // 0

// make(T, ...):创建 slice/map/channel(初始化),返回 T(非指针)
s := make([]int, 0, 10)
m := make(map[string]int)
ch := make(chan int, 5)

// 区别:
// new 用于任意类型,返回指针
// make 仅用于 slice/map/channel,返回类型本身
```

### 6. 何时用 new

```go
// 不常见,大部分情况用 struct literal 替代
p := &Point{X: 1, Y: 2}    // 推荐
p := new(Point)            // 等价但 X/Y 都是 0
*p = Point{X: 1, Y: 2}    // 还要写一次
```

## 二、内存模型

### 1. 栈 vs 堆

Go 的内存分配由编译器通过**逃逸分析**决定:

```go
// 栈分配:不逃逸出函数
func Add(a, b int) int {
    return a + b
}

// 堆分配:返回了局部变量的指针
func NewCounter() *Counter {
    c := Counter{}
    c.n = 0
    return &c                // c 逃逸到堆
}
```

用 `go build -gcflags="-m"` 查看逃逸分析:

```bash
go build -gcflags="-m" main.go
# ./main.go:10:6: can inline NewCounter
# ./main.go:11:2: moved to heap: c
```

### 2. 值的传递

Go 中**所有赋值、函数传参都是值传递**(值拷贝)。

```go
// 引用类型(slice/map/channel/pointer)的"引用"是指向底层数据的指针
// 但变量本身是值,会被拷贝

s := []int{1, 2, 3}
modify(s)            // s 的 slice header 被拷贝(指针+len+cap)
fmt.Println(s)       // [1, 2, 99](底层数组被修改)
```

### 3. 大结构体的优化

```go
type Big struct {
    data [1024 * 1024]byte   // 1MB
}

// 传值:每次拷贝 1MB
func Process(b Big) { ... }

// 传指针:只传 8 字节
func Process(b *Big) { ... }
```

## 三、unsafe.Pointer

### 1. 任意类型转换

```go
import "unsafe"

// float64 bits 与 uint64 互转
func Float64bits(f float64) uint64 {
    return *(*uint64)(unsafe.Pointer(&f))
}

func Float64fromBits(b uint64) float64 {
    return *(*float64)(unsafe.Pointer(&b))
}

// byte slice 转 string(零拷贝)
func BytesToString(b []byte) string {
    return unsafe.String(unsafe.SliceData(b), len(b))   // Go 1.20+
}

// string 转 []byte(零拷贝)
func StringToBytes(s string) []byte {
    return unsafe.Slice(unsafe.StringData(s), len(s))   // Go 1.20+
}
```

### 2. unsafe.Sizeof / Alignof / Offsetof

```go
import "unsafe"

type S struct {
    a bool   // 1 字节
    b int64  // 8 字节
    c bool   // 1 字节
}

fmt.Println(unsafe.Sizeof(S{}))      // 24(含 padding)
fmt.Println(unsafe.Alignof(S{}))     // 8
fmt.Println(unsafe.Offsetof(S{}.b))  // 8
```

## 四、内存布局示例

```go
type Example struct {
    flag  bool    // 1 字节
    count int32   // 4 字节
    ptr   *int    // 8 字节
    big   int64   // 8 字节
}

// 布局(64-bit):
// offset 0:   flag (1 字节) + 3 字节 padding
// offset 4:   count (4 字节)
// offset 8:   ptr (8 字节)
// offset 16:  big (8 字节)
// 总大小:24 字节
```

## 五、GC(垃圾回收)

### 1. 三色标记清除

- **白**:未访问
- **灰**:已标记但子节点未标记
- **黑**:已标记且子节点已标记
- **并发执行**:GC 与用户代码并发
- **写屏障**:保证不漏标正在被引用的对象

### 2. 调优 GC

```bash
# 限制 GC 占用 CPU 比例(默认 100)
GOGC=200 go run main.go      # 默认 100,即堆翻倍时触发
GOGC=50 go run main.go       # 更频繁 GC,内存占用低
GOGC=off go run main.go      # 关闭 GC(调试用)

# 调试 GC
GODEBUG=gctrace=1 go run main.go
```

### 3. 减少 GC 压力

```go
// 1. 复用对象(sync.Pool)
var pool = sync.Pool{
    New: func() any {
        return new(bytes.Buffer)
    },
}

buf := pool.Get().(*bytes.Buffer)
defer pool.Put(buf)

// 2. 减少分配
// 预分配:make([]T, 0, n)
// 字符串拼接:用 strings.Builder,不用 +
// 避免循环内 append(必要时先 make)

// 3. 使用值类型
type Point struct { X, Y int }    // 小,栈分配
```

## 六、综合实战:简单的内存池

```go
package mempool

import "sync"

type Pool[T any] struct {
    mu    sync.Mutex
    items []T
    new   func() T
}

func New[T any](new func() T) *Pool[T] {
    return &Pool[T]{new: new}
}

func (p *Pool[T]) Get() T {
    p.mu.Lock()
    if n := len(p.items); n > 0 {
        item := p.items[n-1]
        p.items = p.items[:n-1]
        p.mu.Unlock()
        return item
    }
    p.mu.Unlock()
    return p.new()
}

func (p *Pool[T]) Put(item T) {
    p.mu.Lock()
    p.items = append(p.items, item)
    p.mu.Unlock()
}
```

## 七、要点速记

- **`&` 取址,`*` 解引用,nil 指针解引用 panic**
- **`make` 给 slice/map/channel,`new` 给类型零值指针**
- **大结构体传指针,小结构体传值**
- **Go 是值传递,引用类型通过指针间接实现**
- **逃逸分析:返回指针 → 堆;局部变量 → 栈**
- **`go build -gcflags="-m"` 查看逃逸**
- **`unsafe.Pointer` 可绕过类型安全,谨慎使用**
- **`unsafe.String` / `unsafe.Slice` Go 1.20+ 提供零拷贝**
- **Go GC 是三色标记 + 并发 + 写屏障**
- **`GOGC` 控制 GC 频率(默认 100)**
- **`sync.Pool` 复用对象减少 GC 压力**
