# 11 - 并发进阶:共享状态与同步原语

并发最大的难题:**多个 goroutine 安全访问共享数据**。Go 提供 `sync` 包和原子操作。

## 一、竞态条件

```go
// ❌ 错误:数据竞争
var counter int
for i := 0; i < 1000; i++ {
    go func() {
        counter++      // 不安全!
    }()
}
```

检测:

```bash
go run -race main.go
```

## 二、互斥锁 sync.Mutex

### 1. 基本用法

```go
var (
    mu      sync.Mutex
    counter int
)

func increment() {
    mu.Lock()
    defer mu.Unlock()
    counter++
}
```

### 2. sync.RWMutex(读写锁)

读多写少场景,允许多个并发读。

```go
var (
    rwmu sync.RWMutex
    data map[string]int
)

func read(k string) (int, bool) {
    rwmu.RLock()
    defer rwmu.RUnlock()
    v, ok := data[k]
    return v, ok
}

func write(k string, v int) {
    rwmu.Lock()
    defer rwmu.Unlock()
    data[k] = v
}
```

### 3. 选择锁的策略

| 场景 | 推荐 |
| --- | --- |
| 写多读少 | `Mutex` |
| 读多写少 | `RWMutex` |
| 短临界区 | `Mutex` |
| 临界区涉及 IO | 缩小临界区 |

## 三、sync.Once

保证某操作只执行一次。

```go
var (
    once     sync.Once
    instance *Singleton
)

func GetInstance() *Singleton {
    once.Do(func() {
        instance = &Singleton{}
        instance.init()
    })
    return instance
}
```

## 四、原子操作 sync/atomic

无需加锁,适合简单计数器、标志位。

```go
import "sync/atomic"

var counter int64

// 原子加
atomic.AddInt64(&counter, 1)

// 原子读
v := atomic.LoadInt64(&counter)

// 原子存
atomic.StoreInt64(&counter, 0)

// CAS(Compare And Swap)
old := atomic.LoadInt64(&counter)
new := atomic.CompareAndSwapInt64(&counter, old, old+1)

// 原子 bool
var flag int32
atomic.StoreInt32(&flag, 1)
if atomic.LoadInt32(&flag) == 1 { /* ... */ }
```

**性能**:原子操作通常比互斥锁快 5-10 倍。

## 五、sync.Map(并发 map)

读多写少场景的并发安全 map。

```go
var m sync.Map

// 存
m.Store("key", "value")

// 取
v, ok := m.Load("key")

// 取或存
v, loaded := m.LoadOrStore("key", "default")

// 删
m.Delete("key")

// 遍历
m.Range(func(k, v interface{}) bool {
    fmt.Println(k, v)
    return true    // 继续;false 终止
})
```

**缺点**:类型必须是 `any`,读写比普通 map 慢。

## 六、条件变量 sync.Cond

适合"等待条件满足"的场景。

```go
var (
    mu    sync.Mutex
    cond  = sync.NewCond(&mu)
    ready bool
)

// 等待者
func wait() {
    mu.Lock()
    for !ready {
        cond.Wait()      // 释放锁并等待,被唤醒后重新获取
    }
    mu.Unlock()
}

// 通知者
func signal() {
    mu.Lock()
    ready = true
    cond.Broadcast()    // 唤醒所有
    // cond.Signal()    // 唤醒一个
    mu.Unlock()
}
```

## 七、限流器(semaphore)

用 buffered channel 实现:

```go
type Semaphore chan struct{}

func NewSemaphore(n int) Semaphore {
    return make(chan struct{}, n)
}

func (s Semaphore) Acquire() {
    s <- struct{}{}
}

func (s Semaphore) Release() {
    <-s
}

func (s Semaphore) TryAcquire() bool {
    select {
    case s <- struct{}{}:
        return true
    default:
        return false
    }
}

// 用法
sem := NewSemaphore(10)
sem.Acquire()
defer sem.Release()
// 临界资源(最多 10 并发)
```

## 八、errgroup

简化多 goroutine 错误处理(需 `golang.org/x/sync/errgroup`)。

```go
import "golang.org/x/sync/errgroup"

func main() {
    g := new(errgroup.Group)

    for _, url := range urls {
        url := url
        g.Go(func() error {
            return fetch(url)
        })
    }

    if err := g.Wait(); err != nil {
        fmt.Println("error:", err)
    }
}
```

## 九、Go 调度模型 (GMP)

### 1. 三个角色

- **G (Goroutine)**:用户级协程
- **M (Machine)**:OS 线程(由 Go 管理)
- **P (Processor)**:逻辑处理器,持有本地 goroutine 队列

```text
        P0            P1            P2
       ↙  ↘         ↙  ↘         ↙  ↘
      M0  G队列      M1  G队列      M2  G队列
```

### 2. 关键参数

```bash
GOMAXPROCS=4     # P 的数量,默认 = CPU 核数
GOMAXPROCS=1     # 单核(便于调试竞态)
```

```go
runtime.GOMAXPROCS(runtime.NumCPU())   // 显式设置
```

### 3. 调度策略

- **work stealing**:空闲 P 从其他 P 偷一半 G
- **hand off**:M 阻塞时,G 移交给其他 M
- **preemptive**:Go 1.14+ 支持抢占式调度(基于信号)

## 十一、综合实战:线程安全计数器 + 限流器

```go
package main

import (
    "fmt"
    "sync"
    "sync/atomic"
    "time"
)

// 原子计数器
type Counter struct {
    value int64
}

func (c *Counter) Inc() int64 {
    return atomic.AddInt64(&c.value, 1)
}

func (c *Counter) Get() int64 {
    return atomic.LoadInt64(&c.value)
}

// 信号量限流器
type Limiter struct {
    sem chan struct{}
}

func NewLimiter(n int) *Limiter {
    return &Limiter{sem: make(chan struct{}, n)}
}

func (l *Limiter) Acquire() {
    l.sem <- struct{}{}
}

func (l *Limiter) Release() {
    <-l.sem
}

func (l *Limiter) TryAcquire(timeout time.Duration) bool {
    timer := time.NewTimer(timeout)
    defer timer.Stop()

    select {
    case l.sem <- struct{}{}:
        return true
    case <-timer.C:
        return false
    }
}

func main() {
    var c Counter
    var wg sync.WaitGroup

    for i := 0; i < 100; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            c.Inc()
        }()
    }
    wg.Wait()
    fmt.Println("counter:", c.Get())   // 100

    // 限流
    lim := NewLimiter(3)

    for i := 0; i < 10; i++ {
        go func(i int) {
            if !lim.TryAcquire(time.Second) {
                fmt.Printf("job %d: rejected\n", i)
                return
            }
            defer lim.Release()
            fmt.Printf("job %d: running\n", i)
            time.Sleep(500 * time.Millisecond)
        }(i)
    }

    time.Sleep(3 * time.Second)
}
```

## 十二、要点速记

- **竞态检测:`go run -race` / `go test -race`**
- **临界区要小,不要在锁内做 IO**
- **`sync.Mutex` 写锁,`sync.RWMutex` 读写分离**
- **`sync.Once` 用于单例,内部用 `atomic + mutex` 实现**
- **原子操作比锁快,但只能用于简单类型(int/uint/pointer)**
- **`sync.Map` 用于读多写少,key/value 都是 `any`**
- **`sync.Cond` 等待条件,`Wait` 自动释放锁**
- **用 buffered channel 实现信号量/限流器**
- **GOMAXPROCS 默认 = CPU 核数,控制并行度**
- **GMP 调度:work stealing + hand off + preemptive**
- **errgroup 同步多个 goroutine,首个错误传播**

### 3. `cache.go` - 内存缓存

```go
package cache_lib

import (
    "errors"
    "sync"
    "sync/atomic"
    "time"
)

var ErrNotFound = errors.New("key not found")

// Item 缓存条目
type Item struct {
    Value     any
    ExpiresAt time.Time
}

func (i Item) Expired() bool {
    return !i.ExpiresAt.IsZero() && time.Now().After(i.ExpiresAt)
}

// Cache 接口
type Cache interface {
    Get(key string) (any, error)
    Set(key string, value any, ttl time.Duration) error
    Delete(key string) error
    Len() int
}

// MemoryCache 线程安全内存缓存
type MemoryCache struct {
    mu      sync.RWMutex
    items   map[string]Item
    hits    atomic.Uint64
    misses  atomic.Uint64
}

func NewMemory() *MemoryCache {
    return &MemoryCache{items: make(map[string]Item)}
}

func (c *MemoryCache) Get(key string) (any, error) {
    c.mu.RLock()
    item, ok := c.items[key]
    c.mu.RUnlock()

    if !ok {
        c.misses.Add(1)
        return nil, ErrNotFound
    }
    if item.Expired() {
        c.Delete(key)
        c.misses.Add(1)
        return nil, ErrNotFound
    }
    c.hits.Add(1)
    return item.Value, nil
}

func (c *MemoryCache) Set(key string, value any, ttl time.Duration) error {
    c.mu.Lock()
    defer c.mu.Unlock()

    var expires time.Time
    if ttl > 0 {
        expires = time.Now().Add(ttl)
    }
    c.items[key] = Item{Value: value, ExpiresAt: expires}
    return nil
}

func (c *MemoryCache) Delete(key string) error {
    c.mu.Lock()
    defer c.mu.Unlock()
    delete(c.items, key)
    return nil
}

func (c *MemoryCache) Len() int {
    c.mu.RLock()
    defer c.mu.RUnlock()
    return len(c.items)
}

// Stats 返回命中统计
func (c *MemoryCache) Stats() (hits, misses uint64) {
    return c.hits.Load(), c.misses.Load()
}

// GCExpired 清理过期项
func (c *MemoryCache) GCExpired() int {
    c.mu.Lock()
    defer c.mu.Unlock()

    removed := 0
    for k, v := range c.items {
        if v.Expired() {
            delete(c.items, k)
            removed++
        }
    }
    return removed
}
```

### 4. `lru.go` - LRU 淘汰

```go
package cache_lib

import (
    "container/list"
    "sync"
    "time"
)

// LRU 最近最少使用缓存
type LRU struct {
    mu       sync.Mutex
    capacity int
    items    map[string]*list.Element
    order    *list.List
}

type entry struct {
    key     string
    value   any
    expires time.Time
}

func NewLRU(capacity int) *LRU {
    return &LRU{
        capacity: capacity,
        items:    make(map[string]*list.Element),
        order:    list.New(),
    }
}

func (l *LRU) Get(key string) (any, bool) {
    l.mu.Lock()
    defer l.mu.Unlock()

    elem, ok := l.items[key]
    if !ok {
        return nil, false
    }
    e := elem.Value.(*entry)
    if !e.expires.IsZero() && time.Now().After(e.expires) {
        l.order.Remove(elem)
        delete(l.items, key)
        return nil, false
    }

    l.order.MoveToFront(elem)  // 标记最近使用
    return e.value, true
}

func (l *LRU) Set(key string, value any, ttl time.Duration) {
    l.mu.Lock()
    defer l.mu.Unlock()

    if elem, ok := l.items[key]; ok {
        e := elem.Value.(*entry)
        e.value = value
        if ttl > 0 {
            e.expires = time.Now().Add(ttl)
        }
        l.order.MoveToFront(elem)
        return
    }

    // 容量满,淘汰最久未用
    if l.order.Len() >= l.capacity {
        oldest := l.order.Back()
        if oldest != nil {
            l.order.Remove(oldest)
            delete(l.items, oldest.Value.(*entry).key)
        }
    }

    var expires time.Time
    if ttl > 0 {
        expires = time.Now().Add(ttl)
    }
    elem := l.order.PushFront(&entry{key, value, expires})
    l.items[key] = elem
}

func (l *LRU) Len() int {
    l.mu.Lock()
    defer l.mu.Unlock()
    return l.order.Len()
}
```

### 5. `singleflight.go` - 防缓存击穿

```go
package cache_lib

import "sync"

// SingleFlight 防止多个 goroutine 同时获取同一个 key
// (缓存击穿:同一时刻大量请求穿透到数据库)
type SingleFlight[T any] struct {
    mu    sync.Mutex
    calls map[string]*call[T]
}

type call[T any] struct {
    wg  sync.WaitGroup
    val T
    err error
}

func NewSingleFlight[T any]() *SingleFlight[T] {
    return &SingleFlight[T]{calls: make(map[string]*call[T])}
}

// Do 对同一 key 只执行 fn 一次,其他 goroutine 等待结果
func (sf *SingleFlight[T]) Do(key string, fn func() (T, error)) (T, error) {
    sf.mu.Lock()
    if c, ok := sf.calls[key]; ok {
        sf.mu.Unlock()
        c.wg.Wait()
        return c.val, c.err
    }

    c := &call[T]{}
    c.wg.Add(1)
    sf.calls[key] = c
    sf.mu.Unlock()

    c.val, c.err = fn()

    sf.mu.Lock()
    delete(sf.calls, key)
    sf.mu.Unlock()
    c.wg.Done()

    return c.val, c.err
}
```

### 6. `limiter.go` - 限流

```go
package cache_lib

import (
    "sync"
    "time"
)

// TokenBucket 令牌桶限流
type TokenBucket struct {
    mu       sync.Mutex
    capacity int
    tokens   float64
    refill   float64       // tokens per second
    lastTime time.Time
}

func NewTokenBucket(capacity int, refillPerSec float64) *TokenBucket {
    return &TokenBucket{
        capacity: capacity,
        tokens:   float64(capacity),
        refill:   refillPerSec,
        lastTime: time.Now(),
    }
}

// Allow 尝试获取一个令牌
func (tb *TokenBucket) Allow() bool {
    tb.mu.Lock()
    defer tb.mu.Unlock()

    now := time.Now()
    elapsed := now.Sub(tb.lastTime).Seconds()
    tb.lastTime = now

    // 补充令牌
    tb.tokens += elapsed * tb.refill
    if tb.tokens > float64(tb.capacity) {
        tb.tokens = float64(tb.capacity)
    }

    if tb.tokens >= 1 {
        tb.tokens--
        return true
    }
    return false
}

// AllowN 一次获取 n 个令牌
func (tb *TokenBucket) AllowN(n int) bool {
    tb.mu.Lock()
    defer tb.mu.Unlock()

    now := time.Now()
    elapsed := now.Sub(tb.lastTime).Seconds()
    tb.lastTime = now
    tb.tokens += elapsed * tb.refill
    if tb.tokens > float64(tb.capacity) {
        tb.tokens = float64(tb.capacity)
    }

    if tb.tokens >= float64(n) {
        tb.tokens -= float64(n)
        return true
    }
    return false
}
```

### 7. `cache_test.go`

package cache_lib

import (
    "errors"
    "sync"
    "testing"
    "time"
)

func TestMemoryBasic(t *testing.T) {
    c := NewMemory()

    if err := c.Set("k", "v", time.Minute); err != nil {
        t.Fatal(err)
    }
    v, err := c.Get("k")
    if err != nil {
        t.Fatal(err)
    }
    if v != "v" {
        t.Errorf("want v, got %v", v)
    }

    // 不存在的 key
    if _, err := c.Get("nope"); !errors.Is(err, ErrNotFound) {
        t.Errorf("want ErrNotFound, got %v", err)
    }
}

func TestMemoryTTL(t *testing.T) {
    c := NewMemory()
    c.Set("k", "v", 10*time.Millisecond)

    time.Sleep(50 * time.Millisecond)

    if _, err := c.Get("k"); !errors.Is(err, ErrNotFound) {
        t.Error("want expired")
    }
}

func TestMemoryConcurrent(t *testing.T) {
    c := NewMemory()
    var wg sync.WaitGroup

    for i := 0; i < 100; i++ {
        wg.Add(2)
        go func(i int) {
            defer wg.Done()
            c.Set("k", i, time.Minute)
        }(i)
        go func() {
            defer wg.Done()
            c.Get("k")
        }()
    }
    wg.Wait()
}

func TestLRU(t *testing.T) {
    c := NewLRU(2)
    c.Set("a", 1, 0)
    c.Set("b", 2, 0)
    c.Set("c", 3, 0)        // a 被淘汰

    if _, ok := c.Get("a"); ok {
        t.Error("a should be evicted")
    }
    if _, ok := c.Get("b"); !ok {
        t.Error("b should exist")
    }
    if _, ok := c.Get("c"); !ok {
        t.Error("c should exist")
    }
}

func TestSingleFlight(t *testing.T) {
    sf := NewSingleFlight[int]()
    var calls int32
    var wg sync.WaitGroup

    for i := 0; i < 100; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            _, _ = sf.Do("key", func() (int, error) {
                atomic.AddInt32(&calls, 1)
                time.Sleep(10 * time.Millisecond)
                return 42, nil
            })
        }()
    }
    wg.Wait()

    if atomic.LoadInt32(&calls) != 1 {
        t.Errorf("want 1 call, got %d", calls)
    }
}

func TestTokenBucket(t *testing.T) {
    tb := NewTokenBucket(5, 1.0)

    // 5 个应该全部通过

        }

### 8. 关键点

| 概念 | 用法 |
| --- | --- |
| 接口优先 | `Cache` 接口 + 多种实现 |
| `sync.RWMutex` | 读多写少 |
| `atomic.Uint64` | 无锁计数器 |
| TTL 过期 | `ExpiresAt` + `time.Now()` 比较 |
| LRU | `container/list` 双向链表 |
| SingleFlight | `sync.WaitGroup` 共享结果 |
| 令牌桶 | 时间窗口补充令牌 |
| 线程安全 | 所有方法持有锁 |
| `-race` | 测试必跑,验证无竞态 |
