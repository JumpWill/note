# 02 - 基础语法

## 一、变量

### 1. 三种声明方式

```go
// 1. var 声明(可放在包级或函数内)
var name string = "Go"
var age int = 10

// 2. 类型推断
var name = "Go"           // 自动推断 string
var age = 10              // 自动推断 int

// 3. 短变量声明(仅函数内)
name := "Go"
age := 10

// 4. 批量声明
var (
    host   = "localhost"
    port   = 8080
    debug  = false
)
```

### 2. 默认零值

未显式赋值的变量自动获得零值:

```go
var i int         // 0
var f float64     // 0.0
var b bool        // false
var s string      // "" (空字符串)
var p *int        // nil
var slice []int   // nil
var m map[string]int  // nil
```

### 3. 变量作用域

```go
package main

var global = "全局变量"   // 包级作用域

func main() {
    local := "局部变量"   // 函数级作用域
    println(global, local)

    if true {
        block := "块级变量"
        println(block)   // 仅块内可见
    }
    // println(block)  // 编译错误
}
```

## 二、常量

### 1. const 声明

```go
const Pi = 3.14159
const MaxUsers = 1000

// 批量声明
const (
    StatusOK       = 200
    StatusNotFound = 404
    StatusError    = 500
)

// 类型化常量
const (
    TypedPi   float64 = 3.14159
    TypedName string  = "Go"
)
```

### 2. iota 枚举

```go
const (
    Sunday = iota   // 0
    Monday          // 1
    Tuesday         // 2
    Wednesday
    Thursday
    Friday
    Saturday
)

// 跳跃
const (
    A = iota * 10   // 0
    B              // 10
    C              // 20
    D              // 30
)

// 位掩码
const (
    Read    = 1 << iota  // 1
    Write               // 2
    Execute             // 4
)
```

### 3. 无类型常量

```go
const Untyped = 1000        // 无类型
var i int = Untyped         // OK,自动转 int
var f float64 = Untyped     // OK,自动转 float64
```

## 三、基本数据类型

### 1. 整型

| 类型 | 大小 | 范围 |
| --- | --- | --- |
| `int8` | 1 字节 | -128 ~ 127 |
| `int16` | 2 字节 | -32768 ~ 32767 |
| `int32` (rune) | 4 字节 | -2^31 ~ 2^31-1 |
| `int64` | 8 字节 | -2^63 ~ 2^63-1 |
| `int` | 平台相关(32/64 位) | |
| `uint8` (byte) | 1 字节 | 0 ~ 255 |
| `uint16` | 2 字节 | 0 ~ 65535 |
| `uint32` | 4 字节 | 0 ~ 2^32-1 |
| `uint64` | 8 字节 | 0 ~ 2^64-1 |
| `uint` | 平台相关 | |
| `uintptr` | 平台相关 | 存指针 |

```go
var a int = 42
var b int8 = -128
var c uint8 = 255     // byte
var d int64 = 9_000_000_000  // 下划线分隔
```

### 2. 浮点型

```go
var f1 float32 = 3.14
var f2 float64 = 3.14159265358979

// 科学计数法
var f3 = 1.2e3        // 1200.0
```

**精度问题**:

```go
a := 0.1
b := 0.2
c := a + b
println(c)             // 0.30000000000000004

// 解决:用整数(分)或 decimal 库
```

### 3. 布尔

```go
var ok bool = true
if ok {
    println("yes")
}
```

### 4. 字符串

```go
var s1 = "hello"               // 不可变
var s2 = `多行
字符串`                          // 原生(raw)

fmt.Println(len("hello"))    // 5(字节数)
fmt.Println("你好"[0])        // 228(字节,不是 rune)
```

### 5. byte 与 rune

```go
// byte = uint8,处理 ASCII
// rune = int32,处理 Unicode

s := "你好 Go"
for i, c := range s {
    fmt.Printf("字符 %d: %c (字节位置 %d)\n", i, c, i)  // c 是 rune
}

for i := 0; i < len(s); i++ {
    fmt.Printf("%c ", s[i])   // 按字节遍历,UTF-8 不友好
}
```

### 6. 类型转换

```go
// 显式转换,无隐式
var i int = 42
var f float64 = float64(i)
var u uint = uint(f)

// 字符串 <-> 数字
str := strconv.Itoa(42)            // "42"
n, _ := strconv.Atoi("42")         // 42, error

f64, _ := strconv.ParseFloat("3.14", 64)
b, _ := strconv.ParseBool("true")
```

## 四、复合类型

### 1. 数组

```go
// 固定长度,值类型
var a1 [5]int                    // [0,0,0,0,0]
a2 := [5]int{1, 2, 3, 4, 5}
a3 := [...]int{1, 2, 3, 4, 5}    // 自动推断长度

// 数组是值类型,赋值会拷贝
a := [3]int{1, 2, 3}
b := a
b[0] = 99
fmt.Println(a[0])  // 1(原数组不变)
```

### 2. 切片(slice)

```go
// 动态长度,引用类型
s1 := []int{1, 2, 3}
s2 := make([]int, 0, 10)   // 长度 0,容量 10

// 切片是对底层数组的视图
arr := [5]int{1, 2, 3, 4, 5}
s := arr[1:4]              // [2, 3, 4]
s[0] = 99                  // 修改会反映到原数组
fmt.Println(arr[1])        // 99
```

### 3. map

```go
m := map[string]int{
    "a": 1,
    "b": 2,
}

m2 := make(map[string]int)

// 检查存在
v, ok := m["key"]
if ok {
    fmt.Println(v)
}

// 删除
delete(m, "a")
```

### 4. 结构体

```go
type Point struct {
    X, Y int
}

p := Point{X: 1, Y: 2}
p2 := Point{1, 2}          // 按顺序
fmt.Println(p.X)
```

### 5. 指针

```go
x := 42
p := &x                  // *int
fmt.Println(*p)          // 解引用
*p = 100                  // 修改
```

## 五、运算符

```go

```

### 2. 比较

```go
== != < > <= >=
// 仅对相同类型或可比较类型
// slice、map、函数 不可直接比较
```

### 3. 逻辑

```go
&& || !
```

### 4. 位运算

```go
& | ^ &^   // AND, OR, XOR, AND NOT
<< >>      // 左移, 右移
```

## 六、格式化输出

```go
fmt.Printf("整数: %d\n", 42)
fmt.Printf("浮点: %f\n", 3.14)
fmt.Printf("科学: %e\n", 3.14)
fmt.Printf("字符串: %s\n", "hi")
fmt.Printf("布尔: %t\n", true)
fmt.Printf("指针: %p\n", &x)
fmt.Printf("类型: %T\n", x)
fmt.Printf("百分号: %%\n")

// 宽度与对齐
fmt.Printf("|%5d|\n", 42)          // |   42|
fmt.Printf("|%-5d|\n", 42)         // |42   |
fmt.Printf("|%05d|\n", 42)         // |00042|
fmt.Printf("|%.2f|\n", 3.14159)    // |3.14|

// Sprint 系列
s := fmt.Sprintf("hi %s", "go")
```

## 七、要点速记

- **三种变量声明:`var` 类型声明 / `var` 推断 / `:=` 短声明**
- **零值机制:每种类型都有默认零值**
- **`iota` 常量生成器,块内自增**
- **byte = uint8 处理 ASCII,rune = int32 处理 Unicode**
- **字符串不可变,索引是字节不是字符**
- **数组是值类型(拷贝),切片是引用类型(视图)**
- **类型转换必须显式,无隐式**
- **`strconv` 处理字符串与数字转换**
- **`%T` 打印类型,`%v` 默认格式,`%+v` 带字段名**
- **`%5d` 右对齐宽度 5,`%-5d` 左对齐,`%05d` 补零**
