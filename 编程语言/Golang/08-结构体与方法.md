# 08 - 结构体与方法

## 一、结构体基础

### 1. 定义与初始化

```go
type Point struct {
    X, Y int             // 同行可缩写
}

type User struct {
    ID        int
    Name      string
    Email     string
    CreatedAt time.Time
}

// 多种初始化方式
p1 := Point{X: 1, Y: 2}
p2 := Point{1, 2}                    // 按顺序
p3 := Point{Y: 20}                    // 部分字段,其余零值
p4 := new(Point)                      // *Point,字段全零
p5 := &Point{}                        // 同 new
```

### 2. 字段访问

```go
p := Point{X: 1, Y: 2}
p.X = 10
fmt.Println(p.Y)

// 字段名访问 map
u := User{ID: 1, Name: "alice"}
fmt.Println(u.Name)
```

### 3. 结构体嵌入(匿名字段)

```go
type Base struct {
    ID int
}

type Extended struct {
    Base                       // 嵌入,字段被提升
    Name string
}

e := Extended{
    Base: Base{ID: 1},
    Name: "x",
}
fmt.Println(e.ID)          // 1(提升字段)
fmt.Println(e.Base.ID)     // 1(显式访问)
```

## 二、方法

### 1. 值接收者 vs 指针接收者

```go
type Counter struct {
    n int
}

// 值接收者:不修改原值
func (c Counter) Value() int {
    return c.n
}

// 指针接收者:可修改
func (c *Counter) Increment() {
    c.n++
}

c := Counter{}
c.Increment()
fmt.Println(c.Value())     // 1

// 大结构体用指针接收者(避免拷贝)
type Big struct {
    data [1_000_000]int
}

func (b *Big) Process() { /* ... */ }
```

### 2. 何时用指针接收者

| 场景 | 推荐 |
| --- | --- |
| 方法需要修改接收者 | `*T` |
| 结构体很大(拷贝代价高) | `*T` |
| 一致性(同类型方法不要混用) | 全部 `*T` 或全部 `T` |
| 小结构体,只读 | `T`(简洁) |

### 3. 方法集

类型 `T` 的方法集 = 所有接收者为 `T` 的方法
类型 `*T` 的方法集 = 所有 `T` + 所有 `*T` 的方法

```go
type T struct{}

func (t T) ValueMethod() {}
func (t *T) PtrMethod() {}

t := T{}
t.ValueMethod()         // OK
t.PtrMethod()           // OK(自动取址)

pt := &T{}
pt.ValueMethod()        // OK
pt.PtrMethod()          // OK
```

### 4. 方法值与方法表达式

```go
c := Counter{n: 5}

// 方法值
v := c.Value
fmt.Println(v())         // 5

// 方法表达式
v = Counter.Value
fmt.Println(v(c))        // 5
```

## 三、组合与"继承"

Go **没有继承**,用**嵌入(组合)** 实现类似功能。

```go
type Animal struct {
    Name string
}

func (a *Animal) Speak() string {
    return fmt.Sprintf("%s makes a sound", a.Name)
}

type Dog struct {
    Animal                    // 嵌入
    Breed string
}

// Dog 拥有 Speak 方法(从 Animal 提升)
d := Dog{
    Animal: Animal{Name: "Buddy"},
    Breed:  "Golden",
}
fmt.Println(d.Speak())    // "Buddy makes a sound"

// 覆盖(同名方法)
func (d *Dog) Speak() string {
    return fmt.Sprintf("%s barks", d.Name)
}

fmt.Println(d.Speak())    // "Buddy barks"
```

## 四、JSON 序列化

### 1. struct tag

```go
type User struct {
    ID        int       `json:"id"`
    Name      string    `json:"name"`
    Email     string    `json:"email,omitempty"`
    Password  string    `json:"-"`                // 不序列化
    CreatedAt time.Time `json:"created_at"`
    Internal  string    `json:"internal,string"` // 序列化为字符串
}
```

### 2. 序列化与反序列化

```go
u := User{
    ID:        1,
    Name:      "alice",
    Email:     "a@b.com",
    CreatedAt: time.Now(),
}

// 序列化
data, err := json.Marshal(u)
data, err := json.MarshalIndent(u, "", "  ")  // 缩进

// 反序列化
var u2 User
err = json.Unmarshal(data, &u2)

// 流式编码(适合大文档)
enc := json.NewEncoder(os.Stdout)
enc.Encode(u)

// 流式解码
dec := json.NewDecoder(reader)
var u3 User
dec.Decode(&u3)
```

### 3. 自定义 JSON 编解码

```go
// 实现 json.Marshaler / json.Unmarshaler
type Status int

const (
    Active Status = iota + 1
    Inactive
    Banned
)

func (s Status) MarshalJSON() ([]byte, error) {
    switch s {
    case Active:
        return []byte(`"active"`), nil
    case Inactive:
        return []byte(`"inactive"`), nil
    case Banned:
        return []byte(`"banned"`), nil
    }
    return nil, fmt.Errorf("invalid status: %d", s)
}

func (s *Status) UnmarshalJSON(data []byte) error {
    switch string(data) {
    case `"active"`:
        *s = Active
    case `"inactive"`:
        *s = Inactive
    case `"banned"`:
        *s = Banned
    default:
        return fmt.Errorf("invalid status: %s", data)
    }
    return nil
}
```

### 4. Map 与 Struct 互转

```go
// struct -> map
func ToMap(v any) map[string]any {
    data, _ := json.Marshal(v)
    var m map[string]any
    json.Unmarshal(data, &m)
    return m
}

// map -> struct
func FromMap(m map[string]any, v any) error {
    data, _ := json.Marshal(m)
    return json.Unmarshal(data, v)
}
```

## 五、综合实战:用户配置系统

```go
package main

import (
    "encoding/json"
    "fmt"
    "os"
)

type Address struct {
    City   string `json:"city"`
    Street string `json:"street"`
    Zip    string `json:"zip,omitempty"`
}

type User struct {
    ID      int      `json:"id"`
    Name    string   `json:"name"`
    Email   string   `json:"email"`
    Addr    *Address `json:"address,omitempty"`
    Tags    []string `json:"tags"`
}

func (u *User) AddTag(tag string) {
    u.Tags = append(u.Tags, tag)
}

func (u User) String() string {
    data, _ := json.MarshalIndent(u, "", "  ")
    return string(data)
}

func main() {
    u := &User{
        ID:    1,
        Name:  "alice",
        Email: "alice@example.com",
        Addr:  &Address{City: "Beijing", Street: "Main St"},
    }
    u.AddTag("admin")
    u.AddTag("active")

    fmt.Println(u)

    // 保存到文件
    data, _ := json.MarshalIndent(u, "", "  ")
    os.WriteFile("user.json", data, 0644)

    // 从文件读取
    var loaded User
    data, _ = os.ReadFile("user.json")
    json.Unmarshal(data, &loaded)
    fmt.Printf("loaded: %+v\n", loaded)
}
```

## 六、要点速记

- **结构体值类型,赋值/传参会拷贝**
- **嵌入(匿名字段)实现组合,有字段提升**
- **方法接收者:`T` 值 / `*T` 指针,需修改或大结构体用指针**
- **`*T` 方法集 = `T` 方法集 ∪ `*T` 方法集**
- **JSON tag:`json:"name,omitempty"`、`json:"-"`**
- **`json.Marshal` / `json.Unmarshal` 编解码**
- **`json.Marshaler` / `json.Unmarshaler` 自定义编解码**
- **`json.NewEncoder(w).Encode(v)` 流式编码**
- **Go 无继承,只有组合(嵌入)**

### 3. `errors.go`

```go
package config_lib

import (
    "errors"
    "fmt"
)

var (
    ErrNotFound    = errors.New("config: not found")
    ErrInvalidKey  = errors.New("config: invalid key")
    ErrParseFailed = errors.New("config: parse failed")
)

type KeyError struct {
    Key string
    Err error
}

func (e *KeyError) Error() string {
    return fmt.Sprintf("config key %q: %v", e.Key, e.Err)
}

func (e *KeyError) Unwrap() error {
    return e.Err
}
```

### 4. `config.go` - 嵌套配置

```go
package config_lib

import "time"

// Config 顶层配置,嵌入子配置
type Config struct {
    Server   ServerConfig   `json:"server"`
    Database DBConfig      `json:"database"`
    Logging  LoggingConfig `json:"logging"`
}

type ServerConfig struct {
    Host         string        `json:"host"`
    Port         int           `json:"port"`
    Timeout      time.Duration `json:"timeout"`
    MaxConns     int           `json:"max_conns"`
}

type DBConfig struct {
    URL          string `json:"url"`
    PoolSize     int    `json:"pool_size"`
    SSLMode      string `json:"ssl_mode"`
}

type LoggingConfig struct {
    Level   string `json:"level"`
    Format  string `json:"format"`
    Output  string `json:"output"`
}

// Default 返回默认配置
func Default() *Config {
    return &Config{
        Server: ServerConfig{
            Host:     "0.0.0.0",
            Port:     8080,
            Timeout:  30 * time.Second,
            MaxConns: 1000,
        },
        Database: DBConfig{
            URL:      "postgres://localhost/db",
            PoolSize: 10,
            SSLMode:  "prefer",
        },
        Logging: LoggingConfig{
            Level:  "info",
            Format: "json",
            Output: "stdout",
        },
    }
}

// Validate 校验
func (c *Config) Validate() error {
    if c.Server.Port <= 0 || c.Server.Port > 65535 {
        return &KeyError{Key: "server.port", Err: ErrInvalidKey}
    }
    if c.Database.PoolSize <= 0 {
        return &KeyError{Key: "database.pool_size", Err: ErrInvalidKey}
    }
    return nil
}

// ServerAddr 返回服务端地址
func (c *Config) ServerAddr() string {
    return fmt.Sprintf("%s:%d", c.Server.Host, c.Server.Port)
}
```

### 5. `source.go` - 数据源接口

```go
package config_lib

import "errors"

// Source 数据源抽象
type Source interface {
    Read(key string) (string, error)
    Keys() ([]string, error)
}

// MapSource 内存数据源(从 map)
type MapSource struct {
    data map[string]string
}

func NewMapSource(data map[string]string) *MapSource {
    return &MapSource{data: data}
}

func (m *MapSource) Read(key string) (string, error) {
    v, ok := m.data[key]
    if !ok {
        return "", &KeyError{Key: key, Err: ErrNotFound}
    }
    return v, nil
}

func (m *MapSource) Keys() ([]string, error) {
    keys := make([]string, 0, len(m.data))
    for k := range m.data {
        keys = append(keys, k)
    }
    return keys, nil
}

// EnvSource 环境变量数据源
type EnvSource struct {
    prefix string
}

func NewEnvSource(prefix string) *EnvSource {
    return &EnvSource{prefix: prefix}
}

func (e *EnvSource) Read(key string) (string, error) {
    v := os.Getenv(e.prefix + key)
    if v == "" {
        return "", &KeyError{Key: key, Err: ErrNotFound}
    }
    return v, nil
}

func (e *EnvSource) Keys() ([]string, error) {
    return nil, nil
}
```

### 6. `loader.go` - 多源加载

```go
package config_lib

import (
    "encoding/json"
    "fmt"
    "os"
    "strings"
    "time"
)

// FileSource JSON 文件数据源
type FileSource struct {
    path string
}

func NewFileSource(path string) *FileSource {
    return &FileSource{path: path}
}

func (f *FileSource) Read(key string) (string, error) {
    // 简化:实际可用 viper / koanf 等
    data, err := os.ReadFile(f.path)
    if err != nil {
        if os.IsNotExist(err) {
            return "", &KeyError{Key: key, Err: ErrNotFound}
        }
        return "", fmt.Errorf("read %s: %w", f.path, err)
    }
    var m map[string]any
    if err := json.Unmarshal(data, &m); err != nil {
        return "", fmt.Errorf("%w: %v", ErrParseFailed, err)
    }
    v, ok := m[key]
    if !ok {
        return "", &KeyError{Key: key, Err: ErrNotFound}
    }
    return fmt.Sprint(v), nil
}

func (f *FileSource) Keys() ([]string, error) {
    data, err := os.ReadFile(f.path)
    if err != nil {
        return nil, err
    }
    var m map[string]any
    if err := json.Unmarshal(data, &m); err != nil {
        return nil, err
    }
    keys := make([]string, 0, len(m))
    for k := range m {
        keys = append(keys, k)
    }
    return keys, nil
}

// Loader 多源加载器
type Loader struct {
    sources []Source
}

func NewLoader(sources ...Source) *Loader {
    return &Loader{sources: sources}
}

// Load 从多个源加载,后面的源覆盖前面的
func (l *Loader) Load() (*Config, error) {
    cfg := Default()

    for _, src := range l.sources {
        keys, err := src.Keys()
        if err != nil {
            return nil, err
        }

        for _, key := range keys {
            v, err := src.Read(key)
            if err != nil {
                continue // 跳过不存在的 key
            }
            if err := applyTo(cfg, key, v); err != nil {
                return nil, &KeyError{Key: key, Err: err}
            }
        }
    }

    if err := cfg.Validate(); err != nil {
        return nil, err
    }
    return cfg, nil
}

// applyTo 用字符串值更新 cfg(简化:仅示例几个字段)
func applyTo(c *Config, key, value string) error {
    switch key {
    case "server.host":
        c.Server.Host = value
    case "server.port":
        var p int
        if _, err := fmt.Sscanf(value, "%d", &p); err != nil {
            return ErrInvalidKey
        }
        c.Server.Port = p
    case "database.url":
        c.Database.URL = value
    case "logging.level":
        c.Logging.Level = value
    default:
        // 忽略未知 key
    }
    return nil
}

// Duration 解析持续时间(支持 "30s"、"1m" 等)
func parseDuration(s string) time.Duration {
    if d, err := time.ParseDuration(s); err == nil {
        return d
    }
    return 0
}

var _ = strings.HasPrefix    // 防止 unused 警告
```

### 7. `config_test.go`

```go
package config_lib

import (
    "testing"
    "time"
)

func TestDefault(t *testing.T) {
    cfg := Default()
    if cfg.Server.Port != 8080 {
        t.Errorf("want 8080, got %d", cfg.Server.Port)
    }
}

func TestValidate(t *testing.T) {
    cfg := Default()

    cfg.Server.Port = 0
    if err := cfg.Validate(); err == nil {
        t.Error("want error for invalid port")
    }

    cfg.Server.Port = 8080
    if err := cfg.Validate(); err != nil {
        t.Errorf("want nil, got %v", err)
    }
}

func TestMapSource(t *testing.T) {
    src := NewMapSource(map[string]string{
        "server.host": "example.com",
    })

    v, err := src.Read("server.host")
    if err != nil {
        t.Fatal(err)
    }
    if v != "example.com" {
        t.Errorf("want example.com, got %s", v)
    }

    if _, err := src.Read("nonexistent"); err == nil {
        t.Error("want error for missing key")
    }
}

func TestLoader(t *testing.T) {
    file := NewMapSource(map[string]string{
        "server.host": "0.0.0.0",
        "server.port": "9090",
    })
    env := NewMapSource(map[string]string{
        "server.port": "9999",     // env 覆盖 file
    })

    loader := NewLoader(file, env)
    cfg, err := loader.Load()
    if err != nil {
        t.Fatal(err)
    }
    if cfg.Server.Port != 9999 {
        t.Errorf("want 9999, got %d", cfg.Server.Port)
    }
}

func TestKeyError(t *testing.T) {
    e := &KeyError{Key: "foo", Err: ErrNotFound}
    if e.Error() == "" {
        t.Error("want non-empty error string")
    }
    if e.Unwrap() != ErrNotFound {
        t.Error("want Unwrap to return ErrNotFound")
    }
}
```

### 8. 使用示例

```go
// main.go
package main

import (
    "fmt"
    "log"

    "github.com/user/config_lib"
)

func main() {
    file := config_lib.NewFileSource("config.json")
    env := config_lib.NewEnvSource("APP_")
    loader := config_lib.NewLoader(file, env)

    cfg, err := loader.Load()
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println("server:", cfg.ServerAddr())
    fmt.Println("db:", cfg.Database.URL)
}
```

### 9. 关键点

| 概念 | 用法 |
| --- | --- |
| 结构体嵌入 | `Config` 嵌入 `ServerConfig` 等 |
| JSON tag | `json:"field_name,omitempty"` |
| 自定义错误 | `KeyError` 实现 `Error()` + `Unwrap()` |
| 接口抽象 | `Source` 接口允许多种数据源 |
| 多源覆盖 | Loader 后面的源覆盖前面的 |
| 哨兵错误 | `errors.Is(err, ErrNotFound)` |
| 嵌套配置 | 子配置作为独立结构体 |
