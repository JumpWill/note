# 02 - 基础语法

## 一、八大数据类型

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `nil` | 无效值 | `nil` |
| `boolean` | 布尔 | `true` / `false` |
| `number` | 双精度浮点 | `42` `3.14` |
| `string` | 字符串 | `"hello"` |
| `function` | 函数 | `function() end` |
| `userdata` | C 数据结构 | (C 扩展) |
| `thread` | 协程 | `coroutine.create()` |
| `table` | 表 | `{}` |

### 1. type() 获取类型

```lua
print(type(nil))         -- "nil"
print(type(true))        -- "boolean"
print(type(42))          -- "number"
print(type("hi"))        -- "string"
print(type(print))       -- "function"
print(type({}))          -- "table"
print(type(coroutine.create(print)))  -- "thread"
```

## 二、nil

唯一值 `nil`,表示"无值"。

```lua
local name = nil

-- if nil 为假,if 0 为真
if name then
    print("not nil")
else
    print("this is nil")
end

-- 访问不存在的字段
local t = {a = 1}
print(t["b"])        -- nil

-- 删除变量
name = nil
```

## 三、boolean

```lua
local ok = true
local fail = false

-- 注意:只有 nil 和 false 为假
if 0 then print("0 is truthy") end         -- 真
if "" then print("empty is truthy") end    -- 真
```

## 四、number

### 1. 双精度浮点

```lua
local pi = 3.14
local n = 42
local big = 1.5e10        -- 科学计数法

-- 进制
local hex = 0xff           -- 255
local bin = 0b1010         -- 10
```

### 2. 取整

```lua
print(math.floor(3.99))   -- 3
print(math.ceil(3.14))    -- 4

-- LuaJIT 支持 dual-number(整数 + 浮点)
local i = 100              -- 默认整数
local f = 3.14             -- 浮点
```

### 3. 数学运算

```lua
print(math.pi)             -- 3.1415926535898
print(math.huge)           -- inf
print(math.sin(math.pi/2)) -- 1.0
print(math.random(1, 100)) -- 1-100

-- 标准库函数
print(math.max(1, 2, 3))  -- 3
print(math.min(1, 2, 3))  -- 1
print(math.floor(3.7))     -- 3
print(math.ceil(3.2))      -- 4
print(math.modf(3.14))     -- 3.0  0.14
```

## 五、string

### 1. 三种字面量

```lua
local s1 = 'hello'              -- 单引号
local s2 = "hello"              -- 双引号(同义)
local s3 = [["hello\n"]]        -- 长字符串(不转义)
local s4 = [=[hello [=[nested]]]=]  -- 自定义分隔符(可嵌套)
```

### 2. 字符串连接

```lua
-- .. 是字符串连接运算符
print("Hello " .. "World")     -- "Hello World"
print(0 .. 1)                  -- "01"(数字自动转字符串)

-- 性能:循环中拼接用 table.concat,不用 ..
local parts = {}
for i = 1, 100 do
    table.insert(parts, "item" .. i)
end
local result = table.concat(parts, ",")
```

### 3. 强制类型转换

```lua
local n = tonumber("42")         -- 42
local n2 = tonumber("abc")       -- nil
local s = tostring(42)           -- "42"
```

### 4. string.format

```lua
local s = string.format("%s-%d-%.2f", "hello", 42, 3.14)
-- "hello-42-3.14"

-- 常用格式符
-- %s 字符串
-- %d 整数
-- %f 浮点(默认 6 位)
-- %.2f 保留 2 位
-- %x 十六进制
-- %e 科学计数法

-- 宽度与对齐
print(string.format("[%10s]", "hi"))      -- "[        hi]"
print(string.format("[%-10s]", "hi"))     -- "[hi        ]"
print(string.format("[%05d]", 42))        -- "[00042]"
```

### 5. 字符串特性

```lua
-- 不可变:任何"修改"都创建新字符串
local s = "hello"
-- s[1] = "H"    -- 不支持直接修改

-- Lua 字符串 intern(内化):相同字符串只存一份
local a = "hello"
local b = "hello"
print(a == b)               -- true
-- 内部用 hash 比较,O(1)
```

### 6. 字符串库

```lua
local s = "Hello,World"

print(string.len(s))              -- 11
print(string.sub(s, 1, 5))        -- "Hello"
print(string.upper(s))            -- "HELLO,WORLD"
print(string.lower(s))            -- "hello,world"
print(string.find(s, "World"))    -- 7    11
print(string.gsub(s, "l", "L"))    -- "HeLLo,World"  2
print(string.rep("ab", 3))        -- "ababab"
print(string.format("%d", 42))    -- "42"
print(string.byte("A"))           -- 65
print(string.char(65))            -- "A"
print(string.match(s, "(%w+),(%w+)"))  -- "Hello"  "World"

-- 常用模式
-- %w 字母数字     %d 数字     %s 空白
-- %a 字母         %p 标点     %u 大写
-- %l 小写         %c 控制字符
```

## 六、表达式与运算符

### 1. 算术

```lua
+ - * / %   ^   -
-- 加 减 乘 除 取模 幂 一元负
print(10 % 3)      -- 1
print(2 ^ 10)      -- 1024
```

### 2. 关系

```lua
< > <= >= == ~=
-- ~= 是"不等于"
-- 类型不同时直接 false(不报错)
print(1 == "1")     -- false
print(nil == nil)   -- true
print(1 ~= 2)       -- true
```

### 3. 逻辑

```lua
and or not

-- 短路求值
print(false and error("never"))   -- false(不执行 error)
print(true or error("never"))     -- true(不执行 error)

-- and/or 返回第一个能确定结果的 operand
print(0 and 5)        -- 5(0 真,返回右)
print(nil and 5)      -- nil(左假,返回左)
print(1 or 5)         -- 1(左真,返回左)

-- 三元运算符写法:(cond) and a or b
local age = 20
local status = (age >= 18) and "adult" or "minor"
```

### 4. 字符串

```lua
..      -- 字符串连接
```

### 5. 长度

```lua
#       -- 取字符串 / 表的长度
print(#"hello")    -- 5
print(#{1,2,3})    -- 3
```

### 6. 优先级(从高到低)

```
^ (幂)
not  - (一元)
*  /  %
+  -
..
<  >  <=  >=  ==  ~=
and
or
```

### 7. 没有的运算符

```lua
-- 没有位运算(& | ^ ~ << >>)
-- 没有 += 等复合赋值
a += 1   -- ❌ 语法错误

-- 没有三元 a ? b : c
local x = (cond) and a or b   -- 替代写法
```

## 七、要点速记

- **8 种数据类型:`nil / boolean / number / string / function / userdata / thread / table`**
- **`type()` 返回类型字符串**
- **只有 `nil` 和 `false` 为假,其他都真**
- **字符串不可变,intern 机制使相等比较 O(1)**
- **`..` 连接字符串,循环拼接用 `table.concat` 性能更好**
- **`string.format` 用 `%s / %d / %f` 等**
- **逻辑运算 `and / or` 短路且返回 operand**
- **没有位运算、没有 `+=`、没有三元**
- **`#` 取字符串 / 表长度**
