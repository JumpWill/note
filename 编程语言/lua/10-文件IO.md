# 10 - 文件 IO

Lua 文件操作分两种:**简单模式**和**完全模式**。

## 一、打开模式

| 模式 | 描述 |
| --- | --- |
| `r` | 只读(文件必须存在) |
| `w` | 只写(存在清空,不存在创建) |
| `a` | 追加(末尾写) |
| `r+` | 读写(必须存在) |
| `w+` | 读写(清空) |
| `a+` | 追加 + 读 |
| `b` | 二进制模式(可与上面组合,如 `rb` / `wb`) |

## 二、简单模式

用 `io.read / io.write / io.input / io.output` 操作**当前文件**。

```lua
-- 读取整个文件
io.input("test.lua")             -- 设置当前输入文件
local content = io.read("*a")    -- 读取全部
print(content)

-- 写文件
io.output("out.txt")              -- 设置当前输出文件
io.write("hello\n")
io.write("world\n")
io.close()                        -- 关闭当前文件

-- 标准输入(io.read 默认从 stdin)
local line = io.read()
```

### io.read 模式

| 模式 | 描述 |
| --- | --- |
| `"*a"` | 读全部内容 |
| `"*l"` 或 `"*line"` | 读一行(默认) |
| `"*n"` 或 `"*number"` | 读数字 |
| `n` | 读 n 个字符 |
| `0` | 不读,返回空串 |

```lua
io.input("data.txt")
local all = io.read("*a")          -- 全部
local line = io.read("*l")         -- 一行
local num = io.read("*n")          -- 数字
local chunk = io.read(100)         -- 100 字符
```

## 三、完全模式

`io.open` 返回文件句柄,用 `:方法()` 操作,**可同时处理多个文件**。

```lua
-- 读取
local f = io.open("test.lua", "r")
local first_line = f:read("*l")
local all = f:read("*a")
f:close()

-- 写入
local out = io.open("out.txt", "w")
out:write("Hello\n")
out:write("World\n")
out:close()

-- 追加
local log = io.open("app.log", "a")
log:write("[INFO] started\n")
log:close()

-- 同一时间操作多个文件
local src = io.open("input.txt", "r")
local dst = io.open("output.txt", "w")

for line in src:lines() do
    dst:write(line:upper() .. "\n")
end

src:close()
dst:close()
```

### 文件方法

| 方法 | 作用 |
| --- | --- |
| `:read(...)` | 读 |
| `:write(...)` | 写 |
| `:lines()` | 迭代器,逐行 |
| `:seek(whence, offset)` | 设置/获取位置 |
| `:flush()` | 刷新缓冲 |
| `:close()` | 关闭 |
| `:setvbuf(mode, size)` | 设置缓冲模式 |

### seek 用法

```lua
local f = io.open("file.txt", "r")

print(f:seek())              -- 返回当前位置(默认从文件头开始)
f:seek("set", 0)            -- 定位到文件头
f:seek("cur", 10)           -- 从当前位置 +10
f:seek("end")               -- 定位到文件尾(返回文件大小)
f:seek("end", -100)         -- 文件尾前 100 字节

f:close()
```

## 四、io.lines

```lua
-- 简单模式:从当前输入文件读
for line in io.lines() do          -- 默认 stdin
    print(line)
end

for line in io.lines("file.txt") do  -- 指定文件
    print(line)
end

-- 完全模式
local f = io.open("file.txt", "r")
for line in f:lines() do
    print(line)
end
f:close()
```

## 五、二进制文件

```lua
-- 写二进制
local f = io.open("data.bin", "wb")
f:write("hello")     -- 字符串即字节
f:close()

-- 读二进制
local f = io.open("data.bin", "rb")
local bytes = f:read("*a")   -- 字节字符串
print(#bytes)
f:close()
```

## 六、综合实战:配置加载器

### 1. 项目结构

```text
config_loader/
├── main.lua
└── src/
    └── ini.lua
```

### 2. `src/ini.lua`

```lua
local M = {}

-- 解析 INI 格式
-- [section]
-- key = value
-- ;comment

function M.parse(path)
    local cfg = {}
    local cur_section = nil

    local f = io.open(path, "r")
    if not f then
        return nil, "open failed: " .. path
    end

    for line in f:lines() do
        -- 去除注释和空白
        line = line:gsub(";.*$", ""):gsub("^%s+", ""):gsub("%s+$", "")

        if line == "" then
            -- 空行
        elseif line:match("^%[.-%]$") then
            -- [section]
            cur_section = line:match("^%[(.-)%]$")
            cfg[cur_section] = cfg[cur_section] or {}
        elseif cur_section then
            -- key = value
            local k, v = line:match("^([^=]+)%s*=%s*(.+)$")
            if k then
                cfg[cur_section][k:match("^%s*(.-)%s*$")] = v
            end
        end
    end

    f:close()
    return cfg
end

-- 写入 INI
function M.write(path, cfg)
    local f = io.open(path, "w")
    if not f then return false end

    -- 默认节在前
    if cfg._default then
        for k, v in pairs(cfg._default) do
            f:write(string.format("%s = %s\n", k, v))
        end
        f:write("\n")
    end

    for section, opts in pairs(cfg) do
        if section ~= "_default" then
            f:write(string.format("[%s]\n", section))
            for k, v in pairs(opts) do
                f:write(string.format("%s = %s\n", k, v))
            end
            f:write("\n")
        end
    end

    f:close()
    return true
end

-- 嵌套访问: cfg.server.host
function M.get(cfg, dotted)
    local keys = {}
    for k in dotted:gmatch("[^.]+") do
        table.insert(keys, k)
    end

    local v = cfg
    for _, k in ipairs(keys) do
        v = v and v[k]
        if not v then return nil end
    end
    return v
end

return M
```

### 3. `main.lua`

```lua
package.path = "./src/?.lua;" .. package.path

local ini = require("ini")

-- 写示例
local cfg = {
    _default = {timeout = "30", debug = "false"},
    server = {host = "0.0.0.0", port = "8080"},
    database = {url = "postgres://...", pool = "10"},
}

ini.write("config.ini", cfg)

-- 读
local parsed = ini.parse("config.ini")
print(ini.get(parsed, "server.host"))    -- "0.0.0.0"
print(ini.get(parsed, "server.port"))    -- "8080"
print(ini.get(parsed, "server.missing")) -- nil
```

### 4. 生成的 `config.ini`

```ini
timeout = 30
debug = false

[server]
host = 0.0.0.0
port = 8080

[database]
url = postgres://...
pool = 10
```

## 七、要点速记

- **简单模式:`io.input / io.read / io.write / io.output`**(单文件)
- **完全模式:`io.open + 文件:方法()`**(多文件)
- **`io.lines(path)`** 自动关闭的迭代器
- **`a` 模式追加(EOF 保留),`w` 清空**
- **`b` 二进制模式必须加**,否则 Windows 换行转换
- **`f:seek("end")`** 可获取文件大小
- **`io.tmpfile()`** 自动删除的临时文件
- **错误处理用 `pcall` 或检查 `f` 是否 nil**
