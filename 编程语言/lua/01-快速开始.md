# 01 - 快速开始

## 一、安装

### 1. macOS

```bash
brew install lua
brew install luarocks    # 包管理
```

### 2. Ubuntu / Debian

```bash
sudo apt install lua5.3 lua5.3-dev luarocks
```

### 3. CentOS / RHEL

```bash
sudo yum install lua lua-devel luarocks
```

### 4. 源码

```bash
curl -L -R -O https://www.lua.org/ftp/lua-5.4.6.tar.gz
tar zxf lua-5.4.6.tar.gz
cd lua-5.4.6
make all test
sudo make install
```

### 5. 验证

```bash
lua -v
# Lua 5.4.6  Copyright (C) 1994-2023 Lua.org, PUC-Rio
```

## 二、第一个程序

### 1. 文件方式



```lua
#!/usr/bin/env lua
```


## 五、变量

### 1. 全局变量

```lua
-- 默认全局,删除即置 nil
global_var = 123
name = "lua"

-- 删除全局变量
name = nil
```

### 2. 局部变量

```lua
-- 用 local 声明,作用域到块结束
local local_var = 123
local x, y = 1, 2

-- 块作用域
do
    local temp = 10
    print(temp)
end
-- print(temp)   -- nil,已离开作用域
```

### 3. 多重赋值

```lua
local a, b, c = 1, 2, 3
local x, y = y, x       -- 交换 x,y

-- 多返回值
local a, b, c = foo()   -- foo 返回多个值

-- 表解构
local t = {10, 20, 30}
local x, y, z = unpack(t)
```

### 4. 变量命名规范

```lua
-- 局部变量:小写 + 下划线
local user_count = 0
local max_size = 100

-- 常量:全大写
local MAX_SIZE = 1000
local PI = 3.14159

-- 模块内私有:_ 前缀
local _private_helper = function() end

-- 模块对外:_M 或 M
local M = {}
```

## 六、第一个完整程序

```lua
-- greet.lua
local M = {}

function M.greet(name)
    return "Hello, " .. name .. "!"
end

-- 测试
if arg and arg[0] == "greet.lua" then
    print(M.greet("World"))
end

return M
```

```bash
lua greet.lua
# Hello, World!

-- 或从其他脚本
local g = require("greet")
print(g.greet("Lua"))
# Hello, Lua!
```

## 七、常用命令行选项

```bash
lua -v              # 版本
lua -e "code"       # 执行命令
lua -i              # 交互模式
lua -l module       # 加载库
lua -               # 从 stdin 读取
lua -p              # 跳过编译优化(调试用)
```

```bash
# 调试运行
lua -e "debug.sethook(print, 'crl')" main.lua

# 设置 _PROMPT
lua -e "_PROMPT='lua> '" -i
```

## 八、要点速记

- **注释:`--` 单行,`--[[ ]]` 多行,`--[==[ ]==]` 嵌套多行**
- **关键字 23 个,全部小写**
- **默认全局变量,`local` 声明局部**
- **块作用域:do ... end / function / if / while / for**
- **多重赋值:`local a, b = 1, 2` / `a, b = b, a`**
- **标识符约定:局部小写、常量大写、模块私有加 `_`**
- **`lua` REPL、`luac` 编译器、`luajit` JIT 版**
