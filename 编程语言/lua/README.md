## 速查表

| 概念 | 一句话 |
| --- | --- |
| table | Lua 唯一的复合类型,同时是数组和哈希表 |
| metatable | 给 table 附加行为(运算符重载、OOP) |
| __index | 元方法,table 字段查找 fallback,OOP 基础 |
| 协程 | Lua 的协作式多任务,类似 Python generator |
| require | 加载模块,带缓存,路径搜索 package.path |
| pcall | protected call,捕获错误的函数调用 |
| collectgarbage | 手动控制 GC(增量标记清除) |
| _ENV / _G | 全局环境(Lua 5.2+) |
| string intern | 相同字符串只存一份,O(1) 相等比较 |

## 常用工具

| 工具 | 用途 |
| --- | --- |
| `lua` | REPL |
| `luac` | 字节码编译器 |
| `lua -e "code"` | 执行命令 |
| `lua -l module` | 加载库 |
| `lua -i` | 交互模式 |
| `luajit` | 高性能 JIT 版本 |
| `lua-rocks` | 包管理(LuaRocks) |
| `ZeroBrane Studio` | IDE |
