# 11 - 并发编程

Rust 通过所有权和类型系统在**编译期**防止数据竞争。两种并发模型:线程 + channel(OS 线程)、async/await(协程)。

## 一、线程基础

### 1. 创建线程

```rust
use std::thread;
use std::time::Duration;

fn main() {
    // 主线程
    for i in 1..=3 {
        println!("main: {}", i);
        thread::sleep(Duration::from_millis(100));
    }

    // 子线程
    let handle = thread::spawn(|| {
        for i in 1..=5 {
            println!("child: {}", i);
            thread::sleep(Duration::from_millis(100));
        }
    });

    handle.join().unwrap(); // 等待子线程完成
}
```

### 2. `move` 闭包

```rust
use std::thread;

fn main() {
    let data = vec![1, 2, 3];

    let handle = thread::spawn(move || {
        println!("{:?}", data);
    });

    handle.join().unwrap();
    // data 已 move
}
```

### 3. 线程句柄

```rust
use std::thread;

fn main() {
    let mut handles = vec![];

    for i in 0..5 {
        let h = thread::spawn(move || {
            println!("线程 {} 开始", i);
            i * 2  // 线程返回值
        });
        handles.push(h);
    }

    let results: Vec<i32> = handles
        .into_iter()
        .map(|h| h.join().unwrap())
        .collect();

    println!("结果: {:?}", results);
}
```

## 二、消息传递 (channel)

### 1. mpsc - 多生产者单消费者

```rust
use std::sync::mpsc;
use std::thread;
use std::time::Duration;

fn main() {
    let (tx, rx) = mpsc::channel();

    thread::spawn(move || {
        let vals = vec![
            String::from("hi"),
            String::from("from"),
            String::from("the"),
            String::from("thread"),
        ];

        for val in vals {
            tx.send(val).unwrap();
            thread::sleep(Duration::from_millis(100));
        }
    });

    for received in rx {
        println!("got: {}", received);
    }
}
```

### 2. 多生产者

```rust
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();

    for i in 0..3 {
        let tx = tx.clone();
        thread::spawn(move || {
            for j in 0..3 {
                tx.send(format!("线程 {} 消息 {}", i, j)).unwrap();
            }
        });
    }

    drop(tx); // 关闭原始 tx,否则 rx 永不结束

    for msg in rx {
        println!("{}", msg);
    }
}
```

### 3. 同步 channel

```rust
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::sync_channel(3); // 缓冲区 3

    let h = thread::spawn(move || {
        for i in 0..10 {
            tx.send(i).unwrap(); // 缓冲区满时阻塞
            println!("sent: {}", i);
        }
    });

    for msg in rx {
        println!("got: {}", msg);
    }

    h.join().unwrap();
}
```

## 三、共享状态 (Mutex + Arc)

### 1. Mutex 基础

```rust
use std::sync::Mutex;

fn main() {
    let m = Mutex::new(5);

    {
        let mut num = m.lock().unwrap();
        *num += 1;
    } // 锁自动释放

    println!("{:?}", m);
}
```

### 2. Arc + Mutex 多线程

```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let mut handles = vec![];

    for _ in 0..10 {
        let counter = Arc::clone(&counter);
        let h = thread::spawn(move || {
            let mut n = counter.lock().unwrap();
            *n += 1;
        });
        handles.push(h);
    }

    for h in handles {
        h.join().unwrap();
    }

    println!("最终: {}", *counter.lock().unwrap());
}
```

### 3. RwLock - 读写锁

```rust
use std::sync::{Arc, RwLock};
use std::thread;

fn main() {
    let data = Arc::new(RwLock::new(vec![1, 2, 3]));
    let mut handles = vec![];

    // 多个读
    for i in 0..3 {
        let data = Arc::clone(&data);
        let h = thread::spawn(move || {
            let r = data.read().unwrap();
            println!("reader {}: {:?}", i, *r);
        });
        handles.push(h);
    }

    // 一个写
    let data = Arc::clone(&data);
    let h = thread::spawn(move || {
        let mut w = data.write().unwrap();
        w.push(4);
    });
    handles.push(h);

    for h in handles {
        h.join().unwrap();
    }
}
```

### 4. 死锁避免

```rust
// 原则:
// 1. 锁顺序固定
// 2. 持锁时间尽量短
// 3. 避免在持锁时调用户代码

use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let a = Arc::new(Mutex::new(0));
    let b = Arc::new(Mutex::new(0));

    // 两个线程都按 a -> b 顺序加锁
    let a1 = Arc::clone(&a);
    let b1 = Arc::clone(&b);
    let h1 = thread::spawn(move || {
        let _ga = a1.lock().unwrap();
        std::thread::sleep(std::time::Duration::from_millis(50));
        let _gb = b1.lock().unwrap();
    });

    let a2 = Arc::clone(&a);
    let b2 = Arc::clone(&b);
    let h2 = thread::spawn(move || {
        let _ga = a2.lock().unwrap();
        std::thread::sleep(std::time::Duration::from_millis(50));
        let _gb = b2.lock().unwrap();
    });

    h1.join().unwrap();
    h2.join().unwrap();
}
```

## 四、`Send` 与 `Sync`

### 1. Send

`Send` 表示类型的所有权可以**在线程间转移**。

```rust
// 基本类型都 Send
let n = 42;
let h = std::thread::spawn(move || println!("{}", n));

// Rc<T> 不 Send
// use std::rc::Rc;
// let r = Rc::new(5);
// std::thread::spawn(move || println!("{}", r)); // ❌

// Arc<T> Send
use std::sync::Arc;
let a = Arc::new(5);
let h = std::thread::spawn(move || println!("{}", a));
```

### 2. Sync

`Sync` 表示 `&T` 可以**在多线程间共享**。

```rust
// 基本类型都 Sync
// Mutex<T> Sync(Mutex 内部保证同步)

// Rc<T> 不 Sync
// Arc<T> Sync
```

### 3. 手动实现(unsafe)

```rust
struct MyData {
    value: i32,
}

// 自动 Send + Sync(因为 i32 Send + Sync)
unsafe impl Send for MyData {}
unsafe impl Sync for MyData {}
```

## 五、原子操作

```rust
use std::sync::atomic::{AtomicUsize, Ordering};
use std::sync::Arc;
use std::thread;

fn main() {
    let counter = Arc::new(AtomicUsize::new(0));
    let mut handles = vec![];

    for _ in 0..10 {
        let c = Arc::clone(&counter);
        let h = thread::spawn(move || {
            for _ in 0..1000 {
                c.fetch_add(1, Ordering::Relaxed);
            }
        });
        handles.push(h);
    }

    for h in handles {
        h.join().unwrap();
    }

    println!("最终: {}", counter.load(Ordering::Relaxed));
}
```

**Ordering**:

| 模式 | 含义 |
| --- | --- |
| `Relaxed` | 无顺序保证 |
| `Acquire` | 后续读能看到之前所有写 |
| `Release` | 之前所有写对后续读可见 |
| `AcqRel` | 同时 Acquire + Release |
| `SeqCst` | 全序(最强保证,最慢) |

## 六、屏障与一次性

### 1. Barrier - 等待所有线程

```rust
use std::sync::{Arc, Barrier};
use std::thread;

fn main() {
    let n = 5;
    let barrier = Arc::new(Barrier::new(n));
    let mut handles = vec![];

    for i in 0..n {
        let b = Arc::clone(&barrier);
        let h = thread::spawn(move || {
            println!("线程 {} 到达屏障", i);
            b.wait();
            println!("线程 {} 通过屏障", i);
        });
        handles.push(h);
    }

    for h in handles {
        h.join().unwrap();
    }
}
```

### 2. Once - 只执行一次

```rust
use std::sync::Once;

static INIT: Once = Once::new();

fn init() {
    INIT.call_once(|| {
        println!("初始化中...");
    });
}

fn main() {
    init();
    init(); // 不会再执行
}
```

## 七、Async/Await(协程)

### 1. 入门

```rust
// Cargo.toml: tokio = { version = "1", features = ["full"] }

use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let h1 = tokio::spawn(async {
        sleep(Duration::from_secs(1)).await;
        println!("task 1 done");
        1
    });

    let h2 = tokio::spawn(async {
        sleep(Duration::from_secs(2)).await;
        println!("task 2 done");
        2
    });

    let (r1, r2) = tokio::join!(h1, h2);
    println!("{:?} {:?}", r1, r2);
}
```

### 2. async 通道

```rust
use tokio::sync::mpsc;

#[tokio::main]
async fn main() {
    let (tx, mut rx) = mpsc::channel(32);

    tokio::spawn(async move {
        for i in 0..5 {
            tx.send(i).await.unwrap();
        }
    });

    while let Some(v) = rx.recv().await {
        println!("got: {}", v);
    }
}
```

### 3. async Mutex(注意!)

```rust
use tokio::sync::Mutex;
use std::sync::Arc;

#[tokio::main]
async fn main() {
    let data = Arc::new(Mutex::new(0));

    let h1 = {
        let d = Arc::clone(&data);
        tokio::spawn(async move {
            let mut n = d.lock().await;
            *n += 1;
        })
    };

    let h2 = {
        let d = Arc::clone(&data);
        tokio::spawn(async move {
            let mut n = d.lock().await;
            *n += 2;
        })
    };

    let _ = tokio::join!(h1, h2);
    println!("{}", *data.lock().await);
}
```

**`std::sync::Mutex` vs `tokio::sync::Mutex`**:
- `std::Mutex` 跨 `.await` 会死锁
- 异步上下文必须用 `tokio::sync::Mutex`

### 4. Future 与 Stream

```rust
use tokio::time::{sleep, Duration};

async fn fetch(n: u32) -> u32 {
    sleep(Duration::from_millis(100 * n)).await;
    n * 10
}

#[tokio::main]
async fn main() {
    // join:等待所有 future
    let (a, b, c) = tokio::join!(fetch(1), fetch(2), fetch(3));
    println!("{} {} {}", a, b, c);

    // select:等待第一个完成
    tokio::select! {
        v = fetch(1) => println!("first: {}", v),
        v = fetch(2) => println!("first: {}", v),
        _ = sleep(Duration::from_millis(50)) => println!("timeout"),
    }
}
```

## 八、线程局部存储

```rust
use std::cell::RefCell;
use std::thread;

thread_local! {
    static COUNTER: RefCell<u32> = RefCell::new(0);
}

fn main() {
    COUNTER.with(|c| *c.borrow_mut() += 1);

    let h = thread::spawn(|| {
        COUNTER.with(|c| *c.borrow_mut() = 100);
    });

    h.join().unwrap();

    COUNTER.with(|c| println!("主线程: {}", *c.borrow())); // 1
}
```

## 九、要点速记

- **线程创建:`thread::spawn(closure)`,返回 `JoinHandle`**
- **`move` 闭包强制转移所有权,跨线程必备**
- **`mpsc::channel`**:多生产者单消费者消息传递**
- **`Arc<Mutex<T>>`**:多线程共享可变数据**
- **`Send`**:所有权可在线程间转移;`Sync`:`&T` 可多线程共享**
- **`Rc<T>` 非 Send/Sync,只能单线程**
- **原子操作 `AtomicUsize` 等,无锁,注意 `Ordering`**
- **`async/await`** 协程模型,需 `#[tokio::main]` 入口
- **异步锁 `tokio::sync::Mutex` 跨 `.await` 不会死锁**
- **`tokio::join!`** 并发等待,`select!`** 取第一个**
- **`tokio::spawn`** 在运行时上调度任务**
- **`std::sync::Mutex` 不能跨 `.await` 持有,会死锁**

```rust
use std::fmt;

pub trait Job: Send + 'static {
    type Output: Send + 'static;
    fn run(self: Box<Self>) -> Self::Output;
    fn name(&self) -> &str { "job" }
}

impl fmt::Debug for dyn Job {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(self.name())
    }
}

/// 示例任务:抓取 URL 长度
pub struct FetchJob {
    pub url: String,
}

impl Job for FetchJob {
    type Output = usize;

    fn run(self: Box<Self>) -> usize {
        println!("[fetch] {}", self.url);
        // 实际:reqwest / ureq
        self.url.len()
    }

    fn name(&self) -> &str { "fetch" }
}
```

### 4. `src/result.rs` - 结果收集

```rust
use std::sync::mpsc::{Receiver, Sender};

pub type JobResult<O> = (String, O);

pub struct ResultCollector<O> {
    tx: Sender<JobResult<O>>,
    rx: Receiver<JobResult<O>>,
}

impl<O> ResultCollector<O> {
    pub fn new() -> Self {
        let (tx, rx) = std::sync::mpsc::channel();
        Self { tx, rx }
    }

    pub fn sender(&self) -> Sender<JobResult<O>> {
        self.tx.clone()
    }

    pub fn drain(self) -> Vec<JobResult<O>> {
        self.rx.iter().collect()
    }
}

impl<O> Default for ResultCollector<O> {
    fn default() -> Self {
        Self::new()
    }
}
```

### 5. `src/shutdown.rs` - 关闭信号

```rust
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;

#[derive(Clone, Default)]
pub struct Shutdown {
    flag: Arc<AtomicBool>,
}

impl Shutdown {
    pub fn new() -> Self {
        Self { flag: Arc::new(AtomicBool::new(false)) }
    }

    pub fn is_shutdown(&self) -> bool {
        self.flag.load(Ordering::SeqCst)
    }

    pub fn trigger(&self) {
        self.flag.store(true, Ordering::SeqCst);
    }
}
```

### 6. `src/pool.rs` - 工作池

```rust
use std::sync::{mpsc, Arc, Mutex};
use std::thread;

use crate::job::Job;
use crate::shutdown::Shutdown;

type JobSender = mpsc::Sender<Box<dyn Job<Output = ()>>>;

pub struct ThreadPool {
    workers: Vec<Worker>,
    sender: Option<JobSender>,
    shutdown: Shutdown,
}

impl ThreadPool {
    pub fn new(size: usize, shutdown: Shutdown) -> Self {
        assert!(size > 0);

        let (tx, rx) = mpsc::channel::<Box<dyn Job<Output = ()>>>();
        let rx = Arc::new(Mutex::new(rx));

        let workers = (0..size)
            .map(|i| Worker::new(i, Arc::clone(&rx)))
            .collect();

        Self { workers, sender: Some(tx), shutdown }
    }

    pub fn execute<J: Job<Output = ()>>(&self, job: J) {
        let job = Box::new(job);
        if let Some(tx) = &self.sender {
            tx.send(job).expect("pool is closed");
        }
    }

    pub fn shutdown_signal(&self) -> Shutdown {
        self.shutdown.clone()
    }

    pub fn worker_count(&self) -> usize {
        self.workers.len()
    }
}

impl Drop for ThreadPool {
    fn drop(&mut self) {
        // 1. 关闭 sender,worker 收到断开信号后退出
        drop(self.sender.take());

        // 2. 触发关闭标志(用于 sleep 等阻塞操作)
        self.shutdown.trigger();

        // 3. join 所有 worker
        for w in &mut self.workers {
            if let Some(h) = w.handle.take() {
                let _ = h.join();
            }
        }
    }
}

struct Worker {
    id: usize,
    handle: Option<thread::JoinHandle<()>>,
}

impl Worker {
    fn new(id: usize, receiver: Arc<Mutex<mpsc::Receiver<Box<dyn Job<Output = ()>>>>>) -> Self {
        let handle = thread::spawn(move || loop {
            let job = receiver.lock().unwrap().recv();
            match job {
                Ok(job) => {
                    println!("[worker {}] 收到任务", id);
                    job.run();
                }
                Err(_) => {
                    println!("[worker {}] 关闭", id);
                    break;
                }
            }
        });

        Self { id, handle: Some(handle) }
    }
}
```

### 8. `src/main.rs`

```rust
use std::time::Duration;
use web_crawler::{FetchJob, Job, ResultCollector, Shutdown, ThreadPool};

fn main() {
    let shutdown = Shutdown::new();
    let pool = ThreadPool::new(4, shutdown.clone());

    let collector = ResultCollector::new();
    let result_tx = collector.sender();

    let urls = vec![
        "https://example.com",
        "https://example.org",
        "https://example.net",
        "https://example.io",
        "https://rust-lang.org",
    ];

    // 提交任务
    for url in urls {
        let tx = result_tx.clone();
        pool.execute(FetchJob {
            url: url.to_string(),
        });
        // 真实场景:每个 job 完成后 send 结果
        // 这里简化,直接 println
    }

    // 等一会儿让任务执行
    std::thread::sleep(Duration::from_millis(500));

    // 触发关闭
    shutdown.trigger();
    drop(pool);

    // 收集结果
    let results = collector.drain();
    println!("收集到 {} 个结果", results.len());
}
```

### 9. `tests/pool_test.rs`

```rust
use std::sync::atomic::{AtomicUsize, Ordering};
use std::sync::Arc;
use std::time::Duration;

use web_crawler::{Job, Shutdown, ThreadPool};

struct CounterJob {
    counter: Arc<AtomicUsize>,
}

impl Job for CounterJob {
    type Output = ();

    fn run(self: Box<Self>) -> () {
        self.counter.fetch_add(1, Ordering::SeqCst);
    }

    fn name(&self) -> &str { "counter" }
}

#[test]
fn test_pool_executes_jobs() {
    let counter = Arc::new(AtomicUsize::new(0));
    let pool = ThreadPool::new(4, Shutdown::new());

    for _ in 0..100 {
        let c = Arc::clone(&counter);
        pool.execute(CounterJob { counter: c });
    }

    // 等执行完成
    std::thread::sleep(Duration::from_millis(200));
    drop(pool);

    assert_eq!(counter.load(Ordering::SeqCst), 100);
}

#[test]
fn test_shutdown_signal() {
    let shutdown = Shutdown::new();
    let pool = ThreadPool::new(2, shutdown.clone());

    assert!(!shutdown.is_shutdown());

    shutdown.trigger();
    assert!(shutdown.is_shutdown());

    drop(pool);
}
```

### 10. 关键设计点

| 设计 | 用途 |
| --- | --- |
| `Box<dyn Job>` | Trait Object,异构任务 |
| `mpsc::channel` | 多生产者单消费者 |
| `Arc<Mutex<Receiver>>` | Worker 共享 receiver |
| `Shutdown` 标志 | 通知 sleep 等阻塞操作退出 |
| `Drop` 关闭 | RAII 优雅退出 |
| `Send + 'static` | 跨线程传递 |
