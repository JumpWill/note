# 04 - 结构体与枚举

## 一、结构体 (Struct)

### 1. 三种结构体

```rust
// 命名字段结构体(最常用)
struct User {
    username: String,
    email: String,
    active: bool,
    sign_in_count: u64,
}

// 元组结构体(字段无名字)
struct Point(i32, i32, i32);
struct Color(i32, i32, i32);

// 单元结构体(无字段,用于标记 / trait 实现)
struct Marker;
```

### 2. 创建与访问

```rust
fn main() {
    // 创建实例
    let u = User {
        email: String::from("alice@example.com"),
        username: String::from("alice"),
        active: true,
        sign_in_count: 1,
    };

    // 字段访问
    println!("{}", u.email);

    // 字段简写(变量名 == 字段名)
    let email = String::from("bob@example.com");
    let username = String::from("bob");
    let u2 = User {
        email,        // 等价 email: email
        username,
        active: true,
        sign_in_count: 0,
    };

    // 更新语法
    let u3 = User {
        email: String::from("new@example.com"),
        ..u2  // 其余字段从 u2 复制
    };
    // 注意:u2.username 已 move 到 u3
    // println!("{}", u2.username); // ❌
}
```

### 3. 方法与关联函数

```rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // 关联函数(无 self,类似静态方法)
    fn new(width: u32, height: u32) -> Self {
        Self { width, height }
    }

    fn square(size: u32) -> Self {
        Self::new(size, size)
    }

    // &self 不可变借用
    fn area(&self) -> u32 {
        self.width * self.height
    }

    // &mut self 可变借用
    fn resize(&mut self, w: u32, h: u32) {
        self.width = w;
        self.height = h;
    }

    // 多个参数
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
}

fn main() {
    let r = Rectangle::new(30, 50);  // 关联函数
    println!("面积: {}", r.area());

    let s = Rectangle::square(20);
    println!("正方形: {:?}", s);
}
```

**自动引用/解引用**:方法调用时 `r.area()` 等价 `(&r).area()`,Rust 自动加 `&` / `&mut` / `*`。

### 4. 多个 impl 块

```rust
impl Rectangle {
    fn new(w: u32, h: u32) -> Self { Self { width: w, height: h } }
}

impl Rectangle {
```

### 2. 带数据的枚举

```rust
enum Message {
    Quit,                              // 无数据
    Move { x: i32, y: i32 },          // 类结构体

    ChangeColor(i32, i32, i32),       // 元组

fn process(msg: Message) {

        Message::Quit => println!("Quit"),
        Message::Move { x, y } => println!("Move to ({}, {})", x, y),
        Message::Write(text) => println!("Write: {}", text),
        Message::ChangeColor(r, g, b) => println!("RGB({}, {}, {})", r, g, b),
    }
}

fn main() {
    let m = Message::Move { x: 10, y: 20 };
    process(m);
}
```

### 3. 绑定值 + 守卫

```rust
fn main() {
    let num = Some(4);

    match num {
        Some(x) if x > 2 => println!("大于 2: {}", x),
        Some(x) => println!("小于等于 2: {}", x),
        None => println!("无值"),
```

### 4. 解构

```rust
fn main() {
    // 解构元组
    let pair = (1, 2);
    match pair {
```

### 5. if let / while let / let...else

```rust
fn main() {
    // if let:只关心一个分支
    let some = Some(3);
    if let Some(v) = some {
        println!("v = {}", v);
    } else {
        println!("none");
    }

    // while let:循环直到不匹配
    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {
        println!("{}", top);
    }

    // let...else:不匹配则必须发散
    fn parse(s: &str) -> Option<i32> {
        let Ok(n) = s.parse() else { return None };
        Some(n)
    }
}
```

### 6. matches! 宏

```rust
fn main() {
    let x = Some(3);
    println!("{}", matches!(x, Some(3)));         // true
    println!("{}", matches!(x, Some(_)));         // true
    println!("{}", matches!(x, Some(1 | 2)));     // false

    // 实际使用
    let events = vec![Some("ok"), None, Some("err")];
    let ok_count = events.iter().filter(|e| matches!(e, Some("ok"))).count();
}
```

## 五、要点速记

- **结构体三种形态**:命名字段、元组、单元
- **方法定义在 `impl` 块内,首参数为 `&self`**
- **关联函数无 `self`,用于构造器**
- **枚举变体可挂不同类型数据,类似 tagged union**
- **`Option<T>` / `Result<T,E>` 是核心枚举**
- **match 必须穷尽,`_` 通配**
- **`if let` 简化单分支 match,`while let` 循环匹配**
- **`let...else` 失败必须 return / panic**
- **`matches!` 宏返回 bool**
- **`Some(x) if x > 0` 是 match guard**
- **`id @ 3..=7` 是 @ 绑定,同时测试并捕获**

### 4. `src/lexer.rs`

```rust
use crate::token::Token;

pub struct Lexer<'a> {
    input: &'a str,
    pos: usize,
}

impl<'a> Lexer<'a> {
    pub fn new(input: &'a str) -> Self {
        Self { input, pos: 0 }
    }

    fn peek(&self) -> Option<char> {
        self.input[self.pos..].chars().next()
    }

    fn advance(&mut self) -> Option<char> {
        let c = self.peek()?;
        self.pos += c.len_utf8();
        Some(c)
    }

    fn skip_whitespace(&mut self) {
        while let Some(c) = self.peek() {
            if c.is_whitespace() {
                self.advance();
            } else {
                break;
            }
        }
    }

    fn number(&mut self) -> f64 {
        let start = self.pos;
        while let Some(c) = self.peek() {
            if c.is_ascii_digit() || c == '.' {
                self.advance();
            } else {
                break;
            }
        }
        self.input[start..self.pos].parse().unwrap()
    }
}

impl<'a> Iterator for Lexer<'a> {
    type Item = Token;

    fn next(&mut self) -> Option<Token> {
        self.skip_whitespace();
        let c = self.peek()?;

        let tok = match c {
            '+' => { self.advance(); Token::Plus }
            '-' => { self.advance(); Token::Minus }
            '*' => { self.advance(); Token::Star }
            '/' => { self.advance(); Token::Slash }
            '(' => { self.advance(); Token::LParen }
            ')' => { self.advance(); Token::RParen }
            '0'..='9' | '.' => Token::Number(self.number()),
            _ => return None,
        };

        Some(tok)
    }
}
```

### 5. `src/ast.rs`

```rust
/// AST 节点 - 用枚举表达 tagged union
#[derive(Debug, Clone, PartialEq)]
pub enum Expr {
    Number(f64),
    Binary {
        op: BinOp,
        left: Box<Expr>,
        right: Box<Expr>,
    },
    Unary {
        op: UnaryOp,
        operand: Box<Expr>,
    },
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum BinOp {
    Add, Sub, Mul, Div,
}

impl std::fmt::Display for BinOp {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            BinOp::Add => write!(f, "+"),
            BinOp::Sub => write!(f, "-"),
            BinOp::Mul => write!(f, "*"),
            BinOp::Div => write!(f, "/"),
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum UnaryOp {
    Neg,
}
```

### 6. `src/parser.rs`

```rust
use crate::ast::{BinOp, Expr, UnaryOp};
use crate::token::Token;

pub struct Parser<I: Iterator<Item = Token>> {
    tokens: std::iter::Peekable<I>,
}

impl<I: Iterator<Item = Token>> Parser<I> {
    pub fn new(iter: I) -> Self {
        Self { tokens: iter.peekable() }
    }

    fn next_token(&mut self) -> Option<Token> {
        self.tokens.next()
    }

    fn peek(&mut self) -> Option<&Token> {
        self.tokens.peek()
    }

    /// expression := term (('+' | '-') term)*
    pub fn expression(&mut self) -> Option<Expr> {
        let mut left = self.term()?;
        while let Some(op) = self.peek().and_then(|t| match t {
            Token::Plus => Some(BinOp::Add),
            Token::Minus => Some(BinOp::Sub),
            _ => None,
        }) {
            self.next_token();
            let right = self.term()?;
            left = Expr::Binary { op, left: Box::new(left), right: Box::new(right) };
        }
        Some(left)
    }

    /// term := factor (('*' | '/') factor)*
    fn term(&mut self) -> Option<Expr> {
        let mut left = self.factor()?;
        while let Some(op) = self.peek().and_then(|t| match t {
            Token::Star => Some(BinOp::Mul),
            Token::Slash => Some(BinOp::Div),
            _ => None,
        }) {
            self.next_token();
            let right = self.factor()?;
            left = Expr::Binary { op, left: Box::new(left), right: Box::new(right) };
        }
        Some(left)
    }

    /// factor := number | '(' expression ')' | '-' factor
    fn factor(&mut self) -> Option<Expr> {
        match self.next_token()? {
            Token::Number(n) => Some(Expr::Number(n)),
            Token::LParen => {
                let e = self.expression()?;
                if self.next_token() != Some(Token::RParen) {
                    return None;
                }
                Some(e)
            }
            Token::Minus => {
                let e = self.factor()?;
                Some(Expr::Unary { op: UnaryOp::Neg, operand: Box::new(e) })
            }
            _ => None,
        }
    }
}
```

### 7. `src/eval.rs`

```rust
use crate::ast::{BinOp, Expr};

pub fn eval(expr: &Expr) -> f64 {
    match expr {
        Expr::Number(n) => *n,
        Expr::Binary { op, left, right } => {
            let l = eval(left);
            let r = eval(right);
            match op {
                BinOp::Add => l + r,
                BinOp::Sub => l - r,
                BinOp::Mul => l * r,
                BinOp::Div => l / r,
            }
        }
        Expr::Unary { op, operand } => {
            let v = eval(operand);
            match op {
                crate::ast::UnaryOp::Neg => -v,
            }
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_eval() {
        let expr = Expr::Number(42.0);
        assert_eq!(eval(&expr), 42.0);
```

### 8. `src/pretty.rs`

```rust
use crate::ast::{BinOp, Expr, UnaryOp};

/// 中缀打印
pub fn pretty(expr: &Expr) -> String {
    match expr {
        Expr::Number(n) => format!("{}", n),
        Expr::Binary { op, left, right } => {
            format!("({} {} {})", pretty(left), op, pretty(right))
        }
        Expr::Unary { op, operand } => {
            let sym = match op {
                UnaryOp::Neg => "-",
            };
            format!("({}{})", sym, pretty(operand))
        }
    }
}
```

```rust
pub fn evaluate(input: &str) -> Option<f64> {
```

### 10. 使用示例

```rust
use expr_eval::{evaluate, pretty, Parser, Lexer};

fn main() {
    // 一行求值
    if let Some(v) = evaluate("1 + 2 * 3") {
        println!("1 + 2 * 3 = {}", v); // 7
    }

    // 分步:parse + pretty + eval
    let tokens = Lexer::new("(1 + 2) * 3").collect::<Vec<_>>();
    let ast = Parser::new(tokens.into_iter()).expression().unwrap();
    println!("AST: {}", pretty(&ast));    // ((1 + 2) * 3)
    println!("值:  {}", expr_eval::eval(&ast)); // 9
}
```

### 11. 关键点

| 概念 | 用法 |
| --- | --- |
| 枚举表达 AST | `Expr::Number(f64)`、`Expr::Binary { ... }` |
| Box 递归 | `Box<Expr>` 让递归类型有固定大小 |
| 关联函数 | `Parser::new(iter)` |
| 方法 | `Lexer::peek()` / `next()` 内部状态管理 |
| 模式匹配 | `match tok { Token::Number(n) => ..., _ => ... }` |
| 卫语句 | `if condition { ... } else { return ... }` |
| peekable 迭代器 | `std::iter::Peekable<I>` 实现 lookahead |
| Display trait | 自定义枚举的 `to_string()` |
