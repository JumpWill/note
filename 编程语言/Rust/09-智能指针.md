# 09 - 智能指针

智能指针是实现了 `Deref` 和/或 `Drop` trait 的数据结构。`Vec` 和 `String` 实际上都是智能指针。

## 一、`Box<T>` - 堆分配

### 1. 基本用法

```rust
fn main() {
    let b = Box::new(5);
    println!("b = {}", b); // 自动解引用
}
```

### 2. 递归类型

```rust
// 编译期必须知道大小,递归类型用 Box 提供固定大小
#[derive(Debug)]
enum List {
    Cons(i32, Box<List>),
    Nil,
}

use List::{Cons, Nil};

fn main() {
    let list = Cons(1, Box::new(Cons(2, Box::new(Cons(3, Box::new(Nil))))));

    fn print_list(l: &List) {
        match l {
            Cons(v, next) => {
                println!("{}", v);
                print_list(next);
            }
            Nil => println!("end"),
        }
    }

    print_list(&list);
}
```

### 3. 用途

```rust
fn main() {
    // 1. 堆分配大数据(避免栈复制)
    let big: Box<[u8; 1_000_000]> = Box::new([0; 1_000_000]);

    // 2. 递归类型(上例)

    // 3. Trait Object(运行时多态)
    let shapes: Vec<Box<dyn Draw>> = vec![
        Box::new(Circle { r: 1.0 }),
        Box::new(Square { s: 2.0 }),
    ];
}

trait Draw { fn draw(&self); }
struct Circle { r: f64 }
impl Draw for Circle { fn draw(&self) { println!("circle"); } }
struct Square { s: f64 }
impl Draw for Square { fn draw(&self) { println!("square"); } }
```

## 二、Deref - 自定义解引用

### 1. 实现 Deref

```rust
use std::ops::Deref;

struct MyBox<T>(T);

impl<T> MyBox<T> {
    fn new(x: T) -> Self {
        MyBox(x)
    }
}

impl<T> Deref for MyBox<T> {
    type Target = T;
    fn deref(&self) -> &T {
        &self.0
    }
}

fn hello(s: &str) {
    println!("hello, {}", s);
}

fn main() {
    let m = MyBox::new(String::from("Rust"));
    hello(&m);                  // Deref coercion:&MyBox<String> -> &str
    hello(&(*m)[..]);           // 手动解引用
}
```

### 2. DerefMut

```rust
use std::ops::{Deref, DerefMut};

struct MyBox<T>(T);

impl<T> Deref for MyBox<T> {
    type Target = T;
    fn deref(&self) -> &T { &self.0 }
}

impl<T> DerefMut for MyBox<T> {
    fn deref_mut(&mut self) -> &mut T { &mut self.0 }
}

fn main() {
    let mut m = MyBox::new(5);
    *m += 1; // 通过 DerefMut 修改内部
    println!("{}", *m); // 6
}
```

### 3. Deref coercion 规则

```text
&T      -> &U      当 T: Deref<Target=U>
&mut T  -> &mut U  当 T: DerefMut<Target=U>
&mut T  -> &U      当 T: Deref<Target=U>
```

## 三、Drop - 清理逻辑

### 1. 自定义 Drop

```rust
struct CustomSmartPointer {
    data: String,
}

impl Drop for CustomSmartPointer {
    fn drop(&mut self) {
        println!("Dropping with data: {}", self.data);
    }
}

fn main() {
    let c = CustomSmartPointer { data: String::from("first") };
    let d = CustomSmartPointer { data: String::from("second") };

    println!("created");
    // c 先 drop(后定义先 drop)
}
```

### 2. 提前 drop

```rust
fn main() {
    let c = CustomSmartPointer { data: String::from("x") };
    println!("before drop");
    drop(c);                       // 显式调用 std::mem::drop
    println!("after drop");
}

impl Drop for CustomSmartPointer {
    fn drop(&mut self) {
        println!("Dropping: {}", self.data);
    }
}
```

## 四、`Rc<T>` - 单线程引用计数

`Rc<T>` = Reference Counted,允许多个所有者,**仅用于单线程**。

### 1. 基本用法

```rust
use std::rc::Rc;

enum List {
    Cons(i32, Rc<List>),
    Nil,
}

fn main() {
    let a = Rc::new(List::Cons(5, Rc::new(List::Cons(10, Rc::new(List::Nil)))));
    println!("count: {}", Rc::strong_count(&a)); // 1

    let b = List::Cons(3, Rc::clone(&a));        // 计数 +1
    println!("count: {}", Rc::strong_count(&a)); // 2

    let c = List::Cons(4, Rc::clone(&a));
    println!("count: {}", Rc::strong_count(&a)); // 3
}
```

### 2. 共享只读数据

```rust
use std::rc::Rc;

struct Config {
    debug: bool,
    version: String,
}

fn main() {
    let cfg = Rc::new(Config {
        debug: true,
        version: String::from("1.0"),
    });

    // 多个持有者
    let h1 = Rc::clone(&cfg);
    let h2 = Rc::clone(&cfg);

    println!("{}, {}, {}", cfg.debug, h1.version, h2.version);
}
```

## 五、`Arc<T>` - 多线程引用计数

`Arc<T>` = Atomically Reference Counted,线程安全版本。

```rust
use std::sync::Arc;
use std::thread;

fn main() {
    let data = Arc::new(vec![1, 2, 3, 4, 5]);
    let mut handles = vec![];

    for i in 0..3 {
        let data = Arc::clone(&data);
        let h = thread::spawn(move || {
            println!("线程 {} 看到: {:?}", i, data);
        });
        handles.push(h);
    }

    for h in handles {
        h.join().unwrap();
    }
}
```

## 六、`RefCell<T>` - 运行时借用检查

`RefCell<T>` 在**运行时**检查借用规则,允许"内部可变性"。

### 1. 内部可变性

```rust
use std::cell::RefCell;

fn main() {
    // 不可变引用,但内部可变
    let data = RefCell::new(5);

    {
        let mut r = data.borrow_mut();
        *r += 1;
    }

    println!("{}", data.borrow()); // 6
}
```

### 2. 借用冲突运行时 panic

```rust
use std::cell::RefCell;

fn main() {
    let data = RefCell::new(vec![1, 2, 3]);

    let r1 = data.borrow();
    let r2 = data.borrow();  // ✅ 多个不可变

    // let r3 = data.borrow_mut(); // ❌ panic! 已经存在借用
}
```

### 3. 常用组合

```rust
use std::cell::RefCell;
use std::rc::Rc;

// 单线程多所有者可变数据
type SharedList = Rc<RefCell<Vec<i32>>>;

fn main() {
    let shared: SharedList = Rc::new(RefCell::new(vec![]));

    let s1 = Rc::clone(&shared);
    s1.borrow_mut().push(1);

    let s2 = Rc::clone(&shared);
    s2.borrow_mut().push(2);

    println!("{:?}", shared.borrow()); // [1, 2]
}
```

## 七、`Cell<T>` - 适用 Copy 类型

```rust
use std::cell::Cell;

fn main() {
    let c = Cell::new(5);

    let old = c.get();    // 拿到拷贝
    c.set(10);

    println!("{} {}", old, c.get()); // 5 10
}
```

**`Cell<T>` vs `RefCell<T>`**:

| 特性 | `Cell<T>` | `RefCell<T>` |
| --- | --- | --- |
| 适用类型 | `Copy` | 任意 |
| 访问 | `get`/`set` 返回拷贝 | `borrow`/`borrow_mut` 返回引用 |
| 检查时机 | 编译时(无须检查) | 运行时 |

## 八、`Weak<T>` - 避免循环引用

```rust
use std::cell::RefCell;
use std::rc::{Rc, Weak};

#[derive(Debug)]
struct Node {
    value: i32,
    parent: RefCell<Weak<Node>>,    // 父用 Weak
    children: RefCell<Vec<Rc<Node>>>,
}

fn main() {
    let leaf = Rc::new(Node {
        value: 3,
        parent: RefCell::new(Weak::new()),
        children: RefCell::new(vec![]),
    });

    let branch = Rc::new(Node {
        value: 5,
        parent: RefCell::new(Weak::new()),
        children: RefCell::new(vec![Rc::clone(&leaf)]),
    });

    // 设置 leaf 的父指向 branch(Weak 不增加 strong count)
    *leaf.parent.borrow_mut() = Rc::downgrade(&branch);

    println!("leaf.parent = {:?}", leaf.parent.borrow().upgrade());
    println!("branch strong = {}", Rc::strong_count(&branch));
    println!("leaf strong = {}", Rc::strong_count(&leaf));
}
```

## 九、`Cow<T>` - 写时克隆

`Cow<T>` = Clone-on-Write,延迟克隆。

```rust
use std::borrow::Cow;

fn process(s: &str) -> Cow<str> {
    if s.contains("bad") {
        // 需要修改,转为 owned
        Cow::Owned(s.replace("bad", "good"))
    } else {
        // 不需要修改,借
        Cow::Borrowed(s)
    }
}

fn main() {
    println!("{}", process("hello"));       // hello(borrowed)
    println!("{}", process("bad word"));    // good word(owned)
}
```

## 十、实战:LRU 缓存

```rust
use std::cell::RefCell;
use std::collections::HashMap;
use std::rc::Rc;

struct LruCache {
    map: HashMap<String, Rc<RefCell<Node>>>,
    head: Rc<RefCell<Node>>,
    capacity: usize,
}

struct Node {
    key: String,
    value: i32,
    prev: Option<Rc<RefCell<Node>>>,
    next: Option<Rc<RefCell<Node>>>,
}

impl LruCache {
    fn new(capacity: usize) -> Self {
        // 哨兵节点
        let head = Rc::new(RefCell::new(Node {
            key: String::new(),
            value: 0,
            prev: None,
            next: None,
        }));

        LruCache {
            map: HashMap::new(),
            head,
            capacity,
        }
    }

    fn get(&mut self, key: &str) -> Option<i32> {
        if let Some(node) = self.map.get(key).cloned() {
            // 移到头部
            // ... 简化
            Some(node.borrow().value)
        } else {
            None
        }
    }
}
```

## 十一、智能指针选择指南

| 场景 | 推荐 |
| --- | --- |
| 堆分配、单一所有者 | `Box<T>` |
| 单线程共享只读 | `Rc<T>` |
| 多线程共享只读 | `Arc<T>` |
| 单线程内部可变性 | `RefCell<T>` |
| 多线程内部可变性 | `Mutex<T>` / `RwLock<T>` |
| Copy 类型的内部可变性 | `Cell<T>` |
| 避免循环引用 | `Weak<T>` |
| 写时克隆 | `Cow<'_, T>` |

## 十二、要点速记

- **`Box<T>`**:堆分配,单一所有者,固定大小**
- **`Rc<T>`**:单线程引用计数共享所有权**
- **`Arc<T>`**:多线程引用计数共享所有权**
- **`RefCell<T>`**:运行时借用检查,内部可变性**
- **`Cell<T>`**:Copy 类型的内部可变性**
- **`Weak<T>`**:不增加引用计数,打破循环**
- **`Cow<T>`**:借/拥有二选一,需要时再克隆**
- **`Deref` 让自定义类型像引用一样使用**
- **`Drop` 在值离开作用域时自动调用**
- **`std::mem::drop` 提前 drop,不要直接调 `drop(&mut x)`**

### 3. `src/node.rs`

```rust
use std::cell::RefCell;
use std::rc::{Rc, Weak};

#[derive(Debug)]
pub struct Node {
    pub id: usize,
    pub data: String,
    pub outgoing: RefCell<Vec<Rc<Node>>>,     // 出边 -> 强引用
    pub incoming: RefCell<Vec<Weak<Node>>>,   // 入边 -> 弱引用(避免循环)
}

impl Node {
    pub fn new(id: usize, data: impl Into<String>) -> Self {
        Self {
            id,
            data: data.into(),
            outgoing: RefCell::new(Vec::new()),
            incoming: RefCell::new(Vec::new()),
        }
    }

    pub fn add_outgoing(self: &Rc<Self>, to: &Rc<Node>) {
        self.outgoing.borrow_mut().push(Rc::clone(to));
        to.incoming.borrow_mut().push(Rc::downgrade(self));
    }

    pub fn outgoing_count(&self) -> usize {
        self.outgoing.borrow().len()
    }

    pub fn incoming_count(&self) -> usize {
        self.incoming.borrow().iter().filter_map(|w| w.upgrade()).count()
    }
}
```

### 5. `src/graph.rs`

```rust
use std::cell::RefCell;
use std::collections::HashMap;
use std::rc::Rc;

use crate::node::Node;

#[derive(Default)]
pub struct Graph {
    nodes: RefCell<HashMap<usize, Rc<Node>>>,
    next_id: RefCell<usize>,
}

impl Graph {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn add_node(&self, data: impl Into<String>) -> Rc<Node> {
        let mut next_id = self.next_id.borrow_mut();
        let id = *next_id;
        *next_id += 1;
        drop(next_id);

        let node = Rc::new(Node::new(id, data));
        self.nodes.borrow_mut().insert(id, Rc::clone(&node));
        node
    }

    pub fn add_edge(&self, from: usize, to: usize, label: impl Into<String>) {
        let nodes = self.nodes.borrow();
        let from_node = nodes.get(&from).expect("source node not found");
        let to_node = nodes.get(&to).expect("target node not found");
        from_node.add_outgoing(to_node);
    }

    pub fn get_node(&self, id: usize) -> Option<Rc<Node>> {
        self.nodes.borrow().get(&id).cloned()
    }

    pub fn node_count(&self) -> usize {
        self.nodes.borrow().len()
    }

    pub fn nodes(&self) -> Vec<Rc<Node>> {
        self.nodes.borrow().values().cloned().collect()
    }

    /// DFS 遍历
    pub fn dfs(&self, start: usize) -> Vec<usize> {
        let nodes = self.nodes.borrow();
        let start = match nodes.get(&start) {
            Some(n) => Rc::clone(n),
            None => return Vec::new(),
        };
        drop(nodes);

        let mut visited = HashMap::new();
        let mut result = Vec::new();
        Self::dfs_helper(&start, &mut visited, &mut result);
        result
    }

    fn dfs_helper(node: &Rc<Node>, visited: &mut HashMap<usize, bool>, result: &mut Vec<usize>) {
        if visited.insert(node.id, true).is_some() {
            return;
        }
        result.push(node.id);
        for next in node.outgoing.borrow().iter() {
            Self::dfs_helper(next, visited, result);
        }
    }
}
```

### 6. `src/iter.rs` - 自定义迭代器

```rust
use std::rc::Rc;
use crate::node::Node;

pub struct OutgoingIter {
    current: usize,
    nodes: Vec<Rc<Node>>,
}

impl OutgoingIter {
    pub fn new(start: Rc<Node>) -> Self {
        let mut nodes = vec![start];
        let mut visited = vec![start.id];
        let mut i = 0;

        while i < nodes.len() {
            for next in nodes[i].outgoing.borrow().iter() {
                if !visited.contains(&next.id) {
                    visited.push(next.id);
                    nodes.push(Rc::clone(next));
                }
            }
            i += 1;
        }

        Self { current: 0, nodes }
    }
}

impl Iterator for OutgoingIter {
    type Item = Rc<Node>;

    fn next(&mut self) -> Option<Self::Item> {
        if self.current < self.nodes.len() {
            let item = Rc::clone(&self.nodes[self.current]);
            self.current += 1;
            Some(item)
        } else {
            None
        }
    }
}
```

```rust
use graph_lib::Graph;

#[test]
fn test_basic_graph() {
    let g = Graph::new();
    let a = g.add_node("A");

fn test_dfs() {
    let g = Graph::new();
    let a = g.add_node("A");
    let b = g.add_node("B");
    let c = g.add_node("C");
    let d = g.add_node("D");

    a.add_outgoing(&b);
    b.add_outgoing(&c);
    b.add_outgoing(&d);

    let order = g.dfs(0);
    assert_eq!(order[0], 0);  // A
    assert!(order.contains(&1));
    assert!(order.contains(&2));
    assert!(order.contains(&3));

#[test]
fn test_cycle_handling() {
    // 即使有环(Weak 入边),结构也不会泄漏
    let g = Graph::new();
    let a = g.add_node("A");
    let b = g.add_node("B");

    a.add_outgoing(&b);
    b.add_outgoing(&a);  // 形成环

    // drop 图,所有节点被释放
    drop(g);
    // 强引用计数归零,内存释放
    assert_eq!(Rc::strong_count(&a), 1);  // 仅本地变量持有
}
```

### 9. 关键点

| 概念 | 用法 |
| --- | --- |
| `Rc<Node>` | 多所有者共享节点 |
| `RefCell<Vec>` | 运行时借用检查,允许通过共享引用修改 |
| `Weak<Node>` | 入边用弱引用,**打破环** |
| `Box` | 间接存储、Trait Object |
| `Drop` | 自动调用,无需手动清理 |

### 10. 使用示例

```rust
use graph_lib::{Graph, OutgoingIter};

fn main() {
    let g = Graph::new();
    let root = g.add_node("root");
    let a = g.add_node("A");
    let b = g.add_node("B");

    root.add_outgoing(&a);
    a.add_outgoing(&b);

    // 自定义迭代器

    for node in iter {

    }
}
```
