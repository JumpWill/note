# 06 - 错误处理

Rust 的错误处理是核心特性之一:**没有异常**,通过类型系统强制处理。

## 一、两类错误

| 类别 | 何时用 | 方式 |
| --- | --- | --- |
| 不可恢复错误 | bug、不可继续 | `panic!` |
| 可恢复错误 | 文件找不到、网络失败等 | `Result<T, E>` |

## 二、`panic!` 不可恢复错误

### 1. 触发 panic

```rust
fn main() {
    // 显式 panic
    panic!("crash and burn");

    // 隐式 panic
    let v = vec![1, 2, 3];
    let x = v[99]; // panic: index out of bounds

    // 算术
    // let y = 1 / 0; // panic (整数除法)
}
```

### 2. 堆栈回溯

```bash
# debug 模式:显示完整堆栈
RUST_BACKTRACE=1 cargo run

# 设置环境变量
RUST_BACKTRACE=full cargo run   # 全部帧
RUST_BACKTRACE=0 cargo run      # 关闭(默认)
```

### 3. `panic!` vs `unwrap` / `expect`

```rust
fn main() {
    // panic! 立即终止
    panic!("直接崩溃");

    // unwrap:Ok 返回值,Err panic(不推荐在生产)
    let f = std::fs::File::open("nope.txt").unwrap();

    // expect:同 unwrap,但带消息
    let f = std::fs::File::open("nope.txt").expect("打开失败");
}
```

## 三、`Result<T, E>` 可恢复错误

### 1. 定义

```rust
enum Result<T, E> {
    Ok(T),    // 成功
    Err(E),   // 失败
}
```

### 2. 基础用法

```rust
use std::fs::File;
use std::io::{self, Read};

fn read_file(path: &str) -> Result<String, io::Error> {
    let mut file = File::open(path)?;          // ? 传播错误
    let mut content = String::new();
    file.read_to_string(&mut content)?;
    Ok(content)
}

fn main() {
    // match 处理
    match read_file("hello.txt") {
        Ok(content) => println!("{}", content),
        Err(e) => println!("err: {}", e),
    }

    // if let
    if let Ok(c) = read_file("hello.txt") {
        println!("{}", c);
    }
}
```

### 3. `?` 操作符

```rust
use std::fs::File;
use std::io::{self, Read};

// 使用 ? 简化错误传播
fn read_username(path: &str) -> Result<String, io::Error> {
    let mut f = File::open(path)?;
    let mut s = String::new();
    f.read_to_string(&mut s)?;
    Ok(s)
}

// 等价于
fn read_username_explicit(path: &str) -> Result<String, io::Error> {
    let mut f = match File::open(path) {
        Ok(file) => file,
        Err(e) => return Err(e),
    };
    let mut s = String::new();
    match f.read_to_string(&mut s) {
        Ok(_) => Ok(s),
        Err(e) => Err(e),
    }
}
```

### 4. `?` 与 From trait

`?` 自动调用 `From::from` 把错误转换成函数返回的错误类型。

```rust
use std::fs::File;
use std::io;

// 自定义错误
#[derive(Debug)]
enum MyError {
    Io(io::Error),
    Parse(std::num::ParseIntError),
}

// 为 io::Error 实现 From
impl From<io::Error> for MyError {
    fn from(err: io::Error) -> Self {
        MyError::Io(err)
    }
}

// 为 ParseIntError 实现 From
impl From<std::num::ParseIntError> for MyError {
    fn from(err: std::num::ParseIntError) -> Self {
        MyError::Parse(err)
    }
}

fn read_and_parse(path: &str) -> Result<i32, MyError> {
    let mut s = String::new();
    File::open(path)?.read_to_string(&mut s)?;  // ? 自动转换
    let n: i32 = s.trim().parse()?;             // ? 自动转换
    Ok(n)
}

use std::io::Read;
```

### 5. Result 常用方法

```rust
fn main() {
    let ok: Result<i32, &str> = Ok(42);
    let err: Result<i32, &str> = Err("bad");

    // 解包
    println!("unwrap_or: {}", err.unwrap_or(0));         // 0
    println!("unwrap_or_else: {}", err.unwrap_or_else(|e| e.len() as i32));
    println!("unwrap_or_default: {}", err.unwrap_or_default()); // i32::default = 0

    // 转换
    println!("map: {:?}", ok.map(|x| x * 2));             // Ok(84)
    println!("map_err: {:?}", ok.map_err(|e| format!("E: {}", e)));

    // 链式
    println!("and_then: {:?}", ok.and_then(|x| if x > 0 { Ok(x) } else { Err("neg") }));
    println!("or_else: {:?}", err.or_else(|_| Ok(0)));

    // 组合
    let ok2: Result<i32, &str> = Ok(2);
    println!("and: {:?}", ok.and(ok2));      // Ok(2)
    println!("or: {:?}", err.or(ok2));        // Ok(2)

    // 查询
    println!("is_ok: {}, is_err: {}", ok.is_ok(), err.is_err());

    // 转 Option
    println!("ok(): {:?}", ok.ok());          // Some(42)
    println!("err(): {:?}", err.err());       // Some("bad")

    // as_ref
    let r: Result<&i32, &str> = ok.as_ref();
    println!("as_ref: {:?}", r);
}
```

## 四、自定义错误类型

### 1. 手写 enum + impl

```rust
use std::fmt;

#[derive(Debug)]
pub enum AppError {
    NotFound(String),
    InvalidInput(String),
    Io(std::io::Error),
    Parse(std::num::ParseIntError),
}

impl fmt::Display for AppError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            AppError::NotFound(p) => write!(f, "未找到: {}", p),
            AppError::InvalidInput(m) => write!(f, "无效输入: {}", m),
            AppError::Io(e) => write!(f, "IO 错误: {}", e),
            AppError::Parse(e) => write!(f, "解析错误: {}", e),
        }
    }
}

// 实现 std::error::Error(支持 ? 自动转换与 source 链)
impl std::error::Error for AppError {
    fn source(&self) -> Option<&(dyn std::error::Error + 'static)> {
        match self {
            AppError::Io(e) => Some(e),
            AppError::Parse(e) => Some(e),
            _ => None,
        }
    }
}

// 为 From 实现以支持 ?
impl From<std::io::Error> for AppError {
    fn from(e: std::io::Error) -> Self {
        AppError::Io(e)
    }
}

impl From<std::num::ParseIntError> for AppError {
    fn from(e: std::num::ParseIntError) -> Self {
        AppError::Parse(e)
    }
}
```

### 2. 用 `thiserror` 简化(库代码推荐)

```toml
[dependencies]
thiserror = "1"
```

```rust
use thiserror::Error;
use std::io;

#[derive(Error, Debug)]
pub enum AppError {
    #[error("资源未找到: {0}")]
    NotFound(String),

    #[error("无效输入: {0}")]
    InvalidInput(String),

    #[error("IO 错误")]
    Io(#[from] io::Error),                            // 自动 From impl

    #[error("解析错误")]
    Parse(#[from] std::num::ParseIntError),

    #[error("数值溢出")]
    Overflow,

    #[error(transparent)]                             // 透传
    Other(#[from] anyhow::Error),
}

fn process_file(path: &str) -> Result<(), AppError> {
    let _ = std::fs::read_to_string(path)?;           // 自动转 Io
    Ok(())
}
```

### 3. 用 `anyhow` 简化(应用程序推荐)

```toml
[dependencies]
anyhow = "1"
```

```rust
use anyhow::{Context, Result, bail, ensure};

fn process_file(path: &str) -> Result<String> {
    let content = std::fs::read_to_string(path)
        .with_context(|| format!("读取文件失败: {}", path))?;

    ensure!(!content.is_empty(), "文件为空");

    if content.len() > 1000 {
        bail!("文件太大: {} 字节", content.len());
    }

    Ok(content)
}

// 错误链:Caused by: 读取文件失败: xxx.txt (os error 2)
```

## 五、错误处理模式

### 1. 库 vs 应用程序

```rust
// 库:返回具体错误类型
pub fn library_fn() -> Result<(), LibError> { ... }

// 应用:用 anyhow::Result 简化
fn app_main() -> anyhow::Result<()> {
    library_fn()?;
    Ok(())
}
```

### 2. 何时用 `unwrap` / `expect`

| 场景 | 推荐 |
| --- | --- |
| 原型 / 示例 | `unwrap` / `expect` |
| 单元测试 | `unwrap` / `expect`(失败就 panic) |
| 确定不可能失败 | `expect("逻辑不可能失败")` |
| 生产库代码 | `Result<T, E>` 返回 |
| 生产应用代码 | `?` + `anyhow::Result` |

### 3. 自定义错误 + 应用包装

```rust
use thiserror::Error;

#[derive(Error, Debug)]
pub enum DomainError {
    #[error("用户 {0} 不存在")]
    UserNotFound(u64),
    #[error("余额不足")]
    InsufficientBalance,
}

fn transfer(from: u64, to: u64, amount: u64) -> anyhow::Result<()> {
    anyhow::ensure!(from != 0, DomainError::UserNotFound(from));
    // ...
    Ok(())
}
```

## 六、`Box<dyn Error>` - 通用错误

```rust
use std::error::Error;

fn run() -> Result<(), Box<dyn Error>> {
    let _f = std::fs::File::open("file.txt")?;        // io::Error
    let _n: i32 = "42".parse()?;                       // ParseIntError
    Ok(())
}

fn main() {
    if let Err(e) = run() {
        println!("err: {}", e);
        // 打印错误链
        let mut source = e.source();
        while let Some(s) = source {
            println!("caused by: {}", s);
            source = s.source();
        }
    }
}
```

## 七、panic 安全 (Poisoning)

```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let m = Arc::new(Mutex::new(0));
    let m2 = Arc::clone(&m);

    let _ = thread::spawn(move || {
        let mut guard = m2.lock().unwrap();
        *guard += 1;
        panic!("线程内 panic");
    }).join();

    // 锁被"中毒",但仍可获取
    match m.lock() {
        Ok(g) => println!("got: {}", *g),
        Err(p) => {
            // PoisonError 包含 guard,可恢复
            let g = p.into_inner();
            println!("recovered: {}", *g);
        }
    }
}
```

## 八、实用:文件操作错误处理

```rust
use std::fs;
use std::io;
use std::path::Path;

#[derive(Debug)]
pub enum FileError {
    NotFound(String),
    PermissionDenied(String),
    InvalidUtf8(String),
    Io(io::Error),
}

impl From<io::Error> for FileError {
    fn from(e: io::Error) -> Self {
        match e.kind() {
            io::ErrorKind::NotFound => FileError::NotFound(e.to_string()),
            io::ErrorKind::PermissionDenied => FileError::PermissionDenied(e.to_string()),
            _ => FileError::Io(e),
        }
    }
}

impl std::fmt::Display for FileError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::NotFound(p) => write!(f, "文件未找到: {}", p),
            Self::PermissionDenied(p) => write!(f, "权限不足: {}", p),
            Self::InvalidUtf8(p) => write!(f, "非 UTF-8 文件: {}", p),
            Self::Io(e) => write!(f, "IO 错误: {}", e),
        }
    }
}

pub fn read_file_safe(path: &str) -> Result<String, FileError> {
    let p = Path::new(path);
    if !p.exists() {
        return Err(FileError::NotFound(path.to_string()));
    }
    let bytes = fs::read(p)?;
    let s = String::from_utf8(bytes)
        .map_err(|_| FileError::InvalidUtf8(path.to_string()))?;
    Ok(s)
}

fn main() {
    match read_file_safe("test.txt") {
        Ok(c) => println!("{}", c),
        Err(e) => println!("err: {}", e),
    }
}
```

## 九、要点速记

- **两类错误:panic!(不可恢复) + Result(可恢复)**
- **`RUST_BACKTRACE=1` 看 panic 堆栈**
- **`?` 操作符自动传播错误,通过 `From` 自动转换类型**
- **Result 方法:`unwrap_or` / `map` / `and_then` / `ok` / `err`**
- **库代码用 `thiserror` 定义具体错误类型**
- **应用程序用 `anyhow::Result` + `?` + `Context`**
- **`Box<dyn Error>` 是通用错误,适合 main 函数**
- **实现 `std::error::Error + Display + From` 是错误类型三件套**
- **`PoisonError` 中仍可拿到 guard,不会真正"锁死"**
- **测试中 panic 是预期行为,用 `#[should_panic]` 测试**

### 3. `src/error.rs` - 库层错误

use thiserror::Error;
use std::io;

#[derive(Error, Debug)]
pub enum ConfigError {
    #[error("配置文件未找到: {0}")]
    NotFound(String),

    #[error("权限不足: {0}")]
    PermissionDenied(String),

    #[error("IO 错误: {0}")]
    Io(#[from] io::Error),

    #[error("TOML 解析错误: {0}")]
    Parse(#[from] toml::de::Error),

    #[error("配置验证失败: {0}")]
    Validation(String),

    #[error("环境变量缺失: {0}")]

}

pub type Result<T> = std::result::Result<T, ConfigError>;

### 5. `src/validator.rs` - 配置校验

```rust
use crate::config::Config;
use crate::error::{ConfigError, Result};

pub fn validate(cfg: &Config) -> Result<()> {
    if cfg.server.port == 0 {
        return Err(ConfigError::Validation("server.port 不能为 0".into()));
    }
    if cfg.database.pool_size == 0 {
        return Err(ConfigError::Validation("database.pool_size 不能为 0".into()));
    }
    if !["debug", "info", "warn", "error"].contains(&cfg.logging.level.as_str()) {
        return Err(ConfigError::Validation(format!(
            "logging.level 无效: {}", cfg.logging.level
        )));
    }
    Ok(())
}
```

### 6. `src/loader.rs` - 加载逻辑

```rust
use crate::config::Config;
use crate::error::{ConfigError, Result};
use crate::validator;
use std::path::Path;

pub fn load_from_file(path: &str) -> Result<Config> {
    let content = std::fs::read_to_string(path)?;
    let cfg: Config = toml::from_str(&content)?;
    validator::validate(&cfg)?;
    Ok(cfg)
}

pub fn load_with_env_override(path: &str) -> Result<Config> {
    let mut cfg = load_from_file(path)?;

    // 环境变量覆盖(可选)
    if let Ok(host) = std::env::var("APP_SERVER_HOST") {
        cfg.server.host = host;
    }
    if let Ok(port) = std::env::var("APP_SERVER_PORT") {
        cfg.server.port = port.parse()
            .map_err(|_| ConfigError::Validation("无效端口".into()))?;
    }

    // 校验(覆盖后)
    validator::validate(&cfg)?;
    Ok(cfg)
}

pub fn load_default() -> Result<Config> {
    let candidates = [
        "./config.toml",
        "./config/config.toml",
        "/etc/config_tool/config.toml",
    ];

    for p in &candidates {
        if Path::new(p).exists() {
            return load_with_env_override(p);
        }
    }

    Err(ConfigError::NotFound("未找到任何配置".into()))
}
```

### 10. 错误传播流

```text
load_from_file()
  └─ read_to_string() → io::Error
      └─ ? 自动转 ConfigError::Io (#[from])

  └─ toml::from_str() → toml::de::Error
      └─ ? 自动转 ConfigError::Parse (#[from])

  └─ validate(&cfg) → ConfigError::Validation (直接返回)

main()
  └─ load_default() → ConfigError
      └─ .context("加载配置失败") → anyhow::Error(包装)

  └─ ? 传播到 main 返回 → process::exit(1)
```
