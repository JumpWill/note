# 14 - 高级特性

unsafe、FFI、宏、属性、过程宏。涉及 Rust 底层能力的进阶话题。

## 一、`unsafe Rust`

### 1. 何时需要 unsafe

五种行为只在 `unsafe` 内合法:

1. 解引用裸指针
2. 调用 unsafe 函数 / 方法
3. 访问 / 修改可变静态变量
4. 实现 unsafe trait
5. 访问 `union` 的字段

```rust
unsafe fn dangerous() {
    println!("do dangerous things");
}

fn main() {
    unsafe {
        dangerous();
    }
}
```

### 2. 裸指针

```rust
fn main() {
    let mut n = 5;

    // 从引用转裸指针
    let r1 = &n as *const i32;
    let r2 = &mut n as *mut i32;

    // 从地址
    let address = 0x12345usize;
    let r3 = address as *const i32;

    unsafe {
        println!("r1: {}", *r1);    // 解引用
        *r2 = 10;                   // 修改
    }
}
```

### 3. unsafe 函数封装到 safe API

```rust
use std::slice;

/// 安全封装:提供 offset 切片
pub fn split_at_mut(values: &mut [i32], mid: usize) -> (&mut [i32], &mut [i32]) {
    let len = values.len();
    let ptr = values.as_mut_ptr();

    assert!(mid <= len);

    unsafe {
        (
            slice::from_raw_parts_mut(ptr, mid),
            slice::from_raw_parts_mut(ptr.add(mid), len - mid),
        )
    }
}

fn main() {
    let mut v = vec![1, 2, 3, 4, 5];
    let (left, right) = split_at_mut(&mut v, 2);
    println!("{:?} {:?}", left, right);
}
```

### 4. extern / FFI

```rust
// 调用 C 标准库
extern "C" {
    fn abs(input: i32) -> i32;
}

fn main() {
    unsafe {
        println!("abs(-3) = {}", abs(-3));
    }
}
```

### 5. 全局可变静态

```rust
static mut COUNTER: u32 = 0;

fn add_to_count(inc: u32) {
    unsafe {
        COUNTER += inc;
    }
}

fn main() {
    add_to_count(5);
    unsafe {
        println!("counter: {}", COUNTER); // 5
    }
}
```

## 二、FFI - 与 C 互操作

### 1. 调用 C 函数

```rust
// Cargo.toml: lib = "foo"

// src/lib.rs
extern "C" {
    fn c_function(x: i32) -> i32;
}

#[no_mangle]
pub extern "C" fn rust_function(x: i32) -> i32 {
    x * 2
}
```

### 2. FFI - 调用 C 标准库

```rust
use std::ffi::CString;
use std::os::raw::c_char;

extern "C" {
    fn strlen(s: *const c_char) -> usize;
}

fn main() {
    let s = CString::new("hello").unwrap();
    unsafe {
        println!("len: {}", strlen(s.as_ptr())); // 5
    }
}
```

### 3. LuaJIT FFI

```rust
use std::ffi::c_void;

extern "C" {
    fn printf(fmt: *const u8, ...) -> i32;
}

fn main() {
    unsafe {
        printf(b"Hello from C: %d\n\0".as_ptr(), 42);
    }
}
```

## 三、宏 (Macros)

### 1. 声明宏 `macro_rules!`

```rust
// 简单宏
macro_rules! say_hello {
    () => {
        println!("Hello!");
    };
}

// 带参数
macro_rules! create_function {
    ($func_name:ident) => {
        fn $func_name() {
            println!("function {:?} is called", stringify!($func_name));
        }
    };
}

// 多模式
macro_rules! vec_new {
    () => { Vec::new() };
    ($($x:expr),+ $(,)?) => {
        {
            let mut v = Vec::new();
            $(
                v.push($x);
            )+
            v
        }
    };
}

fn main() {
    say_hello!();
    create_function!(foo);
    foo();

    let v = vec_new![1, 2, 3, 4];
    println!("{:?}", v);
}
```

### 2. 常用内置宏

```rust
// stringify! - 转字符串
let s = stringify!(1 + 2);   // "1 + 2"

// concat! - 拼接
let s = concat!("a", "b", 1);  // "ab1"

// include_str! - 包含文件内容
let s = include_str!("hello.txt");

// env! - 环境变量
let home = env!("HOME");

// cfg! - 编译期条件
let is_linux = cfg!(unix);

// dbg! - 调试
let x = 42;
dbg!(x); // println + 返回值

// todo! / unimplemented!
// todo!()         // 占位,未实现

// format! / println! / vec! / panic!
```

### 3. 过程宏 (Procedural Macros)

**自定义 derive**:

```rust
// 简化的 #[derive(Hello)]
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, DeriveInput};

#[proc_macro_derive(Hello)]
pub fn hello_derive(input: TokenStream) -> TokenStream {
    let ast = parse_macro_input!(input as DeriveInput);
    let name = &ast.ident;
    let gen = quote! {
        impl #name {
            pub fn hello(&self) {
                println!("Hello from {}", stringify!(#name));
            }
        }
    };
    gen.into()
}
```

使用:

```rust
use hello::Hello;

#[derive(Hello)]
struct MyStruct;

fn main() {
    let s = MyStruct;
    s.hello(); // "Hello from MyStruct"
}
```

## 六、Trait Object 进阶

### 1. 对象安全 (Object Safety)

不是所有 trait 都能作 dyn。

```rust
// 对象安全的 trait
trait Draw {
    fn draw(&self);
}

fn render(s: &dyn Draw) {
    s.draw();
}

// ❌ 不是对象安全的
trait Cloneable {
    fn clone(&self) -> Self;   // 返回 Self
}
```

限制:
- 不能返回 `Self`
- 不能有泛型参数
- 不能用 `where Self: Sized`

### 2. Trait Upcasting (1.86+)

```rust
trait Animal { fn name(&self) -> &str; }
trait Dog: Animal {
    fn bark(&self);
}

// 1.86+ 可以
fn use_animal(d: &dyn Dog) {
    let a: &dyn Animal = d;
    println!("{}", a.name());
}
```

## 七、PhantomData 与零成本抽象

```rust
use std::marker::PhantomData;

// 编译期类型标签
struct Meters(f64);
struct Seconds(f64);

// 类型转换函数
fn distance(d: Meters, t: Seconds) -> f64 {
    d.0 / t.0
}

// 标记类型,无运行时开销
struct Iter<'a, T: 'a> {
    ptr: *const T,
    end: *const T,
    _marker: PhantomData<&'a T>,    // 携带生命周期但不占空间
}
```

## 八、生命周期变型 (Variance)

- `&'a T` 对 `'a` 是协变(covariant)
- `&'a mut T` 对 `'a` 协变,对 `T` 不变(invariant)
- `Box<T>` 对 `T` 协变

```rust
fn foo<'a>(s: &'a str) -> &'a str { s }

fn main() {
    let s: &'static str = "hi";
    let r: &str = foo(s); // 'static 协变到任意 'a
}
```

## 十、要点速记

- **`unsafe` 五种能力**:解引用裸指针、unsafe 函数、修改静态变量、实现 unsafe trait、访问 union**
- **unsafe 不关闭借用检查,只关闭部分安全检查**
- **FFI 用 `extern "C"` 块声明 C 函数,用 `#[no_mangle] + extern "C"` 暴露 Rust 函数**
- **C 字符串交互用 `CString` / `CStr`**
- **`bindgen` 自动生成 C 头绑定**
- **`macro_rules!` 是声明宏,过程宏更强但需 proc-macro crate**
- **`dbg!` 调试宏,`todo!` 占位,`unimplemented!` 标记**
- **`#[derive(...)]` 自动实现常见 trait**
- **`#[must_use]` 警告返回值被忽略**
- **`#[inline(always)]` 强制内联**
- **`#[cold]` 标记冷路径,优化分支预测**
- **`PhantomData<T>` 携带类型信息,零运行时开销**
- **变型规则:`&T` 协变,`&mut T` 对 T 不变**
- **`dyn Trait` 要求 trait 是对象安全的**

### 4. `log_macro_derive/src/lib.rs`

```rust
use proc_macro::TokenStream;
use quote::{quote, format_ident};
use syn::{parse_macro_input, DeriveInput, Data, Fields};

/// 给 struct 派生 Loggable,自动生成 log_fmt() 方法
#[proc_macro_derive(Loggable, attributes(log))]
pub fn loggable_derive(input: TokenStream) -> TokenStream {
    let ast = parse_macro_input!(input as DeriveInput);
    let name = &ast.ident;
    let (impl_generics, ty_generics, where_clause) = ast.generics.split_for_impl();

    // 收集字段
    let fields = match &ast.data {
        Data::Struct(s) => match &s.fields {
            Fields::Named(named) => &named.named,
            _ => panic!("Loggable only supports named fields"),
        },
        _ => panic!("Loggable only supports structs"),
    };

    // 生成字段访问
    let field_access = fields.iter().map(|f| {
        let fname = f.ident.as_ref().unwrap();
        let ftname = &f.ty;
        quote! { .field(stringify!(#fname), &format_args!("{:?}", self.#fname).to_string()).map_err(|_| #ftname) }
    });

    // 简化版:用 Result<(), String> 类型状态机演示
    let expanded = quote! {
        impl #impl_generics #name #ty_generics #where_clause {
            pub fn log_fmt(&self) -> String {
                format!("{} {{ {} }}",
                    stringify!(#name),
                    vec![ #( format!("{}: {:?}", stringify!(#field), self.#field) ),* ]
                        .join(", ")
                )
            }
        }
    };

    // 实际展开(简化):忽略类型状态机
    let _ = field_access;

    TokenStream::from(expanded)
}

/// 自定义属性宏:为函数加 trace!
#[proc_macro_attribute]
pub fn trace(_args: TokenStream, input: TokenStream) -> TokenStream {
    let item = parse_macro_input!(input as syn::ItemFn);
    let fn_name = &item.sig.ident;
    let fn_name_str = fn_name.to_string();
    let vis = &item.vis;
    let sig = &item.sig;
    let body = &item.block;

    let expanded = quote! {
        #vis #sig {
            eprintln!("[trace] enter: {}", #fn_name_str);
            let __result = (|| #body)();
            eprintln!("[trace] exit:  {}", #fn_name_str);
            __result
        }
    };

    TokenStream::from(expanded)
}

/// 函数式宏:log_info!(level, "fmt", args)
#[proc_macro]
pub fn log_info(input: TokenStream) -> TokenStream {
    use syn::{parse::ParseStream, parse_macro_input, Token, LitStr};

    let mut level = String::from("INFO");
    let mut format_str = String::new();

    let parser = syn::parse::ParseStream::from(input);
    // 简化解析
    let input2 = input.clone();
    let parsed: syn::Result<LogArgs> = syn::parse2(input2.into());
    if let Ok(args) = parsed {
        level = args.level;
        format_str = args.message.value();
    }

    let _ = (level, format_str);

    // 简化:返回原 token
    input
}

struct LogArgs {
    level: String,
    message: LitStr,
}

impl syn::parse::Parse for LogArgs {
    fn parse(input: ParseStream) -> syn::Result<Self> {
        let _level: syn::Ident = input.parse()?;
        let _comma: Token![,] = input.parse()?;
        let message: LitStr = input.parse()?;
        Ok(Self { level: "INFO".into(), message })
    }
}
```

### 7. `tests/integration_test.rs`(用户 crate 中)

```rust

    name: String,
    email: String,

        id: 1,
        name: "alice".into(),

    assert!(s.contains("alice"));
    assert!(s.contains("User"));
```
