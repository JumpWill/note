# 15 - 宏与元编程

宏是 Rust 元编程的核心,在编译期生成代码,实现**编译期计算**和**消除样板**。

## 一、宏的分类

| 类型 | 形式 | 能力 |
| --- | --- | --- |
| 声明宏 | `macro_rules!` | 模式匹配 + 替换 |
| 派生宏 | `#[derive(MyDerive)]` | 自动为类型实现 trait |
| 属性宏 | `#[my_attr]` | 标注任意 item,生成代码 |
| 函数式宏 | `my_macro!(...)` | 像函数调用,签名灵活 |

后三种统称**过程宏**(procedural macro),需要独立的 proc-macro crate。

## 二、`macro_rules!` 声明宏

### 1. 基本语法

```rust
// 无参数
macro_rules! say_hello {
    () => {
        println!("Hello!");
    };
}

// 带一个参数
macro_rules! create_function {
    ($func_name:ident) => {
        fn $func_name() {
            println!("function {:?} is called", stringify!($func_name));
        }
    };
}

// 多参数 + 多模式
macro_rules! vec_new {
    () => { Vec::new() };
    ($($x:expr),+ $(,)?) => {{
        let mut v = Vec::new();
        $( v.push($x); )+
        v
    }};
}

fn main() {
    say_hello!();
    create_function!(foo);
    foo();

    let v = vec_new![1, 2, 3, 4];
    println!("{:?}", v);
}
```

### 2. 片段说明符

| 指示符 | 匹配 |
| --- | --- |
| `ident` | 标识符 |
| `expr` | 表达式 |
| `ty` | 类型 |
| `pat` | 模式 |
| `path` | 路径(`std::io::Write`) |
| `stmt` | 单条语句 |
| `block` | `{ ... }` 块 |
| `item` | 项(fn / struct / mod ...) |
| `meta` | 属性内容 |
| `tt` | 单个 token 树 |
| `literal` | 字面量 |
| `vis` | 可见性(`pub` 等) |

### 3. 重复模式

```rust
// $(...)* 零次或多次
// $(...)+ 一次或多次
// $(...)? 零次或一次
// 分隔符: $(... sep ...)*  中间夹 sep

macro_rules! hashmap {
    ($($key:expr => $val:expr),* $(,)?) => {{
        let mut m = std::collections::HashMap::new();
        $( m.insert($key, $val); )*
        m
    }};
}

fn main() {
    let m = hashmap! {
        "a" => 1,
        "b" => 2,
    };
    println!("{:?}", m);
}
```

### 4. 调用宏的方式

```rust
macro_rules! foo {
    () => { println!("hi") };
}

fn main() {
    foo!();            // () 形式
    foo![];            // [] 形式
    foo!{};            // {} 形式
}
```

### 5. 卫生 (Hygiene)

宏内定义的标识符不会与外部冲突,外部定义的标识符在宏内是上文的标识符。

```rust
macro_rules! make_var {
    ($name:ident = $val:expr) => {
        let $name = $val;
    };
}

fn main() {
    let x = 1;
    make_var!(x = 2);          // 新建局部 x
    println!("{}", x);          // 1(原 x 不变)
    println!("{:?}", x);        // 还是 1
}
```

## 三、过程宏 (Procedural Macros)

过程宏在编译期接收 `TokenStream`,返回另一个 `TokenStream`。需要单独的 crate 类型。

### 1. 项目结构

```
hello_macro/
├── Cargo.toml              # workspace 根
├── hello_macro/            # 用户 crate(库)
│   ├── Cargo.toml
│   └── src/lib.rs
└── hello_macro_derive/     # 过程宏 crate
    ├── Cargo.toml
    └── src/lib.rs
```

`Cargo.toml`(workspace):

```toml
[workspace]
members = ["hello_macro", "hello_macro_derive"]
```

### 2. 用户 crate:`hello_macro/Cargo.toml`

```toml
[package]
name = "hello_macro"
version = "0.1.0"
edition = "2021"

[lib]
path = "src/lib.rs"

[dependencies]
hello_macro_derive = { path = "../hello_macro_derive" }
```

`hello_macro/src/lib.rs`:

```rust
pub use hello_macro_derive::Hello;   // 重导出

pub trait Hello {
    fn hello(&self);
}
```

### 3. 过程宏 crate:`hello_macro_derive/Cargo.toml`

```toml
[package]
name = "hello_macro_derive"
version = "0.1.0"
edition = "2021"

[lib]
proc-macro = true                  # 关键!
path = "src/lib.rs"

[dependencies]
syn = "2"
quote = "1"
```

`hello_macro_derive/src/lib.rs`:

```rust
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, DeriveInput};

#[proc_macro_derive(Hello)]
pub fn hello_derive(input: TokenStream) -> TokenStream {
    // 解析为 DeriveInput
    let ast = parse_macro_input!(input as DeriveInput);

    // 取类型名
    let name = &ast.ident;

    // 生成代码
    let gen = quote! {
        impl crate::Hello for #name {
            fn hello(&self) {
                println!("Hello from {}!", stringify!(#name));
            }
        }
    };

    gen.into()
}
```

### 4. 使用

```rust
use hello_macro::Hello;

#[derive(Hello)]
struct Pancakes;

#[derive(Hello)]
struct Waffles;

fn main() {
    Pancakes.hello(); // "Hello from Pancakes!"
    Waffles.hello();
}
```

## 四、派生宏进阶

### 1. 解析结构体字段

```rust
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, DeriveInput, Data, Fields};

#[proc_macro_derive(Builder, attributes(builder))]
pub fn builder_derive(input: TokenStream) -> TokenStream {
    let ast = parse_macro_input!(input as DeriveInput);
    let name = &ast.ident;
    let builder_name = syn::Ident::new(&format!("{}Builder", name), name.span());

    let fields = match &ast.data {
        Data::Struct(s) => match &s.fields {
            Fields::Named(named) => &named.named,
            _ => panic!("Only named fields supported"),
        },
        _ => panic!("Only struct supported"),
    };

    let field_names: Vec<_> = fields.iter().map(|f| &f.ident).collect();
    let field_types: Vec<_> = fields.iter().map(|f| &f.ty).collect();

    let builder_fields = field_names.iter().zip(field_types.iter()).map(|(n, t)| {
        quote! { #n: Option<#t> }
    });

    let setters = field_names.iter().zip(field_types.iter()).map(|(n, t)| {
        let setter = syn::Ident::new(&format!("with_{}", n.as_ref().unwrap()), n.span());
        quote! {
            pub fn #setter(mut self, v: #t) -> Self {
                self.#n = Some(v);
                self
            }
        }
    });

    let build_assigns = field_names.iter().map(|n| {
        quote! {
            #n: self.#n.clone().ok_or(concat!("missing field: ", stringify!(#n)))?
        }
    });

    let expanded = quote! {
        impl #name {
            pub fn builder() -> #builder_name {
                #builder_name { ..Default::default() }
            }
        }

        #[derive(Default)]
        pub struct #builder_name {
            #( #builder_fields, )*
        }

        impl #builder_name {
            #( #setters )*

            pub fn build(self) -> Result<#name, &'static str> {
                Ok(#name {
                    #( #build_assigns, )*
                })
            }
        }
    };

    expanded.into()
}
```

使用:

```rust
#[derive(Builder)]
struct ServerConfig {
    host: String,
    port: u16,
    debug: bool,
}

fn main() {
    let cfg = ServerConfig::builder()
        .with_host("0.0.0.0".into())
        .with_port(8080)
        .with_debug(false)
        .build()
        .unwrap();
    println!("{}:{}", cfg.host, cfg.port);
}
```

### 2. helper 属性(#[builder(default)] 等)

```rust
use syn::{parse_macro_input, DeriveInput, Data, Fields, Attribute, Meta, Lit, NestedMeta};

// 解析 #[builder(default = "expr")]
fn parse_default(attr: &Attribute) -> Option<syn::Expr> {
    if !attr.path.is_ident("builder") {
        return None;
    }
    if let Meta::List(list) = attr.parse_meta().ok()? {
        for nested in &list.nested {
            if let syn::NestedMeta::Meta(Meta::NameValue(nv)) = nested {
                if nv.path.is_ident("default") {
                    if let syn::Lit::Str(lit) = &nv.lit {
                        return Some(lit.parse().ok()?);
                    }
                }
            }
        }
    }
    None
}
```

## 五、自定义属性宏

属性宏作用于整个 item(如整个 fn / struct),而非单字段。

### 1. 路由属性宏示例

```rust
// route_macro/src/lib.rs
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, ItemFn, Lit, Meta, NestedMeta};

#[proc_macro_attribute]
pub fn route(args: TokenStream, input: TokenStream) -> TokenStream {
    // 解析 args:"GET, \"/users\""
    let mut method = String::from("GET");
    let mut path = String::new();

    let parser = syn::parse::<Meta>(args.clone().into()).unwrap();
    if let Meta::List(list) = parser {
        for (i, nested) in list.nested.iter().enumerate() {
            if let NestedMeta::Lit(Lit::Str(s)) = nested {
                if i == 0 { method = s.value(); }
                if i == 1 { path = s.value(); }
            }
        }
    }

    let func = parse_macro_input!(input as ItemFn);
    let fn_name = &func.sig.ident;
    let fn_body = &func.block;

    let expanded = quote! {
        pub fn #fn_name(req: HttpRequest) -> HttpResponse {
            println!("[{}] {}", #method, #path);
            #fn_body
        }
    };

    expanded.into()
}
```

### 2. 缓存结果属性宏

```rust
#[proc_macro_attribute]
pub fn cache(_args: TokenStream, input: TokenStream) -> TokenStream {
    let func = parse_macro_input!(input as ItemFn);
    let fn_name = &func.sig.ident;
    let fn_name_str = fn_name.to_string();
    let inputs = &func.sig.inputs;
    let output = &func.sig.output;
    let body = &func.block;
    let vis = &func.vis;

    let expanded = quote! {
        #vis fn #fn_name(#inputs) #output {
            use std::sync::OnceLock;
            use std::collections::HashMap;

            static CACHE: OnceLock<std::sync::Mutex<HashMap<String, String>>> =
                OnceLock::new();
            let cache = CACHE.get_or_init(|| std::sync::Mutex::new(HashMap::new()));

            let key = format!("{}::{}", #fn_name_str, "todo:args-hash");

            if let Some(v) = cache.lock().unwrap().get(&key) {
                // 简化:不反序列化,直接返回
                return /* cached value */ todo!();
            }

            // 调用原函数
            let result = (|| #body)();

            // 缓存(简化)
            // cache.lock().unwrap().insert(key, ...);

            result
        }
    };

    expanded.into()
}
```

## 六、函数式宏

函数式宏像函数调用,签名自定义,适合实现 DSL。

### 1. HTML DSL 示例

```rust
// 项目结构
html_macro/
├── Cargo.toml
└── src/lib.rs

// Cargo.toml
[lib]
proc-macro = true
[dependencies]
syn = "2"
quote = "1"
```

```rust
use proc_macro::TokenStream;
use quote::quote;
use syn::parse::{Parse, ParseStream};
use syn::{Ident, Token};

// 节点定义
struct HtmlNode {
    tag: Ident,
    children: Vec<HtmlNode>,
}

impl Parse for HtmlNode {
    fn parse(input: ParseStream) -> syn::Result<Self> {
        let tag: Ident = input.parse()?;
        let content;
        syn::braced!(content in input);

        let mut children = Vec::new();
        while !content.is_empty() {
            children.push(content.parse()?);
        }

        Ok(HtmlNode { tag, children })
    }
}

#[proc_macro]
pub fn html(input: TokenStream) -> TokenStream {
    let node = syn::parse_macro_input!(input as HtmlNode);

    let tag = node.tag;
    let children = node.children.iter().map(|c| {
        let tag = &c.tag;
        quote! { #tag }
    });

    let expanded = quote! {
        HtmlElement {
            tag: stringify!(#tag).to_string(),
            children: vec![ #( #children ),* ],
        }
    };

    expanded.into()
}

pub struct HtmlElement {
    pub tag: String,
    pub children: Vec<&'static str>,
}
```

使用:

```rust
use html_macro::html;

fn main() {
    let _page = html! {
        html {
            head {
                title { "Hi" }
            }
            body {
                h1 { "Hello" }
                p { "world" }
            }
        }
    };
}
```

## 七、实战:命令行参数解析宏

### 1. 简单版本

```rust
macro_rules! clap_app {
    ($name:ident => {
        $(
            $flag:ident : $type:ty = $default:expr,
        )*
    }) => {{
        let mut $name = std::collections::HashMap::new();
        $(
            $name.insert(stringify!($flag), $default);
        )*
        $name
    }};
}

fn main() {
    let args = clap_app!(opts => {
        name: String = "world".to_string(),
        count: u32 = 0,
        verbose: bool = false,
    });
    println!("{:?}", args);
}
```

### 2. 用 clap 替代(实战推荐)

```toml
[dependencies]
clap = { version = "4", features = ["derive"] }
```

```rust
use clap::Parser;

#[derive(Parser, Debug)]
#[command(name = "my_app", version, about)]
struct Args {
    /// 名字
    #[arg(short, long, default_value = "world")]
    name: String,

    /// 计数
    #[arg(short, long, default_value_t = 0)]
    count: u32,

    /// 详细模式
    #[arg(short, long)]
    verbose: bool,
}

fn main() {
    let args = Args::parse();
    println!("{:?}", args);
}
```

## 十、要点速记

- **`macro_rules!`** 是声明宏,模式匹配替换
- **过程宏**需要 `proc-macro = true` 的独立 crate
- **派生宏**签名为 `#[proc_macro_derive(Name)]`
- **属性宏**签名为 `#[proc_macro_attribute]`,作用于整个 item
- **函数式宏**签名为 `#[proc_macro]`,签名灵活,适合 DSL
- **`syn` 解析 TokenStream 成 AST,`quote!` 重新生成 TokenStream**
- **`parse_macro_input!` 把 TokenStream 解析为 syn 类型**
- **`#name` / `#( ... ),*` / `#( ... ),+` 是 quote 的语法**
- **`cargo expand` 调试宏展开**
- **`#[derive(...)]` 自动实现 trait,常见于 serde / thiserror / clap**
- **派生宏项目结构:用户 crate + 过程宏 crate,后者只导 proc-macro**
