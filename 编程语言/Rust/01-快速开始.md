# 01 - 快速开始

## 一、安装

### macOS / Linux

```bash
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
source "$HOME/.cargo/env"
```

### Windows

下载 [rustup-init.exe](https://rustup.rs/),运行后按提示操作。

### 验证

```bash
rustc --version    # rustc 1.xx.x
cargo --version    # cargo 1.xx.x
```

### 工具链组件

```bash
# 离线文档
rustup component add rust-docs

# 代码格式化
rustup component add rustfmt

# Lint
rustup component add clippy

# 调试器(lldb 后端)
rustup component add rust-src
```

## 三、Cargo

### 1. 常用命令

| 命令 | 作用 |
| --- | --- |
| `cargo new <name>` | 创建二进制项目 |
| `cargo new --lib <name>` | 创建库项目 |
| `cargo build` | 编译 |
| `cargo build --release` | 发布构建(优化) |
| `cargo run` | 编译并运行 |
| `cargo check` | 快速检查(不生成可执行文件) |
| `cargo test` | 运行测试 |
| `cargo doc --open` | 生成并打开文档 |
| `cargo fmt` | 格式化代码 |
| `cargo clippy` | Lint |
| `cargo update` | 更新依赖 |
| `cargo clean` | 清理 `target/` |
| `cargo tree` | 查看依赖树 |

### 2. 项目结构

```
my_project/
├── Cargo.toml          # 项目清单(必选)
├── Cargo.lock          # 依赖锁定文件(自动生成)
├── src/
│   ├── main.rs         # 二进制入口
│   ├── lib.rs          # 库入口
│   └── bin/            # 其他二进制
├── tests/              # 集成测试
├── examples/           # 示例代码
├── benches/            # 基准测试
└── target/             # 构建产物
```

### 3. Cargo.toml

```toml
[package]
name = "my_project"
version = "0.1.0"
edition = "2021"        # Rust 版本:2015 / 2018 / 2021 / 2024
rust-version = "1.75"   # 最低支持的 rustc

[dependencies]
serde = { version = "1", features = ["derive"] }
tokio = { version = "1", features = ["full"] }

[dev-dependencies]
criterion = "0.5"

[[bin]]
name = "my_app"
path = "src/main.rs"

[profile.release]
opt-level = 3
lto = true
codegen-units = 1
```

### 4. 工作空间 (workspace)

```toml
# Cargo.toml (workspace root)

    "crates/core",
```

## 四、猜数游戏

经典入门项目,涵盖变量、循环、模式匹配、依赖管理。

### 1. 创建项目

```bash
cargo new guessing_game
cd guessing_game
```

### 2. 引入依赖

```toml
# Cargo.toml
[dependencies]
rand = "0.8"
```

### 3. 完整代码

```rust
// src/main.rs
use std::cmp::Ordering;
use std::io;
use rand::Rng;

fn main() {
    println!("Guess the number!");

    // 1. 生成 1~100 的随机数
    let secret_number = rand::thread_rng().gen_range(1..=100);

    loop {
        println!("\nPlease input your guess.");

        // 2. 读取输入
        let mut guess = String::new();
        io::stdin()
            .read_line(&mut guess)
            .expect("Failed to read line");

        // 3. 解析为 u32(失败则继续循环)
        let guess: u32 = match guess.trim().parse() {
            Ok(num) => num,
            Err(_) => {
                println!("Please type a number!");
                continue;
            }
        };

        println!("You guessed: {}", guess);

        // 4. 比较
        match guess.cmp(&secret_number) {
            Ordering::Less => println!("Too small!"),
            Ordering::Greater => println!("Too big!"),
            Ordering::Equal => {
                println!("You win!");
                break;
            }
        }
    }
}
```

### 4. 运行

```bash
cargo run
```

## 六、发布 crate

### 1. 登录 crates.io

```bash
cargo login <api-token>
```

### 2. 元数据完善

```toml
[package]
name = "my_crate"
version = "0.1.0"
edition = "2021"
description = "A short description"
license = "MIT OR Apache-2.0"
repository = "https://github.com/user/repo"

readme = "README.md"
keywords = ["cli", "tools"]
categories = ["command-line-utilities"]
```

### 3. 发布

```bash
cargo publish              # 发布到 crates.io
cargo publish --dry-run    # 预检
cargo yank --version 0.1.0 # 撤回某个版本(不删除,但阻止新使用)
```

## 七、Rust 版次

| Edition | 引入时间 | 主要变化 |
| --- | --- | --- |
| 2015 | Rust 1.0 | 初版 |
| 2018 | Rust 1.31 | 模块系统、async/await 雏形 |
| 2021 | Rust 1.56 | `intoiterator` 闭包捕获、disjoint capture |
| 2024 | Rust 1.85 | `gen` 块、临时 `&mut` 放宽、RPIT lifetime 捕获 |

新项目默认用 `2021` 或 `2024`。

## 十、要点速记

- **`rustup` 是工具链管理器**:`rustup update` 升级
- **`cargo` 是构建 + 依赖 + 测试一体工具**
- **`cargo new` 创建项目,`cargo run` 编译并运行**
- **`cargo check` 比 `cargo build` 快,适合边写边检查**
- **`cargo build --release` 优化构建,用于生产**
- **依赖锁定在 `Cargo.lock`,二进制项目也应提交**
- **`cargo fmt` 必跑,`cargo clippy` 必跑**
- **`rust-analyzer` 是 LSP 标准**
