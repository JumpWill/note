# 13 - 测试

Rust 内置测试框架,无需第三方。`#[test]` 标注、`cargo test` 运行。

## 一、单元测试

### 1. 基本测试

```rust
pub fn add(a: i32, b: i32) -> i32 {
    a + b
}

pub fn divide(a: i32, b: i32) -> i32 {
    if b == 0 {
        panic!("除数不能为零");
    }
    a / b
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_add() {
        assert_eq!(add(2, 3), 5);
    }

    #[test]
    fn test_add_zero() {
        assert_eq!(add(0, 0), 0);
    }

    #[test]
    #[should_panic(expected = "除数不能为零")]
    fn test_divide_by_zero() {
        divide(10, 0);
    }
}
```

### 2. 断言宏

```rust
#[test]
fn test_assertions() {
    // assert!:布尔断言
    assert!(1 + 1 == 2);

    // assert_eq! / assert_ne!:带值打印
    assert_eq!(2 + 2, 4, "应该等于 4");
    assert_ne!(2 + 2, 5);

    // 带自定义消息
    let x = 42;
    assert!(x > 0, "x 必须正数,got {}", x);

    // assert!(matches!(...))
    let v = Some(3);
    assert!(matches!(v, Some(1 | 3)));
}
```

### 3. #[should_panic]

```rust
#[test]
#[should_panic]
fn test_panic() {
    panic!("boom");
}

#[test]
#[should_panic(expected = "特定消息")]
fn test_panic_msg() {
    panic!("特定消息: invalid");
}
```

### 4. #[ignore] 与运行

```rust
#[test]
#[ignore]                       // 默认跳过
fn expensive_test() {
    // ...
}

#[test]
fn fast_test() {
    // ...
}
```

```bash
cargo test                       # 跑所有
cargo test -- --ignored          # 只跑被忽略的
cargo test -- --include-ignored  # 全部跑
cargo test fast_test             # 名字匹配
```

### 5. Result 返回类型

```rust
#[test]
fn test_result() -> Result<(), String> {
    let n: i32 = "42".parse().map_err(|e| e.to_string())?;
    assert_eq!(n, 42);
    Ok(())
}
```

## 十、要点速记

- **`#[test]` 标注测试函数,`cargo test` 跑测试**
- **`assert!` / `assert_eq!` / `assert_ne!` 是断言宏**
- **`#[should_panic]` 标记预期 panic 的测试**
- **`#[ignore]` 跳过,`cargo test -- --ignored` 跑被跳过的**
- **`#[cfg(test)]` 仅在测试时编译**
- **集成测试放 `tests/` 目录,每个文件是独立 crate**
- **`tests/common/mod.rs` 共享测试代码**
- **`///` 注释中 ``` 块是文档测试,`cargo test --doc` 跑**
- **`Result<T, E>` 返回类型让测试自动传播错误**
- **`pretty_assertions` / `proptest` / `mockall` / `criterion` 常用测试库**
- **`--nocapture` 看 println! 输出,`--test-threads=1` 顺序跑**

### 4. `src/task.rs`

```rust
use std::fmt;

pub struct Task {
    pub id: u64,
    pub name: String,
    pub func: Box<dyn FnOnce() + Send + 'static>,
}

impl Task {
    pub fn new<F>(name: impl Into<String>, f: F) -> Self
    where
        F: FnOnce() + Send + 'static,
    {
        Self {
            id: next_id(),
            name: name.into(),
            func: Box::new(f),
        }
    }

    pub fn run(self) {
        (self.func)();
    }
}

impl fmt::Debug for Task {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.debug_struct("Task")
            .field("id", &self.id)
            .field("name", &self.name)
            .finish()
    }
}

static COUNTER: std::sync::atomic::AtomicU64 = std::sync::atomic::AtomicU64::new(1);

fn next_id() -> u64 {
    COUNTER.fetch_add(1, std::sync::atomic::Ordering::SeqCst)
}

#[cfg(test)]
mod tests {
    use super::*;
    use std::sync::{Arc, Mutex};

    #[test]
    fn test_task_runs() {
        let ran = Arc::new(Mutex::new(false));
        let ran_clone = Arc::clone(&ran);

        let t = Task::new("test", move || {
            *ran_clone.lock().unwrap() = true;
        });

        t.run();
        assert!(*ran.lock().unwrap());
    }

    #[test]
    fn test_task_id_increments() {
        let t1 = Task::new("a", || {});
        let t2 = Task::new("b", || {});
        assert!(t2.id > t1.id);
    }

    #[test]
    fn test_task_debug() {
        let t = Task::new("foo", || {});
        assert!(format!("{:?}", t).contains("foo"));
    }
}
```

### 5. `src/queue.rs`

```rust
use std::collections::VecDeque;

use crate::task::Task;

pub struct TaskQueue {
    inner: VecDeque<Task>,
}

impl TaskQueue {
    pub fn new() -> Self {
        Self { inner: VecDeque::new() }
    }

    pub fn push(&mut self, task: Task) {
        self.inner.push_back(task);
    }

    pub fn pop(&mut self) -> Option<Task> {
        self.inner.pop_front()
    }

    pub fn len(&self) -> usize {
        self.inner.len()
    }

    pub fn is_empty(&self) -> bool {
        self.inner.is_empty()
    }

    pub fn peek(&self) -> Option<&Task> {
        self.inner.front()
    }
}

impl Default for TaskQueue {
    fn default() -> Self {
        Self::new()
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_fifo_order() {
        let mut q = TaskQueue::new();
        q.push(Task::new("a", || println!("a")));
        q.push(Task::new("b", || println!("b")));

        let t = q.pop().unwrap();
        assert_eq!(t.name, "a");
    }

    #[test]
    fn test_empty() {
        let mut q = TaskQueue::new();
        assert!(q.is_empty());
        assert!(q.pop().is_none());
    }
}
```

### 6. `src/worker.rs`

```rust
use std::sync::{Arc, Mutex};
use std::thread;

use crate::queue::TaskQueue;

pub struct Worker {
    handle: Option<thread::JoinHandle<()>>,
    queue: Arc<Mutex<TaskQueue>>,
}

impl Worker {
    pub fn new() -> Self {
        let queue = Arc::new(Mutex::new(TaskQueue::new()));
        let q_clone = Arc::clone(&queue);

        let handle = thread::spawn(move || loop {
            let task = {
                let mut q = q_clone.lock().unwrap();
                q.pop()
            };

            match task {
                Some(t) => t.run(),
                None => {
                    // 简化:无任务时立即退出
                    break;
                }
            }
        });

        Self { handle: Some(handle), queue }
    }

    pub fn submit<F>(&self, name: &str, f: F)
    where
        F: FnOnce() + Send + 'static,
    {
        self.queue.lock().unwrap().push(crate::task::Task::new(name, f));
    }
}

impl Drop for Worker {
    fn drop(&mut self) {
        // 取出所有任务后,worker 自然退出
        if let Some(h) = self.handle.take() {
            let _ = h.join();
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use std::sync::atomic::{AtomicU32, Ordering};

    #[test]
    fn test_worker_executes() {
        let worker = Worker::new();
        let counter = Arc::new(AtomicU32::new(0));
        let c = Arc::clone(&counter);

        worker.submit("test", move || {
            c.fetch_add(1, Ordering::SeqCst);
        });

        std::thread::sleep(std::time::Duration::from_millis(50));
        assert_eq!(counter.load(Ordering::SeqCst), 1);
    }
}
```

use task_queue::{Task, TaskQueue};

pub fn make_named_queue(n: usize) -> TaskQueue {
    let mut q = TaskQueue::new();
    for i in 0..n {
        q.push(Task::new(format!("task-{}", i), || {}));
    }
    q
}

pub fn counter_closure() -> (impl FnOnce() + Send + 'static, std::sync::Arc<std::sync::atomic::AtomicU32>) {
    use std::sync::atomic::AtomicU32;
    use std::sync::Arc;
    let counter = Arc::new(AtomicU32::new(0));
    let c = Arc::clone(&counter);
    let f = move || {
        c.fetch_add(1, std::sync::atomic::Ordering::SeqCst);
    };
    (f, counter)
}

fn test_queue_throughput() {

### 9. `tests/concurrency.rs` - 并发测试

```rust
use std::sync::atomic::{AtomicU32, Ordering};
use std::sync::Arc;

use task_queue::Worker;

#[test]
fn test_worker_handles_concurrent_submissions() {
    let worker = Worker::new();
    let total = Arc::new(AtomicU32::new(0));
    let mut handles = vec![];

    for _ in 0..4 {
        let t = Arc::clone(&total);
        let w = &worker;
        // 注:此处 Worker 不可多 worker 共享(简化),仅演示
        let h = std::thread::spawn(move || {
            for _ in 0..25 {
                w.submit("job", move || {
                    t.fetch_add(1, Ordering::SeqCst);
                });
            }
        });
        handles.push(h);
    }

    for h in handles {
        h.join().unwrap();
    }

    std::thread::sleep(std::time::Duration::from_millis(200));
    assert_eq!(total.load(Ordering::SeqCst), 100);
}
```
