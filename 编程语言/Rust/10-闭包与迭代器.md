# 10 - 闭包与迭代器

闭包(closure)是 Rust 函数式编程的基石,与迭代器(iterator)配合,让集合处理既简洁又零成本。

## 一、闭包基础

### 1. 语法

```rust
fn main() {
    // 单参数,单表达式
    let double = |x| x * 2;

    // 多参数
    let add = |a, b| a + b;

    // 多行闭包
    let complex = |x: i32| -> i32 {
        let y = x + 1;
        y * 2
    };

    // 无参数
    let greet = || println!("hi");

    println!("{}", double(5));     // 10
    println!("{}", add(3, 4));     // 7
    println!("{}", complex(3));    // 8
    greet();
}
```

### 2. 类型推断

```rust
fn main() {
    // 推断后类型固定
    let f = |x| x;  // 推断为 Fn(i32) -> i32
    f(5);
    // f("hi"); // ❌ 类型不匹配
}
```

### 3. 显式标注

```rust
fn main() {
    let f: fn(i32) -> i32 = |x| x + 1;

    // 完整
    let g = |x: i32| -> i32 { x * 2 };
}
```

## 二、捕获环境

闭包有三种方式捕获环境中的变量。

### 1. 三种 trait

| Trait | 含义 | 调用方式 |
| --- | --- | --- |
| `Fn` | 不可变借用捕获,可重复调用 | `&self` |
| `FnMut` | 可变借用捕获,可重复调用 | `&mut self` |
| `FnOnce` | 获取所有权,只能调用一次 | `self` |

```rust
fn main() {
    // Fn:不可变借用
    let x = 10;
    let print_x = || println!("x = {}", x);
    print_x();
    print_x();
    println!("x 仍可用: {}", x);

    // FnMut:可变借用
    let mut count = 0;
    let mut inc = || {
        count += 1;
        println!("count = {}", count);
    };
    inc();
    inc();

    // FnOnce:消耗捕获值
    let s = String::from("hi");
    let consume = move || {
        println!("{}", s);
        drop(s);
    };
    consume();
    // consume(); // ❌ 已被 move
}
```

### 2. `move` 关键字

强制让闭包获取捕获变量的所有权。

```rust
use std::thread;

fn main() {
    let data = vec![1, 2, 3];

    // move 到子线程
    let h = thread::spawn(move || {
        println!("data: {:?}", data);
    });
    h.join().unwrap();
    // data 不能再用
}
```

## 三、闭包作为参数与返回值

### 1. 作为参数

```rust
// 接受 Fn
fn apply<F: Fn(i32) -> i32>(f: F, x: i32) -> i32 {
    f(x)
}

// 接受 FnMut
fn apply_mut<F: FnMut(i32)>(mut f: F, x: i32) {
    f(x);
}

// 接受 FnOnce
fn apply_once<F: FnOnce(i32) -> i32>(f: F, x: i32) -> i32 {
    f(x)
}

fn main() {
    println!("{}", apply(|x| x * 2, 5));  // 10
}
```

### 2. 作为返回值 (`impl Trait`)

```rust
fn make_adder(n: i32) -> impl Fn(i32) -> i32 {
    move |x| x + n
}

fn main() {
    let add5 = make_adder(5);
    println!("{}", add5(10)); // 15
}
```

### 3. 作为返回值 (`Box<dyn Fn>`)

```rust
fn make_op(op: &str) -> Box<dyn Fn(i32, i32) -> i32> {
    match op {
        "add" => Box::new(|a, b| a + b),
        "mul" => Box::new(|a, b| a * b),
        _ => Box::new(|a, b| a - b),
    }
}

fn main() {
    let add = make_op("add");
    println!("{}", add(3, 4)); // 7
}
```

## 四、迭代器基础

### 1. Iterator trait

```rust
pub trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;

    // 提供大量默认方法(map/filter/sum/...)
}
```

### 2. 三种迭代

```rust
fn main() {
    let v = vec![1, 2, 3];

    // iter():&T
    for x in v.iter() {
        println!("{}", x);
    }
    // v 仍可用

    // iter_mut():&mut T
    let mut v2 = vec![1, 2, 3];
    for x in v2.iter_mut() {
        *x *= 2;
    }
    println!("{:?}", v2); // [2, 4, 6]

    // into_iter():T
    let v3 = vec![1, 2, 3];
    for x in v3.into_iter() {
        println!("{}", x);
    }
    // v3 已消耗
}
```

### 3. 实现自定义迭代器

```rust
struct Counter {
    count: u32,
    max: u32,
}

impl Counter {
    fn new(max: u32) -> Self {
        Counter { count: 0, max }
    }
}

impl Iterator for Counter {
    type Item = u32;

    fn next(&mut self) -> Option<Self::Item> {
        if self.count < self.max {
            self.count += 1;
            Some(self.count)
        } else {
            None
        }
    }
}

fn main() {
    let sum: u32 = Counter::new(5).sum();
    println!("sum: {}", sum); // 15

    let v: Vec<u32> = Counter::new(3).collect();
    println!("{:?}", v); // [1, 2, 3]
}
```

## 五、迭代器适配器

### 1. 转换适配器(惰性)

```rust
fn main() {
    let v = vec![1, 2, 3, 4, 5];

    // map:转换
    let doubled: Vec<i32> = v.iter().map(|x| x * 2).collect();
    println!("{:?}", doubled); // [2, 4, 6, 8, 10]

    // filter:过滤
    let evens: Vec<i32> = v.iter().copied().filter(|x| x % 2 == 0).collect();
    println!("{:?}", evens); // [2, 4]

    // filter_map:过滤 + 转换
    let parsed: Vec<i32> = vec!["1", "two", "3"]
        .iter()
        .filter_map(|s| s.parse().ok())
        .collect();
    println!("{:?}", parsed); // [1, 3]

    // enumerate:加索引
    for (i, x) in v.iter().enumerate() {
        println!("{}: {}", i, x);
    }

    // zip:合并两个
    let names = vec!["a", "b", "c"];
    let ages = vec![1, 2, 3];
    let pairs: Vec<_> = names.iter().zip(ages.iter()).collect();
    println!("{:?}", pairs);

    // chain:连接
    let a = vec![1, 2];
    let b = vec![3, 4];
    let chained: Vec<_> = a.iter().chain(b.iter()).copied().collect();
    println!("{:?}", chained); // [1, 2, 3, 4]

    // take_while / skip_while
    let less: Vec<_> = (1..10).take_while(|&x| x < 5).collect();
    println!("{:?}", less); // [1, 2, 3, 4]

    // rev:反向
    let rev: Vec<_> = v.iter().rev().copied().collect();
    println!("{:?}", rev); // [5, 4, 3, 2, 1]
}
```

### 2. 消费适配器(终止)

```rust
fn main() {
    let v = vec![1, 2, 3, 4, 5];

    // sum / product
    let s: i32 = v.iter().sum();
    let p: i32 = v.iter().product();

    // count
    let n = v.iter().filter(|x| *x > 2).count();

    // fold:累积
    let sum = v.iter().fold(0, |acc, x| acc + x);

    // reduce:类似 fold,用第一个元素作初值
    let max = v.iter().copied().reduce(|a, b| a.max(b));

    // any / all
    let has_even = v.iter().any(|x| x % 2 == 0);
    let all_pos = v.iter().all(|x| *x > 0);

    // find / position
    let first_even = v.iter().find(|x| *x % 2 == 0);
    let pos = v.iter().position(|x| *x == 3);

    // min / max
    let (min, max) = (v.iter().min(), v.iter().max());

    // collect 到不同容器
    use std::collections::HashSet;
    let s: HashSet<i32> = v.iter().copied().collect();

    println!("{}", s);
}
```

### 3. 工具方法

```rust
fn main() {
    // peek:看下一个但不消费
    let v = vec![1, 2, 3];
    let mut iter = v.iter().peekable();
    println!("{:?}", iter.peek());  // Some(&1)
    println!("{:?}", iter.next());  // Some(&1)

    // inspect:调试用
    let s: i32 = (1..=3)
        .inspect(|x| println!("before: {}", x))
        .sum();

    // scan:带状态的 map
    let running: Vec<i32> = (1..=5)
        .scan(0, |state, x| {
            *state += x;
            Some(*state)
        })
        .collect();
    println!("{:?}", running); // [1, 3, 6, 10, 15]

    // partition:按条件分组
    let (evens, odds): (Vec<_>, Vec<_>) = (1..=10).partition(|x| x % 2 == 0);
    println!("{:?}, {:?}", evens, odds);

    // flatten / flat_map
    let nested = vec![vec![1, 2], vec![3, 4]];
    let flat: Vec<_> = nested.into_iter().flatten().collect();
    println!("{:?}", flat); // [1, 2, 3, 4]
}
```

## 六、IntoIterator 与 `for` 循环

`for x in collection` 自动调用 `IntoIterator::into_iter`。

### 1. 自定义类型实现 IntoIterator

```rust
struct Matrix {
    data: Vec<Vec<i32>>,
    rows: usize,
    cols: usize,
}

impl Matrix {
    fn new(rows: usize, cols: usize) -> Self {
        Matrix { data: vec![vec![0; cols]; rows], rows, cols }
    }
}

impl IntoIterator for Matrix {
    type Item = i32;
    type IntoIter = std::vec::IntoIter<i32>;

    fn into_iter(self) -> Self::IntoIter {
        self.data.into_iter().flatten().collect::<Vec<_>>().into_iter()
    }
}

fn main() {
    let mut m = Matrix::new(2, 3);
    for i in 0..2 {
        for j in 0..3 {
            m.data[i][j] = (i * 3 + j) as i32;
        }
    }

    for v in m {
        println!("{}", v);
    }
}
```

## 七、性能:零成本抽象

迭代器编译后与手写循环性能相当,**没有额外运行时开销**。

```rust
// 迭代器
fn sum_iter(v: &[i32]) -> i32 {
    v.iter().map(|x| x * x).filter(|x| x % 2 == 0).sum()
}

// 等价手写循环
fn sum_loop(v: &[i32]) -> i32 {
    let mut total = 0;
    for &x in v {
        let sq = x * x;
        if sq % 2 == 0 {
            total += sq;
        }
    }
    total
}
```

```rust
use std::collections::BTreeMap;

#[derive(Debug)]
struct Item {
    name: String,
    category: String,
    score: u32,
}

fn group_top(items: Vec<Item>) -> BTreeMap<String, Vec<String>> {
    let mut grouped: BTreeMap<String, Vec<Item>> = BTreeMap::new();
    for item in items {
        grouped.entry(item.category).or_default().push(item);
    }

    grouped
        .into_iter()
        .map(|(cat, mut items)| {
            items.sort_by(|a, b| b.score.cmp(&a.score));
            let top3: Vec<String> = items.into_iter().take(3).map(|i| i.name).collect();
            (cat, top3)
        })
        .collect()
}

fn main() {
    let items = vec![

        Item { name: "B".into(), category: "X".into(), score: 80 },
```

## 九、要点速记

- **闭包 = 可捕获环境的匿名函数**
- **三种 trait:`Fn` / `FnMut` / `FnOnce`**
- **`move` 强制获取所有权,跨线程必备**
- **函数参数 `F: Fn(x) -> y` 等价 `f: impl Fn(x) -> y`**
- **迭代器三种:`iter()` / `iter_mut()` / `into_iter()`**
- **适配器是惰性的,消费器触发执行**
- **`map` / `filter` / `fold` 是最常用的组合**
- **`collect` 可收集到任何实现了 `FromIterator` 的类型**
- **迭代器是零成本抽象,与手写循环等价**
- **`IntoIterator` 让 `for x in coll` 工作**

```rust
use std::str::FromStr;

#[derive(Debug, Clone)]
pub struct Sale {
    pub date: String,
    pub product: String,
    pub category: String,
    pub amount: f64,
    pub quantity: u32,
}

impl Sale {
    pub fn revenue(&self) -> f64 {
        self.amount * self.quantity as f64
    }

    pub fn parse(line: &str) -> Option<Self> {
        let mut parts = line.split(',');
        Some(Self {
            date: parts.next()?.to_string(),
            product: parts.next()?.to_string(),
            category: parts.next()?.to_string(),
            amount: parts.next()?.parse().ok()?,
            quantity: parts.next()?.parse().ok()?,
        })
    }
}

// FromStr 实现
impl FromStr for Sale {
    type Err = String;

    fn from_str(s: &str) -> Result<Self, Self::Err> {
        Sale::parse(s).ok_or_else(|| format!("无法解析: {}", s))
    }
}
```

### 5. `src/reader.rs` - 自定义迭代器

```rust
use std::fs::File;
use std::io::{BufRead, BufReader};
use std::str::FromStr;

use crate::record::Sale;

/// CSV 迭代器:跳过表头,逐行产出 Sale
pub struct SaleReader<R: BufRead> {
    inner: R,
    header_skipped: bool,
}

impl<R: BufRead> SaleReader<R> {
    pub fn new(reader: R) -> Self {
        Self { inner: reader, header_skipped: false }
    }
}

impl<R: BufRead> Iterator for SaleReader<R> {
    type Item = Sale;

    fn next(&mut self) -> Option<Self::Item> {
        let mut line = String::new();
        loop {
            line.clear();
            let n = self.inner.read_line(&mut line).ok()?;
            if n == 0 { return None; }
            let trimmed = line.trim();

            if !self.header_skipped {
                self.header_skipped = true;
                continue;
            }

            if trimmed.is_empty() { continue; }

            return Sale::parse(trimmed);
        }
    }
}

pub fn from_file(path: &str) -> std::io::Result<impl Iterator<Item = Sale>> {
    let file = File::open(path)?;
    let reader = BufReader::new(file);
    Ok(SaleReader::new(reader))
}
```

```rust
pub fn total_revenue<F>(sales: &[Sale], filter: F) -> f64
where
    F: Fn(&Sale) -> bool,
{
    sales.iter()
        .filter(|s| filter(s))
        .map(|s| s.revenue())

pub fn make_accumulator<F: FnMut(f64)>(mut f: F) -> impl FnMut(Sale) {
    move |sale| f(sale.revenue())
```

### 7. `src/stats.rs` - 自定义适配器

```rust
use std::collections::HashMap;

/// 滑窗迭代器适配器
pub struct Window<I: Iterator> {
    iter: I,
    size: usize,
    buffer: Vec<Option<I::Item>>,
}

impl<I: Iterator> Window<I>
where
    I::Item: Clone,
{
    pub fn new(iter: I, size: usize) -> Self {
        Self {
            iter,
            size,
            buffer: Vec::with_capacity(size),
        }
    }
}

impl<I: Iterator> Iterator for Window<I>
where
    I::Item: Clone,
{
    type Item = Vec<I::Item>;

    fn next(&mut self) -> Option<Self::Item> {
        // 填满缓冲区
        while self.buffer.len() < self.size {
            match self.iter.next() {
                Some(item) => self.buffer.push(Some(item)),
                None => break,
            }
        }

        if self.buffer.is_empty() {
            return None;
        }

        // 弹出首个元素
        self.buffer.remove(0);

        if self.buffer.len() < self.size {
            return None;
        }

        let window: Vec<_> = self.buffer.iter().filter_map(|x| x.clone()).collect();
        Some(window)
    }
}

/// 扩展 trait,让所有迭代器都能用 window
pub trait WindowExt: Iterator {
    fn window(self, size: usize) -> Window<Self>
    where
        Self: Sized,
        Self::Item: Clone,
    {
        Window::new(self, size)
    }
}

impl<I: Iterator> WindowExt for I {}

/// 计数器
pub fn count_by<I, F, K>(iter: I, key_fn: F) -> HashMap<K, usize>
where
    I: Iterator,
    F: Fn(I::Item) -> K,
    K: std::hash::Hash + Eq,
{
    let mut counts = HashMap::new();
    for item in iter {
        let k = key_fn(item);
        *counts.entry(k).or_insert(0) += 1;
    }
    counts
}
```

```rust
    println!("\n--- 滑窗 3 天平均金额 ---");
    let daily_amounts = sales.iter().map(|s| s.amount);
    for window in daily_amounts.window(3) {
        let avg: f64 = window.iter().sum::<f64>() / window.len() as f64;
        println!("滑窗: {:?}", window);
    }

    // 5. count_by
    let mut sales_iter = sales.into_iter();
    let product_counts = count_by(&mut sales_iter, |s| s.product.clone());
    println!("\n商品出现次数: {:?}", product_counts);
}
```

### 11. 关键点
