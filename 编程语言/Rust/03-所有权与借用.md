# 03 - 所有权与借用

Rust 最独特的特性:无需 GC、无需手动释放,编译期保证内存安全。

## 一、所有权规则

1. Rust 中每个值都有一个所有者(变量)
2. 同一时刻只能有一个所有者
3. 当所有者离开作用域时,值被自动丢弃(`drop`)

```rust
fn main() {
    let s = String::from("hello"); // s 是所有者
    // s 进入作用域
    do_something(s);                // 所有权 move 到函数
    // println!("{}", s);          // ❌ 编译错误:s 已被 move
} // s 在这里本应 drop,但早已 move 走

fn do_something(s: String) {
    println!("{}", s);
} // s 在这里 drop,内存释放
```

## 二、Move 语义

### 1. 栈上复制 vs 堆上 Move

```rust
fn main() {
    // 整数(i32)实现 Copy trait,赋值时复制
    let x = 5;
    let y = x;     // 复制
    println!("{} {}", x, y); // ✅ 仍可用

    // String 堆分配,赋值时 move
    let s1 = String::from("hello");
    let s2 = s1;    // s1 被 move,失效
    // println!("{}", s1); // ❌

    // 深拷贝(显式)
    let s3 = s2.clone();
    println!("{} {}", s2, s3); // ✅
}
```

### 2. 实现 Copy 的类型

```rust
// ✅ 实现 Copy
let a: i32 = 5;
let b: u8 = 1;
let c: f64 = 3.14;
let d: bool = true;
let e: char = 'x';
let f: (i32, char) = (1, 'a');           // 元组元素全 Copy
let g: [i32; 3] = [1, 2, 3];             // 数组元素全 Copy

// ❌ 不实现 Copy
let s: String = String::from("hi");      // 堆分配
let v: Vec<i32> = vec![1, 2];            // 堆分配
let t: (String, i32) = (String::new(), 1); // 含非 Copy 元素
```

## 三、借用 (References)

### 1. 不可变借用 `&T`

```rust
fn calculate_length(s: &String) -> usize {
    s.len()
} // s 是引用,离开作用域时引用被 drop,但不影响原值

fn main() {
    let s1 = String::from("hello");
    let len = calculate_length(&s1);
    println!("'{}' has length {}", s1, len); // s1 仍可用
}
```

### 2. 可变借用 `&mut T`

```rust
fn change(s: &mut String) {
    s.push_str(", world");
}

fn main() {
    let mut s = String::from("hello");
    change(&mut s);
    println!("{}", s); // hello, world
}
```

### 3. 借用规则(编译期检查)

1. **任意时刻,只能有一个可变引用**(`&mut T`)
2. **或者任意多个不可变引用**(`&T`)
3. **不能同时拥有可变和不可变引用**
4. **引用必须总是有效的**

```rust
fn main() {
    let mut s = String::from("hello");

    let r1 = &s;       // ✅
    let r2 = &s;       // ✅ 多个不可变
    // let r3 = &mut s; // ❌ 已存在不可变借用

    // r1, r2 用完后(NLL)
    println!("{} {}", r1, r2);

    let r3 = &mut s;   // ✅ 不可变借用在 NLL 后失效
    r3.push_str("!");
}
```

### 4. 非词法作用域 (NLL)

```rust
fn main() {
    let mut s = String::from("hello");

    let r1 = &s;
    let r2 = &s;
    println!("{} {}", r1, r2); // r1, r2 最后一次使用

    let r3 = &mut s;  // r1, r2 在此已不再使用,编译器自动识别
    r3.push_str(" world");
}
```

### 5. 悬垂引用 (Dangling)

```rust
// ❌ 编译错误
// fn dangle() -> &String {
//     let s = String::from("hi");
//     &s  // s 在此 drop
// }

// ✅ 返回所有权
fn no_dangle() -> String {
    String::from("hi")
}
```

## 四、切片 (Slices)

### 1. 字符串切片 `&str`

```rust
fn main() {
    let s = String::from("hello world");

    // 切片语法 &[start..end](左闭右开)
    let hello: &str = &s[0..5];
    let world: &str = &s[6..11];

    let whole: &str = &s[..];        // 整个字符串
    let from_start: &str = &s[..5];  // 从头到 5
    let to_end: &str = &s[6..];      // 从 6 到尾

    println!("{} | {}", hello, world);
}
```

### 2. first_word 函数

```rust
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &b) in bytes.iter().enumerate() {
        if b == b' ' {
            return &s[..i];
        }
    }
    &s[..]
}

fn main() {
    let s = String::from("hello world");
    println!("{}", first_word(&s)); // hello

    // 字面量也是 &str,可直接传
    println!("{}", first_word("hi rust"));
}
```

### 3. 其他类型的切片

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5];
    let slice: &[i32] = &arr[1..4]; // &[2, 3, 4]

    println!("len: {}", slice.len());
    println!("first: {:?}", slice.first());  // Some(2)
    println!("last: {:?}", slice.last());    // Some(4)
    println!("get(2): {:?}", slice.get(2));  // Some(3)
    println!("get(10): {:?}", slice.get(10)); // None

    // 求和
    let sum: i32 = slice.iter().sum();
    println!("sum: {}", sum); // 9
}
```

### 4. Boxed Slice `Box<[T]>`

```rust
fn main() {
    // 堆分配的切片(长度可变)
    let boxed: Box<[i32]> = vec![1, 2, 3, 4, 5].into_boxed_slice();

    // 转 Vec
    let v: Vec<i32> = boxed.into_vec();

    // 字符串 boxed 切片
    let bs: Box<str> = String::from("hi").into_boxed_str();
}
```

### 5. 函数签名:接受 `&str` 而非 `&String`

```rust
// ✅ 通用:接受 &str、String、字面量
fn print(s: &str) {
    println!("{}", s);
}

fn main() {
    let owned = String::from("hello");
    print(&owned);     // &String -> &str(Deref coercion)
    print("literal");  // &str
    print(&owned[..]); // 显式切片
}
```

## 五、解引用与 Deref

### 1. 自动解引用

```rust
fn main() {
    let s = String::from("hello");
    let rs = &s;

    // 方法调用:自动解引用
    println!("{}", rs.len());   // 等价 s.len()

    // 运算符:自动解引用
    let n = &10;
    println!("{}", n + 1);      // 11,自动 *n + 1
}
```

### 2. 自定义 Deref

```rust
use std::ops::Deref;

struct MyBox<T>(T);

impl<T> Deref for MyBox<T> {
    type Target = T;
    fn deref(&self) -> &T {
        &self.0
    }
}

fn hello(name: &str) {
    println!("hello, {}", name);
}

fn main() {
    let m = MyBox(String::from("Rust"));

    // Deref coercion:&MyBox<String> -> &String -> &str
    hello(&m);

    // 等价手动解引用
    hello(&(*m)[..]);
}
```

**Deref coercion 规则**:
- `&T -> &U` 当 `T: Deref<Target=U>`
- `&mut T -> &mut U` 当 `T: DerefMut<Target=U>`
- `&mut T -> &U` 当 `T: Deref<Target=U>`

### 3. `*` 解引用

```rust
fn main() {
    let mut x = 10;
    let rx = &mut x;

    *rx = 20;       // 通过引用修改值
    println!("{}", x); // 20

    // Box 解引用
    let b = Box::new(5);
    println!("{}", *b); // 5
}
```

## 六、生命周期 (Lifetimes)

### 1. 为什么需要生命周期

```rust
// ❌ 编译器无法推断 x 和 y 谁活得久
// fn longest(x: &str, y: &str) -> &str {
//     if x.len() > y.len() { x } else { y }
// }

// ✅ 显式标注生命周期
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

`'a` 是生命周期参数,表示 `x` 和 `y` 与返回值至少活得一样久。

### 2. 结构体中的生命周期

```rust
struct ImportantExcerpt<'a> {
    part: &'a str,
}

impl<'a> ImportantExcerpt<'a> {
    fn level(&self) -> i32 {
        3
    }

    fn announce_and_return(&self, ann: &str) -> &str {
        println!("注意: {}", ann);
        self.part
    }
}

fn main() {
    let novel = String::from("从前有座山. 山里有座庙.");
    let first = novel.split('.').next().expect("找不到句号");
    let excerpt = ImportantExcerpt { part: first };
    println!("{}", excerpt.part);
}
```

### 3. 生命周期省略规则

编译器在以下情况自动推断生命周期:

1. **每个引用参数**都有独立生命周期
2. **如果只有一个输入生命周期**,输出生命周期与之相同
3. **如果有 `&self` 或 `&mut self`**,输出生命周期与 `self` 相同

```rust
// 规则应用后等价于 fn f<'a>(s: &'a str) -> &'a str
fn first_word(s: &str) -> &str { ... }
```

### 4. 静态生命周期 `'static`

```rust
let s: &'static str = "我有 static 生命周期";
// 字符串字面量都是 'static
// 保存在程序二进制中
```

### 5. 生命周期边界

```rust
// T: 'a 表示 T 至少活得和 'a 一样久
struct Ref<'a, T: 'a> {
    r: &'a T,
}

// 'a: 'b 表示 'a 至少活得和 'b 一样久
fn choose<'a, 'b: 'a>(first: &'a str, second: &'b str) -> &'a str {
    first
}
```

### 6. HRTB (高阶 Trait 边界)

```rust
// 接受任何 lifetime 的 &str
fn longest_with_trait<T>(x: &str, y: &str, ann: T) -> &str
where
    T: std::fmt::Display,
{
    println!("ann: {}", ann);
    if x.len() > y.len() { x } else { y }
}
```

## 七、实战:所有权 / 借用常见模式

### 1. 函数返回新值 vs 修改入参

```rust
// 模式 1:返回新值(无副作用,推荐)
fn add_suffix(s: String, suffix: &str) -> String {
    format!("{}{}", s, suffix)
}

// 模式 2:修改入参(原地)
fn add_suffix_inplace(s: &mut String, suffix: &str) {
    s.push_str(suffix);
}

fn main() {
    let mut s = String::from("hi");
    add_suffix_inplace(&mut s, "!");
    println!("{}", s); // hi!
}
```

```rust
}
```

## 八、要点速记

- **三大规则**:唯一所有者、move 转移、自动 drop
- **`Copy` 类型(i32/bool/char 等)赋值复制,否则 move**
- **借用规则:同时只能一个 `&mut`,或多个 `&`,不能混用**
- **NLL 让借用按最后使用失效,而非词法作用域**
- **切片 `&[T]` / `&str` 是视图,不拥有数据**
- **函数参数优先 `&str` 而非 `&String`**(接受范围更广)
- **Deref coercion 自动转换 `&MyBox<T> -> &T`**
- **生命周期 `'a` 表示引用至少活得 `'a` 那么久**
- **结构体存引用必须有生命周期参数**
- **`'static` 表示整个程序运行期间**
- **三个省略规则让 90% 生命周期无需标注**
- **编译错误信息会告诉你生命周期问题在哪**

```rust
#[derive(Error, Debug)]
pub enum ParseError {
    #[error("行 {line}: 字段数量错误,期望 {expected},实际 {actual}")]
    FieldCount { line: usize, expected: usize, actual: usize },

    #[error("行 {line}: 解析失败: {0}")]
    InvalidValue { line: usize, msg: String },

    #[error("行 {line}: 数据为空")]
    EmptyLine { line: usize },
```

### 4. `src/row.rs` - 借用切片行

```rust
use crate::error::{ParseError, Result};

/// Row 借用原始数据,零拷贝
pub struct Row<'a> {
    raw: &'a str,
    fields: Vec<&'a str>,
}

impl<'a> Row<'a> {
    pub fn parse(line: &'a str, expected: usize, line_no: usize) -> Result<Self> {
        let trimmed = line.trim();
        if trimmed.is_empty() {
            return Err(ParseError::EmptyLine { line: line_no });
        }

        let fields: Vec<&str> = trimmed.split(',').map(str::trim).collect();

        if fields.len() != expected {
            return Err(ParseError::FieldCount {
                line: line_no,
                expected,
                actual: fields.len(),
            });
        }

        Ok(Self { raw: line, fields })
    }

    pub fn get(&self, idx: usize) -> Option<&str> {
        self.fields.get(idx).copied()
    }

    pub fn get_u32(&self, idx: usize, line_no: usize) -> Result<u32> {
        self.get(idx)
            .ok_or_else(|| ParseError::InvalidValue {
                line: line_no,
                msg: format!("字段 {} 不存在", idx),
            })?
            .parse()
            .map_err(|e: std::num::ParseIntError| ParseError::InvalidValue {
                line: line_no,
                msg: format!("解析 u32 失败: {}", e),
            })
    }

    pub fn fields(&self) -> &[&'a str] {
        &self.fields
    }

    pub fn as_str(&self) -> &'a str {
        self.raw
    }
}
```

### 5. `src/iterator.rs` - 借用迭代器

```rust
use crate::error::{ParseError, Result};
use crate::row::Row;

/// 借用 `&str` 内容生成 Row,零拷贝
pub struct RowIter<'a> {
    content: &'a str,
    expected_fields: usize,
    line_no: usize,
}

impl<'a> RowIter<'a> {
    pub fn new(content: &'a str, expected_fields: usize) -> Self {
        Self { content, expected_fields, line_no: 0 }
    }
}

impl<'a> Iterator for RowIter<'a> {
    type Item = Result<Row<'a>>;

    fn next(&mut self) -> Option<Self::Item> {
        // 找下一行
        let start = if self.line_no == 0 {
            0
        } else {
            // 跳过当前行(简化)
            0
        };

        let rest = &self.content[start..];
        let line = rest.lines().next()?;

        self.line_no += 1;
        Some(Row::parse(line, self.expected_fields, self.line_no))
    }
}
```

### 6. `src/parser.rs` - 解析器

```rust
use crate::error::Result;
use crate::iterator::RowIter;
use crate::row::Row;

/// 解析整个 CSV 内容
pub fn parse_csv<'a>(content: &'a str, expected_fields: usize) -> impl Iterator<Item = Result<Row<'a>>> + 'a {
    RowIter::new(content, expected_fields)
}

/// 解析为强类型记录(消费 Row)
#[derive(Debug)]
pub struct Record {
    pub name: String,
    pub age: u32,
    pub email: String,
}

impl Record {
    pub fn from_row(row: &Row, line_no: usize) -> Result<Self> {
        Ok(Self {
            name: row.get(0).unwrap_or("").to_string(),
            age: row.get_u32(1, line_no)?,
            email: row.get(2).unwrap_or("").to_string(),
        })
    }
}

pub fn parse_records(content: &str) -> Result<Vec<Record>> {
    parse_csv(content, 3)
        .enumerate()
        .map(|(i, r)| r.and_then(|row| Record::from_row(&row, i + 1)))
        .collect()
}
```

### 9. 关键点解析

| 概念 | 用法 |
| --- | --- |
| `&'a str` | 借用原始字符串,避免拷贝 |
| `Row<'a>` | 借用生命周期参数 |
| `impl Iterator + 'a` | 迭代器借用同一份数据 |
| `enumerate()` + `Result` | 行号传递 |
| `&str::parse::<u32>()` | 字符串到数字 |
| `From<&str>` | 隐式 String 转换 |

### 10. 性能对比

```rust
// ❌ 反例:每次拷贝
fn parse_eagerly(content: &str) -> Vec<Vec<String>> {

        .map(|line| line.split(',').map(str::to_string).collect())

// ✅ 正例:借用切片,需要时再 to_string
fn parse_lazy<'a>(content: &'a str) -> Vec<Row<'a>> {
```
