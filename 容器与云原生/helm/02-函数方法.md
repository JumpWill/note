# Helm 模板函数速查

> Helm 模板里能用的所有函数大部分来自 [Sprig 函数库](https://masterminds.github.io/sprig/)，加上 Helm 自己加的几个（`tpl`、`lookup`、`required`、`include`、`toYaml`）。
> 这一篇按**用途分组**列出最常用的 ~80 个 + 实战示例，方便查表。

---

## 一、用法速记

```yaml
{{/* 管道：上一级作为下一级第一个参数 */}
{{ "HELLO" | lower | quote }}        # → "hello"

{{/* 多参数：直接调用） */}
{{ include "mychart.labels" . }}

{{/* 带函数调用） */}
{{ add 1 2 }}                        # → 3

{{/* 链式调用） */}
{{ .Values.image.tag | default .Chart.AppVersion | quote }}
```

> **原则**——能用 `.Values` 默认值搞定的就不要写函数；函数只解决 **值缺失 / 转换 / 提取** 的事。

## 二、字符串函数（最常用）

| 函数 | 干啥 | 示例 |
| --- | --- | --- |
| `quote` / `squote` | 包双引号 / 单引号 | `quote "abc"` → `"abc"` |
| `upper` / `lower` | 大小写转换 | `lower "HELLO"` → `hello` |
| `trim` | 去首尾空格 | `trim "  abc  "` → `abc` |
| `trimPrefix` / `trimSuffix` | 去指定前缀/后缀 | `trimSuffix "-" "my-rel-"` → `my-rel` |
| `trimAll` | 去所有指定字符 | `trimAll "-" "--a--b--"` → `ab` |
| `repeat` | 重复 N 次 | `repeat 3 "ab"` → `ababab` |
| `substr` | 子串（从 start 取 count 字符） | `substr 1 4 "abcdef"` → `bcde` |
| `nospace` | 去所有空格 | `nospace "a b c"` → `abc` |
| `printf` | 格式化字符串 | `printf "%s-%s" "a" "b"` → `a-b` |
| `replace` | 字符串替换 | `replace "+" "_" "a+b"` → `a_b` |
| `contains` | 是否包含子串 | `contains "foo" "foobar"` → `true` |
| `hasPrefix` / `hasSuffix` | 前缀/后缀判断 | `hasPrefix "my-" "my-rel"` → `true` |
| `len` | 字符串长度（也用于 list/map） | `len "abc"` → `3` |
| `indent` / `nindent` | 缩进 N 字符（`nindent` = newline + indent） | 见下文 |
| `randAlphaNum` | N 位随机字母数字 | `randAlphaNum 16` |
| `b64enc` / `b64dec` | base64 编解码 | `b64enc "abc"` → `YWJj` |
| `sha256sum` | sha256（返回 hex） | 证书指纹等 |
| `sha1sum` / `adler32sum` | 同上 | — |
| `toString` | 转 string | `toString 1` → `1` |
| `htmlDate` / `htmlDateInZone` | 转 HTML date 格式 | `htmlDate (now)` |

**`indent` vs `nindent`（必会）**：

```yaml
data:
  config: |-
    {{- include "app.config" . | indent 4 }}
```

```text
indent N   = 每行前加 N 个空格（**首行也会加**，连 上一行 一起缩进）
nindent N  = 先换行再加 N 空格（**首行另起一行**）
```

实际 **99% 用 `nindent`**——避免 YAML 模板渲染成 `key:line1` 没换行：

```yaml
# 错误写法（data 内容跟 yaml key 同行）
data:
  config: {{- include "app.config" . | indent 4 }}

# 正确写法（nindent 先换行）
data:
  config: |-
    {{- include "app.config" . | nindent 4 }}
```

## 三、数学函数

| 函数 | 含义 | 示例 |
| --- | --- | --- |
| `add` / `sub` / `mul` / `div` | 加减乘除 | `add 1 2` → `3` |
| `mod` | 取模 | `mod 10 3` → `1` |

```yaml
# 副本数 = min(用户配的, 节点数)
replicas: {{ .Values.replicas | default 3 }}
{{- if and (gt (int .Values.replicas) 0) (lt (int .Values.replicas) 10) }}
# 只在 1-9 之间接受
{{- end }}
```

## 四、类型转换（必学）

| 函数 | 干啥 | 示例 |
| --- | --- | --- |
| `int` / `float` | 转数字 | `int "42"` → `42` |
| `toString` | 转 string | `toString 1.5` → `"1.5"` |
| `toJson` / `toToml` / `toYaml` | 序列化为字符串 | `toJson .Values` |
| `fromJson` / `fromYaml` | 反序列化 | `fromJson .Values.jsonStr` |
| `fromJsonArray` / `fromYamlArray` | 反序列化为 list | — |
| `b64enc` / `b64dec` | base64 | — |

**最常见的坑**：`toJson` 返回的字符串需要 `quote` 才能塞进 YAML：

```yaml
# 错误（生成的字符串没引号，YAML 解析错）
env:
  - name: CONFIG
    value: {{ toJson .Values.config }}

# 正确
env:
  - name: CONFIG
    value: {{ toJson .Values.config | quote }}

# 或者直接用 toYaml 嵌多行（更可读）
env:
  - name: CONFIG
    value: |-
      {{- toYaml .Values.config | nindent 8 }}
```

## 五、日期 / 时间

| 函数 | 含义 |
| --- | --- |
| `now` | 当前时间（time.Time） |
| `date` | 格式化为指定格式（默认是 K8s RFC3339） |
| `dateInZone` | 带时区格式化 |
| `date_modify` | 在 time 上加减（"+1h" / "-30m"） |
| `htmlDate` / `htmlDateInZone` | HTML date 格式 |
| `rfc3339` / `rfc3339InZone` | RFC3339 格式 |
| `unixEpoch` | 转 Unix 时间戳 |
| `toDate` | 字符串 → time.Time |
| `duration` | 字符串 → time.Duration（`"1h30m"`） |

```yaml
# annotation 标当前时间（UTC）
metadata:
  annotations:
    deployed: {{ now | date "2006-01-02T15:04:05Z07:00" | quote }}

# 镜像 tag = 当前日期（CI 用）
image:
  tag: {{ now | date "20060102" }}-{{ .Values.gitSha }}
```

> ⚠️ `now` 默认是**UTC**，不是本地时间。

## 七、列表函数（重要）

| 函数 | 含义 | 示例 |
| --- | --- | --- |
| `list` | 创建列表 | `list "a" "b"` |
| `first` / `last` | 首 / 尾 | `first (list 1 2 3)` → `1` |
| `rest` / `initial` | 去掉首 / 去掉尾 | `rest (list 1 2 3)` → `2 3` |
| `append` / `prepend` | 加元素 | `append (list "a") "b"` |
| `concat` | 拼接多列表 | `concat (list "a") (list "b")` |
| `compact` | 去掉空字符串 | — |
| `uniq` | 去重 | — |
| `has` | 列表是否包含 | `has "b" (list "a" "b" "c")` |
| `index` | 按下标取 | `index (list "a" "b" "c") 1` → `b` |
| `slice` | 子列表 | `slice (list 1 2 3 4) 1 3` → `2 3` |
| `len` | 长度 | `len (list 1 2 3)` → `3` |
| `sortAlpha` | 字母序 | — |
| `reverse` | 反转 | — |
| `without` | 移除指定元素 | `without (list "a" "b" "c") "b"` |
| `chunk` | 按 N 分块 | — |
| `splitList` / `split` | 字符串 → 列表（后者支持正则） | — |
| `join` | 列表 → 字符串 | `join "," (list "a" "b")` → `a,b` |

```yaml
# env 列表的常见组合用法
env:
  {{- range $k, $v := .Values.env }}
  - name: {{ $k | upper }}
    value: {{ $v | quote }}
  {{- end }}

# 字符串拼接成 CSV
data:
  allowList: {{ join "," .Values.allowedDomains | quote }}
```

## 八、字典函数（map 操作）

| 函数 | 含义 | 示例 |
| --- | --- | --- |
| `dict` | 创建字典 | `dict "k1" "v1" "k2" "v2"` |
| `get` / `set` | 取 / 改（**不修改原对象**，返回新 dict） | `get (dict "k" "v") "k"` → `v` |
| `pluck` | 列表里所有 dict 的指定 key | — |
| `keys` / `values` | 所有 key / value | — |
| `hasKey` | 是否有 key | `hasKey (dict "k" 1) "k"` |
| `omit` / `pick` | 排除 / 选择 key | `pick (dict "a" 1 "b" 2) "a"` → `{"a": 1}` |
| `merge` / `mustMerge` | 合并（后覆盖前） | `mustMerge (dict "a" 1) (dict "a" 2)` → `{"a": 2}` |
| `deepCopy` | 深拷贝 | 避免修改原值 |
| `dig` | 嵌套路径取值（**任意层为空都返回默认值**，比 `index` 安全） | 见下文 |

**`dig` vs `index`**（新手必踩）：

```yaml
{{- /* 假设 .Values.foo.bar.baz = "x" */}}
{{ index .Values "foo" "bar" "baz" }}     # → "x"
{{ dig "baz" "default" .Values.foo.bar }}  # → "default"（bar 是 nil）
{{ dig "baz" "default" .Values.foo "bar" "baz" }}  # → "x"
```

`dig` 写法不易 panic（任意中间是 nil 都走默认值）。

## 九、逻辑 / 比较函数

| 函数 | 含义 |
| --- | --- |
| `eq` `ne` `lt` `gt` `le` `ge` | 6 个比较 |
| `and` `or` `not` | 与 / 或 / 非（**短路求值**） |
| `default` | 值为空时取默认值（**最常用之一**） |
| `empty` | 是否为空（nil / 0 / "" / map{} / []） |
| `coalesce` | 第一个非空值（多个 fallback） |
| `fail` | 强制报错 |
| `ternary` | 三元（Go 1.18+ 类似） |
| `typeIs` / `typeOf` / `kindIs` / `kindOf` | 类型 / kind 判断 |
| `lookPath` | 查 PATH 上的可执行文件（template 阶段不常用） |

```yaml
# default + coalesce 链
image: {{ coalesce .Values.image.tag .Chart.AppVersion "latest" }}

# 复杂条件
{{- if and (gt (int .Values.replicas) 0) (eq .Values.env "prod") }}
# 副本 > 0 且环境是 prod
{{- end }}
```

> ⚠️ **比较运算符 vs 函数**：`{{ gt 1 2 }}` vs `{{ if (gt 1 2) }}`——前者是模板引擎原生的 `gt` 函数，**管道里**也要用函数版本。

## 十、正则（按需用）

| 函数 | 含义 |
| --- | --- |
| `regexMatch` | 是否匹配（bool） |
| `regexFind` | 第一个匹配 |
| `regexFindAll` | 所有匹配（`N` 限制返回数） |
| `regexReplaceAll` | 全部替换（支持反向引用） |
| `regexReplaceAllLiteral` | 全部替换（不支持反向引用） |
| `regexSplit` | 按正则切分 |

```yaml
# 把 image tag 里的非数字字母下划线全替换成 -

```

> Helm 用的是 **RE2** 引擎，不支持反向引用和零宽断言。

## 十二、Helm 专属函数

| 函数 | 含义 |
| --- | --- |
| `tpl` | 把字符串当模板渲染 |
| `lookup` | 查 K8s 集群里的真实资源（**运行时**才有值） |
| `required` | 必填校验（缺失报错） |
| `include` / `template` | 调用命名模板 |
| `toYaml` | 渲染 YAML（带缩进） |
| `fromYaml` / `fromJson` | 反序列化 |

### `tpl`（高级用法）

```yaml
# values.yaml
env:
  - name: GREETING
    value: "Hello {{ .Chart.Name }}"

# 模板里渲染 value 里的占位符
env:
  - name: GREETING
    value: {{ tpl (.Values.env[0].value) . | quote }}
```

### `lookup`（慎用）

```yaml
{{- $existing := lookup "v1" "ConfigMap" .Release.Namespace "my-config" -}}
{{- if $existing }}
# CR 已存在，特殊处理
{{- end }}
```

> ⚠️ **坑**：`helm template` 时 `lookup` 永远返回 nil（只在 `helm install/upgrade` 真连集群时有值）。模板渲染两边要都走通。

### `required`（必填校验）

```yaml
spec:
  # 没有这个字段就报错而不是渲染成空字符串
  image: {{ required "image.repository is required" .Values.image.repository }}
```

## 十三、流程控制（不是函数，但配合函数用）

```yaml
{{- if CONDITION }}            # CONDITION 是 bool 或函数返回值
{{- else if OTHER }}
{{- end }}

{{- range LIST }}              # 遍历 list/map/字符串
  {{ . }}                       # 当前元素
{{- end }}

{{- range $k, $v := .Values.foo }}  ← map 的 key/value
  {{ $k }}: {{ $v }}
{{- end }}

{{- with .Values.foo }}         # 把 . 改成 .Values.foo
  {{ . | upper }}
{{- end }}

{{- define "name" }}            # 定义命名模板
{{- end }}

{{- template "name" . }}        # 渲染（不处理输出）
{{- include "name" . }}         # 渲染后传给管道（推荐）

{{- block "name" . }}           # 可被子模板重新定义
{{- end }}
```

**`include` vs `template` 的关键区别**：

```yaml
# template 不能接到管道里（输出到 stdout）
{{- template "name" . | upper }}     # ❌ 报错

# include 返回字符串，可以接
{{- include "name" . | upper | quote }}  # ✅
```

> 生产**全部用 `include`**，不用 `template`。

## 十四、实战模板（综合用）

### 14.1 拼接资源名（helper）

```yaml
{{- /* templates/_helpers.tpl */ -}}
{{- define "myapp.fullname" -}}
{{- if .Values.fullnameOverride -}}
{{- .Values.fullnameOverride | trunc 63 | trimSuffix "-" -}}
{{- else -}}
{{- $name := default .Chart.Name .Values.nameOverride -}}
{{- if contains $name .Release.Name -}}
{{- .Release.Name | trunc 63 | trimSuffix "-" -}}
{{- else -}}
{{- printf "%s-%s" .Release.Name $name | trunc 63 | trimSuffix "-" -}}
{{- end -}}
{{- end -}}
{{- end -}}
```

### 14.2 标准 labels（强烈建议每个 chart 都用）

```yaml
{{- define "myapp.labels" -}}
app.kubernetes.io/name: {{ .Chart.Name }}
app.kubernetes.io/instance: {{ .Release.Name }}
app.kubernetes.io/version: {{ .Chart.AppVersion | quote }}
app.kubernetes.io/managed-by: {{ .Release.Service }}
helm.sh/chart: {{ printf "%s-%s" .Chart.Name .Chart.Version | replace "+" "_" | trunc 63 | trimSuffix "-" }}
{{- end -}}
```

### 14.3 通用 annotations

```yaml
{{- define "myapp.annotations" -}}
{{- if .Values.commonAnnotations }}
{{- toYaml .Values.commonAnnotations | nindent 4 }}
{{- end }}
{{- end -}}
```

### 14.4 多镜像 / 多容器 渲染

```yaml
containers:
  {{- range .Values.containers }}
  - name: {{ .name }}
    image: "{{ .image.repository }}:{{ .image.tag | default $.Chart.AppVersion }}"
    {{- with .resources }}
    resources:
      {{- toYaml . | nindent 4 }}
    {{- end }}
    env:
      {{- range $k, $v := .env }}
      - name: {{ $k | upper }}
        value: {{ $v | quote }}
      {{- end }}
  {{- end }}
```

### 14.5 复杂条件渲染

```yaml
{{- if and .Values.persistence.enabled (not .Values.persistence.existingClaim) }}
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: {{ include "myapp.fullname" . }}
spec:
  accessModes:
    - {{ .Values.persistence.accessMode | default "ReadWriteOnce" }}
  resources:
    requests:
      storage: {{ .Values.persistence.size | default "10Gi" | quote }}
{{- end }}
```

## 十五、踩坑清单

| 现象 | 原因 |
| --- | --- |
| `template "x" . \| upper` 报错 | 用 `include` 代替 `template` |
| `toJson .Values` 渲染成无引号字符串 | 缺 `\| quote` 或直接用 `toYaml` |
| `nospace` 把字符串压成一长串 | 想要 `replace " " ""` 还是 `nospace` 看场景 |
| `index` 中间 nil 报错 | 用 `dig` 替代 |
| `default "" .Values.x` 还在空 | 字段不存在 vs 字段为空字符串都是 `default` 兜底 |
| `lookup` 在 `helm template` 拿不到值 | template 阶段无集群访问 |
| `printf "%v" .Values.foo` 出错 | Go fmt 动词不熟悉；推荐 `quote` 包起来 |
| `repeat 100 "="` 超过 200 字符 | Helm 默认行长度限制（命令行截断） |
| `range` 改 `.` 后访问外层报错 | 用 `$.Values.x` |
| 数字比较 0 vs "" | Helm 里 `eq 0 ""` 是 false；类型严格 |
