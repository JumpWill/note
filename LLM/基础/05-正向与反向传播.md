# 正向与反向传播

## 1. 前向传播 (Forward Pass)

### 1.1 一句话

输入 $x$ 沿神经网络逐层计算，最终得到输出 $\hat{y}$ 和损失 $L(y, \hat{y})$ 的过程。

### 1.2 数学形式

对 $L$ 层网络：

$$
x^{(l)} = f^{(l)}(W^{(l)} x^{(l-1)} + b^{(l)}), \quad l = 1, 2, \ldots, L
$$

$$
\hat{y} = x^{(L)}, \quad \mathcal{L} = L(y, \hat{y})
$$

### 1.3 一个 2 层 MLP 的完整前向

```python
# 输入: x [N, d]
h_pre = x @ W1.T + b1          # [N, h_dim]
h = torch.relu(h_pre)          # [N, h_dim]
y_pre = h @ W2.T + b2          # [N, out_dim]
loss = F.cross_entropy(y_pre, y)
```

每一步都把上一层的输出送入下一层 → 信息"正向"流动。

### 1.4 关键事实

- 前向是**计算图构建**过程，记录每一步的输入输出与算子
- 前向保存所有**中间激活** (activation)，反向要用
- 显存压力主要来自前向缓存的中间张量

## 2. 反向传播 (Backward Pass)

### 2.1 核心：链式法则

$$
\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial x^{(L)}} \cdot \frac{\partial x^{(L)}}{\partial x^{(L-1)}} \cdots \frac{\partial x^{(l+1)}}{\partial x^{(l)}} \cdot \frac{\partial x^{(l)}}{\partial W^{(l)}}
$$

等价于沿计算图反向传播梯度 $\frac{\partial L}{\partial \cdot}$。

### 2.2 向量-雅可比积 (VJP)

对任意算子 $y = f(x)$，反向需要计算：

$$
\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot J_f, \quad J_f = \frac{\partial y}{\partial x}
$$

实际工程中**不显式构造雅可比矩阵** $J_f$ (太大了)，而是直接实现 VJP 函数。每个 PyTorch 算子都有前向 + VJP (autograd.Function)。

```python
class ReLUFunction(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)
        return x.clamp(min=0)

    @staticmethod
    def backward(ctx, grad_out):
        x, = ctx.saved_tensors
        return grad_out * (x > 0).float()  # ∂ReLU/∂x
```

### 2.3 反向的"消息传递"视角

把每张量看作节点，梯度看作"消息"。反向过程就是消息从 loss 节点沿计算图反向传播：

```text
       loss
       ↓ ∂L/∂ŷ
       ŷ
      ↙ ↘
  ∂L/∂W₂  ∂L/∂h
    ↓       ↓
   W₂      h
           ↓ ∂L/∂h_pre
          h_pre
         ↙   ↘
   ∂L/∂W₁   ∂L/∂x
     ↓       ↓
    W₁       x
```

每条边对应一个算子的 VJP。

### 2.4 完整 2 层 MLP 的反向

```python
# autograd 自动
loss.backward()

# 等价的手写梯度 (教学用)
dL_dy_pre = F.softmax(y_pre, dim=-1) - F.one_hot(y)  # [N, out_dim]

dL_dW2 = dL_dy_pre.T @ h                              # [out_dim, h_dim]
dL_db2 = dL_dy_pre.sum(0)
dL_dh   = dL_dy_pre @ W2                              # [N, h_dim]

dL_dh_pre = dL_dh * (h_pre > 0).float()               # ReLU VJP
dL_dW1 = dL_dh_pre.T @ x                              # [h_dim, d]
dL_db1 = dL_dh_pre.sum(0)
```

## 3. 计算图 (Computational Graph)

### 3.1 节点与边

```text
        x
        │
       Linear (W₁, b₁)
        │
        z₁
        │
        ReLU
        │
        h
        │
       Linear (W₂, b₂)
        │
        z₂
        │
      Softmax
        │
        p
        │
       NLLLoss
        │
       loss
```

- 节点：张量 (tensor)
- 边：算子 (function)
- 前向：自上而下求值
- 反向：自下而上求导

### 3.2 静态图 vs 动态图

| | 静态图 (TF 1.x, JAX) | 动态图 (PyTorch) |
|---|---|---|
| 构建时机 | 前向前先编译 | 前向时即时构建 |
| 灵活性 | 低 (图结构固定) | 高 (可分支/循环) |
| 优化空间 | 大 | 小 (但有 torch.compile) |
| 调试 | 难 | 易 (像普通 Python) |

现代 PyTorch 是动态图，但 `torch.compile()` 会把动态图 trace 成静态图再优化。

### 3.3 Leaf vs Non-leaf

```python
x = torch.randn(3, requires_grad=True)   # leaf, requires_grad=True
W = torch.randn(3, 3, requires_grad=True)  # leaf
h = x @ W                                # non-leaf (中间结果)
loss = h.sum()
loss.backward()
print(x.grad)  # OK, leaf 节点保留 .grad
print(h.grad)  # 错误！non-leaf 不保留 grad (默认)
```

非叶子节点的梯度在反向传播后默认释放。要保留用 `.retain_grad()`。

## 4. 自动微分 (Autograd) 细节

### 4.1 PyTorch 实现机制

每次前向：

1. 调用算子的 `forward()` 得到输出
2. 调用算子的 `setup_context()` 保存反向需要的信息 (输入、mask 等)
3. 把 `(output, op)` 注册到图中
4. 输出张量标记 `grad_fn` 指向算子

反向时：

1. 从 `loss` 出发，调用 `loss.grad_fn` 的 `backward()`
2. 该算子用 `setup_context` 保存的信息 + `grad_out` 计算 `grad_in`
3. 把 `grad_in` 传给上游算子
4. 递归直到所有叶子节点

### 4.2 显存开销

反向传播的显存消耗：

| 内容 | 量级 |
|------|------|
| 模型参数 | $\mathcal{O}(\|θ\|)$ |
| 优化器状态 | $\mathcal{O}(\|θ\|)$，Adam 是 $2×$ |
| 激活缓存 | $\mathcal{O}(L \cdot B \cdot T \cdot d)$，LLM 杀手 |
| 梯度 | $\mathcal{O}(\|θ\|)$ |

中间激活是 LLM 训练显存的最大头。

### 4.3 `with torch.no_grad()`

关闭 autograd，常用于：

- 评估循环
- 参数冻结
- 生成中间常数

```python
with torch.no_grad():
    val_loss = compute_loss(model, val_batch)
```

节省的反向图构建显存 ≈ 30%~50%。

### 4.4 `detach()` vs `no_grad()`

- `no_grad()`：上下文，不构建图
- `detach()`：返回一个新张量，与原张量共享数据但脱离计算图

```python
y = x.detach()  # y 不再需要梯度
```

## 5. 内存优化技巧

### 5.1 Gradient Checkpointing (重计算)

把中间激活不存，反向时**重算**前向：

```
正常:     前向存全部激活 → 反向 O(1) 重算
Checkpoint: 前向只存部分激活 → 反向重算 O(√n) 次前向

内存: L · d → √L · d
计算: 1 × → 2 ×
```

LLM 标配，DeepSpeed/HuggingFace 都内置：

```python
from torch.utils.checkpoint import checkpoint
h = checkpoint(self.layer, h)
```

### 5.2 算子融合 (Operator Fusion)

把多个小算子合并成一个 CUDA kernel：

```
   Linear → Bias → ReLU            Linear → Bias → ReLU
     │       │       │                  (fused kernel)
     ▼       ▼       ▼                       │
   mat   add  max(0)                      one launch
   kernel kernel kernel
   (3 launches, 3x intermediate)
```

`torch.compile` / `torch.jit.script` / `triton` 都能融合。

LLM 中关键：Flash Attention 把 softmax+matmul+mask 融合到 O(1) 次 kernel。

### 5.3 混合精度 (Mixed Precision)

| 精度 | 位宽 | 用途 |
|------|------|------|
| FP32 | 32 | 主权重、梯度、优化器状态 |
| FP16 / BF16 | 16 | 前向/反向计算 |
| FP8 | 8 | H100 新增，推理+部分训练 |

```python
with torch.autocast("cuda", dtype=torch.bfloat16):
    loss = model(batch)
loss.backward()
```

节省显存、加速，但需要：

- **主权重保持 FP32** (master weight)
- 损失放大 (loss scaling) 防止 FP16 underflow

### 5.4 ZeRO-Offload

把优化器状态/梯度 offload 到 CPU，显存换内存。

```python
from deepspeed.ops.adam import DeepSpeedCPUAdam
```

训练万亿参数模型时关键。

## 6. Transformer 中的梯度流

### 6.1 单层 Block

```
x → RMSNorm ─┐
              ├→ Attention → + → ─→ RMSNorm ─┐
              │                                ├→ FFN → + → out
              └──────────────────────────────┘
```

残差连接的梯度路径：

$$
\frac{\partial \text{out}}{\partial x} = I + \frac{\partial \text{block}}{\partial x}
$$

恒等映射 $I$ 让梯度永远不消失 → 极深网络可训练。

### 6.2 Pre-Norm vs Post-Norm

**Pre-Norm** (主流 LLM)：

```
out = x + SubLayer(LN(x))
```

- 梯度 $\frac{\partial \text{out}}{\partial x} \approx I$ + 小残差 → 训练稳
- 收敛略慢但稳，LLM 标配

**Post-Norm** (原 Transformer)：

```
out = LN(x + SubLayer(x))
```

- 早期 Transformer / ViT 某些变体
- 深层训练不稳，需要 warmup + 小 lr

### 6.3 Attention 梯度分析

$$
\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
$$

反向流：

- $\partial L / \partial V = P^T \cdot \partial L / \partial O$
- $\partial L / \partial P$ → 经过 softmax 反向 → $\partial L / \partial (QK^T)$
- $\partial L / \partial Q, \partial L / \partial K$ 由 matmul 反向得到

Flash Attention 重排计算顺序，但**梯度数值结果一致**。

## 7. 数值稳定性

### 7.1 常见炸点

| 现象 | 原因 | 排查 |
|------|------|------|
| loss = NaN | log(0)、溢出、链式乘 > 1 | lr 太大、logits 过大 |
| loss = Inf | 16-bit 上溢 | 用 BF16 / 加 loss scaling |
| grad = NaN | 同上 | clip_grad_norm |
| 输出全 0 | ReLU 全死 / 初始化过小 | 检查 init scale |

### 7.2 数值技巧

```python
# 1) Log-Sum-Exp 稳定
def logsumexp(x):
    m, _ = x.max(dim=-1, keepdim=True)
    return m + (x - m).exp().sum(-1).log()

# 2) Softmax 稳定
def softmax(x):
    m, _ = x.max(dim=-1, keepdim=True)
    e = (x - m).exp()
    return e / e.sum(-1, keepdim=True)

# 3) CrossEntropy 直接算 (PyTorch 已优化)
loss = F.cross_entropy(logits, labels)
```

### 7.3 BF16 vs FP16

| | FP16 | BF16 |
|---|---|---|
| 指数位 | 5 | 8 |
| 尾数位 | 10 | 7 |
| 范围 | 窄 (易上溢/下溢) | 宽 (≈FP32) |
| 精度 | 高 | 低 |
| 适用 | 推理 + 老卡 | LLM 训练首选 (A100/H100) |

## 8. 实战流程

一个完整的训练 step 内部发生了什么：

```python
# === 准备 ===
model.train()
optimizer.zero_grad()  # 清梯度

# === 前向 (构建计算图) ===
with torch.autocast('cuda', dtype=torch.bfloat16):
    logits = model(input_ids)            # 算子1, 算子2, ...
    loss = F.cross_entropy(logits, labels, ignore_index=-100)

# === 反向 (沿图反传) ===
loss.backward()                           # 算子反向 1, 2, ..., .grad 写入

# === 优化器 ===
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
optimizer.step()                          # 应用梯度
```

耗时分解 (LLM 训练典型)：

```
前向:        ~40%
反向:        ~40%
优化器.step: ~10%
其他:        ~10%
```

`torch.compile` 可以把前向+反向融合，进一步加速 20%~40%。

## 9. 调试工具

### 9.1 检查梯度

```python
# 打印所有参数的梯度统计
for name, p in model.named_parameters():
    if p.grad is None:
        print(f"{name}: NO GRAD")
    else:
        print(f"{name}: grad_norm={p.grad.norm():.4e}")
```

### 9.2 梯度流检测

```python
# 检测是否有 dead ReLU / 梯度消失
def grad_norm_by_layer(model):
    norms = {}
    for name, p in model.named_parameters():
        if p.grad is not None:
            norms[name] = p.grad.norm().item()
    return norms
```

如果某层梯度 norm 远小于其他层 → 该层可能"死了" (dying ReLU) 或学习率太小。

### 9.3 Torchviz / 计算图可视化

```python
from torchviz import make_dot
make_dot(loss, params=dict(model.named_parameters())).render("graph")
```

生成计算图 PDF，方便理解复杂模型。

### 9.5 Profiler

```python
with torch.profiler.profile(activities=[torch.profiler.ProfilerActivity.CUDA]) as prof:
    loss = model(batch)
    loss.backward()
print(prof.key_averages().table(sort_by="cuda_time_total", row_limit=10))
```

找前向/反向里的瓶颈算子。

## 10. 选型速查

| 优化技巧 | 收益 | 代价 | 推荐场景 |
|----------|------|------|----------|
| Gradient Checkpointing | 显存 ÷ 2~8 | 计算 +20%~30% | LLM 训练标配 |
| 混合精度 (BF16) | 显存 ÷ 2、加速 1.5x | 几乎无 | LLM 标配 |
| torch.compile | 加速 1.2~2x | 编译时间长 | 调试通过后 |
| Flash Attention | 长上下文加速 | - | 长序列 LLM 必开 |
| Operator Fusion | 加速 1.1~1.3x | - | 推理 / 服务 |
| ZeRO-Offload | 显存 → 内存 | 通信开销 | 万亿模型 |
| Quantization (训练) | 显存 ÷ 4 | 精度略降 | 显存不够 |
