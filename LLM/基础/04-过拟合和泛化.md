# 过拟合与泛化

## 1. 基本概念

### 1.1 过拟合 (Overfitting)

模型在训练集上表现很好，但在新数据 (验证/测试集) 上表现差。

```text
训练损失: 0.1    ↘ 持续下降
验证损失: 0.1 → 0.8 → 1.5   ↗ 反弹上升

         ↑
         过拟合开始点 (early stopping 最佳点)
```

直觉：模型把训练数据的"噪声"也学了，记住了样本而非学到规律。

### 1.2 欠拟合 (Underfitting)

训练和验证都表现差 → 模型能力不够或训练不到位。

```text
训练损失: 2.5 → 2.3 → 2.2 (卡住)
验证损失: 2.6 → 2.4 → 2.3 (同步)
         ↑
         两者都高，且相近
```

### 1.3 泛化 (Generalization)

模型在**未见过的数据**上的表现。泛化误差 = 测试误差 - 训练误差，是衡量模型真正价值的指标。

### 1.4 Bias-Variance 分解

测试误差可分解为三部分：

$$
\mathbb{E}[(y - \hat{f}(x))^2] = \underbrace{\text{Bias}^2}_{\text{偏离真实}} + \underbrace{\text{Variance}}_{\text{对数据敏感}} + \underbrace{\sigma^2}_{\text{不可消除噪声}}
$$

| 现象 | Bias | Variance |
|------|------|----------|
| 欠拟合 | 高 | 低 |
| 过拟合 | 低 | 高 |
| 理想 | 低 | 低 |

LLM 场景里模型容量极大 → bias 低，过拟合主要是高 variance。

## 2. 过拟合诊断

### 2.1 训练曲线

```text
Loss
  │              ──── 训练损失 (持续下降)
  │           ╱
  │        ╱
  │     ╱    ⌒⌒⌒ 验证损失 (先降后升)
  │   ╱   ⌒
  │ ╱  ⌒
  │╱⌒
  └──────────────────── step
       ↑
   过拟合拐点
```

### 2.2 量化指标

| 指标 | 含义 |
|------|------|
| 训练/验证损失差 | $L_{val} - L_{train}$，越大越过拟合 |
| Gap ratio | $L_{val} / L_{train}$，> 1.5 通常有问题 |
| Train acc vs Val acc | 分类任务经典判断 |
| Perplexity gap | LLM 同理 |

### 2.3 LLM 特有信号

- 训练 loss 接近 0 但验证 PPL 不下降
- 模型**逐字背诵**训练数据 (memorization) → 检测：让模型补全，看是否与训练样本一字不差
- 验证集生成内容开始"模式化"/重复/失去多样性

## 3. 应对方法

### 3.1 数据层

#### 增加数据

最有效的正则化，没有之一。

经验法则：训练数据量翻倍 → 性能提升通常比所有正则化技巧加起来还多。

LLM 时代：继续追加清洗后的网页/书籍/代码数据。

#### 数据质量

脏数据的害处 > 数据量不足。

- 去重：near-duplicate (MinHash) 检测
- 去毒：toxic / NSFW 过滤
- 去噪：HTML / 乱码 / 低质
- 质量打分：heuristic (长度、标点、词频) 或 learned (FastText quality classifier)

#### 数据增强

NLP：

| 方法 | 做法 | 适用 |
|------|------|------|
| 回译 (Back-translation) | 中文 → 英文 → 中文 | 分类、NER |
| 同义词替换 | WordNet / embedding 找近义词 | 文本分类 |
| EDA | 随机插入/删除/交换/同义词 | 小数据集 |
| LLM 重写 | GPT-4 生成同义改写 | 高质量改写 |
| Mixup | 文本 embedding 凸组合 | 表征学习 |
| Context 扰动 | 打乱/截断句子顺序 | 鲁棒性 |

视觉经典 (NLP 借鉴思想)：

- **Mixup**：$x' = \lambda x_i + (1-\lambda)x_j$，$y' = \lambda y_i + (1-\lambda) y_j$，$\lambda \sim \text{Beta}(\alpha, \alpha)$
- **CutMix**：图像块替换，标签按面积混合
- **Cutout**：随机遮挡区域

NLP 中可在 embedding 层做 Mixup，对小模型有提升。

### 3.2 模型层

#### 控制容量

- 减小 hidden size / 层数 / 头数 → 容量下降 → 不容易过拟合
- 但太小会欠拟合
- LLM 时代：**容量通常够大**，过拟合问题靠数据 / 正则化解决

#### 参数共享 / Weight Tying

Transformer 中 embedding 与 output head 共享权重，减少参数 30%~50%。LLM 标配。

### 3.3 显式正则化

#### L2 / Weight Decay

$$
L_{total} = L + \lambda \| \theta \|^2
$$

把大权重往 0 拉，限制模型复杂度。LLM 中常用 $\lambda = 0.1$。

注意：bias / LayerNorm / embedding **不衰减** (常见做法)。

实现：AdamW 把 weight decay 从梯度路径解耦，详见 [03-梯度下降](03-梯度下降.md#adamw-llm-标配)。

#### L1 正则

$$
L_{total} = L + \lambda \|\theta\|_1
$$

诱导**稀疏解** (大量权重变 0)。NLP 中不如 L2 常用。

#### Dropout

训练时随机将一部分激活置 0：

$$
\tilde{x} = x \odot m, \quad m \sim \text{Bernoulli}(1-p)
$$

- 推理时关闭
- LLM 预训练通常**不用** (数据足够多)
- SFT / 微调常用 0.1
- 分类器 / 小模型常用 0.3~0.5

变体：

- **DropConnect**：丢权重
- **Spatial Dropout**（CNN）：丢整个通道
- **Attention Dropout**（Transformer）：丢注意力权重

#### Stochastic Depth

训练时随机跳过整个残差块 (ResNet 提出)：

$$
x_{l+1} = x_l + b_l \cdot \mathcal{F}(x_l, W_l), \quad b_l \sim \text{Bernoulli}(p_l)
$$

深层 Transformer 可用，每个 block 有自己的 $p_l$，越深的 block 越倾向被跳过。

#### Label Smoothing

把 one-hot 软化：

$$
y_i^{smooth} = (1-\epsilon) y_i + \frac{\epsilon}{K}
$$

- 防止模型过度自信
- 训练 loss 会"假性升高"，但泛化更好
- 分类任务常用 $\epsilon = 0.1$

#### Early Stopping

验证损失连续 N 步不下降就停止训练。

```python
best_val = float('inf')
patience = 0
for epoch in range(max_epochs):
    train_loss = train_one_epoch(model)
    val_loss = evaluate(model)
    if val_loss < best_val:
        best_val = val_loss
        save_checkpoint(model)
        patience = 0
    else:
        patience += 1
        if patience >= max_patience:
            break
```

最简单也最有效的正则化之一。LLM 训练里等价于 cosine decay 自然停止。

### 3.4 隐式正则化

不是显式 penalty，但实践中能极大改善泛化。

#### 优化器隐式正则化

- **SGD 噪声**：相比 GD 的"锐极小"，SGD 收敛到"平坦极小"，泛化更好
- **Adam**：相比 SGD 隐式 bias 略偏向"锐"，但 AdamW + 适度 weight decay 仍工作良好
- **学习率衰减**：cosine 末尾 lr → 0，类似隐式 early stopping

#### BatchNorm / LayerNorm

- BN 引入 batch 内统计噪声 → 轻微正则化效果
- LN 主要稳定训练，对泛化也有帮助

#### 梯度裁剪

clip 隐式限制模型"异常更新"，降低对单 batch 过拟合的概率。LLM 训练标配 (`max_norm=1.0`)。

#### 数据顺序 (Shuffle)

不同 epoch shuffle 顺序 → 等效数据增强 (每轮看到不同的 batch 组合)。

### 3.5 集成与蒸馏

#### 经典集成

- **Bagging**：多个模型投票，减小 variance
- **Boosting**：串行训练纠错，减小 bias
- **Stacking**：用元学习器组合多模型

#### LLM 集成

LLM 单模型已经很强，集成成本高，但仍然有用：

- **Voting**：多模型生成 → 投票
- **Best-of-N**：采样 N 个答案，挑最好的
- **Self-consistency**：采样 N 个 → 取多数答案 (CoT 场景)
- **MoE**：单次前向，但内部有多个专家"投票"

#### 知识蒸馏 (Knowledge Distillation)

用大模型的"软标签"训练小模型。学生学到"暗知识"——样本间的相似度，比硬标签包含更多信息。

LLM 场景：

- 蒸馏到小模型 (7B → 1.8B)
- 蒸馏到 SLM (Phi 系列的核心方法)

#### 模型平均 (SWA / EMA)

训练后期对多个 checkpoint 参数做平均：

$$
\theta_{EMA} = \alpha \theta_{EMA} + (1-\alpha) \theta_{step}
$$

得到一个"平坦极小"，泛化更好，几乎无额外成本。

## 4. 训练流程设计

### 4.1 数据划分

| 用途 | 比例 (大数据) | 比例 (小数据) |
|------|---------------|---------------|
| Train | 90%~98% | 60%~80% |
| Val | 5%~10% | 10%~20% |
| Test | 1%~5% | 10%~20% |

- **Test set 不能动**，只能最终评估用
- Val 可多次评估 (调超参)
- LLM 训练常用小 val (~0.1%)，因为评估贵

### 4.2 K 折交叉验证 (小数据)

```python
from sklearn.model_selection import KFold
for fold, (train_idx, val_idx) in enumerate(KFold(n_splits=5).split(X)):
    model = train_model(X[train_idx], y[train_idx])
    score = evaluate(model, X[val_idx], y[val_idx])
```

每个样本都做一次 val，结果更稳健。**LLM 训练不用** (成本太高)。

### 4.3 过拟合应对流程

```text
过拟合信号 (val 不降 / 降后升)
    ↓
1. 检查数据：是否有重复 / 标签错
    ↓
2. 减小模型容量或加正则化
    - 加 Dropout (0.1~0.3)
    - 加 Weight Decay (0.01~0.1)
    - 加 Label Smoothing (0.1)
    - 加 Early Stopping
    ↓
3. 加数据增强
    ↓
4. 蒸馏 / 模型平均 (SWA / EMA)
    ↓
5. 增大训练数据 (终极手段)
```

### 4.4 训练中监控指标

```python
# 必须监控的指标
- train_loss
- val_loss
- val_metric (任务相关: accuracy, F1, BLEU, ROUGE)
- learning_rate
- grad_norm
- tokens_per_second
```

## 5. LLM 特定问题

### 5.1 数据记忆 / 隐私

LLM 可能逐字记住训练数据，泄漏隐私。

检测：

- 给模型训练样本前缀，看是否一字不差补全
- Membership Inference Attack (MIA)

缓解：

- 数据去重 (n-gram overlap 检测)
- 差分隐私训练 (DP-SGD)

### 5.2 对齐税 (Alignment Tax)

SFT / RLHF 可能轻微降低预训练时学到的能力 (MMLU 分数略降)。这是"对齐阶段的过拟合"。

缓解：

- 混合 SFT + 预训练数据
- LoRA 等参数高效微调 (限制改动幅度)
- DPO > PPO (前者更稳定)

### 5.3 Length Bias

训练数据中长答案多 → 模型倾向生成冗长输出。RLHF 部分缓解，但仍有 bias。

缓解：

- 控制生成 max_length
- Reward 模型加长度惩罚

### 5.4 模式崩塌 (Mode Collapse)

SFT 数据风格太单一 → 模型只会一种回答风格。RLHF 后尤其明显。

缓解：

- SFT 数据多样化
- 温度 / top_p 调高

## 6. 选型速查

| 场景 | 推荐正则化组合 |
|------|----------------|
| LLM 预训练 | Weight decay (0.1) + 大量数据 + dropout=0 |
| 全参数 SFT | Weight decay (0.1) + dropout (0.1) + warmup-cosine |
| LoRA 微调 | Weight decay (0.01) + dropout (0.05) |
| 小数据分类 | Dropout (0.5) + L2 + Label Smoothing + 数据增强 |
| 视觉 CNN | Dropout + BN + 数据增强 (flip/crop/Mixup/CutMix) |
| RLHF (PPO) | KL 约束 + reward clipping + reference model |
| 表征学习 | InfoNCE + 数据增强 + weight decay |
