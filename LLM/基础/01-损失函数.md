# 损失函数

## 1. 基本概念

### 什么是损失函数

损失函数 (Loss Function) 衡量模型预测值 $\hat{y}$ 与真实值 $y$ 之间的差距，记为 $L(y, \hat{y})$。

训练的核心目标：

$$
\theta^* = \arg\min_\theta \frac{1}{N}\sum_{i=1}^{N} L(y_i, f_\theta(x_i))
$$

其中 $\theta$ 是模型参数。损失越小 → 预测越准。

### 为什么需要损失函数

- **可微**：梯度能反向传播 (BP) 回参数
- **可加**：样本级损失求和/求平均得到 batch 级损失
- **语义对齐**：损失下降 ≈ 任务指标上升 (但不完全等价)

### 经验风险 vs 结构风险

- **ERM (经验风险最小化)**：只看训练集损失，容易过拟合
- **SRM (结构风险最小化)**：在 ERM 上加正则项 $L_{total} = L_{data} + \lambda L_{reg}$

正则项可以是 L2 (权重衰减)、L1、Dropout、KL 散度等。

### 损失函数 vs 评估指标

| | 损失函数 | 评估指标 |
|---|---|---|
| 目的 | 可微 → 优化 | 反映真实任务表现 |
| 要求 | 处处可微 | 不可微也无所谓 |
| 例 | Cross-Entropy | Accuracy、F1、BLEU |

LLM 里：训练用 **Cross-Entropy**，评估用 **Perplexity** + **下游任务指标**。

## 2. 常用损失函数

### 2.1 回归损失

#### MSE (L2 Loss)

$$
L_{MSE} = \frac{1}{N}\sum (y_i - \hat{y}_i)^2
$$

- 优点：处处可微，梯度大 → 收敛快
- 缺点：对异常值 (outlier) 平方后爆炸，不鲁棒

#### MAE (L1 Loss)

$$
L_{MAE} = \frac{1}{N}\sum |y_i - \hat{y}_i|
$$

- 优点：对异常值线性，更鲁棒
- 缺点：在 0 点不可导 (subgradient)，收敛慢

#### Huber Loss

$$
L_\delta(y, \hat{y}) =
\begin{cases}
\frac{1}{2}(y - \hat{y})^2, & |y - \hat{y}| \le \delta \\
\delta |y - \hat{y}| - \frac{1}{2}\delta^2, & |y - \hat{y}| > \delta
\end{cases}
$$

小误差用 L2 (梯度大、收敛快)，大误差用 L1 (抗噪)。$\delta$ 控制切换点。回归任务的稳健默认选择。

#### Quantile Loss

$$
L_q = \sum_{i: y_i \ge \hat{y}_i} q|y_i - \hat{y}_i| + \sum_{i: y_i < \hat{y}_i} (1-q)|y_i - \hat{y}_i|
$$

预测分位数 ($q=0.5$ 即 MAE)。时序预测、风险建模常用。

### 2.2 分类损失

#### Cross-Entropy (多分类, LLM 主体)

$$
L_{CE} = -\sum_i y_i \log p_i
$$

其中 $y$ 是 one-hot，$p_i = \text{softmax}(z_i)$。

实际 LLM 训练就是：对词表 $V$ 个 token 做多分类，每个 token 算一次 CE，平均。

PyTorch 写法：

```python
F.cross_entropy(logits, labels, ignore_index=-100)
```

内部已包含 `log_softmax + NLLLoss`，比手写数值稳定。

#### Binary Cross-Entropy (二分类)

$$
L_{BCE} = -[y \log p + (1-y)\log(1-p)]
$$

独立 logit (最后一层 1 个输出 + Sigmoid)，不用 softmax。多标签任务也用这个，每个标签独立算。

#### Focal Loss

$$
L_{FL} = -\alpha (1-p_y)^\gamma \log p_y
$$

$(1-p_y)^\gamma$ 自动降低"易分类样本"的权重，难样本 (小 $p_y$) 权重接近 1。解决正负样本极不均衡 (如 1:1000)。

- $\gamma=0$ 时退化为普通 CE
- 典型取值 $\gamma=2, \alpha=0.25$

#### Label Smoothing

把硬标签改一改：

$$
y_i^{smooth} = (1-\epsilon) y_i + \frac{\epsilon}{K}
$$

防止模型把 softmax 推到极端、过度自信。代价：CE 数值会"假性"升高 (因为永远不能达到 0)，但泛化和下游任务更稳。

### 2.3 语言模型专用

#### Next-Token Cross-Entropy

LLM 训练 loss 的标准定义：

$$
L = -\frac{1}{T}\sum_{t=1}^{T} \log p_\theta(x_t | x_{<t})
$$

- 每个 token 算一次 CE
- 对 batch 求平均
- padding token 用 `ignore_index=-100` 跳过
- 总 loss = (回答部分 loss) × 权重 + (问题部分 loss) × 权重 (通常问题权重低或为 0)

#### Perplexity (PPL)

$$
\text{PPL} = \exp(L)
$$

直觉：模型在每一步预测时"平均在多少个候选里选"。PPL=10 表示 ≈10 个候选里分不清。

- 训练曲线看 loss，发布/对比看 PPL
- 同一个模型，tokenizer 不同 PPL 不能直接比

#### KL 散度

$$
D_{KL}(p \| q) = \sum p(x) \log \frac{p(x)}{q(x)}
$$

衡量两个分布的距离。用途：

- **知识蒸馏**：让学生分布 $q$ 拟合教师分布 $p$
- **RLHF/DPO**：约束策略不要偏离参考模型太远 ($D_{KL}$ 惩罚)
- **前向 / 反向 KL**：$\text{KL}(p\|q)$ mode-seeking，$\text{KL}(q\|p)$ mode-covering

### 2.4 对比 / 检索损失

#### InfoNCE (NT-Xent)

$$
L = -\log \frac{\exp(\text{sim}(z_i, z_j^+)/\tau)}{\sum_{k=1}^{N}\exp(\text{sim}(z_i, z_k)/\tau)}
$$

- $z_i$ 为 anchor，$z_j^+$ 为正样本，其他 batch 内样本为负样本
- $\tau$ 温度，越小分布越"尖锐"
- CLIP / SimCSE / 对比学习标配

#### Triplet Loss

$$
L = \max(0, d(a, p) - d(a, n) + \text{margin})
$$

三元组 (anchor, positive, negative)。margin 让正负样本距离拉开至少这个值。检索、人脸识别。

#### MarginRankingLoss

$$
L = \max(0, -y \cdot (s^+ - s^-) + \text{margin})
$$

$y \in \{+1, -1\}$ 表示正负样本。Reranker、句对排序常用。

### 2.5 RLHF 系列损失

#### Policy Gradient (REINFORCE)

$$
L = -\mathbb{E}_{x \sim \pi_\theta}[r(x) \log \pi_\theta(x)]
$$

直接用奖励 $r$ 加权，最大似然估计。但方差极大，需要大量样本。

#### PPO Loss (Proximal Policy Optimization)

$$
L_{PPO} = -\mathbb{E}\left[\min\left(\frac{\pi_\theta(a|s)}{\pi_{old}(a|s)} \hat{A}, \text{clip}\left(\frac{\pi_\theta}{\pi_{old}}, 1-\epsilon, 1+\epsilon\right)\hat{A}\right)\right]
$$

加上 **clip** 防止策略更新步长过大。RLHF 标准训练损失。需要 4 个模型：policy、ref、value、reward。

#### DPO Loss (Direct Preference Optimization)

跳过 reward model，直接用偏好对 $(y_w, y_l)$ 训练：

$$
L_{DPO} = -\log \sigma\left(\beta \log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right)
$$

只需要 2 个模型 (policy + ref)。稳定、便宜，效果与 PPO 相当。当前对齐训练的事实标准。

#### KTO / ORPO

- **KTO**：用单条样本的"好/坏"标注，不需偏好对
- **ORPO**：把 SFT + 偏好优化合二为一，更省显存

### 2.6 蒸馏损失

#### KL Distillation

$$
L = T^2 \cdot D_{KL}(\text{softmax}(z^T/T) \| \text{softmax}(z^S/T))
$$

- $T$ 温度，软化概率分布，让学生学到教师的"暗知识"
- 前面的 $T^2$ 是补偿因子，保持梯度量级

#### Combined Loss

$$
L_{total} = \alpha L_{CE}(y, p^S) + (1-\alpha) L_{KL}(p^T/T \| p^S/T)
$$

CE 保证正确，KL 学分布。一般 $\alpha=0.5$。

## 3. 选型指南

| 任务 | 推荐损失 |
|------|----------|
| LLM 预训练 / SFT | Cross-Entropy + ignore_index |
| 分类 (均衡) | Cross-Entropy |
| 分类 (类别不均衡) | Focal Loss |
| 二分类 / 多标签 | BCE (with logits) |
| 回归 (无异常值) | MSE |
| 回归 (有异常值) | Huber / MAE |
| Embedding 对比 | InfoNCE |
| Reranker | MarginRanking / Listwise |
| 偏好对齐 | DPO / PPO |
| 知识蒸馏 | KL + CE |
| 时序预测分位数 | Quantile Loss |

## 4. 实战注意点

### 数值稳定

- 永远用 `F.cross_entropy` 而不是手写 `softmax + log + nll`
- BCE 用 `with_logits` 版本，不要先 Sigmoid 再算
- 大 batch + FP16 时考虑 `logits / temperature` 是否会溢出

### Loss = NaN / Inf

排查顺序：

1. 学习率太大 → 降到 1e-5
2. 输入有异常值 → 检查数据
3. Logits 过大 → 加 `logits_scale` 截断或用 log_softmax
4. Label 全是 ignore_index → 检查 mask

### Loss 不降

- 任务不对：分类用 MSE 怎么都难下
- 学习率太小 / 太大
- 数据标签噪声大
- Loss 公式写错 (常见：忘 mean、忘 ignore_index)

### Batch 归一

CE/MSE 一般 batch 内求 mean；InfoNCE 要在 batch 内做负样本，需要 sum 或不归一化，根据上下文选择；对比示例用平均。
