# 主流架构：DNN / CNN / Transformer

## 1. 总览

深度学习三大基础架构，分别对应**三种主流数据结构**：

| 架构 | 适合的数据 | 核心操作 | 代表模型 |
|------|-----------|----------|----------|
| **DNN / MLP** | 表格型（一维向量） | 全连接 + 激活 | 早期感知机、深层 MLP |
| **CNN** | 网格型（图像、视频） | 卷积 + 池化 | ResNet、EfficientNet、ViT (混合) |
| **Transformer** | 序列型（语言、任意 token） | Self-Attention | GPT、Claude、LLaMA、ViT |

```
数据形态决定架构选择：

表格数据 (tabular)        ─→  DNN / MLP
二维网格 (image, audio)    ─→  CNN → ViT
序列 / 集合 (language)     ─→  RNN → Transformer
任意关系 (graph, points)  ─→  GNN / PointNet
```

## 2. DNN / MLP（深度神经网络 / 多层感知机）

### 2.1 基本结构

最朴素的"层叠全连接"：

$$
x^{(l)} = \sigma(W^{(l)} x^{(l-1)} + b^{(l)}), \quad l = 1, \ldots, L
$$

每一层都是 Linear + Activation 堆叠。

### 2.2 特点

**优点**：

- 结构简单，通用近似定理：足够宽就能拟合任意函数
- 实现简单，PyTorch 几行代码
- 表格数据 / 小维度特征首选

**缺点**：

- 参数爆炸：$d_{in} \times d_{out}$，图像像素 (224×224×3=150K) → 第一层就上亿参数
- 无平移不变性 / 局部性 / 权重共享 → 浪费算力
- 对结构化数据 (图像、序列) 不友好

### 2.3 当前定位

- LLM 中充当 **FFN（前馈层）**：Transformer block 内嵌的两层 MLP
- 表格数据 baseline
- 大模型中作为子模块而非主架构

## 3. CNN（卷积神经网络）

### 3.1 核心思想

**局部连接 + 权值共享**：

- 局部连接：每个神经元只看输入的一小块（感受野）
- 权值共享：同一滤波器扫遍整张图
- 空间下采样：Pooling

```
输入图像 [3, 224, 224]
   ↓ Conv (3 → 64, 3×3, stride=1) → [64, 224, 224]
   ↓ ReLU
   ↓ MaxPool 2×2 → [64, 112, 112]
   ↓ Conv (64 → 128, 3×3) → [128, 112, 112]
   ↓ ReLU
   ↓ MaxPool 2×2 → [128, 56, 56]
   ...
   ↓ GlobalAvgPool → [512]
   ↓ Linear → [num_classes]
```

### 3.2 关键组件

#### 卷积 (Convolution)

二维卷积（实际是 cross-correlation）：

$$
Y_{i,j,k} = \sum_{c, u, v} W_{u,v,c,k} \cdot X_{i+u, j+v, c} + b_k
$$

- $W$ 形状 $(k_h, k_w, c_{in}, c_{out})$ → 参数与图像大小**无关**
- 滑动步长 (stride)、填充 (padding) 控制输出尺寸

#### 池化 (Pooling)

下采样，减小计算量、扩大感受野：

- **MaxPool**：取窗口最大值
- **AvgPool**：取窗口均值
- **GlobalAvgPool**：整张图取均值 (替代全连接层做分类)

#### 归一化

- **BatchNorm** (CNN 标配)：稳定训练、轻微正则化
- **GroupNorm / LayerNorm**：小 batch / Transformer 场景

### 3.3 Inductive Bias（CNN 的"先天优势"）

| 偏置 | 含义 | 实现 |
|------|------|------|
| **平移不变性** | 猫在左在右都能识别 | 权值共享 |
| **局部性** | 局部像素才有强相关 | 局部连接 |
| **尺度层次** | 边缘 → 纹理 → 部件 → 物体 | 池化 + 深层 |

这三种偏置让 CNN 在**小数据集**上就能学好。

### 3.4 代表模型演进

```
LeNet-5 (1998)
   ↓
AlexNet (2012) ─ ImageNet 冠军，ReLU + Dropout + GPU
   ↓
VGG (2014) ─ 3×3 卷积堆叠，更深
   ↓
GoogLeNet/Inception (2014) ─ 多尺度并行
   ↓
ResNet (2015) ─ 残差连接，让网络深到 152 层也能训
   ↓
DenseNet (2016) ─ 密集连接
   ↓
EfficientNet (2019) ─ 复合缩放 (深度/宽度/分辨率)
   ↓
ConvNeXt (2022) ─ 把 ResNet 现代化 (用 Transformer 配方)
   ↓
ViT (2020+) ─ Transformer 抢过视觉，但 CNN + Transformer 混合仍有优势
```

### 3.5 何时用 CNN

- 图像 / 视频分类、检测、分割
- 中小数据集 (CNN 的 inductive bias 仍有效)
- 边缘部署 (MobileNet、EfficientNet 量化友好)
- 实时性要求高的场景

## 4. Transformer

### 4.1 核心思想

**Self-Attention**：序列中每个位置能直接看到所有其他位置。

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
$$

- $Q, K, V$ 来自同一输入的三个投影
- $QK^T / \sqrt{d_k}$ 是位置间的相似度
- 加权聚合 $V$ 得到每个位置的输出

Multi-Head Attention：并行多组 Q/K/V，捕获不同子空间。

### 4.2 完整 Block

```
x
 ├→ LayerNorm ─→ Multi-Head Attention ─→ + ─┐
 │                                          ├→ LayerNorm → FFN → + → out
 └──────────────────────────────────────────┘
```

(Pre-Norm，当前主流)

### 4.3 Inductive Bias

Transformer 几乎没有：

| 偏置 | CNN | Transformer |
|------|-----|-------------|
| 平移不变性 | ✅ 强 | ❌ 弱（需要位置编码） |
| 局部性 | ✅ 强 | ❌ 弱（每个 token 看所有） |
| 尺度层次 | ✅ 池化提供 | ❌ 弱（靠深度堆叠） |
| 置换不变性 | ❌ | ✅（除位置编码外） |

代价：要学出这些偏置就需要**大量数据**。

### 4.4 为什么 Transformer 赢了

1. **并行性**：RNN 必须串行，Attention 整序列并行 → GPU 友好
2. **长距离依赖**：Attention 直接连任意两个位置，无 RNN 的"遗忘"
3. **Scaling**：性能随参数/数据/算力单调上升（Scaling Law）
4. **通用性**：NLP → CV → Audio → 多模态 → Robotics → 蛋白质

### 4.5 三种 Transformer 家族

#### Encoder-only (BERT 系)

双向注意力，理解类任务：

- 文本分类、NER、检索 (BERT、RoBERTa)
- 适合"读懂"任务

#### Decoder-only (GPT 系)

单向 (masked) 自注意力，生成类任务：

- LLM 主流 (GPT、LLaMA、Claude、Qwen、DeepSeek)
- 适合"生成"任务

#### Encoder-Decoder (T5 / BART)

编码双向、解码单向，序列到序列：

- 翻译、摘要、问答
- T5、mBART、Whisper

### 4.6 何时用 Transformer

- **NLP / 序列任务**：事实标准
- **大模型训练**：Scaling Law + 并行性是杀手锏
- **多模态**：图像 patch tokenize 后当 sequence
- **结构化数据**：Graph Transformer、Point Transformer 也通用

## 5. 三者对比

### 5.1 参数与计算

| 维度 | DNN/MLP | CNN | Transformer |
|------|---------|-----|-------------|
| 参数复杂度 | $d_{in} \cdot d_{out}$ | $k^2 \cdot c_{in} \cdot c_{out}$ | $4 d^2 + n \cdot d^2$ (含 FFN) |
| 计算复杂度 | $\mathcal{O}(d^2)$ | $\mathcal{O}(k^2 \cdot c^2 \cdot HW)$ | $\mathcal{O}(n^2 \cdot d)$ |
| 数据效率 | 中 | 高（小数据集友好） | 低（需要大数据） |
| 并行性 | 高 | 高 | 高 |
| 长距离依赖 | 无（要深层堆叠） | 受限（要很深） | ✅ 直接 |

### 5.2 Inductive Bias

| 偏置 | DNN | CNN | Transformer |
|------|-----|-----|-------------|
| 平移不变性 | ❌ | ✅ | ❌ |
| 局部性 | ❌ | ✅ | ❌ |
| 层次性 | 弱 | ✅ | 弱 |
| 数据需求 | 中 | 低 | 高 |

### 5.3 典型应用

| 任务 | 首选 |
|------|------|
| 表格分类 / 回归 | DNN / MLP |
| 小数据集图像分类 | CNN (ResNet) |
| 大规模图像分类 | ViT / Hybrid |
| 目标检测 | YOLO / DETR / Faster R-CNN |
| 图像分割 | U-Net / Mask2Former |
| 文本理解 (分类、NER) | BERT (Encoder) |
| 文本生成 / 对话 | GPT (Decoder) |
| 翻译 / 摘要 | T5 / BART (Enc-Dec) |
| 多模态 (CLIP / LLaVA) | Transformer |

## 6. 混合架构

实际系统常常组合使用：

### 6.1 CNN + Transformer

- **DETR**：CNN backbone 提特征，Transformer 做检测
- **CoAtNet**：CNN 早期 + Transformer 后期，混合归纳偏置

### 6.2 Transformer + MLP-Mixer

- MLP-Mixer：纯 MLP 替代 Attention，部分任务可行

### 6.3 Mamba / SSM (新趋势)

Mamba 用状态空间模型替代 Attention：

- 线性复杂度 $\mathcal{O}(n)$ vs $\mathcal{O}(n^2)$
- 长序列场景（百万 token）优势明显
- 与 Attention 互补，混合架构常用

### 6.4 混合专家 (MoE)

不是新架构，是 Transformer FFN 的"稀疏化"：

- Mixtral 8x7B：8 个专家，每次激活 2 个
- 总参数大、推理成本低
- 当前超大模型 (GPT-4、DeepSeek-V3) 都用 MoE

## 7. 如何选择架构

```
数据是什么？
│
├─ 表格 (低维、特征独立)
│   └─ MLP / DNN
│
├─ 图像 / 视频 / 音频
│   ├─ 小数据 (< 100K)
│   │   └─ CNN (ResNet)
│   └─ 大数据 (> 1M)
│       └─ ViT / Hybrid
│
├─ 序列 / 语言
│   └─ Transformer (Decoder-only 是主流)
│
└─ 图 / 点云 / 多模态
    └─ GNN / PointNet / 多模态 Transformer
```
