# 08. 聚类 (Clustering)

聚类是无监督学习的核心任务：将样本分成若干"组"，使得同组样本相似、异组样本相异。

## 8.1 什么是聚类

无标签情况下发现数据中的**自然分组**：

```
              ● ●         ▲▲▲▲
   原始数据    ● ● ●       ▲▲▲
              ●            ▲▲
                ↑           ↑
              聚成 2 类
```

应用：

- **客户细分**：用户分群
- **图像分割**：相似像素分组
- **文档组织**：主题发现
- **异常检测**：远离所有簇的样本
- **特征学习**：聚类中心作为特征

## 8.2 聚类类型

### 基于划分 (Partition-based)

K-Means、K-Medoids、CLARANS。

### 基于层次 (Hierarchical)

AHC (凝聚)、Diana (分裂)。

### 基于密度 (Density-based)

DBSCAN、HDBSCAN、OPTICS。

### 基于模型 (Model-based)

GMM (高斯混合)、HMM。

### 基于网格 (Grid-based)

CLIQUE、WaveCluster。

### 基于图 (Graph-based)

谱聚类 (Spectral)。

## 8.3 K-Means

最经典的聚类算法。

### 算法 (Lloyd's Algorithm)

```
1. 随机初始化 K 个中心 μ_1, ..., μ_K
2. 重复:
   a. 分配: 每个样本归到最近中心
      c_i = argmin_k ||x_i - μ_k||
   b. 更新: 中心 = 该簇均值
      μ_k = mean(x_i | c_i == k)
3. 收敛 (分配不变)
```

### 目标函数

$$
J = \sum_{i=1}^N \sum_{k=1}^K \mathbb{1}[c_i = k] \|x_i - \mu_k\|^2
$$

Lloyd 算法单调减小 $J$ (但只能收敛到**局部最优**)。

### K-Means++ (智能初始化)

随机选第一个中心，后续每个点被选为新中心的概率：

$$
P(x_i) \propto \min_k D(x_i, \mu_k)^2
$$

→ 显著减少坏初始化概率。

```python
from sklearn.cluster import KMeans

model = KMeans(
    n_clusters=5,
    init='k-means++',
    n_init=10,          # 多次初始化取最好
    max_iter=300,
    random_state=42,
)
labels = model.fit_predict(X)
print(f"Cluster centers: {model.cluster_centers_.shape}")
print(f"Inertia: {model.inertia_}")  # 簇内平方和
```

### Mini-Batch K-Means

大数据集：用 mini-batch 近似更新中心，速度快 10x。

```python
from sklearn.cluster import MiniBatchKMeans

model = MiniBatchKMeans(
    n_clusters=5,
    batch_size=100,
    random_state=42,
)
labels = model.fit_predict(X)
```

### K-Means 优缺点

**优点**：

- 简单、快 ($\mathcal{O}(NdK)$ 每轮)
- 易并行
- 大数据可扩展

**缺点**：

- 必须指定 K
- 对初始化敏感 (用 k-means++ 缓解)
- 只能找**球形**簇
- 对异常值敏感
- 特征需缩放

## 8.4 K 值选择

### 肘部法则 (Elbow)

画 $K$ vs $J$ (inertia)：

```
J
│
│●
│ ●
│  ●
│   ●● ← 肘部
│     ●●●●●
└──────────── K
```

### 轮廓系数 (Silhouette)

$$
s_i = \frac{b_i - a_i}{\max(a_i, b_i)}
$$

- $a_i$：样本到同簇其他样本的平均距离
- $b_i$：样本到最近其他簇样本的平均距离

$s_i \in [-1, 1]$，越大越好。

```python
from sklearn.metrics import silhouette_score

for k in [2, 3, 4, 5, 6, 8, 10]:
    labels = KMeans(n_clusters=k, random_state=42).fit_predict(X)
    score = silhouette_score(X, labels)
    print(f"K={k}: Silhouette = {score:.3f}")
```

### Gap Statistic

比较 $J$ 与参考分布（随机均匀）的期望 $E[J^*]$：

$$
\text{Gap}(K) = E[\log J^*] - \log J
$$

选最大的 $K$ 使 Gap 大。

## 8.5 DBSCAN

基于密度的聚类，能找任意形状的簇，识别异常点。

### 思想

- $\epsilon$-邻域：与样本距离 < $\epsilon$ 的样本集合
- 核心点：$\epsilon$-邻域内 ≥ `min_samples` 个样本
- 边界点：在核心点邻域内，但自身不是核心点
- 噪声点：既不是核心点也不是边界点

### 算法

```
1. 找所有核心点
2. 把密度可达的核心点连成一组
3. 边界点归到最近核心点的簇
4. 噪声点 (-1)
```

### 关键参数

| 参数 | 作用 |
|------|------|
| `eps` | 邻域半径 |
| `min_samples` | 核心点最少邻居数 |

```python
from sklearn.cluster import DBSCAN

model = DBSCAN(eps=0.5, min_samples=5)
labels = model.fit_predict(X)
print(f"聚类数: {len(set(labels)) - (1 if -1 in labels else 0)}")
print(f"噪声数: {(labels == -1).sum()}")
```

### 优缺点

**优点**：

- 不需要指定 K
- 找任意形状簇
- 识别异常
- 对噪声鲁棒

**缺点**：

- eps / min_samples 难选
- 不同密度簇效果差
- 大数据慢 ($\mathcal{O}(N \log N)$)

### HDBSCAN

DBSCAN 的层次版本，自动选 eps，能处理不同密度。

```python
import hdbscan

model = hdbscan.HDBSCAN(min_cluster_size=5)
labels = model.fit_predict(X)
```

## 8.6 层次聚类

### 凝聚 (Agglomerative, AHC)

自底向上合并最近的两簇：

```
N 个点 → N-1 个点 → ... → 1 个簇

距离度量:
- 单连接 (single-link): 两簇最近点距离
- 全连接 (complete-link): 两簇最远点距离
- 平均连接 (average-link): 两簇所有点对距离平均
- Ward: 合并后簇内方差最小化
```

```python
from sklearn.cluster import AgglomerativeClustering

model = AgglomerativeClustering(
    n_clusters=4,
    linkage='ward',  # 'average', 'complete', 'single'
)
labels = model.fit_predict(X)
```

### 可视化 (Dendrogram)

```python
from scipy.cluster.hierarchy import dendrogram, linkage

Z = linkage(X, method='ward')
dendrogram(Z)
plt.show()
```

### 优缺点

**优点**：

- 不需要指定 K (可看 dendrogram 决定)
- 输出层次关系
- 任意距离度量

**缺点**：

- $\mathcal{O}(N^3)$ 复杂度
- 合并后**无法撤销**
- 大数据慢

## 8.7 高斯混合模型 (GMM)

概率模型：假设数据由 K 个高斯分布混合生成。

### 模型

$$
P(x) = \sum_{k=1}^K \pi_k \mathcal{N}(x | \mu_k, \Sigma_k)
$$

- $\pi_k$：混合系数 ($\sum \pi_k = 1$)
- $\mathcal{N}(\mu_k, \Sigma_k)$：第 $k$ 个高斯分量

### 估计 (EM 算法)

**E-step**：计算每个样本属于各分量的概率

$$
\gamma_{ik} = \frac{\pi_k \mathcal{N}(x_i | \mu_k, \Sigma_k)}{\sum_{k'} \pi_{k'} \mathcal{N}(x_i | \mu_{k'}, \Sigma_{k'})}
$$

**M-step**：最大化期望似然更新参数

$$
\mu_k = \frac{\sum_i \gamma_{ik} x_i}{\sum_i \gamma_{ik}}, \quad
\Sigma_k = \frac{\sum_i \gamma_{ik} (x_i - \mu_k)(x_i - \mu_k)^T}{\sum_i \gamma_{ik}}, \quad
\pi_k = \frac{\sum_i \gamma_{ik}}{N}
$$

### 代码

```python
from sklearn.mixture import GaussianMixture

model = GaussianMixture(
    n_components=5,
    covariance_type='full',  # 'full', 'tied', 'diag', 'spherical'
    max_iter=100,
    random_state=42,
)
labels = model.fit_predict(X)

# 软分配 (每个样本属于各簇概率)
probs = model.predict_proba(X)

# 概率密度估计
log_dens = model.score_samples(X)
```

### 协方差类型

- `spherical`：每个簇各向同性球形 (类似 K-Means)
- `diag`：每个簇各向异性、对角协方差
- `full`：每个簇完整协方差
- `tied`：所有簇共享一个协方差

参数数：少 → 强假设、速度快；多 → 弱假设、过拟合风险。

### 模型选择

```python
for n in range(1, 10):
    gmm = GaussianMixture(n_components=n, random_state=42)
    gmm.fit(X)
    bic = gmm.bic(X)
    aic = gmm.aic(X)
    print(f"K={n}: BIC={bic:.0f}, AIC={aic:.0f}")
```

### 优点

- 输出**软聚类**（每个样本的概率分布）
- 簇形状灵活（取决于协方差类型）
- 概率模型，理论优美

## 8.8 谱聚类 (Spectral)

适合非凸形状、图结构数据。

### 思想

构造样本的相似度图，求 Laplacian 矩阵的特征向量，再 K-Means。

### 步骤

1. 计算相似度矩阵 $W$（RBF, k-NN）
2. 构造度矩阵 $D$
3. 归一化 Laplacian: $L = I - D^{-1/2}WD^{-1/2}$
4. 求 $L$ 的前 $K$ 个最小特征向量
5. 在特征向量上跑 K-Means

```python
from sklearn.cluster import SpectralClustering

model = SpectralClustering(
    n_clusters=5,
    affinity='nearest_neighbors',  # 或 'rbf'
    n_neighbors=10,
    random_state=42,
)
labels = model.fit_predict(X)
```

适用：

- 非凸形状
- 图数据
- 图像分割 (Normalized Cut)

## 8.9 聚类评估

### 内部指标 (无标签)

#### 轮廓系数

[-1, 1]，越大越好。

#### Calinski-Harabasz

$$
\text{CH} = \frac{\text{trace}(B)/K}{\text{trace}(W)/(N-K)}
$$

$B$ = 簇间协方差，$W$ = 簇内协方差。越大越好。

#### Davies-Bouldin

簇内距离 / 簇间距离的比值平均。越小越好。

```python
from sklearn.metrics import (
    silhouette_score,
    calinski_harabasz_score,
    davies_bouldin_score,
)
```

### 外部指标 (有标签)

#### Adjusted Rand Index (ARI)

[-1, 1]，1 = 完美，0 = 随机。

#### Normalized Mutual Information (NMI)

[0, 1]，1 = 完美。

#### V-measure / Fowlkes-Mallows

ARI / NMI 的变体。

```python
from sklearn.metrics import (
    adjusted_rand_score,
    normalized_mutual_info_score,
    homogeneity_score,
    completeness_score,
    v_measure_score,
)
```

### 注意

- 真实标签 $y$ 与聚类标签无对应关系 → 用 ARI / NMI
- 不能用 accuracy_score

## 8.12 代码示例

### 完整流程

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import StandardScaler

# 生成数据
X, y_true = make_blobs(n_samples=1000, centers=5, random_state=42)

# 缩放
X_scaled = StandardScaler().fit_transform(X)

# 多种算法对比
algorithms = {
    'K-Means': KMeans(n_clusters=5, random_state=42),
    'DBSCAN': DBSCAN(eps=0.5, min_samples=10),
    'AHC': AgglomerativeClustering(n_clusters=5),
}

fig, axes = plt.subplots(1, 3, figsize=(15, 5))
for ax, (name, model) in zip(axes, algorithms.items()):
    labels = model.fit_predict(X_scaled)
    score = silhouette_score(X_scaled, labels) if len(set(labels)) > 1 else -1
    ax.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis')
    ax.set_title(f"{name}\nSilhouette = {score:.3f}")

plt.show()
```
