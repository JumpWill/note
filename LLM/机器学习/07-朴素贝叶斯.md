# 07. 朴素贝叶斯 (Naive Bayes, NB)

朴素贝叶斯是基于**贝叶斯定理** + **特征条件独立假设**的简单分类器。形式简单，但在文本分类等场景仍表现优异。

## 7.1 贝叶斯定理

### 基本形式

$$
P(y|x) = \frac{P(x|y) P(y)}{P(x)}
$$

- $P(y|x)$：后验 (给定 x 后 y 的概率)
- $P(y)$：先验 (y 的边缘概率)
- $P(x|y)$：似然 (y 条件下 x 的概率)
- $P(x)$：证据 (x 的边缘概率)

### 分类决策

$$
y^* = \arg\max_y P(y|x) = \arg\max_y P(x|y) P(y)
$$

($P(x)$ 与 $y$ 无关，可省略)

## 7.2 朴素贝叶斯假设

**条件独立**：

$$
P(x_1, x_2, \ldots, x_d | y) = \prod_{j=1}^d P(x_j | y)
$$

这是"朴素"（naive）的来源——**特征间独立**。

代入贝叶斯：

$$
P(y|x) \propto P(y) \prod_{j=1}^d P(x_j | y)
$$

$$
y^* = \arg\max_y P(y) \prod_{j=1}^d P(x_j | y)
$$

## 7.3 估计方法

### 先验

$$
\hat{P}(y = c) = \frac{N_c}{N}
$$

### 似然 (MLE)

$$
\hat{P}(x_j = v | y = c) = \frac{N_{jc}}{N_c}
$$

$N_{jc}$ 是类 $c$ 中特征 $j$ 取值 $v$ 的样本数。

### 平滑 (Laplace / Additive)

零概率问题：训练集中未见 (x_j = v, y = c) 的组合 → $P = 0$ → 整个乘积为 0。

Laplace 平滑：

$$
\hat{P}(x_j = v | y = c) = \frac{N_{jc} + \alpha}{N_c + \alpha V}
$$

$V$ 是特征 $j$ 的可能取值数，$\alpha \geq 0$ 是平滑系数（$\alpha = 1$ 为经典 Laplace）。

## 7.4 变体

### Gaussian NB

特征连续、假设高斯分布：

$$
P(x_j | y) = \frac{1}{\sqrt{2\pi\sigma_y^2}} \exp\left(-\frac{(x_j - \mu_y)^2}{2\sigma_y^2}\right)
$$

$\mu_y, \sigma_y$ 按类 $y$ 的样本估计。

```python
from sklearn.naive_bayes import GaussianNB

model = GaussianNB()
model.fit(X_train, y_train)
```

适用：连续特征，常被用作 baseline。

### Multinomial NB

特征是**计数**（文本词频）：

$$
P(x | y) = \frac{N!}{x_1! \cdots x_d!} \prod_j p_{yj}^{x_j}
$$

$p_{yj} = P(x_j | y)$ 是特征 $j$ 在类 $y$ 下的概率。

```python
from sklearn.naive_bayes import MultinomialNB

model = MultinomialNB(alpha=1.0)  # Laplace
model.fit(X_count_train, y_train)  # X 是计数矩阵
```

适用：文本分类 (TF-IDF / 词频)。

### Bernoulli NB

特征是**二值**（词是否出现）：

$$
P(x | y) = \prod_j p_{yj}^{x_j} (1-p_{yj})^{1-x_j}
$$

```python
from sklearn.naive_bayes import BernoulliNB

model = BernoulliNB(alpha=1.0, binarize=0.5)  # binarize 阈值
model.fit(X_train, y_train)
```

适用：短文本、词袋 (bag of presence)。

### Complement NB

MultinomialNB 的改进，**用补集**估计，对不均衡更鲁棒：

$$
\hat{\theta}_{cj} = \frac{\alpha_{cj} + \alpha}{\sum_{j'} (\alpha_{cj'} + \alpha)}
$$

```python
from sklearn.naive_bayes import ComplementNB

model = ComplementNB(alpha=1.0)
model.fit(X_train, y_train)
```

适用：不均衡文本数据集。

### Categorical NB

特征是**离散类别**：

$$
P(x_j = v | y = c) = \frac{N_{jcv} + \alpha}{N_c + \alpha V_j}
$$

```python
from sklearn.naive_bayes import CategoricalNB

model = CategoricalNB(alpha=1.0)
model.fit(X_train, y_train)  # X 是整数编码
```

## 7.5 代码

### 文本分类经典案例

```python
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

# 数据
texts = ["good movie", "bad movie", ...]
labels = [1, 0, ...]

# 划分
X_train, X_test, y_train, y_test = train_test_split(texts, labels)

# Pipeline
pipe = Pipeline([
    ('vec', TfidfVectorizer(max_features=10000)),
    ('clf', MultinomialNB(alpha=0.1)),
])

pipe.fit(X_train, y_train)
y_pred = pipe.predict(X_test)
print(classification_report(y_test, y_pred))
```

### 概率输出

```python
y_proba = pipe.predict_proba(X_test)
# 第一列是类 0 概率，第二列是类 1 概率
```

## 7.6 数学性质

### 决策边界

朴素贝叶斯在特定条件下是**线性** (Gaussian NB) 或**指数族**决策边界。

### 一致性

随着 $N \to \infty$ 且独立性假设成立，NB 收敛到贝叶斯最优分类器。

### 即使独立性不成立

很多场景下，独立性假设虽不真，但 NB 仍能给出好的**排序** (因为 $P(y|x)$ 的相对顺序对独立性不敏感)。

### VC 维

MultinomialNB 的 VC 维与特征数和类别数线性相关。

## 7.7 优缺点

### 优点

- **简单**：训练快 (一次扫描数据)
- **推理快**：只算一些概率
- **小数据**：表现比复杂模型好
- **可解释**：每个特征的概率可查
- **多分类**自然
- **增量学习**容易
- 对**特征数**不敏感 (高维友好)

### 缺点

- 独立性假设**通常不成立**
- 概率估计**不准确**（即使排序可能准）
- 对**零频词**需平滑
- 不能学**特征交互**

## 7.9 调参

### 平滑系数 `alpha`

| alpha | 效果 |
|-------|------|
| 0 | 无平滑 (训练集上拟合，可能爆零概率) |
| 1 | 经典 Laplace |
| < 1 | Lidstone 平滑 |
| > 1 | 更平滑 (小数据集友好) |

```python
from sklearn.model_selection import GridSearchCV

params = {'alpha': [0.001, 0.01, 0.1, 1.0, 10.0]}
grid = GridSearchCV(MultinomialNB(), params, cv=5)
grid.fit(X_train, y_train)
```

### 特征选择

NB 假设独立，对不相关特征**不敏感**（不像 LR 会被高维伤）。

## 7.10 实际代码示例

### 垃圾邮件分类

```python
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline
from sklearn.model_selection import cross_val_score

# 加载数据
df = pd.read_csv('spam.csv')
X = df['message']
y = df['label']  # 'spam' / 'ham'

# Pipeline
pipe = Pipeline([
    ('tfidf', TfidfVectorizer(
        max_features=10000,
        ngram_range=(1, 2),    # 1-gram + 2-gram
        min_df=2,
        sublinear_tf=True,
    )),
    ('nb', MultinomialNB(alpha=0.1)),
])

# 评估
scores = cross_val_score(pipe, X, y, cv=5, scoring='f1')
print(f"CV F1: {scores.mean():.3f} ± {scores.std():.3f}")
```

### 高斯 NB 的简单分类

```python
from sklearn.datasets import load_iris
from sklearn.naive_bayes import GaussianNB

X, y = load_iris(return_X_y=True)
model = GaussianNB()
model.fit(X, y)
print(f"Accuracy = {model.score(X, y):.3f}")
```

## 7.12 进阶话题

### 校准 (Calibration)

NB 的概率输出通常偏极端。可用：

- Platt Scaling：在 NB 输出上学 LR
- Isotonic Regression：非参数校准

```python
from sklearn.calibration import CalibratedClassifierCV

calib = CalibratedClassifierCV(
    base_estimator=MultinomialNB(alpha=0.1),
    method='sigmoid',  # 'isotonic'
    cv=5,
)
```

### 处理冗余特征

NB 对冗余特征**不鲁棒**（独立性假设被打破）：

- 删冗余特征
- 用特征选择
- 用 PCA 降维

### 多标签分类

```python
from sklearn.naive_bayes import MultinomialNB

# 多标签：每标签独立 NB
model = MultinomialNB(alpha=0.1)
model.fit(X_train, y_train)  # y_train 是 multi-label
```
