# 10. 异常检测 (Anomaly Detection)

异常检测是识别与"正常"显著不同的样本。广泛用于欺诈检测、设备故障、网络入侵、数据清洗等。

## 10.1 什么是异常

定义：**与数据集中其他样本显著不同**的样本。

三类异常：

- **点异常 (Point)**：单个样本偏离主体
- **上下文异常 (Contextual)**：在特定上下文下异常
- **集合异常 (Collective)**：一组样本整体异常（如季节性异常模式）

## 10.2 应用场景

- **金融**：欺诈交易、洗钱
- **工业**：设备故障预测、传感器异常
- **网络安全**：入侵检测、DDoS
- **医疗**：疾病早期信号
- **运维**：服务异常、指标告警
- **数据清洗**：剔除异常点
- **时间序列**：异常波动、突发事件

## 10.3 方法分类

### 按技术

| 类别 | 方法 | 思想 |
|------|------|------|
| 统计 | Z-Score, IQR, Grubbs | 数据服从某分布，找偏离 |
| 距离 | KNN, Mahalanobis | 找远离邻居的 |
| 密度 | LOF, DBSCAN | 低密度区域 |
| 线性 | One-Class SVM, PCA | 学正常样本的边界 |
| 树 | Isolation Forest | 随机切分易分离 |
| 神经网络 | AutoEncoder, VAE | 重构误差大 |
| 概率 | GMM, KDE | 概率密度低 |

### 按监督

- **无监督**：训练只用正常样本（or 混合）→ 找出偏离
- **半监督**：只用正常样本训 → 偏离即异常
- **监督**：异常/正常都有标签 → 普通二分类

## 10.4 统计方法

### Z-Score

$$
z = \frac{x - \mu}{\sigma}
$$

$|z| > 3$ 通常视为异常（假设正态）。

```python
from scipy import stats

z = np.abs(stats.zscore(X))
mask = (z < 3).all(axis=1)  # 不是异常的行
```

### IQR

$$
\text{lower} = Q_1 - 1.5 \times \text{IQR}, \quad \text{upper} = Q_3 + 1.5 \times \text{IQR}
$$

适合非正态数据。

```python
Q1, Q3 = np.percentile(X, [25, 75])
IQR = Q3 - Q1
lower, upper = Q1 - 1.5*IQR, Q3 + 1.5*IQR
mask = ((X >= lower) & (X <= upper)).all(axis=1)
```

### Grubbs 检验

检验最大值/最小值是否为异常。

$$
G = \frac{\max |x_i - \bar{x}|}{s}
$$

适合正态、小数据集。

### 局限

- 假设分布（不一定成立）
- 高维失效
- 不能建模特征关系

## 10.5 基于距离

### KNN 距离

样本到第 K 个邻居的距离大 → 异常。

```python
from sklearn.neighbors import NearestNeighbors

nn = NearestNeighbors(n_neighbors=5)
nn.fit(X)
dist, _ = nn.kneighbors(X)
anomaly_score = dist[:, -1]  # 第 K 个邻居距离
```

### Mahalanobis 距离

考虑特征相关性的距离：

$$
d_M(x) = \sqrt{(x - \mu)^T \Sigma^{-1} (x - \mu)}
$$

```python
from scipy.spatial.distance import mahalanobis

cov = np.cov(X, rowvar=False)
mean = X.mean(axis=0)
cov_inv = np.linalg.inv(cov)
d = [mahalanobis(x, mean, cov_inv) for x in X]
```

## 10.6 基于密度 (LOF)

**Local Outlier Factor**：样本的局部密度显著低于邻居 → 异常。

### 核心：可达距离

$$
\text{rd}_k(x, y) = \max(d_k(y), d(x, y))
$$

$d_k(y)$ 是 $y$ 到其第 $k$ 个邻居的距离。

### 局部可达密度 (LRD)

$$
\text{lrd}_k(x) = \frac{1}{\frac{1}{k}\sum_{y \in N_k(x)} \text{rd}_k(x, y)}
$$

### LOF

$$
\text{LOF}_k(x) = \frac{\frac{1}{k}\sum_{y \in N_k(x)} \text{lrd}_k(y)}{\text{lrd}_k(x)}
$$

- LOF ≈ 1：与邻居密度相同
- LOF > 1：异常（密度比邻居低）
- LOF < 1：密集区域

```python
from sklearn.neighbors import LocalOutlierFactor

lof = LocalOutlierFactor(
    n_neighbors=20,
    contamination=0.1,  # 异常比例
)
labels = lof.fit_predict(X)  # -1 = 异常
scores = -lof.negative_outlier_factor_  # 越大越异常
```

### 优点

- 能捕捉局部异常（局部密度不同的数据集）

## 10.7 Isolation Forest

**核心思想**：异常点容易被孤立 → 用随机切分，异常点需要的切分次数少。

### 算法

1. 随机选一个特征 + 随机选一个切分值
2. 递归切分
3. 异常点路径短（少数几次就被孤立）

### 异常分数

$$
s(x, n) = 2^{-\frac{E[h(x)]}{c(n)}}
$$

$h(x)$ = 路径长度，$c(n)$ = 平均路径长度。$s$ 越大越异常。

```python
from sklearn.ensemble import IsolationForest

model = IsolationForest(
    n_estimators=100,
    contamination=0.1,
    random_state=42,
)
labels = model.fit_predict(X)  # -1 = 异常
scores = -model.score_samples(X)
```

### 优点

- 快（线性复杂度）
- 不依赖距离度量
- 适合高维

## 10.9 One-Class SVM

**核心**：学一个超平面（球），使正常样本在内、异常在外。

$$
\min_{w, \rho, \xi} \frac{1}{2}\|w\|^2 + \frac{1}{\nu N}\sum \xi_i - \rho
$$

$$
\text{s.t.} \quad w^T \phi(x_i) \geq \rho - \xi_i, \xi_i \geq 0
$$

$\nu$ 是异常比例上界。

```python
from sklearn.svm import OneClassSVM

model = OneClassSVM(
    kernel='rbf',
    nu=0.1,            # 预期异常比例
    gamma='scale',
)
labels = model.fit_predict(X)  # -1 = 异常
```

### 适用

- 半监督场景：只用正常样本训练
- 中小数据集
- 与 SVM 类似优缺点

## 10.10 AutoEncoder 重构法

### 思想

训练 AutoEncoder 学 $f \approx X$。

异常点重构误差大（模型没学好）。

```python
from tensorflow.keras import layers, Model

input_dim = X.shape[1]
encoding_dim = 8

inputs = layers.Input(shape=(input_dim,))
encoded = layers.Dense(encoding_dim, activation='relu')(inputs)
decoded = layers.Dense(input_dim, activation='sigmoid')(encoded)

autoencoder = Model(inputs, decoded)
autoencoder.compile(optimizer='adam', loss='mse')
autoencoder.fit(X, X, epochs=50, batch_size=32, validation_split=0.1)

# 重构误差 = 异常分数
reconstructions = autoencoder.predict(X)
mse = np.mean((X - reconstructions)**2, axis=1)
threshold = np.percentile(mse, 95)
anomalies = mse > threshold
```

### 变体

- VAE (Variational AutoEncoder)
- LSTM AutoEncoder (时序)
- GAN-based anomaly

## 10.11 GMM / KDE

### GMM

拟合正常数据为多高斯混合，低概率为异常。

```python
from sklearn.mixture import GaussianMixture

gmm = GaussianMixture(n_components=5, random_state=42)
gmm.fit(X)

# 概率密度
log_dens = gmm.score_samples(X)
threshold = np.percentile(log_dens, 5)
anomalies = log_dens < threshold
```

### KDE

核密度估计：

```python
from sklearn.neighbors import KernelDensity

kde = KernelDensity(bandwidth=0.5, kernel='gaussian')
kde.fit(X)

log_dens = kde.score_samples(X)
```

## 10.12 DBSCAN 的副产品

DBSCAN 标记的噪声点 (-1) 就是异常。

```python
from sklearn.cluster import DBSCAN

db = DBSCAN(eps=0.5, min_samples=10)
labels = db.fit_predict(X)
anomalies = labels == -1
```

## 10.13 时间序列异常

### 移动平均 / 标准差

滚动窗口的均值 ± 3σ 范围外：

```python
window = 30
rolling_mean = X.rolling(window).mean()
rolling_std = X.rolling(window).std()
anomalies = (X > rolling_mean + 3*rolling_std) | (X < rolling_mean - 3*rolling_std)
```

### STL 分解

分解为季节 + 趋势 + 残差。残差大 → 异常。

```python
from statsmodels.tsa.seasonal import STL

stl = STL(X, period=12).fit()
resid = stl.resid
anomalies = np.abs(resid) > 3 * np.std(resid)
```

### 突变检测 (Change Point)

Bayesian Change Point Detection、Prophet 的转折点检测。

## 10.14 评估指标

### 无监督评估

无标签难评。可用：

- 注入人造异常 → 监督指标
- 看排序：异常分数排前面的应是真异常

### 半监督评估（仅正常训练）

正常 / 异常样本分开，用 PR-AUC、F1。

### 监督指标

| 指标 | 适用 |
|------|------|
| Precision@k | Top K 异常里真异常的比例 |
| Recall | 召回比例 |
| F1 | 平衡 |
| PR-AUC | 不均衡场景 |

```python
from sklearn.metrics import precision_recall_curve, average_precision_score

ap = average_precision_score(y_true, anomaly_scores)
```

## 10.15 选型速查

| 场景 | 推荐 |
|------|------|
| 一维 / 简单 | Z-Score, IQR |
| 中维 + 速度 | Isolation Forest |
| 高维 + 非线性 | AutoEncoder |
| 半监督 (仅正常) | One-Class SVM, KDE |
| 局部异常 | LOF |
| 时序 | STL 残差, LSTM AE |
| 概率密度 | GMM, KDE |
| 集成鲁棒 | IForest + LOF + OCSVM 投票 |

## 10.16 实践技巧

1. **数据标注难**：业务难定义什么是异常，优先无监督
2. **污染率**：设置合理的 `contamination` (0.01~0.1)
4. **集成**：IForest + LOF 投票更稳
5. **可视化**：t-SNE/UMAP 看异常点
6. **持续监控**：在线学习适应漂移
7. **业务对齐**：与领域专家合作定义异常

## 10.17 完整示例

```python
import numpy as np
from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor
from sklearn.svm import OneClassSVM
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import classification_report

# 数据
X = np.random.randn(1000, 5)
X[:20] += 5  # 注入异常

# 缩放
X_scaled = StandardScaler().fit_transform(X)

# 多种方法集成
iforest = IsolationForest(contamination=0.05, random_state=42).fit(X_scaled)
lof = LocalOutlierFactor(contamination=0.05).fit(X_scaled)
ocsvm = OneClassSVM(nu=0.05).fit(X_scaled)

# 投票
votes = (
    (iforest.predict(X_scaled) == -1).astype(int) +
    (lof.fit_predict(X_scaled) == -1).astype(int) +
    (ocsvm.predict(X_scaled) == -1).astype(int)
)

anomalies = votes >= 2  # 至少 2 个认为异常
print(f"检测到 {anomalies.sum()} 个异常")
```
