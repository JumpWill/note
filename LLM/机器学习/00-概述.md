# 机器学习总览

## 什么是机器学习

机器学习 (Machine Learning, ML) 是让计算机系统从**数据**中自动学习规律并做出预测或决策，而不依赖人工显式编写的规则。

```
传统编程:  数据 + 规则 → 输出
机器学习:  数据 + 输出 → 学到规则 → 预测新数据
```

形式化定义：

> 给定训练集 $\mathcal{D} = \{(x_i, y_i)\}_{i=1}^N$，从假设空间 $\mathcal{H}$ 中学习一个函数 $f_\theta: \mathcal{X} \to \mathcal{Y}$，使得在未见过的测试集上损失 $L(f_\theta(x), y)$ 最小。

## 学习范式

机器学习有五种主要范式：

| 范式 | 数据形式 | 目标 | 典型任务 |
|------|---------|------|----------|
| **监督学习** | $(x, y)$ | 学 $f(x) \to y$ | 分类、回归 |
| **无监督学习** | $x$ | 学 $f(x) \to$ 结构 | 聚类、降维、密度估计 |
| **半监督学习** | 少量 $(x, y)$ + 大量 $x$ | 学 $f$ | 标签昂贵场景 |
| **自监督学习** | $x$ 自身生成伪标签 | 学表征 | LLM 预训练、BERT |
| **强化学习** | 状态 + 奖励 | 学策略 $\pi(a \mid s)$ | 游戏、机器人 |
