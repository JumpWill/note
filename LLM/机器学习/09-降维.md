# 09. 降维 (Dimensionality Reduction)

降维把高维数据映射到低维空间，保留关键信息。广泛用于可视化、特征工程、压缩、去噪。

## 9.1 为什么要降维

### 维度灾难

$d$ 维空间中，数据稀疏、距离不区分 → 模型性能下降。

### 降维目的

- **可视化**：降到 2D / 3D
- **去噪**：去除低方差方向
- **特征工程**：低维特征馈给下游模型
- **压缩**：存储 / 传输节省
- **去相关**：特征间不再相关

### 维度选择

- 保留 95% / 99% 方差
- 肘部法则
- 下游任务性能

## 9.2 PCA (Principal Component Analysis)

最经典的线性降维方法。

### 思想

找 $k$ 个**正交方向**，使数据在这 $k$ 维上投影方差最大。

### 数学推导

样本中心化：$\bar{x} = \frac{1}{N}\sum x_i$，$X_{\text{centered}} = X - \bar{x}$。

协方差矩阵：

$$
\Sigma = \frac{1}{N} X^T X
$$

特征分解：

$$
\Sigma = U \Lambda U^T
$$

$U$ 的前 $k$ 列 = 主成分方向，$\Lambda$ 的前 $k$ 个特征值 = 各方向方差。

投影到 $k$ 维：

$$
X_{\text{proj}} = X_{\text{centered}} \cdot U_k
$$

### 算法 (等价形式：SVD)

```
1. 中心化 X
2. SVD: X = U Σ V^T
3. 取 V 的前 k 列
4. X_proj = X · V[:, :k]
```

### 重构

$$
\hat{X} = X_{\text{proj}} V_k^T + \bar{x}
$$

### 保留方差比例

$$
\text{ratio} = \frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i}
$$

```python
from sklearn.decomposition import PCA

pca = PCA(n_components=0.95)  # 保留 95% 方差
X_proj = pca.fit_transform(X)

print(f"Original shape: {X.shape}")
print(f"Reduced shape: {X_proj.shape}")
print(f"Explained variance ratio: {pca.explained_variance_ratio_}")
print(f"Cumulative ratio: {pca.explained_variance_ratio_.cumsum()}")
```

### 关键超参

| 超参 | 作用 |
|------|------|
| `n_components` | 主成分数，可选保留方差比 |
| `whiten` | 是否归一化主成分（等价方差） |
| `svd_solver` | 'auto', 'full', 'arpack', 'randomized' |

### 性质

- **线性变换**：可解释
- **全局方法**：考虑所有样本
- **最大化方差** = **最小化重构误差**
- 对**缩放**敏感 → 必须先标准化
- **正交**：主成分间不相关

### 局限

- 只能捕捉**线性**关系
- 假设方差 = 信息 → 不一定成立
- 对**异常值**敏感

### 应用

- 数据压缩
- 去噪 (丢弃低方差成分)
- 白化 (Whiten)
- 数据可视化
- 人脸识别 (Eigenfaces)
- 特征预处理

## 9.3 增量 PCA (Incremental PCA)

大数据集不能全部加载到内存，用增量 PCA。

```python
from sklearn.decomposition import IncrementalPCA

pca = IncrementalPCA(n_components=50, batch_size=100)
# 分批 fit
for X_batch in data_batches:
    pca.partial_fit(X_batch)
X_proj = pca.transform(X)
```

## 9.4 Kernel PCA

PCA 的非线性版本，用核方法映射到高维再 PCA。

```python
from sklearn.decomposition import KernelPCA

kpca = KernelPCA(
    n_components=50,
    kernel='rbf',   # 'linear', 'poly', 'sigmoid'
    gamma=0.1,
)
X_proj = kpca.fit_transform(X)
```

适用：

- 非线性流形
- 图像数据

缺点：

- 如何选核 + 超参
- 不如 PCA 可解释

## 9.5 t-SNE

非线性降维，专为**可视化**设计 (2D/3D)。

### 思想

- 高维空间：算样本对相似度 (高斯分布)
- 低维空间：算样本对相似度 (t 分布)
- 最小化两个分布的 KL 散度

### 高维相似度

$$
p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}
$$

### 低维相似度

$$
q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l}(1 + \|y_k - y_l\|^2)^{-1}}
$$

### KL 散度

$$
\text{KL}(P||Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}
$$

### 关键超参

| 超参 | 作用 |
|------|------|
| `perplexity` | 关注局部 vs 全局，默认 30 |
| `learning_rate` | 梯度下降学习率 |
| `n_iter` | 迭代次数，越大越稳定 |
| `early_exaggeration` | 早期放大簇间距 |

```python
from sklearn.manifold import TSNE

tsne = TSNE(
    n_components=2,
    perplexity=30,
    learning_rate='auto',
    n_iter=1000,
    random_state=42,
)
X_tsne = tsne.fit_transform(X)
```

### 重要警告

- ❌ t-SNE **不能** 用于下游 ML 任务的特征提取（仅可视化）
- ❌ 距离/簇**大小**无意义
- ❌ 不同次运行**结果不同**
- ✅ 簇的**形状**有意义
- ✅ perplexity 影响结果，建议多次尝试

### 加速

大数据 (>10K) 用 `openTSNE`：

```python
import openTSNE
tsne = openTSNE.TSNE(perplexity=30, n_jobs=-1)
X_tsne = tsne.fit(X)
```

## 9.6 UMAP

与 t-SNE 类似但更快，支持新数据 transform。

### 思想

基于黎曼几何和代数拓扑理论。

- 构造模糊单纯复形
- 低维保持拓扑结构

```python
import umap

reducer = umap.UMAP(
    n_components=2,
    n_neighbors=15,
    min_dist=0.1,
    metric='euclidean',
    random_state=42,
)
X_umap = reducer.fit_transform(X)

# 也支持新数据
X_new_umap = reducer.transform(X_new)
```

### 优势

- 比 t-SNE **快得多** (10x+)
- 支持新数据 transform
- 保留全局结构比 t-SNE 好
- 可用作通用 ML 特征提取

### 关键超参

| 超参 | 作用 |
|------|------|
| `n_neighbors` | 局部邻域大小 |
| `min_dist` | 簇内点的紧凑度 |
| `n_components` | 目标维度 |
| `metric` | 距离度量 |

### 与 t-SNE 对比

| 维度 | t-SNE | UMAP |
|------|-------|------|
| 速度 | 慢 | **快** |
| 新数据 | ❌ | ✅ |
| 全局结构 | 中 | **好** |
| 簇大小 | 不准 | 较准 |

## 9.7 LDA (Linear Discriminant Analysis)

**有监督**降维，与 PCA 类似但用标签信息。

### 思想

找投影方向，使**类间方差**最大 / **类内方差**最小。

### 算法

$$
W = \arg\max_W \frac{W^T S_B W}{W^T S_W W}
$$

$S_B$ = 类间协方差矩阵
$S_W$ = 类内协方差矩阵

解：$S_W^{-1} S_B$ 的前 $k$ 个特征向量。

```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

lda = LinearDiscriminantAnalysis(n_components=2)
X_lda = lda.fit_transform(X, y)
```

### 性质

- **有监督**：用标签
- 最多降到 $C-1$ 维 ($C$ = 类别数)
- 假设：高斯、协方差相同

### 应用

- 预处理
- 可视化 (类别分得开)
- 人脸识别 (Fisherfaces)

## 9.8 ICA (Independent Component Analysis)

找使数据各分量**独立**的线性变换。

### 应用

- **盲源分离**：从混合信号还原源信号
  - 鸡尾酒会问题
- EEG / fMRI 信号分离
- 图像特征提取

```python
from sklearn.decomposition import FastICA

ica = FastICA(n_components=5, random_state=42)
X_ica = ica.fit_transform(X)
```

### 与 PCA 对比

| 维度 | PCA | ICA |
|------|-----|-----|
| 准则 | 方差最大 | 独立 |
| 高斯性 | 无假设 | 非高斯假设 |
| 解释 | 主成分 | 独立分量 |

## 9.9 因子分析 (Factor Analysis)

假设观测变量是**潜在因子**的线性组合 + 噪声。

$$
x = \Lambda z + \epsilon, \quad z \sim \mathcal{N}(0, I), \epsilon \sim \mathcal{N}(0, \Psi)
$$

与 PCA 的区别：

- 因子分析**显式建模噪声** $\Psi$
- PCA 隐式假设各方向噪声方差相同

```python
from sklearn.decomposition import FactorAnalysis

fa = FactorAnalysis(n_components=5)
X_fa = fa.fit_transform(X)
```

## 9.10 字典学习 / 稀疏编码

学一组**基向量** (字典)，使样本能稀疏线性表示。

应用：

- 图像去噪
- 图像分类
- 信号重建

```python
from sklearn.decomposition import DictionaryLearning

dl = DictionaryLearning(n_components=50, alpha=1.0)
X_code = dl.fit_transform(X)
```

## 9.11 截断 SVD (Truncated SVD)

专门用于稀疏矩阵（如文本 TF-IDF）。

与 PCA 的区别：

- PCA 中心化数据 → 稀疏变稠密
- Truncated SVD **不中心化** → 适合稀疏

```python
from sklearn.decomposition import TruncatedSVD

svd = TruncatedSVD(n_components=100)
X_svd = svd.fit_transform(X_tfidf)  # X_tfidf 稀疏
```

又称 LSA（Latent Semantic Analysis）。

## 9.12 特征选择

不同于特征提取（变换），特征选择选原始特征的子集。

### 过滤式 (Filter)

按统计量选，与模型无关：

- 方差阈值
- 相关系数
- 互信息
- 卡方检验

```python
from sklearn.feature_selection import SelectKBest, chi2, mutual_info_classif

selector = SelectKBest(chi2, k=10)
X_sel = selector.fit_transform(X, y)
```

### 包裹式 (Wrapper)

用模型性能指导：

- 前向选择
- 后向消除
- RFE (递归特征消除)

```python
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestClassifier

rfe = RFE(estimator=RandomForestClassifier(), n_features_to_select=10)
X_rfe = rfe.fit_transform(X, y)
```

### 嵌入式 (Embedded)

模型训练过程选特征：

- L1 正则 (Lasso)
- 树模型的 feature_importances_

```python
from sklearn.linear_model import LogisticRegression
from sklearn.feature_selection import SelectFromModel

model = LogisticRegression(penalty='l1', C=1.0, solver='liblinear')
selector = SelectFromModel(model)
X_sel = selector.fit_transform(X, y)
```

## 9.13 选型速查

| 场景 | 方法 |
|------|------|
| 通用线性 | PCA |
| 非线性流形 | Kernel PCA / UMAP |
| 可视化 (默认) | UMAP / t-SNE |

| 有监督降维 | LDA |
| 信号分离 | ICA |

## 9.14 代码示例

### 完整可视化流程

```python
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import umap

# 数据
X, y = load_digits(return_X_y=True)
X_scaled = StandardScaler().fit_transform(X)

# PCA 预处理 (加速 + 去噪)
pca = PCA(n_components=50)
X_pca = pca.fit_transform(X_scaled)

# UMAP 2D
reducer = umap.UMAP(random_state=42)
X_umap = reducer.fit_transform(X_pca)

# 画图
plt.scatter(X_umap[:, 0], X_umap[:, 1], c=y, cmap='tab10', s=5)
plt.colorbar()
plt.title("UMAP of Digits")
plt.show()
```

### 选择保留维度

```python
import numpy as np

pca = PCA().fit(X_scaled)
cumsum = np.cumsum(pca.explained_variance_ratio_)
n_components = np.argmax(cumsum >= 0.95) + 1
print(f"保留 95% 方差需要 {n_components} 维")
```
