# 16. 特征工程 (Feature Engineering)

特征工程是从原始数据构造机器学习可用特征的艺术与科学。被誉为"ML 的核心"，比算法选择影响更大。

## 16.1 为什么特征工程重要

> "Better features beat better algorithms."
> — Pedro Domingos

数据质量直接决定模型上限：

- **Garbage in, garbage out**
- 优秀特征 + 普通算法 > 普通特征 + 优秀算法
- 减少数据量需求
- 提升泛化

## 16.2 特征类型

| 类型 | 例子 | 常用处理 |
|------|------|----------|
| 数值 | 年龄、收入、温度 | 缩放、变换、离散化 |
| 类别 | 城市、品类 | 编码 |
| 序数 | 评级 (低/中/高) | 整数编码 |
| 时间 | 日期、时间戳 | 拆解、差分 |
| 文本 | 评论、文章 | TF-IDF、Embedding |
| 布尔 | 性别、是否会员 | 0/1 |
| 缺失 | 任意类型 | 填充 |

## 16.3 数值特征处理

### 缩放 (Scaling)

不同量纲会让某些算法失效（KNN, SVM, NN）。

**StandardScaler (z-score)**：

$$
x' = \frac{x - \mu}{\sigma}
$$

输出均值为 0，方差为 1。假设近似正态。

**MinMaxScaler**：

$$
x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
$$

输出 ∈ [0, 1]。对异常值敏感。

**RobustScaler**：

$$
x' = \frac{x - \text{median}}{IQR}
$$

用中位数和 IQR，对异常值鲁棒。

**MaxAbsScaler**：

$$
x' = \frac{x}{\max(|x|)}
$$

输出 ∈ [-1, 1]，稀疏友好。

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```

### 何时用哪个

| 算法 | 推荐 |
|------|------|
| LR / SVM / NN / KNN | Standard / MinMax |
| Tree (DT/RF/XGB) | 不要缩放 |
| 异常值多 | Robust |

### 对数变换

对长尾分布 (收入、人数)：

$$
x' = \log(x + 1)
$$

```python
import numpy as np
X_log = np.log1p(X)
```

### Box-Cox / Yeo-Johnson

自动找最优变换：

$$
y = \begin{cases}
\frac{x^\lambda - 1}{\lambda} & \text{if } \lambda \neq 0, x > 0 \\
\log x & \text{if } \lambda = 0, x > 0
\end{cases}
$$

```python
from sklearn.preprocessing import PowerTransformer

pt = PowerTransformer(method='yeo-johnson')  # 支持 x=0
X_trans = pt.fit_transform(X)
```

### 离散化 (Binning)

把连续值变离散：

- **等宽**：每个 bin 同样宽
- **等频**：每个 bin 同样多样本
- **决策树分箱**：用决策树学最优分裂

```python
from sklearn.preprocessing import KBinsDiscretizer

kbins = KBinsDiscretizer(n_bins=10, encode='ordinal', strategy='quantile')
X_binned = kbins.fit_transform(X)
```

### 异常值处理

**封顶 (clip / cap)**：

```python
upper, lower = np.percentile(X, [99, 1])
X_clipped = np.clip(X, lower, upper)
```

**Winsorize**：

```python
from scipy.stats.mstats import winsorize
X_wins = winsorize(X, limits=[0.05, 0.05])  # 上下 5% 封顶
```

**对数变换**也能"压扁"长尾。

## 16.4 类别特征处理

### Label Encoding

每个值映射到整数：

```python
from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()
X_enc = le.fit_transform(X['category'])
```

**仅适合序数特征**（小/中/大）。对无序特征会让算法误认为有顺序。

### One-Hot Encoding

每个值变一列 0/1：

```python
from sklearn.preprocessing import OneHotEncoder

ohe = OneHotEncoder(sparse_output=False, handle_unknown='ignore')
X_enc = ohe.fit_transform(X[['category']])

# pandas
pd.get_dummies(df['category'], drop_first=True)
```

- 维度爆炸：高基数（城市 ID）不适用
- 解决：用平均编码 / 哈希

### Ordinal Encoding (有序类别)

```python
from sklearn.preprocessing import OrdinalEncoder

oe = OrdinalEncoder(categories=[['low', 'med', 'high']])
X_enc = oe.fit_transform(X[['rating']])
```

### Target Encoding (均值编码)

用目标均值替换类别值：

$$
\text{enc}(c) = \mathbb{E}[y | \text{category} = c]
$$

```python
def target_encode(df, col, target):
    means = df.groupby(col)[target].mean()
    return df[col].map(means)

X['cat_enc'] = target_encode(df, 'category', 'y')
```

**注意泄露**：用交叉验证或 smoothing：

$$
\text{enc}(c) = \frac{n_c \cdot \bar{y}_c + m \cdot \bar{y}_{\text{global}}}{n_c + m}
$$

$m$ 是平滑系数。

### Frequency Encoding

用类别出现频率：

```python
freq = df['category'].value_counts()
df['cat_freq'] = df['category'].map(freq)
```

### Hash Encoding

把类别哈希到固定 $k$ 维：

```python
from sklearn.feature_extraction import FeatureHasher

hasher = FeatureHasher(n_features=8, input_type='dict')
X_hash = hasher.transform(df[['category']].to_dict('records'))
```

适合超高基数（id 类）。

### Binary Encoding

类别 → 二进制 → 每位一列。比 OneHot 维度低（$\lceil\log_2 n\rceil$ 列）。

```python
import category_encoders as ce

encoder = ce.BinaryEncoder(cols=['category'])
X_enc = encoder.fit_transform(df[['category']])
```

## 16.5 时间特征

### 拆解

```python
df['hour'] = df['time'].dt.hour
df['day'] = df['time'].dt.day
df['dayofweek'] = df['time'].dt.dayofweek
df['month'] = df['time'].dt.month
df['quarter'] = df['time'].dt.quarter
df['year'] = df['time'].dt.year
df['dayofyear'] = df['time'].dt.dayofyear
df['weekofyear'] = df['time'].dt.isocalendar().week
df['is_weekend'] = df['dayofweek'].isin([5, 6]).astype(int)
```

### 周期性编码

小时 / 月份是周期变量，直接数值会丢失周期性。用 sin/cos：

```python
df['hour_sin'] = np.sin(2 * np.pi * df['hour'] / 24)
df['hour_cos'] = np.cos(2 * np.pi * df['hour'] / 24)
```

### 差分

$$
\Delta y_t = y_t - y_{t-1}
$$

### 滑动窗口

```python
df['rolling_mean_7'] = df['y'].rolling(7).mean().shift(1)
df['rolling_std_7'] = df['y'].rolling(7).std().shift(1)
df['diff_1'] = df['y'].diff(1)
```

### 时间间隔

距某个特定时刻的差：

```python
df['days_since_event'] = (df['time'] - df['event_date']).dt.days
```

## 16.7 缺失值处理

### 类型

- **MCAR** (Missing Completely At Random)：完全随机
- **MAR** (Missing At Random)：依赖其他观测变量
- **MNAR** (Missing Not At Random)：依赖缺失值本身

### 检测

```python
import missingno as msno
msno.matrix(df)
msno.bar(df)
msno.heatmap(df)  # 相关性
```

### 删除

- 列缺失 > 50% → 删列
- 行缺失少量 → 删行

```python
df.dropna(subset=['col1'])
df.drop(columns=['mostly_missing'])
```

### 填充

**数值**：

- 均值 / 中位数 / 众数
- 前向 / 后向填充 (ffill, bfill)
- 插值
- 模型预测

```python
df['age'].fillna(df['age'].median())
df['price'].fillna(method='ffill')
df['temp'].interpolate()
```

**类别**：

- 众数
- 'Missing' / 'Unknown'
- 预测

```python
df['category'].fillna('Unknown')
```

### 缺失指示器

加一列"是否缺失"：

```python
df['age_missing'] = df['age'].isna().astype(int)
```

### 高级填充

```python
from sklearn.experimental import enable_iterative_imputer
from sklearn.impute import IterativeImputer

# 用其他列预测缺失
imputer = IterativeImputer(estimator=RandomForestRegressor())
X_imputed = imputer.fit_transform(X)
```

KNN Imputer：

```python
from sklearn.impute import KNNImputer

imputer = KNNImputer(n_neighbors=5)
X_imputed = imputer.fit_transform(X)
```

## 16.11 特征验证

### PSI (Population Stability Index)

衡量 train/test 分布差异：

$$
\text{PSI} = \sum (p_{\text{train}, i} - p_{\text{test}, i}) \log \frac{p_{\text{train}, i}}{p_{\text{test}, i}}
$$

- PSI < 0.1：稳定
- 0.1 ~ 0.25：略漂移
- > 0.25：漂移严重

### 重要性

训练时关注：

- 树模型 `feature_importances_`
- L1 系数
- Permutation importance
- SHAP

### 监控

- 特征分布随时间变化
- 重要性变化
- 异常值增加

## 16.13 实战建议

### 优先级

1. **理解业务**：专家知识构造最强特征
2. **缺失值**：先处理
3. **类别编码**：高基数用 target encoding
4. **时间拆解**：业务时间模式
5. **交叉特征**：领域知识
6. **特征选择**：剔除无用

### 陷阱

- ❌ 用 test 数据做编码 / 缩放 (泄露)
- ❌ 在全集上 fit 编码器
- ❌ 高基数类别直接 OneHot
- ❌ 时间序列随机化
- ❌ 训练时 fit，部署忘了 transform

### 部署一致性

```python
from sklearn.pipeline import Pipeline

# 训练时
pipe = Pipeline([
    ('preprocess', ColumnTransformer([...])),
    ('clf', RandomForestClassifier()),
])
pipe.fit(X_train, y_train)

# 部署
import joblib
joblib.dump(pipe, 'model.pkl')

# 推理
loaded = joblib.load('model.pkl')
y_pred = loaded.predict(X_new)
```

## 16.14 Pipeline 示例

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression

# 数值处理
numeric_features = ['age', 'income', 'tenure']
numeric_transformer = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler()),
])

# 类别处理
categorical_features = ['city', 'gender']
categorical_transformer = Pipeline([
    ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
    ('onehot', OneHotEncoder(handle_unknown='ignore')),
])

# 合并
preprocessor = ColumnTransformer([
    ('num', numeric_transformer, numeric_features),
    ('cat', categorical_transformer, categorical_features),
])

# 完整 Pipeline
full_pipe = Pipeline([
    ('prep', preprocessor),
    ('clf', LogisticRegression(max_iter=1000)),
])

full_pipe.fit(X_train, y_train)
```
