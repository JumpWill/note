# 03. 决策树

决策树 (Decision Tree) 是模仿人类决策过程的模型。从根节点开始，对每个特征做一次判断，沿对应分支向下，直到叶节点得到预测。

## 3.1 基本思想

### 决策过程

```
       天气？
      /  |  \
    晴   阴   雨
    /      \
 湿度?     风?
  /  \     /  \
是  否   是  否
 ↓   ↓   ↓   ↓
去 不去 去 不去
```

### 树结构

- **根节点**：第一个分裂特征
- **内部节点**：中间判断
- **叶节点**：最终预测
- **路径**：从根到叶的一条规则

### 算法 (递归分裂)

```
function build_tree(X, y):
    if 满足停止条件:
        return LeafNode(prediction=y.mean())

    (feature, threshold) = find_best_split(X, y)
    left = build_tree(X[feature < threshold], y[...])
    right = build_tree(X[feature >= threshold], y[...])
    return InternalNode(feature, threshold, left, right)
```

## 3.2 不纯度 (Impurity)

衡量节点中样本的"不纯"程度。

### Gini 不纯度 (CART)

$$
Gini(D) = 1 - \sum_{c=1}^{C} p_c^2
$$

其中 $p_c$ 是类 $c$ 的比例。

- 节点完全纯（一类）：Gini = 0
- 节点均匀分布（每类 $\frac{1}{C}$）：Gini = $1 - \frac{1}{C}$

### 信息熵 (Entropy, ID3/C4.5)

$$
H(D) = -\sum_{c=1}^{C} p_c \log_2 p_c
$$

- 单位：bit
- 完全纯：H = 0
- 二分类均匀：H = 1

### 回归：MSE Reduction

$$
\text{MSE}(D) = \frac{1}{|D|}\sum_{i \in D} (y_i - \bar{y})^2
$$

分裂后两个子集的加权 MSE 减少量作为分裂增益。

### 对比

| 不纯度 | 计算 | 速度 | 偏好 |
|--------|------|------|------|
| Gini | 简单 | 快 | 多数类 |
| Entropy | log | 慢 | 多样性 |
| MSE | 平方 | 中 | 误差平方 |

实际差异不大，Gini 是默认。

## 3.3 分裂准则

### 分类增益

$$
\Delta = \text{Impurity}(D) - \frac{|D_L|}{|D|}\text{Impurity}(D_L) - \frac{|D_R|}{|D|}\text{Impurity}(D_R)
$$

选 $\Delta$ 最大的 (feature, threshold)。

### 多分类分裂 (CART)

每个候选分裂：试每个特征的每个候选阈值。

- 数值特征：按特征值排序，找最优切点 $\mathcal{O}(d N \log N)$
- 类别特征：所有可能的子集（指数级）或贪心 (CART 用二分化)

### C4.5 vs CART

| 算法 | 分裂数 | 任务 | 输出 |
|------|--------|------|------|
| ID3 | 多叉 | 分类 | 类标签 |
| C4.5 | 多叉 | 分类 | 类概率 |
| CART | 二叉 | 分类 + 回归 | 类别 / 均值 |

## 3.4 关键超参

### 控制生长

| 超参 | 作用 | 默认 |
|------|------|------|
| `max_depth` | 树最大深度 | None (无限) |
| `min_samples_split` | 节点最少样本数才分裂 | 2 |
| `min_samples_leaf` | 叶节点最少样本数 | 1 |
| `max_leaf_nodes` | 最大叶节点数 | None |
| `max_features` | 每次分裂考虑的特征数 | None (全部) |

### 控制剪枝

| 超参 | 作用 |
|------|------|
| `ccp_alpha` | Cost-Complexity Pruning 强度 (越大越剪) |
| `min_impurity_decrease` | 分裂最小增益 |

### 调参建议

```python
from sklearn.tree import DecisionTreeClassifier

# 防过拟合典型值
model = DecisionTreeClassifier(
    max_depth=8,           # 限制深度
    min_samples_leaf=20,   # 叶节点最少样本
    min_samples_split=50,  # 分裂最少样本
    max_features='sqrt',   # 每节点只看 sqrt(d) 个特征
    random_state=42,
)
```

## 3.5 剪枝

### 预剪枝 (Pre-pruning)

分裂前判断是否值得：

- max_depth / min_samples_leaf 达到
- 增益 < 阈值 (min_impurity_decrease)

优点：快、提前停止。

### 后剪枝 (Post-pruning, CCP)

先生长完整树，再剪掉不必要的子树：

$$
\text{Cost} = \text{Impurity}(T) + \alpha \cdot |\text{leaves}(T)|
$$

$\alpha$ 控制剪枝强度。

```python
model = DecisionTreeClassifier(random_state=42)
path = model.cost_complexity_pruning_path(X_train, y_train)
alphas = path.ccp_alphas

# 选最佳 alpha
for alpha in alphas:
    model = DecisionTreeClassifier(ccp_alpha=alpha, random_state=42)
    model.fit(X_train, y_train)
    print(f"alpha={alpha:.4f}: train_acc={...}, val_acc={...}")
```

## 3.6 决策树的数学视角

### 假设空间

把所有可能的 (feature, threshold) 分裂组合抽象为：

$$
f(x) = \sum_{m=1}^{M} c_m \mathbb{1}[x \in R_m]
$$

其中 $R_m$ 是 $m$ 叶节点对应的矩形区域（特征轴平行）。

### 训练目标

$$
\min_{R_m, c_m} \sum_{m=1}^{M} \sum_{i \in R_m} L(y_i, c_m)
$$

理论上这是 NP-hard，实际用贪心（次优但高效）。

### 损失-复杂度权衡

$$
\text{Total Cost} = \text{Empirical Loss} + \alpha \cdot |\text{Tree}|
$$

$\alpha$ 大 → 简单树；小 → 复杂树。

## 3.7 特征重要性

每个特征对不纯度减少的累计贡献：

$$
\text{Importance}(j) = \frac{\sum_{t \in \text{splits on } j} \Delta_t}{\sum_{\text{all splits}} \Delta}
$$

```python
model.fit(X_train, y_train)

# 重要性
importance = model.feature_importances_

# 排序
idx = np.argsort(importance)[::-1]
for i in idx:
    print(f"{feature_names[i]}: {importance[i]:.4f}")

# 可视化
import matplotlib.pyplot as plt
plt.barh([feature_names[i] for i in idx], importance[idx])
```

注意：

- 高基数特征（id 类）重要性虚高
- 相关特征会互相"抢"重要性
- 决策树重要性不稳定（特征稍变，树大变）

## 3.9 优缺点

### 优点

- 可解释性强（可视化、规则提取）
- 不需要特征缩放
- 天然处理非线性关系
- 能处理数值 + 类别混合特征
- 推理快 ($\mathcal{O}(\text{depth})$)

### 缺点

- **单棵树**：方差大、不稳定（训练数据稍变树大变）
- 容易过拟合
- 难学**对角**决策边界（特征轴平行）
- 偏向多值特征

### 改进方向

→ 集成 (Random Forest, GBDT) 解决方差大问题

## 3.11 决策边界可视化

```python
import numpy as np
import matplotlib.pyplot as plt

def plot_decision_boundary(model, X, y):
    h = 0.02
    x_min, x_max = X[:, 0].min()-1, X[:, 0].max()+1
    y_min, y_max = X[:, 1].min()-1, X[:, 1].max()+1
    xx, yy = np.meshgrid(
        np.arange(x_min, x_max, h),
        np.arange(y_min, y_max, h)
    )
    Z = model.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
    plt.contourf(xx, yy, Z, alpha=0.4)
    plt.scatter(X[:, 0], X[:, 1], c=y, edgecolor='k')
    plt.show()

plot_decision_boundary(model, X[:, :2], y)
```

决策边界是**特征轴平行**的矩形 → 单棵树无法学对角线。
