# 02. 线性模型

线性模型是最简单却极为有用的模型族。形式：

$$
f(x) = W^T x + b = \sum_{j=1}^{d} w_j x_j + b
$$

虽然形式简单，但配上正则化、特征工程后，在工业中仍是强 baseline。

## 2.1 线性回归 (Linear Regression)

### 模型

$$
\hat{y} = W^T x + b
$$

### 损失函数 (MSE)

$$
L(W, b) = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2 = \frac{1}{N}\|X W - y\|_2^2
$$

### 闭式解 (Normal Equation)

$$
\theta^* = (X^T X)^{-1} X^T y
$$

推导：对 $L$ 求导，令 $\nabla_W L = 0$：

$$
\frac{\partial L}{\partial W} = \frac{2}{N} X^T (X W - y) = 0
$$

解得 $W^* = (X^T X)^{-1} X^T y$。

### 性质

- 时间复杂度：$\mathcal{O}(d^3)$ 求逆
- 当 $X^T X$ 不可逆 (共线性) 时需用伪逆
- 工程上不用求逆，用 `np.linalg.lstsq` 或梯度下降

### 概率视角

假设 $y = W^T x + \epsilon$，$\epsilon \sim \mathcal{N}(0, \sigma^2)$，则最小化 MSE 等价于**最大似然估计**。

### 代码

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print(f"W = {model.coef_}")
print(f"B = {model.intercept_}")
print(f"MSE = {mean_squared_error(y_test, y_pred):.3f}")
print(f"R²  = {r2_score(y_test, y_pred):.3f}")
```

```python
# 梯度下降实现
import numpy as np

def linear_regression_gd(X, y, lr=0.01, epochs=1000):
    N, d = X.shape
    W = np.zeros(d)
    b = 0.0
    for epoch in range(epochs):
        y_pred = X @ W + b
        grad_W = (2/N) * X.T @ (y_pred - y)
        grad_b = (2/N) * (y_pred - y).sum()
        W -= lr * grad_W
        b -= lr * grad_b
    return W, b
```

## 2.2 正则化基础

### 为什么需要正则化

当特征数 $d$ 接近样本数 $N$ 时：

- $X^T X$ 接近奇异
- 系数 $W$ 变得极大
- 模型过拟合
- 测试集表现差

正则化通过约束 $W$ 的复杂度来缓解。

### 几何直觉

```
原始解:        w*     w 受约束 (L2 ball)
   ·              ·───────·  (新解, 在约束边界)
   │            ╱
   │          ╱
   │        ╱
   └──────┴──────→ w1
```

带正则化后的解在约束边界附近，参数被压缩。

### 三种正则化对比

| 正则 | 公式 | 性质 | 用途 |
|------|------|------|------|
| L2 (Ridge) | $\lambda \\|W\\|_2^2$ | 压缩但保留所有特征 | 防多重共线、防过拟合 |
| L1 (Lasso) | $\lambda \\|W\\|_1$ | 诱导稀疏 (特征选择) | 高维、特征选择 |
| ElasticNet | $\alpha \\|W\\|_1 + \beta \\|W\\|_2^2$ | L1+L2 折中 | 多个相关特征 |

## 2.3 岭回归 (Ridge, L2)

### 损失

$$
L = \frac{1}{N}\sum (y - \hat{y})^2 + \lambda \|W\|_2^2
$$

### 闭式解

$$
W^* = (X^T X + \lambda I)^{-1} X^T y
$$

$\lambda I$ 保证矩阵可逆，即使 $X^T X$ 奇异。

### 性质

- 把 $W$ 系数均匀缩小（不稀疏）
- $\lambda$ 越大 → 系数越小 → 模型越简单
- 对**多重共线性**友好
- 等价于参数 $W$ 的高斯先验 (Bayesian 视角)

### 代码

```python
from sklearn.linear_model import Ridge

# 不同 alpha 对比
for alpha in [0.01, 0.1, 1.0, 10.0, 100.0]:
    model = Ridge(alpha=alpha)
    model.fit(X_train, y_train)
    print(f"alpha={alpha}: R² = {model.score(X_test, y_test):.3f}")

# 自动选 alpha (留一法)
from sklearn.linear_model import RidgeCV
model = RidgeCV(alphas=[0.01, 0.1, 1.0, 10.0], cv=5)
model.fit(X_train, y_train)
print(f"Best alpha = {model.alpha_}")
```

## 2.4 Lasso (L1)

### 损失

$$
L = \frac{1}{N}\sum (y - \hat{y})^2 + \lambda \|W\|_1
$$

### 性质

- $\lambda$ 足够大 → 部分 $W_j = 0$ → 自动**特征选择**
- 适合高维稀疏数据 (基因组、文本)
- 无闭式解，用坐标下降

### 代码

```python
from sklearn.linear_model import Lasso, LassoCV

model = Lasso(alpha=0.1)
model.fit(X_train, y_train)
print(f"非零系数个数 = {(model.coef_ != 0).sum()}")
print(f"被选特征 = {np.array(feature_names)[model.coef_ != 0]}")

# 自动选 alpha
model = LassoCV(alphas=np.logspace(-3, 1, 20), cv=5)
model.fit(X_train, y_train)
print(f"最佳 alpha = {model.alpha_}")
```

## 2.5 ElasticNet

### 损失

$$
L = \frac{1}{N}\sum (y - \hat{y})^2 + \alpha \rho \|W\|_1 + \alpha (1-\rho)/2 \|W\|_2^2
$$

其中 $\rho = l1\_ratio$ 控制 L1/L2 比例。

- $\rho = 1$：纯 Lasso
- $\rho = 0$：纯 Ridge
- $0 < \rho < 1$：两者折中

### 优势

- L1 自动选特征
- L2 解决 Lasso 在相关特征间随机选的问题

### 代码

```python
from sklearn.linear_model import ElasticNet, ElasticNetCV

model = ElasticNet(alpha=0.1, l1_ratio=0.5)
model.fit(X_train, y_train)

# 自动选两个超参
model = ElasticNetCV(
    l1_ratio=[0.1, 0.5, 0.7, 0.9, 1.0],
    alphas=np.logspace(-3, 1, 20),
    cv=5,
)
model.fit(X_train, y_train)
```

## 2.6 多项式回归

线性模型 + 多项式特征 = 多项式回归：

```python
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import Pipeline

poly = Pipeline([
    ('poly', PolynomialFeatures(degree=2, interaction_only=False)),
    ('scaler', StandardScaler()),
    ('lin', Ridge(alpha=1.0)),
])

poly.fit(X_train, y_train)
```

- degree=2：包含 $x_i^2$ 和 $x_i x_j$
- degree=3：包含 $x_i^3$、$x_i^2 x_j$ 等
- degree 越大 → 特征数指数增长 → 容易过拟合

## 2.7 Logistic 回归

### 模型 (二分类)

$$
P(y=1|x) = \sigma(W^T x + b) = \frac{1}{1 + e^{-(W^T x + b)}}
$$

$\sigma$ 是 sigmoid 函数，输出 ∈ (0,1)，可解释为概率。

### 决策边界

$P(y=1|x) > 0.5$ ⇔ $W^T x + b > 0$

→ **线性**决策边界。

### 损失 (Cross Entropy / Log Loss)

$$
L = -\frac{1}{N}\sum_{i=1}^{N}[y_i \log p_i + (1-y_i)\log(1-p_i)]
$$

推导：假设 $y \in \{0, 1\}$，似然函数：

$$
P(y|x) = p^y (1-p)^{1-y}
$$

取对数似然并取负，即得交叉熵。

### 多分类 (Softmax Regression)

模型：

$$
P(y=c|x) = \frac{e^{W_c^T x + b_c}}{\sum_{c'=1}^{C} e^{W_{c'}^T x + b_{c'}}}
$$

损失：多类交叉熵

$$
L = -\frac{1}{N}\sum_i \sum_{c=1}^{C} y_{ic} \log p_{ic}
$$

### 正则化

- `penalty='l1'`：L1
- `penalty='l2'`：L2（默认）
- `penalty='elasticnet'`：ElasticNet
- `C` 是正则强度的倒数（`C` 越小正则越强）

### 代码

```python
from sklearn.linear_model import LogisticRegression

# 二分类
model = LogisticRegression(penalty='l2', C=1.0, max_iter=1000)
model.fit(X_train, y_train)

# 多分类
model = LogisticRegression(
    multi_class='multinomial',  # softmax
    solver='lbfgs',
    C=1.0,
    max_iter=1000,
)
model.fit(X_train, y_train)  # y_train 是 {0, 1, 2, ...}

# 预测
y_pred = model.predict(X_test)
y_proba = model.predict_proba(X_test)[:, 1]  # 正例概率

# 评估
from sklearn.metrics import classification_report, roc_auc_score
print(classification_report(y_test, y_pred))
print(f"AUC = {roc_auc_score(y_test, y_proba):.3f}")

# 系数解释
print(f"特征重要性: {dict(zip(feature_names, model.coef_[0]))}")
```

## 2.8 多标签分类 (Multi-label)

每个样本可同时属于多个类别。

```python
from sklearn.linear_model import LogisticRegression
from sklearn.multiclass import OneVsRestClassifier

# 策略 1: 一对多
model = OneVsRestClassifier(LogisticRegression(max_iter=1000))
model.fit(X_train, y_train)  # y_train 形状 (N, C), 二值

# 预测
y_pred = model.predict(X_test)
```

注意：多标签不能用 softmax（互斥），用 sigmoid + 独立二分类。

## 2.9 广义线性模型 (GLM)

把线性模型推广到指数族分布：

$$
\mathbb{E}[y] = g^{-1}(W^T x + b)
$$

- $g$ 是链接函数 (link function)
- 正态 + 恒等链接 → 线性回归
- Bernoulli + Logit 链接 → Logistic 回归
- Poisson + Log 链接 → Poisson 回归
- Gamma + Inverse 链接 → Gamma 回归

```python
from sklearn.linear_model import PoissonRegressor, TweedieRegressor

# Poisson 回归：计数数据
model = PoissonRegressor(alpha=1.0, max_iter=1000)
model.fit(X_train, y_train)
```

## 2.10 线性模型优缺点

### 优点

- 简单、可解释
- 训练快、推理快
- 适合高维稀疏 (文本、基因组)
- 给出概率输出
- 配合正则化，鲁棒

### 缺点

- 只能学线性关系
- 特征工程是关键（需手动构造非线性）
- 不擅长复杂模式（图像、语音）

### 适用场景

- 表格数据 baseline
- 高维稀疏（文本 TF-IDF）
- 需要解释性 (LR 系数 → 风险因子)
- 概率输出场景

## 2.11 完整 Pipeline 示例

```python
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score

# 数据划分
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)

# 数值 + 类别列分别处理
num_cols = ['age', 'income']
cat_cols = ['gender', 'city']

preprocessor = ColumnTransformer([
    ('num', StandardScaler(), num_cols),
    ('cat', OneHotEncoder(handle_unknown='ignore'), cat_cols),
])

# 完整 Pipeline
pipeline = Pipeline([
    ('prep', preprocessor),
    ('clf', LogisticRegression(C=1.0, max_iter=1000)),
])

# 交叉验证
scores = cross_val_score(pipeline, X_train, y_train, cv=5, scoring='roc_auc')
print(f"CV AUC: {scores.mean():.3f} ± {scores.std():.3f}")

# 训练 + 评估
pipeline.fit(X_train, y_train)
y_proba = pipeline.predict_proba(X_test)[:, 1]
print(f"Test AUC: {roc_auc_score(y_test, y_proba):.3f}")
```

## 2.12 何时不用线性模型

- 图像 / 语音 / 视频 → 用 CNN
- 长序列 / 文本生成 → 用 Transformer
- 强非线性关系 → 用核方法、树模型、神经网络
