# 15. 模型选择与调参

模型选择决定**用什么模型**，调参决定**超参数**。两者结合决定最终性能。

## 15.1 偏差-方差在模型选择中的作用

详见 [01-基本概念](01-基本概念.md) §1.5。

### 关键平衡

| 倾向 | 现象 | 解决 |
|------|------|------|
| Bias 高 (欠拟合) | 训练集差 | 加特征、加深度、减正则 |
| Variance 高 (过拟合) | 训练好测试差 | 加数据、加正则、降复杂度 |

### 模型复杂度图

```
性能
 │      ─────────────────
 │    ╱╲
 │   ╱  ╲     ← 最佳点
 │  ╱    ╲
 │ ╱      ╲
 │╱        ╲
 └───────────── 模型复杂度
   欠拟合   合适   过拟合
```

## 15.2 交叉验证 (Cross-Validation)

### K-Fold

把数据均分 K 份，轮流留一份作验证：

```
Fold: 1 2 3 4 5
iter1: T V F F F
iter2: F T V F F
...
iter5: F F F T V
```

```python
from sklearn.model_selection import KFold, cross_val_score

kfold = KFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(model, X, y, cv=kfold, scoring='accuracy')
print(f"CV Mean: {scores.mean():.3f}, Std: {scores.std():.3f}")
```

### 分层 K-Fold (Stratified)

分类任务保持各类比例：

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(model, X, y, cv=skf, scoring='roc_auc')
```

### Leave-One-Out (LOO)

K = N（每个样本单独验证）：

- 几乎无偏
- **计算昂贵**
- 适合小数据集

```python
from sklearn.model_selection import LeaveOneOut

loo = LeaveOneOut()
scores = cross_val_score(model, X, y, cv=loo)
```

### 时间序列分割 (Time Series Split)

不随机，按时间顺序：

```python
from sklearn.model_selection import TimeSeriesSplit

tscv = TimeSeriesSplit(n_splits=5)
for train_idx, test_idx in tscv.split(X):
    ...
```

### Group K-Fold

按组划分（避免同组数据泄露）：

```python
from sklearn.model_selection import GroupKFold

gkf = GroupKFold(n_splits=5)
for train_idx, test_idx in gkf.split(X, y, groups=groups):
    ...
```

### 重复 K-Fold

跑多次取平均，减小随机性：

```python
from sklearn.model_selection import RepeatedKFold

rkf = RepeatedKFold(n_splits=5, n_repeats=3, random_state=42)
```

## 15.3 网格搜索 (Grid Search)

枚举所有超参组合：

```python
from sklearn.model_selection import GridSearchCV

params = {
    'C': [0.1, 1.0, 10.0],
    'gamma': [0.001, 0.01, 0.1, 1.0],
    'kernel': ['rbf', 'linear'],
}

grid = GridSearchCV(
    SVC(),
    params,
    cv=5,
    scoring='accuracy',
    n_jobs=-1,
    return_train_score=True,
)
grid.fit(X_train, y_train)

print(f"Best params = {grid.best_params_}")
print(f"Best CV = {grid.best_score_:.3f}")
print(f"Test score = {grid.score(X_test, y_test):.3f}")
```

### 优点

- 简单
- 找最优组合

### 缺点

- **维度灾难**：K 个超参 × V 个值 → K^V 组合
- 不连续的超参（学习率）浪费
- 慢

## 15.4 随机搜索 (Random Search)

随机采样超参组合 (Bergstra & Bengio 2012)：

```python
from sklearn.model_selection import RandomizedSearchCV
from scipy.stats import loguniform, uniform

params = {
    'C': loguniform(1e-3, 1e3),       # log 分布
    'gamma': loguniform(1e-4, 1e1),
    'kernel': ['rbf', 'linear'],
}

random_search = RandomizedSearchCV(
    SVC(),
    params,
    n_iter=50,        # 50 个组合
    cv=5,
    scoring='roc_auc',
    n_jobs=-1,
    random_state=42,
)
random_search.fit(X_train, y_train)
```

### 优势

- 比网格搜索**快得多**
- 覆盖更广
- 很多超参**不重要**，没必要细枚举

### 关键洞察

> 当超参对结果的影响不均匀时（少数超参重要），随机搜索通常 60 次就能找到和网格搜索 60^K 次相当的结果。

## 15.5 贝叶斯优化 (Bayesian Optimization)

把超参搜索建模为**函数优化问题**：

$$
f: \mathcal{H} \to \mathbb{R} \text{ (CV score)}
$$

学 $f$ 的代理函数（高斯过程），用**EI**（Expected Improvement）选下一个采样点。

### Optuna / Hyperopt

```python
import optuna

def objective(trial):
    params = {
        'C': trial.suggest_loguniform('C', 1e-3, 1e3),
        'gamma': trial.suggest_loguniform('gamma', 1e-4, 1e1),
        'max_depth': trial.suggest_int('max_depth', 3, 10),
    }
    model = SVC(**params)
    scores = cross_val_score(model, X, y, cv=5)
    return scores.mean()

study = optuna.create_study(direction='maximize')
study.optimize(objective, n_trials=100)

print(f"Best params = {study.best_params}")
print(f"Best CV = {study.best_value:.3f}")

# 可视化
optuna.visualization.plot_optimization_history(study)
optuna.visualization.plot_param_importances(study)
```

### 优势

- 用历史信息智能选点
- 样本效率高
- 适合昂贵模型

### 缺点

- 难并行
- 实现复杂

### Population Based Bandits (PB2)

PBT + 贝叶斯优化。

## 15.8 嵌套交叉验证

**外层**：评估泛化性能
**内层**：调超参

```python
from sklearn.model_selection import cross_val_score

# 外层 KFold（评估）
outer_cv = KFold(n_splits=5, shuffle=True, random_state=42)

# 内层 GridSearchCV（调超参）
inner_cv = KFold(n_splits=3, shuffle=True, random_state=42)

scores = []
for train_idx, test_idx in outer_cv.split(X):
    X_train, X_test = X[train_idx], X[test_idx]
    y_train, y_test = y[train_idx], y[test_idx]

    grid = GridSearchCV(model, params, cv=inner_cv, scoring='accuracy')
    grid.fit(X_train, y_train)

    score = grid.score(X_test, y_test)
    scores.append(score)

print(f"Nested CV: {np.mean(scores):.3f} ± {np.std(scores):.3f}")
```

## 15.9 学习曲线与验证曲线

### 学习曲线

训练集大小 vs 训练/验证分：

```python
from sklearn.model_selection import learning_curve

train_sizes, train_scores, val_scores = learning_curve(
    model, X, y, cv=5,
    train_sizes=np.linspace(0.1, 1.0, 10),
    scoring='accuracy',
)

plt.plot(train_sizes, train_scores.mean(1), label='train')
plt.plot(train_sizes, val_scores.mean(1), label='val')
```

诊断：

- Train 高 Val 低 → 过拟合
- Train 低 Val 低 → 欠拟合
- Train Val 接近 → 理想

### 验证曲线

超参值 vs 训练/验证分：

```python
from sklearn.model_selection import validation_curve

param_range = np.logspace(-3, 3, 7)
train_scores, val_scores = validation_curve(
    SVC(), X, y, param_name='C',
    param_range=param_range, cv=5,
)
```

## 15.10 嵌套 vs 非嵌套

```
Non-nested CV (简单):
直接 GridSearchCV → 在 test 上报告
问题：超参用 test 调过 → 偏高估计

Nested CV (严格):
外层: 评估
内层: 调超参
结果: 无偏估计 (但代价高)
```

## 15.12 实用流程

```
1. 简单 baseline (LR, RF) → 评估指标
2. 数据分析：
   - 类别分布
   - 特征相关性
   - 缺失值
3. 特征工程
4. 多个模型粗略比较 (CV)
5. 选最佳 2-3 模型做超参搜索
6. 嵌套 CV 评估泛化
7. 集成最好模型
8. 最终 test set 评估
```

## 15.13 实践建议

1. **先 baseline 后调参**：用默认 LR/RF 跑，看是否够用
2. **CV 与指标对**：分类 AUC+Stratified；回归 MSE+KFold
3. **不要调 test**：超参调 test 等于数据泄露
4. **嵌套 CV**：要报告泛化误差时必须用
5. **并行**：Grid Search 用 `n_jobs=-1`
6. **时间预算**：贝叶斯优化好但要设上限
7. **分布而非枚举**：学习率等用 loguniform
8. **提前停**：Hyperband / Pruner 节省时间

## 15.14 代码模板

### 完整 Pipeline + Optuna

```python
import optuna
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold, cross_val_score

# Pipeline
def create_model(trial):
    C = trial.suggest_loguniform('C', 1e-3, 1e3)
    penalty = trial.suggest_categorical('penalty', ['l1', 'l2'])
    solver = 'liblinear' if penalty == 'l1' else 'lbfgs'

    return Pipeline([
        ('scaler', StandardScaler()),
        ('clf', LogisticRegression(C=C, penalty=penalty, solver=solver, max_iter=1000)),
    ])

# 目标函数
def objective(trial):
    model = create_model(trial)
    cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
    return cross_val_score(model, X_train, y_train, cv=cv, scoring='roc_auc').mean()

# 优化
study = optuna.create_study(direction='maximize')
study.optimize(objective, n_trials=100, show_progress_bar=True)

# 最佳模型
best_model = create_model(study.best_trial)
best_model.fit(X_train, y_train)
y_pred = best_model.predict_proba(X_test)[:, 1]
print(f"Test AUC = {roc_auc_score(y_test, y_pred):.3f}")
```
