# 11. 时序预测 (Time Series Forecasting)

时序预测基于历史观察预测未来值。广泛应用于销量预测、流量预测、股价、天气、能源负载等。

## 11.1 时序数据特点

- **时间依赖性**：相邻点相关
- **趋势 (Trend)**：长期方向
- **季节性 (Seasonality)**：周期性模式
- **噪声 (Noise)**：随机波动

时序分解：$y_t = T_t + S_t + R_t$

### 特殊性

- 顺序重要 → 不能随机划分
- 未来数据不能用于过去（look-ahead bias）
- 自相关结构

## 11.2 时序模式

### 自相关 (Autocorrelation)

$$
\text{ACF}(k) = \frac{\sum_{t=k+1}^{T}(y_t - \bar{y})(y_{t-k} - \bar{y})}{\sum_{t=1}^{T}(y_t - \bar{y})^2}
$$

### 偏自相关 (PACF)

排除了中间变量影响的 $y_t$ 与 $y_{t-k}$ 的相关性。

```python
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

plot_acf(y, lags=40)
plot_pacf(y, lags=40)
```

### 平稳性 (Stationarity)

**弱平稳**：均值、方差、自协方差与时间无关。

检验：

- ADF 检验 (Augmented Dickey-Fuller)
- KPSS 检验

```python
from statsmodels.tsa.stattools import adfuller

result = adfuller(y)
print(f"ADF Stat = {result[0]:.3f}, p-value = {result[1]:.3f}")
# p < 0.05: 平稳
```

非平稳 → 差分 (differencing)：

$$
y'_t = y_t - y_{t-1}
```

## 11.3 经典方法

### 朴素法 (Naive)

$$
\hat{y}_{t+1} = y_t
$$

最简单 baseline。

### 季节朴素

$$
\hat{y}_{t+1} = y_{t+1-s}
$$

$s$ 为季节周期。

### 移动平均 (MA)

$$
\hat{y}_{t+1} = \frac{1}{k}\sum_{i=0}^{k-1}y_{t-i}
$$

### 指数平滑 (ETS)

$$
\hat{y}_{t+1} = \alpha y_t + (1-\alpha)\hat{y}_t
$$

$\alpha \in [0, 1]$ 控制新观测的权重。

三组件：

- **水平** (Level): $l_t = \alpha y_t + (1-\alpha)(l_{t-1} + b_{t-1})$
- **趋势** (Trend): $b_t = \beta(l_t - l_{t-1}) + (1-\beta)b_{t-1}$
- **季节** (Seasonal): $s_t = \gamma(y_t - l_t) + (1-\gamma)s_{t-s}$

```python
from statsmodels.tsa.holtwinters import ExponentialSmoothing

model = ExponentialSmoothing(
    y, seasonal='add',  # 'mul'
    seasonal_periods=12,
    trend='add',
).fit()
yhat = model.forecast(12)
```

### Holt-Winters

包含趋势 + 季节的指数平滑。

## 11.4 ARIMA

**AutoRegressive Integrated Moving Average**，核心时序模型。

### 模型结构

$$
y'_t = c + \phi_1 y'_{t-1} + \cdots + \phi_p y'_{t-p} + \theta_1 \epsilon_{t-1} + \cdots + \theta_q \epsilon_{t-q} + \epsilon_t
$$

- AR(p)：自回归项
- I(d)：差分次数 (Integrated)
- MA(q)：移动平均项

### 记号 ARIMA(p, d, q)

- p：AR 阶
- d：差分次数
- q：MA 阶

### SARIMA

季节版本：SARIMA(p, d, q)(P, D, Q, s)

- (p, d, q)：非季节
- (P, D, Q)：季节
- s：季节周期

### 参数选择

```python
from statsmodels.tsa.statespace.sarimax import SARIMAX

model = SARIMAX(
    y,
    order=(1, 1, 1),         # p, d, q
    seasonal_order=(1, 1, 1, 12),  # P, D, Q, s
)
results = model.fit()
yhat = results.forecast(steps=12)
```

### 选择超参

| p / q | 看 ACF / PACF 截尾或拖尾 |
|------|------|
| p | PACF 截尾 |
| q | ACF 截尾 |

或用 AIC / BIC：

```python
import itertools
best_aic = float('inf')
best_order = None
for p, d, q in itertools.product(range(3), range(2), range(3)):
    try:
        model = SARIMAX(y, order=(p, d, q)).fit()
        if model.aic < best_aic:
            best_aic = model.aic
            best_order = (p, d, q)
    except:
        continue
print(f"Best order = {best_order}, AIC = {best_aic:.0f}")
```

### auto_arima

```python
from pmdarima import auto_arima

    stepwise=True, suppress_warnings=True,

## 11.5 Prophet

Facebook 2017，专为有强季节性的业务数据设计。

### 模型

$$
y(t) = g(t) + s(t) + h(t) + \epsilon_t
$$

- $g(t)$：趋势 (分段线性 / 逻辑回归)
- $s(t)$：傅里叶级数季节项
- $h(t)$：节假日影响

```python
from prophet import Prophet

df = pd.DataFrame({'ds': dates, 'y': values})
model = Prophet(
    yearly_seasonality=True,
    weekly_seasonality=True,
    daily_seasonality=False,
    changepoint_prior_scale=0.05,
)
model.fit(df)

future = model.make_future_dataframe(periods=30)
forecast = model.predict(future)

model.plot(forecast)
model.plot_components(forecast)
```

### 优势

- 自动检测变化点
- 处理缺失值 / 异常
- 解释性好
- 加节假日、特殊事件

### 局限

- 对高频金融数据弱
- 模型固定（贝叶斯拟合）

## 11.7 机器学习方法

### 特征工程

把时序转为监督学习：

```python
def create_features(df, target_col, lags=[1, 2, 3, 7, 14, 30],
                    windows=[7, 14, 30]):
    df = df.copy()

    # 滞后特征
    for lag in lags:
        df[f'lag_{lag}'] = df[target_col].shift(lag)

    # 滚动统计
    for window in windows:
        df[f'rolling_mean_{window}'] = df[target_col].rolling(window).mean().shift(1)
        df[f'rolling_std_{window}'] = df[target_col].rolling(window).std().shift(1)

    # 时间特征
    df['hour'] = df.index.hour
    df['dayofweek'] = df.index.dayofweek
    df['month'] = df.index.month
    df['quarter'] = df.index.quarter
    df['year'] = df.index.year
    df['dayofyear'] = df.index.dayofyear

    return df.dropna()
```

## 11.9 多步预测策略

| 策略 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| **Recursive** | 单步预测循环 | 模型简单 | 误差累积 |
| **Direct** | 每步独立模型 | 误差不累积 | 训练慢 |
| **Multi-Output** | 一次出多步 | 平衡 | 输出维度 |
| **Seq2Seq** | Encoder-Decoder | 灵活 | 训练复杂 |

## 11.10 评估指标

### 回归指标

- **MAE**：$\frac{1}{T}\sum|y_t - \hat{y}_t|$
- **RMSE**：$\sqrt{\frac{1}{T}\sum(y_t - \hat{y}_t)^2}$
- **MAPE**：$\frac{100\%}{T}\sum\left|\frac{y_t - \hat{y}_t}{y_t}\right|$
- **sMAPE**：对称 MAPE
- **MASE**：与 naive 平均比较

```python
from sklearn.metrics import mean_absolute_error, mean_squared_error
```

### 时间序列特定

- **MASE (Mean Absolute Scaled Error)**: 与 naive 相比
- **Theil's U**: U = 1 比 naive 差；U < 1 比 naive 好
- **Diebold-Mariano 检验**: 两个模型预测性能比较

```python
from sktime.performance_metrics.forecasting import MeanAbsolutePercentageError
```

## 11.14 选型速查

| 场景 | 推荐 |
|------|------|

| 中等复杂 | ARIMA / SARIMA |

## 11.15 常见误区

- ❌ 随机划分数据 → 用 TimeSeriesSplit
- ❌ 忽略外生变量（促销、天气）
- ❌ 看 RMSE 但忽略业务（峰值错失可能更糟）
- ❌ 用未来信息做 lag (look-ahead bias)
- ❌ 训练集不同分布（train 是旧数据，test 是新数据）
- ❌ 不处理概念漂移（节假日变化、消费习惯变化）

## 11.16 完整流程

```python
import pandas as pd
import numpy as np
from prophet import Prophet

# 数据
df = pd.read_csv('sales.csv', parse_dates=['date'])
df.columns = ['ds', 'y']  # Prophet 格式

# 划分
train = df[:-30]
test = df[-30:]

# 训练
model = Prophet(yearly_seasonality=True, weekly_seasonality=True)
model.fit(train)

# 预测
future = pd.concat([train, test])  # 或 model.make_future_dataframe
forecast = model.predict(future)

# 评估
from sklearn.metrics import mean_absolute_error
yhat = forecast.iloc[-30:]['yhat'].values
y_true = test['y'].values
print(f"MAE = {mean_absolute_error(y_true, yhat):.2f}")

# 可视化
model.plot(forecast)
model.plot_components(forecast)
```
