# 04. 集成学习 (Ensemble)

集成学习通过组合多个基学习器（base learner）来获得比单个更好的预测。

核心思想："三个臭皮匠，顶个诸葛亮"。

## 4.1 为什么集成有效

### 偏差-方差分解

- **Bagging**：减小方差（基学习器独立，方差下降 √K 倍）
- **Boosting**：减小偏差（基学习器串行纠错）
- **Stacking**：组合不同模型的优势

### 集成有效的条件

基学习器应该：

1. **准确性 (Accuracy)**：每个都比随机猜好
2. **多样性 (Diversity)**：彼此错误不重叠

如果基学习器完全一致 → 集成无收益
如果基学习器完全随机 → 集成 = 随机猜

## 4.2 Voting (投票)

### 硬投票 (Hard Voting)

每个模型投一票，多数票为最终预测。

```python
from sklearn.ensemble import VotingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.svm import SVC

model = VotingClassifier(
    estimators=[
        ('lr', LogisticRegression(max_iter=1000)),
        ('dt', DecisionTreeClassifier(max_depth=5)),
        ('svc', SVC(probability=True)),
    ],
    voting='hard',  # 'soft' 用概率平均
)
model.fit(X_train, y_train)
```

### 软投票 (Soft Voting)

每个模型的概率加权平均：

$$
P(y=c|x) = \frac{1}{K}\sum_{k=1}^{K} w_k \cdot P_k(y=c|x)
$$

通常比硬投票好。

## 4.3 Bagging (Bootstrap AGGregatING)

### 思想

- 从训练集有放回抽样 $K$ 次，每次得到一个 bootstrap 样本
- 每个 bootstrap 样本训练一个基学习器
- 推理时：分类投票，回归平均

### 算法

```
function bagging(X, y, K, base_model):
    models = []
    for k in 1..K:
        idx = bootstrap_sample(N)        # 有放回抽样
        X_k, y_k = X[idx], y[idx]
        model_k = train(base_model, X_k, y_k)
        models.append(model_k)
    return models
```

### 为什么有效

- 每个 bootstrap 样本只用了 63.2% 的样本（其余 OOB）
- 基学习器看到**不同**的数据 → 多样性高
- 方差被平均 → 集成方差 ≈ 单模型方差 / K

### 数学

假设基学习器独立，单个方差 $\sigma^2$：

$$
\text{Var}(\text{average}) = \frac{\sigma^2}{K}
$$

实际不完全独立（用了部分相同数据），但仍有 $\sqrt{K}$ 量级下降。

### 优缺点

**优点**：

- 简单、并行（基学习器可独立训练）
- 显著降方差
- 不易过拟合

**缺点**：

- 偏差不变（基学习器的偏差被保留）
- 对稳定基学习器（如 LR）收益小
- 训练成本 × K

## 4.4 Random Forest

Bagging + **随机特征子集** = Random Forest (Breiman 2001)。

### 关键改进

每次分裂时：

1. 从 $d$ 个特征中**随机**抽 $m$ 个候选
2. 在这 $m$ 个里找最优分裂

$m$ 的选择：

- 分类：`m = √d` 或 `log₂d`
- 回归：`m = d/3`

### 双重随机化

| 维度 | Bagging | Random Forest |
|------|---------|---------------|
| 样本 | ✅ bootstrap | ✅ bootstrap |
| 特征 | ❌ 全部 | ✅ 随机子集 |

→ 多样性更高 → 集成更强

### OOB (Out-of-Bag) 评估

每个样本有 ~37% 概率不在某棵树的 bootstrap 中 → 这些树对该样本的预测可作为"免费验证集"：

```python
model = RandomForestClassifier(oob_score=True, n_estimators=100)
model.fit(X, y)
print(f"OOB Score = {model.oob_score_:.3f}")
```

无需划分 val set 就能评估。

### 特征重要性

- **Gini 重要性**：每个特征对不纯度减少的累计贡献
- **Permutation 重要性**：打乱某特征后看精度下降（更稳健）

```python
from sklearn.inspection import permutation_importance

# Gini
gini_imp = model.feature_importances_

# Permutation
perm_imp = permutation_importance(model, X_test, y_test, n_repeats=10)
```

### 代码

```python
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(
    n_estimators=300,
    max_depth=15,
    min_samples_leaf=5,
    max_features='sqrt',
    oob_score=True,
    n_jobs=-1,  # 并行
    random_state=42,
)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
y_proba = model.predict_proba(X_test)
```

### 调参要点

| 超参 | 影响 | 推荐值 |
|------|------|--------|
| `n_estimators` | 树越多越稳 | 100~1000 |
| `max_depth` | 防过拟合 | 10~30 |
| `min_samples_leaf` | 防过拟合 | 1~10 |
| `max_features` | 多样性 | 'sqrt' / 0.3~0.8 |
| `class_weight` | 不均衡 | 'balanced' |

## 4.5 Extra Trees

随机森林的"极化版"：

- 分裂点也随机（不在每个特征内找最优阈值）
- 偏差略高、方差更低
- 训练快很多

```python
from sklearn.ensemble import ExtraTreesClassifier

model = ExtraTreesClassifier(n_estimators=300, max_features='sqrt')
```

## 4.6 Boosting

### 思想

串行训练基学习器，每个修正前一个的错误。

```
基学习器 1：拟合数据 → 误差 1
基学习器 2：拟合残差 1 → 误差 2
基学习器 3：拟合残差 2 → 误差 3
...
最终预测 = 所有基学习器加权和
```

### AdaBoost (Adaptive Boosting)

**算法**：

1. 初始化样本权重 $w_i^{(1)} = 1/N$
2. 对 $m = 1, \ldots, M$：
   - 用当前权重训练基学习器 $h_m$
   - 计算加权误差 $\epsilon_m = \frac{\sum w_i \mathbb{1}[h_m(x_i) \neq y_i]}{\sum w_i}$
   - 计算基学习器权重 $\alpha_m = \frac{1}{2}\ln\frac{1-\epsilon_m}{\epsilon_m}$
   - 更新样本权重 $w_i^{(m+1)} = w_i^{(m)} \exp(-\alpha_m y_i h_m(x_i))$
3. 最终 = $\sum \alpha_m h_m(x)$

```python
from sklearn.ensemble import AdaBoostClassifier

model = AdaBoostClassifier(
    n_estimators=100,
    learning_rate=1.0,
    base_estimator=DecisionTreeClassifier(max_depth=1),  # 决策树桩
    random_state=42,
)
```

特点：

- 对噪声敏感（异常点权重指数增长）
- 现代场景多被 GBDT 替代

## 4.7 Gradient Boosting (GBDT)

### 核心思想

把 boosting 重新解释为**函数空间的梯度下降**。

每一步拟合当前模型的**负梯度**：

$$
F_{m+1}(x) = F_m(x) + \gamma_m h_m(x)
$$

其中 $h_m(x)$ 拟合 $-g_m(x) = -\left[\frac{\partial L}{\partial F}\right]_{F=F_m}$。

### 损失函数视角

| 任务 | 损失 | 负梯度 |
|------|------|--------|
| 回归 (MSE) | $\frac{1}{2}(y-F)^2$ | $y - F$ (残差) |
| 回归 (MAE) | $\|y-F\|$ | $\text{sign}(y-F)$ |
| 二分类 (LogLoss) | $\log(1+e^{-yF})$ | $y \cdot \sigma(yF)$ |

### 算法

```
1. 初始化 F_0(x) = constant (如 log odds)
2. for m = 1..M:
   a. 计算负梯度 r_i = -∂L/∂F (即残差)
   b. 用基学习器 h_m 拟合 r
   c. 找最优步长 γ_m (line search)
   d. 更新 F_{m+1} = F_m + ν γ_m h_m
3. 返回 F_M
```

$\nu$ 是 shrinkage / learning rate (0 < $\nu$ < 1)，越小越保守。

### 代码

```python
from sklearn.ensemble import GradientBoostingClassifier

model = GradientBoostingClassifier(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=3,
    subsample=1.0,    # 不采样
    random_state=42,
)
```

## 4.8 XGBoost (eXtreme Gradient Boosting)

GBDT 的工业级实现，陈天奇 2014。

### 改进

- **二阶泰勒展开**：用 Hessian 信息加速收敛
- **正则化**：$\Omega(h) = \gamma T + \frac{1}{2}\lambda \|w\|^2$
- **特征子采样**：列采样 (colsample_bytree)
- **缺失值自动学习分裂方向**
- **近似分裂**：用分位数找候选分裂点
- **并行化**：特征并行 + 树并行

### 目标函数

$$
\text{Obj}^{(m)} = \sum_{i=1}^{N} L(y_i, F_m(x_i)) + \Omega(h_m)
$$

展开到二阶：

$$
\text{Obj}^{(m)} \approx \sum_i \left[L_i + g_i F_m(x_i) + \frac{1}{2}h_i F_m^2(x_i)\right] + \Omega(h_m)
$$

$g_i, h_i$ 是一阶、二阶梯度。

### 代码

```python
import xgboost as xgb

model = xgb.XGBClassifier(
    n_estimators=1000,
    learning_rate=0.05,
    max_depth=6,
    min_child_weight=1,         # 叶节点最小 hessian 和
    subsample=0.8,             # 行采样
    colsample_bytree=0.8,      # 列采样
    gamma=0,                   # 分裂最小增益
    reg_alpha=0,                # L1
    reg_lambda=1,              # L2
    tree_method='hist',        # 直方图算法
    device='cuda',             # GPU 加速
    early_stopping_rounds=50,
    random_state=42,
)

model.fit(
    X_train, y_train,
    eval_set=[(X_val, y_val)],
    verbose=False,
)

print(f"Best iteration = {model.best_iteration}")
print(f"Best score = {model.best_score}")
```

### 调参经验

```python
params = {
    'learning_rate': [0.01, 0.05, 0.1],
    'max_depth': [3, 5, 7, 10],
    'min_child_weight': [1, 3, 5],
    'subsample': [0.6, 0.8, 1.0],
    'colsample_bytree': [0.6, 0.8, 1.0],
    'gamma': [0, 0.1, 0.2],
    'reg_alpha': [0, 0.1, 1.0],
    'reg_lambda': [0.1, 1.0, 5.0],
}
```

## 4.9 LightGBM

微软 2017，GBDT 的另一种实现。

### 改进

- **Histogram 算法**：把连续值离散化为 bin，加速
- **Leaf-wise 生长**：每次分裂增益最大的叶子（vs level-wise）
- **GOSS (Gradient-based One-Side Sampling)**：保留梯度大的样本
- **EFB (Exclusive Feature Bundling)**：互斥特征合并
- **类别特征原生支持**：`categorical_feature` 参数

### Leaf-wise vs Level-wise

```
Level-wise:                   Leaf-wise:
     O                         O
    / \                       / \
   O   O                     O   O
  / \ / \                   / \
 O O O O                  O   O
                          / \
全层长                    O   O
                          可能深但收益高
```

### 代码

```python
import lightgbm as lgb

model = lgb.LGBMClassifier(
    n_estimators=1000,
    learning_rate=0.05,
    num_leaves=31,             # 每棵树最大叶节点数
    max_depth=-1,
    min_child_samples=20,      # 叶节点最小样本数
    subsample=0.8,             # 行采样 (bagging_fraction)
    subsample_freq=5,          # 每 5 轮 bagging 一次
    colsample_bytree=0.8,      # 列采样 (feature_fraction)
    reg_alpha=0,
    reg_lambda=0,
    random_state=42,
)

model.fit(
    X_train, y_train,
    eval_set=[(X_val, y_val)],
    callbacks=[lgb.early_stopping(50), lgb.log_evaluation(100)],
)

# 类别特征
model = lgb.LGBMClassifier(categorical_feature=[0, 3, 7])
```

## 4.10 CatBoost

Yandex 2017，专为类别特征设计。

### 改进

- **目标编码 (Target Encoding)** 自动处理类别
- **对称树 (Oblivious Trees)**：每层用同一特征分裂（更快、避免过拟合）
- **Ordered Boosting**：避免预测偏移
- **缺失值自动处理**

### 代码

```python
from catboost import CatBoostClassifier

model = CatBoostClassifier(
    iterations=1000,
    learning_rate=0.05,
    depth=6,
    cat_features=[0, 3, 7],  # 类别特征列索引
    early_stopping_rounds=50,
    verbose=False,
)
model.fit(X_train, y_train)
```

## 4.11 三大 GBDT 对比

| 维度 | XGBoost | LightGBM | CatBoost |
|------|---------|----------|----------|
| 速度 | 中 | **快** | 慢 |
| 精度 | 高 | 高 | **最高** |
| 内存 | 中 | **低** | 高 |
| 类别特征 | 需编码 | 支持 | **原生** |
| 缺失值 | 自动 | 自动 | 自动 |
| 大数据集 | 强 | **更强** | 强 |

## 4.12 Stacking

### 思想

用基学习器的输出作为**元学习器**的输入。

```
Level 0:  X → [Model_1, Model_2, ..., Model_K] → predictions
Level 1:  predictions → [Meta-Learner] → final prediction
```

### 代码

```python
from sklearn.ensemble import StackingClassifier
from sklearn.linear_model import LogisticRegression

base_learners = [
    ('lr', LogisticRegression(max_iter=1000)),
    ('dt', DecisionTreeClassifier(max_depth=5)),
    ('rf', RandomForestClassifier(n_estimators=100)),
]

meta_learner = LogisticRegression(max_iter=1000)

model = StackingClassifier(
    estimators=base_learners,
    final_estimator=meta_learner,
    cv=5,  # 防止过拟合 (用 CV 预测训练 meta)
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

### 注意

- 元学习器要简单 (如 LR) → 防止过拟合
- 用交叉验证生成元特征 → 防止泄露
- 不一定总比单个最强模型好

## 4.13 集成学习选型速查

| 场景 | 推荐 |
|------|------|
| 表格数据（默认） | XGBoost / LightGBM |
| 类别特征多 | CatBoost |
| 大数据集 (>100K) | LightGBM |
| 解释性要求 | Random Forest + SHAP |
| 精度优先 | 多模型 Stacking |
| 实时推理 | Random Forest / 浅层 GBDT |
