# 17. 不平衡数据 (Imbalanced Data)

不平衡数据指类别比例严重失衡的数据（如欺诈只占 0.1%）。直接训练会偏向多数类，需特殊处理。

## 17.1 什么是类别不平衡

### 严重程度

| 比例 | 程度 |
|------|------|
| 50:50 | 均衡 |
| 10:1 | 轻度 |
| 100:1 | 中度 |
| 1000:1 | 严重 |
| 10000:1 | 极端 |

### 典型场景

- **欺诈检测**：99.9% 正常
- **疾病诊断**：少数阳性
- **罕见事件**：设备故障
- **流失预测**：多数留存
- **离网用户**：少数离网

## 17.2 不平衡为何难

### 指标失真

99% 负例：全预测为负 → 99% Accuracy，但完全没用。

### 模型偏向

模型见到负例多 → 学到"全预测为负"是好的 → 召回率极低。

### 损失倾斜

多数类损失累积 >> 少数类 → 梯度被多数类主导。

## 17.3 评价指标 (必须！)

### 避免使用

- ❌ **Accuracy**：完全失真

### 推荐使用

| 指标 | 适用 |
|------|------|
| **Precision** | 误报代价高 |
| **Recall** | 漏报代价高 |
| **F1 / F-beta** | 平衡 |
| **ROC-AUC** | 整体排序能力 |
| **PR-AUC** | 严重不平衡 |
| **Balanced Accuracy** | 等权重各类 |
| **MCC** | 极端不均衡 |

```python
from sklearn.metrics import (
    precision_score, recall_score, f1_score,
    roc_auc_score, average_precision_score,
    balanced_accuracy_score, matthews_corrcoef,
)

roc_auc_score(y_true, y_score)         # 0.5 = 随机
average_precision_score(y_true, y_score)  # PR-AUC
matthews_corrcoef(y_true, y_pred)       # MCC ∈ [-1, 1]
```

## 17.4 数据层面方法

### 过采样 (Oversampling)

少数类样本增加。

**随机过采样**：

```python
from imblearn.over_sampling import RandomOverSampler

ros = RandomOverSampler(random_state=42)
X_res, y_res = ros.fit_resample(X, y)
```

简单复制 → 过拟合风险。

**SMOTE (Synthetic Minority Oversampling Technique, Chawla 2002)**：

在少数类样本之间**线性插值**生成新样本：

$$
x_{\text{new}} = x_i + \lambda (x_{\text{nn}} - x_i)
$$

```python
from imblearn.over_sampling import SMOTE

smote = SMOTE(random_state=42)
X_res, y_res = smote.fit_resample(X, y)
```

**SMOTE 变体**：

| 变体 | 改进 |
|------|------|
| **Borderline-SMOTE** | 只在边界附近过采样 |
| **ADASYN** | 加权，难学区域多生成 |
| **SMOTE-ENN** | SMOTE + ENN 清洗 |
| **SMOTE-Tomek** | SMOTE + Tomek Links |
| **KMeans-SMOTE** | 先聚类再 SMOTE |

```python
from imblearn.combine import SMOTETomek
from imblearn.over_sampling import BorderlineSMOTE, ADASYN
```

### 欠采样 (Undersampling)

多数类样本减少。

**随机欠采样**：

```python
from imblearn.under_sampling import RandomUnderSampler

rus = RandomUnderSampler(random_state=42)
X_res, y_res = rus.fit_resample(X, y)
```

数据丢失风险。

**集成欠采样**（如 EasyEnsemble, BalanceCascade）：多次欠采样 + 集成。

**NearMiss**：

按距离选多数类样本：

- 版本 1：选离每个少数类最近的 K 个多数类
- 版本 2：选离每个少数类最远的 K 个多数类
- 版本 3：分两步选

```python
from imblearn.under_sampling import NearMiss
nm = NearMiss(version=1)
```

**Tomek Links**：删除边界处多数类样本。

**EditedNearestNeighbours (ENN)**：删除被邻居错分类的多数类样本。

### 过采样 vs 欠采样

| | 过采样 | 欠采样 |
|---|--------|--------|
| 数据保留 | ✅ 全部 | ❌ 删部分 |
| 引入噪声 | 可能（SMOTE） | - |
| 计算 | 略高 | 略低 |
| 大数据 | OK | 不适合（删太多） |

### 推荐

- **小数据**：SMOTE + 集成
- **大数据**：随机欠采样 + cost-sensitive
- **极端不均衡**：SMOTE + ENN 清理

## 17.5 算法层面方法

### 类权重 (Class Weight)

对少数类样本加权：

```python
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.svm import SVC

# sklearn
LogisticRegression(class_weight='balanced')
RandomForestClassifier(class_weight='balanced')
SVC(class_weight='balanced')
```

`'balanced'` 自动用 $w_c = N / (K \cdot N_c)$。

自定义权重：

```python
weights = {0: 1, 1: 100}  # 正例权重 100
LogisticRegression(class_weight=weights)
```

### 阈值调节 (Threshold Tuning)

不要默认 0.5，调到最优：

```python
from sklearn.metrics import precision_recall_curve

precision, recall, thresholds = precision_recall_curve(y_test, y_proba)

# 选最优阈值
f1 = 2 * precision * recall / (precision + recall + 1e-8)
best_threshold = thresholds[np.argmax(f1)]
```

```python
y_pred = (y_proba >= best_threshold).astype(int)
```

### Cost-Sensitive Learning

明确指定误分类代价：

- 矩阵 $C[y, \hat{y}]$ 表示把真 y 错分类为 $\hat{y}$ 的代价
- 优化时考虑代价

### Focal Loss (RetinaNet)

为易分类样本降权：

$$
L_{\text{focal}} = -\alpha (1-p)^\gamma \log p
$$

$\gamma$ 控制对易样本的下调强度。

```python
# PyTorch 实现
def focal_loss(logits, targets, alpha=0.25, gamma=2):
    ce_loss = F.cross_entropy(logits, targets, reduction='none')
    pt = torch.exp(-ce_loss)
    return (alpha * (1 - pt) ** gamma * ce_loss).mean()
```

### One-Class Learning

把异常检测转化为单类问题：

- One-Class SVM
- Isolation Forest
- AutoEncoder

适合极端不均衡（< 0.1%）。

## 17.7 集成 + SMOTE

```python
from imblearn.over_sampling import SMOTE
from imblearn.pipeline import Pipeline as ImbPipeline
from sklearn.ensemble import RandomForestClassifier

pipe = ImbPipeline([
    ('smote', SMOTE(random_state=42)),
    ('clf', RandomForestClassifier(random_state=42)),
])

pipe.fit(X_train, y_train)
```

### 关键陷阱

❌ **先 SMOTE 再 CV** → 泄露！

✅ **用 Pipeline**：SMOTE 只在每折训练集上 fit。

```python
from imblearn.pipeline import Pipeline

pipe = Pipeline([
    ('smote', SMOTE()),
    ('clf', RandomForestClassifier()),
])

# cross_val_score 会自动正确处理
scores = cross_val_score(pipe, X, y, cv=5, scoring='roc_auc')
```

## 17.10 选型速查

| 场景 | 方法 |
|------|------|
| 轻度 (10:1) | class_weight + 阈值 |
| 中度 (100:1) | SMOTE + class_weight |
| 严重 (1000:1) | SMOTE + ENN + 集成 |
| 极端 (1:10000) | Anomaly Detection (One-Class) |
| 海量数据 | 随机欠采样 + cost-sensitive |
| 误判代价高 | 优先 precision |
| 漏判代价高 | 优先 recall |

## 17.11 阈值优化细节

### 找最优阈值

```python
from sklearn.metrics import precision_recall_curve, f1_score

def find_optimal_threshold(y_true, y_proba):
    precision, recall, thresholds = precision_recall_curve(y_true, y_proba)

    # 最大化 F1
    f1 = 2 * precision * recall / (precision + recall + 1e-8)
    best_idx = np.argmax(f1[:-1])  # 最后一个是无穷大
    return thresholds[best_idx]

# 或者基于业务损失
def business_cost(y_true, y_pred, cost_fp, cost_fn):
    fp = ((y_pred == 1) & (y_true == 0)).sum()
    fn = ((y_pred == 0) & (y_true == 1)).sum()
    return cost_fp * fp + cost_fn * fn
```

### 调阈值 vs 调权重

- sklearn 的 `class_weight` 等价于改变预测概率的倾向
- 预测概率再调阈值
- 两者配合

## 17.12 实战代码

### 完整 Pipeline

```python
import numpy as np
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.metrics import roc_auc_score, average_precision_score, classification_report
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from imblearn.over_sampling import SMOTE
from imblearn.under_sampling import RandomUnderSampler
from imblearn.pipeline import Pipeline as ImbPipeline

# 数据
X, y = ...  # y 极度不均衡

# Pipeline (CV 安全)
pipe = ImbPipeline([
    ('scaler', StandardScaler()),
    ('rus', RandomUnderSampler(sampling_strategy=0.5)),  # 多数类保留 50% vs 少数
    ('smote', SMOTE(sampling_strategy=0.8)),
    ('clf', LogisticRegression(class_weight='balanced', max_iter=1000)),
])

# CV
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores_auc = cross_val_score(pipe, X, y, cv=cv, scoring='roc_auc')
scores_ap = cross_val_score(pipe, X, y, cv=cv, scoring='average_precision')

print(f"ROC-AUC: {scores_auc.mean():.3f} ± {scores_auc.std():.3f}")
print(f"PR-AUC:  {scores_ap.mean():.3f} ± {scores_ap.std():.3f}")

# 训练 + 评估
pipe.fit(X_train, y_train)
y_proba = pipe.predict_proba(X_test)[:, 1]
y_pred = (y_proba >= 0.5).astype(int)

print(classification_report(y_test, y_pred))
```

### 阈值调优

```python
from sklearn.metrics import precision_recall_curve

precision, recall, thresholds = precision_recall_curve(y_test, y_proba)
f1 = 2 * precision * recall / (precision + recall + 1e-8)
best_threshold = thresholds[np.argmax(f1[:-1])]

print(f"最优阈值: {best_threshold:.3f}, F1: {np.max(f1):.3f}")
y_pred_opt = (y_proba >= best_threshold).astype(int)
print(classification_report(y_test, y_pred_opt))
```

## 17.13 误区

- ❌ **先 SMOTE 再划分** → 严重泄露
- ❌ **用 Accuracy 评估** → 失真
- ❌ **用 ROC-AUC 不看 PR-AUC** → 极端不均衡可能骗人
- ❌ **不调阈值** → 业务损失大
- ❌ **SMOTE 在测试集上** → 部署一致性破坏
- ❌ **只靠 class_weight 不改采样** → 改善有限

## 17.14 业务对齐

### 案例：欺诈检测

假设：每查出一个欺诈奖励 $1000，误报每个损失 $50。

```python
def business_value(y_true, y_pred):
    tp = ((y_pred == 1) & (y_true == 1)).sum()
    fp = ((y_pred == 1) & (y_true == 0)).sum()
    return tp * 1000 - fp * 50

# 选使业务价值最大的阈值
best_v, best_t = -np.inf, 0
for t in np.linspace(0, 1, 100):
    y_pred = (y_proba >= t).astype(int)
    v = business_value(y_test, y_pred)
    if v > best_v:
        best_v, best_t = v, t

print(f"最优阈值 = {best_t:.2f}, 业务价值 = ${best_v}")
```

### 案例：医疗诊断

- 漏诊代价 >> 误诊代价
- 优先 Recall
- 阈值要低（宁可多查再人工复核）
