# 12. 推荐系统 (Recommender Systems)

推荐系统基于用户历史行为和偏好，预测其可能感兴趣的内容。广泛应用在电商、短视频、新闻、广告、社交等。

## 12.1 核心问题

### 显式 vs 隐式反馈

| 类型 | 来源 | 置信度 |
|------|------|--------|
| 显式 | 评分 (1-5)、点赞 / 点踩 | 高 |
| 隐式 | 点击、观看、购买、停留时长 | 低 |

### 召回 + 排序两阶段

工业推荐系统通常分两阶段：

```
   全部 Item (百万)
        ↓ 召回 (Recall): 选几千候选
   候选集 (千)
        ↓ 粗排 (Coarse Rank): 进一步筛选
   候选集 (百)
        ↓ 精排 (Fine Rank): 精确打分
   推荐列表 (十)
```

## 12.2 基于内容 (Content-Based)

利用物品的元数据（标签、文本、类别），推荐与用户过去喜欢相似的内容。

```
用户喜欢 A、B → 提取 A、B 的特征 → 推荐特征相似的 C
```

### 物品表示

$$
\text{Item Vector} = \phi(\text{title, description, tags, ...})
$$

### 用户表示

$$
\text{User Vector} = \text{agg}(\text{Item Vector of liked items})
$$

聚合方式：均值、加权平均、注意力。

### 评分

$$
\hat{r}(u, i) = \cos(\text{User}_u, \text{Item}_i)
$$

或带偏置：

$$
\hat{r}(u, i) = b_u + b_i + \cos(u, i)
$$

### 优点

- 不需要其他用户数据
- 解决冷启动物品（有内容即可）
- 可解释

### 缺点

- 特征工程依赖领域知识
- 难发现跨类别兴趣

## 12.3 协同过滤 (Collaborative Filtering, CF)

利用"用户-物品"行为矩阵，发现相似性。

### 用户 CF

$$
\hat{r}(u, i) = \bar{r}_u + \frac{\sum_{v \in \text{sim}(u)} \text{sim}(u, v)(r_{v,i} - \bar{r}_v)}{\sum_{v} |\text{sim}(u, v)|}
$$

### 物品 CF

$$
\hat{r}(u, i) = \bar{r}_i + \frac{\sum_{j \in \text{sim}(i)} \text{sim}(i, j)(r_{u,j} - \bar{r}_j)}{\sum_{j} |\text{sim}(i, j)|}
$$

### 相似度

**余弦**：

$$
\text{sim}(a, b) = \frac{a^T b}{\|a\| \|b\|}
$$

**皮尔逊**：

$$
\text{sim}(a, b) = \frac{\sum(a-\bar{a})(b-\bar{b})}{\sqrt{\sum(a-\bar{a})^2 \sum(b-\bar{b})^2}}
$$

**Jaccard**：适合隐式反馈

$$
J(A, B) = \frac{|A \cap B|}{|A \cup B|}
$$

## 12.4 矩阵分解 (Matrix Factorization, MF)

把稀疏的 User-Item 评分矩阵分解为低秩：

$$
R \approx P Q^T
$$

- $P$：用户隐向量 $(n_u \times k)$
- $Q$：物品隐向量 $(n_i \times k)$
- $k$：隐因子维度

### 预测

$$
\hat{r}_{ui} = p_u^T q_i
$$

### 训练 (ALS / SGD)

损失：

$$
L = \sum_{(u,i) \in \Omega} (r_{ui} - p_u^T q_i)^2 + \lambda(\|p_u\|^2 + \|q_i\|^2)
$$

ALS 交替固定 P 优化 Q，再固定 Q 优化 P。

```python
from surprise import SVD, Dataset, Reader

reader = Reader(rating_scale=(1, 5))
data = Dataset.load_from_df(df[['userId', 'itemId', 'rating']], reader)

algo = SVD(n_factors=50, n_epochs=20, random_state=42)
algo.fit(data.build_full_trainset())

pred = algo.predict(uid, iid)  # 预测单个评分
```

### 偏置加入

$$
\hat{r}_{ui} = \mu + b_u + b_i + p_u^T q_i
$$

- $\mu$：全局平均
- $b_u$：用户偏置（评分倾向）
- $b_i$：物品偏置（被评分倾向）

### SVD++

加入隐式反馈（即使没评分）：

$$
\hat{r}_{ui} = \mu + b_u + b_i + (p_u + |N(u)|^{-1/2}\sum_{j \in N(u)} y_j)^T q_i
$$

$N(u)$ 是用户 $u$ 有过行为的物品集合。

## 12.5 隐式反馈

很多场景只有隐式反馈（点击、观看）：

- 把隐式反馈当成 0/1 目标
- 用负采样 + 加权

### 矩阵分解 + 隐式 (ALS)

```
目标: 对于 (u, i) 有交互的 = 1，其他 = 0
置信度: c_ui = 1 + α * x_ui   (x_ui = 交互强度)
```

$$
L = \sum_{u,i} c_{ui}(r_{ui} - p_u^T q_i)^2 + \lambda(\|p_u\|^2 + \|q_i\|^2)
$$

```python
from implicit.als import AlternatingLeastSquares

model = AlternatingLeastSquares(
    factors=64,
    regularization=0.01,
    iterations=20,
)
model.fit(user_item_matrix)

# 推荐
ids, scores = model.recommend(userid, user_item_matrix[userid], N=10)
```

### BPR (Bayesian Personalized Ranking)

优化成对排序：用户喜欢的物品排名 > 不喜欢的。

$$
L = -\sum_{(u, i, j) \in D_s} \log \sigma(\hat{r}_{ui} - \hat{r}_{uj}) + \lambda \|\Theta\|^2
$$

$D_s$ 是 (user, positive, negative) 三元组。

```python
from implicit.bpr import BayesianPersonalizedRanking

model = BayesianPersonalizedRanking(factors=64, iterations=200)
```

## 12.6 双塔模型 (Two-Tower)

工业级召回的常用模型。

### 结构

```
User → Tower_U →  u_vector
                    ↓
                  dot / cosine
                    ↑
Item → Tower_I →  i_vector
```

### 训练

- 召回：用户历史正样本 + 负采样
- 损失：softmax 或 BPR

```python
import tensorflow as tf

# User tower
user_input = tf.keras.Input(shape=(...))
user_vec = tf.keras.layers.Dense(64, activation='relu')(user_input)
user_vec = tf.keras.layers.Dense(64)(user_vec)  # 归一化

# Item tower
item_input = tf.keras.Input(shape=(...))
item_vec = tf.keras.layers.Dense(64, activation='relu')(item_input)
item_vec = tf.keras.layers.Dense(64)(item_vec)

# 内积
score = tf.keras.layers.Dot(axes=1)([user_vec, item_vec])

model = tf.keras.Model([user_input, item_input], score)
```

### 优势

- 推理时物品塔预先算好 → 向量检索
- 大规模可行
- 支持冷启动（用物品/用户特征）

## 12.7 FM (Factorization Machines)

处理稀疏特征 + 自动特征交互。

### 模型

$$
\hat{y} = w_0 + \sum_i w_i x_i + \sum_{i<j} \langle v_i, v_j \rangle x_i x_j
$$

- 第一项：全局
- 第二项：一阶权重
- 第三项：所有二阶交互

### 复杂度

朴素 $\mathcal{O}(k n^2)$，化简后 $\mathcal{O}(kn)$：

$$
\sum_{i<j} \langle v_i, v_j \rangle x_i x_j = \frac{1}{2}\left(\|\sum v_i x_i\|^2 - \sum \|v_i x_i\|^2\right)
$$

```python
from xgboost import xgbmodel  # XGBoost 不直接支持
# 或 pyfm / fastFM
from fastFM import als

model = als.FMRegression(n_iter=1000, rank=8)
model.fit(X_train, y_train)
```

## 12.8 DeepFM

Wide (FM) + Deep (NN) 共享输入 → 既学低阶交互也学高阶。

```
              ┌─ FM ─┐
Input → Embedding →  Concat  → Output
              └─ DNN ─┘
```

```python

from deepctr.feature_column import SparseFeat, DenseFeat, get_feature_names
```

考虑用户行为序列（最近看了什么）。

### GRU4Rec

$$
\hat{y}_t = \text{softmax}(W_o h_t)
$$

### SASRec

自注意力序列推荐 (Self-Attentive Sequential Recommendation)：

```python
# 多层 Transformer
# Position Embedding + Item Embedding
# Masked Self-Attention
# 预测下一位置物品
```

### BERT4Rec

双向 Transformer + Masked Item Prediction：

```
[M] [item1] [item2] [M] [item4] → 预测 item3
```

## 12.10 冷启动

### 用户冷启动

- 人口统计 (年龄、性别、地域)
- 注册信息
- 引导问卷（兴趣选择）
- 跨域迁移

### 物品冷启动

- 内容特征 → 双塔
- 热度加权（冷启动用热度 + 内容）
- 多臂老虎机 (Bandit)

### 系统冷启动

- 规则 / 热门榜单
- 用户调研
- 多样化

## 12.11 多臂老虎机 (Bandit)

冷启动的另一思路：探索 vs 利用。

### Epsilon-greedy

概率 $\epsilon$ 随机探索，$1-\epsilon$ 利用最佳。

### UCB

$$
a^* = \arg\max_a \hat{Q}(a) + c \sqrt{\frac{\ln t}{N(a)}}
$$

### Thompson Sampling

从后验分布采样，利用贝叶斯不确定性。

```python
# contextualbandits 库
from contextualbandits.online import BootstrappedUCB

model = BootstrappedUCB(...)
```

## 12.12 排序学习 (Learning to Rank)

精排阶段用排序模型：

- **Pointwise**：单物品打分（回归 / 分类）
- **Pairwise**：物品对排序 (RankNet, LambdaRank)
- **Listwise**：整个列表 (ListNet, ListMLE)

### LambdaMART / LightGBM Ranker

## 12.14 工业级 Pipeline

```
1. 日志收集：用户行为日志
2. 数据清洗：去噪、归一化
3. 特征工程：
   - 用户特征：基础属性 + 历史统计 + Embedding
   - 物品特征：属性 + 统计 + Embedding
   - 上下文：时间、场景、设备
4. 召回：
   - 协同过滤 (ALS / 双塔)
   - 热门兜底
   - 多路融合
5. 粗排：轻量级模型
6. 精排：深度模型 (DeepFM, DIN, DIEN)
7. 重排：多样性、规则、新鲜度
8. 在线学习：A/B 测试 → 收集反馈 → 更新模型
```

## 12.15 经典模型对比

| 模型 | 阶段 | 优点 | 缺点 |
|------|------|------|------|
| Item CF | 召回 | 简单 | 难冷启动 |
| User CF | 召回 | 个性化 | 用户行为稀疏 |
| MF (ALS) | 召回 | 高效 | 特征少 |
| BPR | 召回 | 排序优 | 需负采样 |
| FM | 排序 | 特征交互 | 浅层 |
| DeepFM | 排序 | 深 + 浅 | 工程复杂 |
| 双塔 | 召回 | 可扩展 | 仅一阶交互 |
| DIN | 精排 | 注意力 | 慢 |
| SASRec | 召回/排序 | 序列建模 | 长序列慢 |
| LambdaMART | 排序 | 工业级 | 需特征 |

## 12.16 关键挑战

- **稀疏性**：99%+ 矩阵为空
- **冷启动**：新物品 / 用户无交互
- **分布偏移**：用户偏好变化
- **流行度偏差**：热门物品被过度推荐
- **多样性**：不能只推一种
- **可解释性**：为什么推荐这个
- **公平性**：避免歧视性
