# 19. 算法选型速查与经典数据集

## 19.1 算法选型决策树

```
问题是什么？
  │
  ├─ 有标签 → 监督学习
  │    │
  │    ├─ 输出离散 → 分类
  │    │    │
  │    │    ├─ 二分类、均衡
  │    │    │    → LR / SVM / DT / RF / XGBoost
  │    │    │
  │    │    ├─ 二分类、不均衡 → 见 [17-不平衡数据]
  │    │    │
  │    │    ├─ 多分类
  │    │    │    → Softmax / RF / XGBoost / LightGBM
  │    │    │
  │    │    ├─ 多标签
  │    │    │    → OvR + 二分类 / 多输出树
  │    │    │
  │    │    └─ 图像分类 → CNN / ViT (见 LLM 笔记)
  │    │
  │    ├─ 输出连续 → 回归
  │    │    │
  │    │    ├─ 线性关系 → Linear / Ridge / Lasso
  │    │    ├─ 通用、表格 → XGBoost / LightGBM
  │    │    ├─ 时序 → ARIMA / Prophet / Transformer (见 [11])
  │    │    └─ 图像 → CNN
  │    │
  │    └─ 排序输出
  │         → LambdaMART / LambdaRank / LTR
  │
  └─ 无标签 → 无监督学习
       │
       ├─ 找分组 → 聚类
       │    ├─ 知道 K → K-Means
       │    ├─ 不知道 K、任意形状 → DBSCAN
       │    ├─ 层次 → AHC
       │    └─ 软聚类 → GMM
       │
       ├─ 找异常 → 异常检测
       │    ├─ 通用 → Isolation Forest
       │    ├─ 高维 → AutoEncoder
       │    └─ 半监督（仅正常） → One-Class SVM
       │
       └─ 降维
            ├─ 线性 → PCA
            ├─ 可视化 → UMAP / t-SNE
            └─ 监督 → LDA
```

## 19.2 按数据规模选型

| 样本数 | 特征数 | 推荐 |
|--------|--------|------|
| < 1K | < 10 | LR / KNN / NB |
| 1K - 10K | < 100 | RF / SVM / GBDT |
| 10K - 100K | < 1K | LightGBM / XGBoost |
| 100K - 1M | < 10K | LightGBM / CatBoost / NN |
| > 1M | < 10K | LightGBM / SGD / Spark MLlib |
| 任意 | > 10K | LR + L1 / Hashing / 降维 |

## 19.3 按业务目标选型

### 预测精度优先

- 表格：XGBoost / LightGBM / CatBoost
- 图像：CNN (ResNet, EfficientNet)
- 文本：Transformer (BERT, GPT)
- 时序：N-BEATS / Transformer / Foundation Models

### 解释性优先

- LR (系数直接解释)
- 决策树 (可视化规则)
- RF + SHAP (全局 + 局部)

### 训练速度

- LR / NB / KNN（小型）
- SGD（在线学习）
- LightGBM（中等）

### 推理速度

- LR / NB / DT / RF（毫秒级）
- XGBoost / LightGBM（10ms 级）
- NN（10-100ms）
- 大模型（秒级）

### 小数据

- NB / KNN / DT
- LR + L2 / ElasticNet
- SVM (RBF)
- 集成学习（减少方差）

## 19.8 算法选择启发式

### 文本数据

- 短文本 + 二分类 → NB / LinearSVC
- 长文本 + 多分类 → FastText / BERT
- 大规模文本 → 双塔 / Faiss

### 图像数据

- 小数据 → 预训练 CNN
- 大数据 → 训练 ResNet / ViT
- 实时 → MobileNet / EfficientNet

### 时序数据

- 强季节性 → Prophet / SARIMA
- 多变量 → LSTM / Transformer
- 高频 → 在线学习

### 推荐

- 召回 → 双塔 / ALS
- 排序 → DeepFM / LambdaMART
- 序列 → SASRec / BERT4Rec

### 表格数据 (默认选择)

```
数据量 < 100K → XGBoost / LightGBM + 特征工程
数据量 > 100K → LightGBM / CatBoost + 调参
高精度优先 → 集成 (Stacking)
可解释优先 → RF + SHAP / LR + 系数
```

## 19.9 复杂度估计

### 时间复杂度

| 算法 | 训练 | 推理 |
|------|------|------|
| LR | O(Nd) | O(d) |
| DT | O(N log N · d) | O(depth) |
| RF | O(K · N log N · d) | O(K · depth) |
| XGBoost | O(K · N log N · d) | O(K · depth) |
| LightGBM | O(K · N · bins · d) | O(K · depth) |
| SVM (Linear) | O(Nd) | O(d) |
| SVM (RBF) | O(N² - N³) | O(K_sv) |
| KNN | 0 | O(Nd) |
| NB | O(N) | O(d) |
| K-Means | O(NKd · iter) | O(Kd) |
| PCA | O(d² N + d³) | O(d²) |

### 空间复杂度

| 算法 | 内存 |
|------|------|
| LR | O(d) |
| DT | O(N) (节点) |
| RF | O(K · N) |
| XGBoost | O(K · d · max_leaves) |
| LightGBM | O(K · 2^d bins) |
| KNN | **O(Nd)** |

## 19.11 何时用神经网络 vs 经典 ML

### 经典 ML 优先

- 表格数据
- 小数据 (< 10K)
- 可解释重要
- 训练 / 推理资源有限
- 部署简单

### 神经网络优先

- 图像 / 视频
- 语音 / 音频
- 文本 / NLP
- 大数据 (> 100K)
- 端到端学习
- 复杂模式

### 混合

- Wide & Deep：LR (wide) + NN (deep)
- TabNet：表格的 NN
- FT-Transformer：表格 Transformer

## 19.12 模型选型 Checklist

```
□ 数据规模
  ├─ 小 (< 10K)：NB / LR / KNN / DT
  ├─ 中 (10K-100K)：SVM / RF / GBDT
  ├─ 大 (100K-1M)：LightGBM / XGBoost / NN
  └─ 超大 (> 1M)：分布式 GBDT / NN

□ 特征类型
  ├─ 纯数值：都行
  ├─ 类别多：CatBoost / Target Encoding
  ├─ 文本：TF-IDF + LR/SVM / BERT
  ├─ 图像：CNN
  ├─ 时序：ARIMA / Prophet / Transformer
  └─ 高维稀疏：LR (L1) / NB / Hashing

□ 任务
  ├─ 分类：见上
  ├─ 回归：见上
  ├─ 聚类：K-Means / DBSCAN
  ├─ 异常：IForest / AutoEncoder
  └─ 排序：LambdaMART

□ 业务约束
  ├─ 精度优先：GBDT / NN
  ├─ 解释优先：LR / DT / SHAP
  ├─ 速度优先：LightGBM / SGD
  └─ 不均衡：SMOTE + class_weight
```
