## 12.1 Boosting 思想

### 与 Bagging 对比

- **Bagging**：独立模型，平行
- **Boosting**：序列模型，依赖

### Boosting 算法

```
初始化 F_0 = 0
for m = 1..M:
    计算残差 r_i = y_i - F_{m-1}(x_i)
    用 h_m 学残差
    F_m = F_{m-1} + ν * h_m
```

## 12.4 LightGBM

```python
import lightgbm as lgb

# 数据集
dtrain = lgb.Dataset(X_train, label=y_train)
dval = lgb.Dataset(X_val, label=y_val, reference=dtrain)

# 参数
params = {
    'objective': 'regression',
    'metric': 'rmse',
    'boosting_type': 'gbdt',
    'num_leaves': 31,
    'learning_rate': 0.05,
    'feature_fraction': 0.8,
    'bagging_fraction': 0.8,
    'bagging_freq': 5,
    'max_depth': -1,  # 不限
    'min_data_in_leaf': 20,
    'lambda_l1': 0.1,
    'lambda_l2': 0.1,
    'verbose': -1,
    'num_threads': 8,
}

# 训练
model = lgb.train(
    params, dtrain,
    num_boost_round=2000,
    valid_sets=[dtrain, dval],
    valid_names=['train', 'val'],
    callbacks=[lgb.early_stopping(50), lgb.log_evaluation(100)],
)
```

### LightGBM 特有

| 参数 | 含义 |
|------|------|
| `num_leaves` | 叶节点数（核心控制） |
| `max_depth` | 深度 |
| `min_data_in_leaf` | 叶最小样本 |
| `feature_fraction` | 列采样 |
| `bagging_fraction` | 行采样 |
| `extra_trees` | 极端随机 |
| `path_smooth` | 叶子平滑 |

### 优势

- **直方图算法**：连续特征分桶
- **leaf-wise** 生长（vs XGBoost depth-wise）
- **GOSS / EFB**：大数据优化

## 12.9 滚动训练 GBM

```python
def rolling_gbm_lgb(X, y, retrain_freq=21, lookback=252, params=None):
    predictions = []
    model = None

    for t in range(lookback, len(X)):
        if (t - lookback) % retrain_freq == 0 or model is None:
            X_train = X.iloc[t - lookback:t]
            y_train = y.iloc[t - lookback:t]

            dtrain = lgb.Dataset(X_train, label=y_train)
            model = lgb.train(
                params, dtrain,
                num_boost_round=500,
            )

        pred = model.predict(X.iloc[t:t+1])[0]
        predictions.append(pred)

    return pd.Series(predictions, index=X.index[lookback:])
```

## 12.10 实战：LightGBM 收益预测

```python
"""GBM 收益预测完整流水线"""
import yfinance as yf
import pandas as pd
import numpy as np
import lightgbm as lgb
from sklearn.model_selection import TimeSeriesSplit
from sklearn.metrics import mean_squared_error

# 1. 数据
prices = yf.download(['AAPL', 'MSFT', 'GOOGL', 'AMZN', 'META', 'NVDA'],
                     start='2015-01-01')['Close']

# 2. 特征
def build_features(close):
    features = pd.DataFrame(index=close.index)
    features['mom_5'] = close.pct_change(5)
    features['mom_20'] = close.pct_change(20)
    features['mom_60'] = close.pct_change(60)
    features['vol_20'] = close.pct_change().rolling(20).std()
    features['vol_60'] = close.pct_change().rolling(60).std()
    features['ma_5_20_ratio'] = close.rolling(5).mean() / close.rolling(20).mean()
    features['ma_20_60_ratio'] = close.rolling(20).mean() / close.rolling(60).mean()
    features['rsi_14'] = compute_rsi(close, 14)
    return features.dropna()

X = pd.concat({stock: build_features(prices[stock]) for stock in prices.columns}, axis=1)
y = prices.pct_change(5).shift(-5).stack()

X, y = X.align(y, axis=0, join='inner')
X, y = X.dropna(), y.dropna()

# 3. CV
tscv = TimeSeriesSplit(n_splits=5, test_size=63)
predictions = []

params = {
    'objective': 'regression',
    'metric': 'rmse',
    'num_leaves': 31,
    'learning_rate': 0.05,
    'feature_fraction': 0.8,
    'bagging_fraction': 0.8,
    'bagging_freq': 5,
    'verbose': -1,
}

for train_idx, test_idx in tscv.split(X):
    X_train, X_test = X.iloc[train_idx], X.iloc[test_idx]
    y_train, y_test = y.iloc[train_idx], y.iloc[test_idx]

    dtrain = lgb.Dataset(X_train, label=y_train)
    dval = lgb.Dataset(X_test, label=y_test, reference=dtrain)

    model = lgb.train(
        params, dtrain,
        num_boost_round=500,
        valid_sets=[dval],
        callbacks=[lgb.early_stopping(30), lgb.log_evaluation(0)],
    )

    pred = pd.Series(model.predict(X_test), index=y_test.index)
    predictions.append(pred)

predictions = pd.concat(predictions)

# 4. IC 评估
ic = predictions.corr(y, axis=1)
print(f"Mean IC: {ic.mean():.4f}")
print(f"ICIR: {ic.mean() / ic.std():.4f}")
```

## 12.13 与 RF 对比

| 维度 | RF | GBM |
|------|----|----|
| 训练方式 | 并行 | 序列 |
| 拟合能力 | 中 | **强** |
| 抗噪声 | 强 | 中 |
| 调参 | 少 | 多 |
| 训练速度 | 快 | 慢 |
| 推荐 | 基线 | **优化时** |
