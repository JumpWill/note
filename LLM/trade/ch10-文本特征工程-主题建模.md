## 15.1 主题建模思想

### 概念

文档集合中，每篇文档由多个主题混合，每个主题由词汇分布表示。

$$
P(w | d) = \sum_z P(w | z) P(z | d)
$$

- $z$：主题
- $w$：词
- $d$：文档

## 15.2 LDA（Latent Dirichlet Allocation）

### 原理

- 隐含主题分布的狄利克雷先验
- 变分推断或 Gibbs 采样

### Sklearn

```python
from sklearn.decomposition import LatentDirichletAllocation
from sklearn.feature_extraction.text import CountVectorizer

# 1. BoW 词袋
vectorizer = CountVectorizer(
    max_features=5000,
    stop_words='english',
    max_df=0.95,
    min_df=2,
    ngram_range=(1, 2),
)
X = vectorizer.fit_transform(documents)  # (n_docs, n_words)

# 2. LDA 模型
lda = LatentDirichletAllocation(
    n_components=10,         # 主题数
    learning_method='batch',
    random_state=42,
    max_iter=25,
    n_jobs=-1,
)
lda.fit(X)

# 3. 文档-主题分布
doc_topics = lda.transform(X)  # (n_docs, n_components)

# 4. 词-主题分布
feature_names = vectorizer.get_feature_names_out()
for topic_idx, topic in enumerate(lda.components_):
    top_words_idx = topic.argsort()[::-1][:10]
    top_words = [feature_names[i] for i in top_words_idx]
    print(f"Topic {topic_idx}: {', '.join(top_words)}")
```

### Coherence Score

```python
from gensim.corpora.dictionary import Dictionary
from gensim.models.coherencemodel import CoherenceModel

# 词袋
texts = [doc.split() for doc in documents]
dictionary = Dictionary(texts)
corpus = [dictionary.doc2bow(text) for text in texts]

# gensim LDA
from gensim.models.ldamodel import LdaModel

lda_gensim = LdaModel(
    corpus=corpus,
    id2word=dictionary,
    num_topics=10,
    random_state=42,
)

# Coherence
coherence_model = CoherenceModel(
    model=lda_gensim,
    texts=texts,
    dictionary=dictionary,
    coherence='c_v',
)
coherence = coherence_model.get_coherence()
print(f"Coherence: {coherence:.4f}")
```

## 15.4 NMF（非负矩阵分解）

### 与 LDA 对比

- NMF：非负矩阵分解
- 假设主题可加性
- 通常更快

```python
from sklearn.decomposition import NMF

# 用 TF-IDF

# NMF
nmf = NMF(n_components=10, random_state=42, max_iter=200)
```

## 15.7 实战：完整主题建模

```python
"""完整主题建模流水线"""
import pandas as pd
import numpy as np
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
from sklearn.decomposition import LatentDirichletAllocation, NMF
import yfinance as yf

# 1. 加载文档（新闻）
docs = pd.read_csv('news.csv')  # date, text

# 2. 文本预处理
import re
def preprocess(text):
    text = re.sub(r'[^a-zA-Z\s]', '', text)
    text = text.lower()
    return text

docs['clean'] = docs['text'].apply(preprocess)

# 3. LDA
vectorizer = CountVectorizer(max_features=5000, stop_words='english', max_df=0.95)
X = vectorizer.fit_transform(docs['clean'])

lda = LatentDirichletAllocation(n_components=10, random_state=42, max_iter=25)
doc_topic = lda.fit_transform(X)

# 4. 主题解读
feature_names = vectorizer.get_feature_names_out()
n_top_words = 10
for topic_idx, topic in enumerate(lda.components_):
    top_idx = topic.argsort()[::-1][:n_top_words]
    print(f"Topic {topic_idx}: {' '.join([feature_names[i] for i in top_idx])}")

# 5. 主题时间序列
docs['date'] = pd.to_datetime(docs['date'])
topic_df = pd.DataFrame(doc_topic, index=docs['date'], columns=[f'topic_{i}' for i in range(10)])

# 6. 主题平均强度
daily_topic = topic_df.groupby(topic_df.index.date).mean()

# 7. 与市场收益相关性
sp500_returns = yf.download('^GSPC', start='2018-01-01')['Close'].pct_change()
sp500_returns.index = sp500_returns.index.date

merged = daily_topic.join(sp500_returns, how='inner')
ic = merged.corr().iloc[:-1, -1]
print(ic)
```

## 15.11 LDA vs NMF

| 维度 | LDA | NMF |
|------|-----|-----|
| 输入 | BoW 计数 | TF-IDF |
| 假设 | 概率 | 线性组合 |
| 速度 | 慢 | **快** |
| 解释 | 概率 | 权重 |
| 文本 | **优** | 中 |

```python
import umap
import hdbscan

# 嵌入

# 降维
umap_model = umap.UMAP(n_components=5)
```
