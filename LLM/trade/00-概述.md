# 概述 — Stefan Jansen ML4T 项目（3rd Edition）

## 项目简介

**Stefan Jansen** 的开源项目 [machine-learning-for-trading](https://github.com/stefan-jansen/machine-learning-for-trading) 是 **"Machine Learning for Algorithmic Trading"** 一书（Packt Publishing，2026 年第三版）的配套代码仓库。

> **From data sourcing to live execution** — from end to end.

第三版包含 **27 章**，覆盖从数据采集、特征工程、机器学习建模，到策略实施、回测评估、再到实盘部署与 MLOps 治理的完整端到端流水线。

## 主要技术栈

### 数据

- **pandas / polars** 数据处理
- **yfinance / alpha_vantage / polygon** 行情
- **SEC EDGAR / XBRL** 基本面
- **Quandl / WRDS / RavenPack** 另类

### 因子 / 特征

- **TA-Lib** 技术指标
- **alphalens-reloaded** 因子评估
- **statsmodels** 时序特征
- **arch / pmdarima** 波动率

### 模型

- **scikit-learn** 基础
- **xgboost / lightgbm / catboost** 梯度提升
- **TabPFN / TabM** 现代表格
- **TensorFlow / PyTorch** 深度学习
- **transformers** (HuggingFace) NLP

### 时间序列 DL

- **PatchTST / iTransformer / TSMixer** 表格化时序
- **TCN / Conv1D** 卷积
- **Mamba / LSTM** 状态空间
- **Transformer** 自注意力

### 回测 / 评估

- **zipline-reloaded** event-driven
- **vectorbt** 矢量化
- **pyfolio-reloaded** 风险指标
- **empyrical / quantstats** 评估

### RL / Agents

- **stable-baselines3** RL
- **langchain / langgraph** LLM agents
- **llama-index** RAG
- **gym / gymnasium** 环境

### 组合 / 风险

- **riskfolio-lib** 组合优化
- **PyPortfolioOpt** 现代组合
- **conformal prediction** 仓位

### MLOps

- **MLflow / W&B** 实验管理
- **Feast** 特征存储
- **Prefect / Airflow** pipeline
- **alibi-detect / evidently** 漂移

### 因果

- **DoWhy / EconML** 因果推断
- **CausalNex / causal-learn** 因果发现
- **CausalImpact** 时序因果

### 图 / 代理

- **Neo4j / NetworkX** 图
- **PyTorch Geometric / DGL** GNN
- **LangGraph / AutoGen / CrewAI** 多代理
