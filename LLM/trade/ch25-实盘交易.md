## 25.1 实盘交易 vs 回测

### 关键差异

- **延迟**：实时性
- **滑点**：实际成交价 ≠ 期望价

- **失败**：网络、API 限流
- **心理**：不能干预

## 25.7 风控

### 关键检查

```python
def risk_check(order, portfolio):
    """风控检查。"""
    checks = []

    # 1. 单股最大持仓
    position_value = order.qty * current_price(order.symbol)
    if position_value > portfolio['equity'] * 0.2:
        checks.append('Single position > 20%')

    # 2. 现金是否足够
    if order.side == 'buy' and order.qty * current_price(order.symbol) > portfolio['cash']:
        checks.append('Insufficient cash')

    # 3. 行业集中度
    sector = get_sector(order.symbol)
    sector_total = sum_sector_exposure(portfolio, sector)
    if sector_total + position_value > portfolio['equity'] * 0.4:
        checks.append(f'Sector {sector} > 40%')

    # 4. 最大回撤
    if portfolio['current_drawdown'] < -0.15:
        checks.append('Drawdown > 15%, no new positions')

    return checks
```

## 25.12 可靠性

### 重试逻辑

```python
import time
from functools import wraps

def retry(max_attempts=3, delay=1):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt < max_attempts - 1:
                        time.sleep(delay * (2 ** attempt))
                    else:
                        raise
        return wrapper
    return decorator

@retry(max_attempts=3)
def submit_order_safe(...):
    return api.submit_order(...)
```

## 25.13 回测 → 实盘 鸿沟

### 关键差异

| 维度 | 回测 | 实盘 |
|------|------|------|
| 价格 | 收盘 | 实时 |
| 滑点 | 假设 | 实际 |
| 流动性 | 无限 | 受限 |
| 延迟 | 无 | 真实 |
| 失败 | 无 | 真实 |

### 减小鸿沟

- 用 limit 单
- 分批执行（TWAP / VWAP）
- 监控实际滑点
- 持续对比

## 25.14 实战：完整实盘系统

```python
"""完整实盘交易系统"""
import time
import logging
from datetime import datetime
from apscheduler.schedulers.blocking import BlockingScheduler
import yfinance as yf
import alpaca_trade_api as tradeapi

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# 1. 配置
api = tradeapi.REST(
    key_id='<KEY>',
    secret_key='<SECRET>',
    base_url='https://paper-api.alpaca.markets',
)

# 2. 策略
def compute_signal(ticker):
    """动量信号。"""
    prices = yf.download(ticker, period='3mo', progress=False)['Close']
    if len(prices) < 60:
        return 0
    momentum = prices.iloc[-1] / prices.iloc[-60] - 1
    return momentum

# 3. 风控
def risk_check(symbol, qty):
    """检查现金和持仓。"""
    account = api.get_account()
    price = yf.Ticker(symbol).history(period='1d')['Close'].iloc[-1]
    cost = qty * price
    return cost <= float(account.cash) * 0.95  # 留 5% 缓冲

# 4. 决策
def decide_action(symbol):
    """决定动作。"""
    signal = compute_signal(symbol)
    position = next(
        (p for p in api.list_positions() if p.symbol == symbol),
        None,
    )
    qty = 100

    if signal > 0.05 and not position:
        return 'buy', qty
    elif signal < -0.05 and position:
        return 'sell', int(position.qty)
    return None, 0

# 5. 执行
def execute():
    symbols = ['AAPL', 'MSFT', 'GOOGL']
    for symbol in symbols:
        action, qty = decide_action(symbol)
        if action and risk_check(symbol, qty if action == 'buy' else 0):
            try:
                api.submit_order(
                    symbol=symbol, qty=qty,
                    side=action, type='market', time_in_force='day',
                )
                logger.info(f"Order: {action} {qty} {symbol}")
            except Exception as e:
                logger.error(f"Order failed: {e}")

# 6. 调度
scheduler = BlockingScheduler()

@scheduler.scheduled_job('cron', day_of_week='mon-fri', hour=10, minute=0)
def daily_execute():
    execute()

@scheduler.scheduled_job('cron', day_of_week='mon-fri', hour=16, minute=0)
def daily_report():
    account = api.get_account()
    logger.info(f"Equity: ${account.equity}")

if __name__ == '__main__':
    logger.info("Starting trading system...")
    scheduler.start()
```
