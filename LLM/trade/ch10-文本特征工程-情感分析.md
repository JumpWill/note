### 字典来源

- **Loughran-McDonald** (金融专用)：pos/neg/litig/uncer
- **VADER**：社交媒体
- **Hu & Liu**：通用

### Loughran-McDonald

```python
from nltk.corpus import stopwords

# 下载 LM 字典
lm_pos = open('LoughranMcDonald_Positive.csv').read().splitlines()
lm_neg = open('LoughranMcDonald_Negative.csv').read().splitlines()

def lm_sentiment(text):
    tokens = text.lower().split()
    pos = sum(1 for t in tokens if t in lm_pos)
    neg = sum(1 for t in tokens if t in lm_neg)
    return pos - neg
```

## 14.10 实战：情感 → 收益因子

```python
"""完整文本情感 → 交易策略"""

import pandas as pd
import yfinance as yf
from transformers import pipeline

# 1. 拉取新闻（示例：Yahoo Finance）
import yfinance as yf

def get_news(ticker):
    stock = yf.Ticker(ticker)
    return stock.news  # 列表，每条含 title, summary, link

# 2. 批量情感
def daily_sentiment(ticker, date):
    news = get_news(ticker)
    if not news:
        return 0
    scores = []
    for item in news:
        # 简单情感
        result = finbert(item.get('title', ''))
        score = result['score'] if result['label'] == 'positive' else -result['score']
        scores.append(score)
    return np.mean(scores) if scores else 0

# 3. 拉价格
prices = yf.download(['AAPL', 'MSFT'], start='2020-01-01')['Close']
returns = prices.pct_change()

# 4. 计算日均情感
dates = pd.date_range('2020-01-01', '2024-01-01', freq='B')
sentiment_df = pd.DataFrame(index=dates)
for ticker in ['AAPL', 'MSFT']:
    sentiment_df[ticker] = [daily_sentiment(ticker, d) for d in dates]

# 5. 评估 IC
forward_returns = returns.shift(-1)  # 明日收益

for ticker in ['AAPL', 'MSFT']:
    s = sentiment_df[ticker].dropna()
    r = forward_returns[ticker].loc[s.index].dropna()
    ic = s.corr(r)
    print(f"{ticker}: IC = {ic:.4f}")
```

## 14.11 文本分类完整流程

```python
"""完整文本分类"""
import pandas as pd
import re
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import TimeSeriesSplit
from sklearn.metrics import accuracy_score, classification_report

# 1. 数据
df = pd.read_csv('news_with_labels.csv')

# 2. 清洗
def clean_text(text):
    text = re.sub(r'[^a-zA-Z\s]', '', text)
    text = text.lower()
    return text.strip()

df['clean'] = df['text'].apply(clean_text)

# 3. 特征
vectorizer = TfidfVectorizer(max_features=5000, stop_words='english', ngram_range=(1, 2))
X = vectorizer.fit_transform(df['clean'])
y = df['label']

# 4. 时序 CV
tscv = TimeSeriesSplit(n_splits=5)
predictions = []

for train_idx, test_idx in tscv.split(df):
    X_train = X[train_idx]
    X_test = X[test_idx]
    y_train = y.iloc[train_idx]
    y_test = y.iloc[test_idx]

    model = LogisticRegression(max_iter=1000, class_weight='balanced')
    model.fit(X_train, y_train)

    pred = model.predict(X_test)
    predictions.append((y_test.values, pred))

# 5. 评估
all_y = np.concatenate([y for y, _ in predictions])
all_pred = np.concatenate([p for _, p in predictions])
print(f"Accuracy: {accuracy_score(all_y, all_pred):.4f}")
print(classification_report(all_y, all_pred))
```

## 14.15 实战陷阱

### 漂移

- 词汇含义随时间变
- "good" 早期 vs 现在

### 讽刺

- "Great, stock down 50%"
- 词典法会误判

### 实体重要性

- 不同公司重要性不同
- 大公司新闻影响更大
