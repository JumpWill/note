## 15.3 反事实与潜在结果

### Rubin 因果模型

$$
\tau_i = Y_i(1) - Y_i(0)
$$

- $Y_i(1)$：处理后的结果
- $Y_i(0)$：未处理的结果
- $\tau_i$：个体处理效应

ATE（平均处理效应）：

$$
\text{ATE} = \mathbb{E}[\tau_i] = \mathbb{E}[Y_i(1) - Y_i(0)]
$$

## 15.13 实战：完整因果流水线

```python
"""Double ML 完整流水线"""
import pandas as pd
import numpy as np
from doubleml import DoubleMLData, DoubleMLPLR, DoubleMLIRM
from sklearn.ensemble import RandomForestRegressor, RandomForestClassifier

# 1. 数据准备
df = pd.DataFrame({
    'returns': np.random.randn(1000),
    'factor_momentum': np.random.randn(1000),
    'market_cap': np.random.randn(1000),
    'volatility': np.random.randn(1000),
})

# 2. 创建 DML 数据对象
dml_data = DoubleMLData(
    data=df,
    y_col='returns',
    d_cols='factor_momentum',
    x_cols=['market_cap', 'volatility'],
)

# 3. 部分线性回归
dml_plr = DoubleMLPLR(
    dml_data,
    ml_l=RandomForestRegressor(n_estimators=100, max_depth=5),
    ml_m=RandomForestRegressor(n_estimators=100, max_depth=5),
    n_folds=5,
    n_rep=3,
)

dml_plr.fit()

# 4. 结果
print(dml_plr.summary)
print(f"ATE: {dml_plr.coef}")
print(f"95% CI: {dml_plr.confint()}")

# 5. IRM (Interactive Regression Model)
dml_irm = DoubleMLIRM(
    dml_data,
    ml_g=RandomForestRegressor(),
    ml_m=RandomForestClassifier(),
    n_folds=5,
)

dml_irm.fit()
print(dml_irm.summary)
```

## 15.14 实战：Causal Forest 异质效应

```python
"""异质处理效应"""
import numpy as np
from econml.dml import CausalForestDML
from sklearn.ensemble import RandomForestRegressor, RandomForestClassifier

# 数据
n = 2000
X = np.random.randn(n, 5)
T = np.random.binomial(1, 0.5, n)
Y = (X[:, 0] + T * (1 + X[:, 1]) + np.random.randn(n))

# 模型
cf = CausalForestDML(
    model_y=RandomForestRegressor(n_estimators=100),
    model_t=RandomForestClassifier(n_estimators=100),
    n_estimators=500,
)

cf.fit(Y, T, X=X)

# 预测个体效应
te = cf.effect(X)

# 异质性
print(f"Mean TE: {te.mean():.4f}")
print(f"Std TE: {te.std():.4f}")

# 按某特征分组
import pandas as pd
te_df = pd.DataFrame({'te': te, 'x0': X[:, 0], 'x1': X[:, 1]})
print(te_df.groupby('x0')['te'].mean())
```

## 15.15 陷阱与限制

### 因果识别假设

- **可忽略性**：$(Y(1), Y(0)) \perp T | X$
- **正值性**：$0 < P(T=1|X) < 1$
- **SUTVA**：稳定单位处理价值

### 实际困难

- 混杂变量难全部识别
- 工具变量难找
- 时变混杂
- 反事实不可观测
