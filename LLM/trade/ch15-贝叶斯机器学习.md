## 10.1 频率 vs 贝叶斯

### 频率派

- 参数固定，未知
- 估计点（MLE）
- 置信区间（基于抽样分布）

### 贝叶斯派

- 参数有先验分布
- 更新为后验分布
- 概率即信念

$$
P(\theta | D) \propto P(D | \theta) P(\theta)
$$

- 先验 × 似然 ∝ 后验

## 10.3 动态夏普比率

### 思想

夏普比率随时间变化，用状态空间模型：

$$
\begin{aligned}
s_t &\sim \mathcal{N}(\mu_s, \sigma_s^2) \\
\sigma_s^2 &= \omega + \alpha (s_{t-1} - \mu_s)^2 \\
s_{t+1} &= \mu_s + s_t + \epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, \sigma_s^2)
\end{aligned}
$$

### 实现

```python
import pymc as pm

returns = ...

with pm.Model() as sharpe_model:
    # 先验
    mu = pm.Normal('mu', mu=0, sigma=10)
    sigma_vol = pm.Exponential('sigma_vol', lam=1.0)
    nu = pm.Exponential('nu', lam=0.1)  # 自由度

    # 状态空间
    z = pm.GaussianRandomWalk('z', sigma=sigma_vol, shape=len(returns))
    obs = pm.StudentT('obs', nu=nu, mu=z, sigma=1, observed=returns)

    trace = pm.sample(2000)

# 动态夏普 = z / sigma_vol
```

### 解读

- $z_t$ 表示某时间夏普
- 趋势 → 持续好
- 突然下跌 → 策略退化信号

## 10.9 高斯过程

```python
import pymc as pm

with pm.Model() as gp_model:
    # 协方差函数
    ell = pm.InverseGamma('ell', alpha=5, beta=1)
    eta = pm.HalfNormal('eta', sigma=1)

    cov = eta ** 2 * pm.gp.cov.Matern52(input_dim=1, ls=ell)
    gp = pm.gp.Latent(cov_func=cov)

    # GP 先验
    f = gp.prior('f', X=X.reshape(-1, 1))

    # 似然
    sigma = pm.HalfNormal('sigma', sigma=1)
    likelihood = pm.Normal('y', mu=f, sigma=sigma, observed=y)

    trace = pm.sample(1000)
```

- 贝叶斯方法适合不确定性大的场景
- 动态夏普 / 协整配对交易效果好
- PyMC3 / PyMC 友好易用

## 10.14 优势 / 劣势

| 优势 | 劣势 |
|------|------|
| 完整后验分布 | 慢 |
| 自然不确定性 | 需要先验 |
| 小数据友好 | 难调 |
| 可解释 | 工具链少 |
