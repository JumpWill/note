## 安装要点

### TA-Lib

TA-Lib 是 C 语言库，安装稍麻烦：

```bash
# Mac
brew install ta-lib
pip install TA-Lib

# Linux (conda)
conda install -c conda-forge ta-lib

# Windows
下载预编译 wheel：https://github.com/mrjbq7/ta-lib
```

### 替代品

若装不上 TA-Lib，可以：

- `pandas-ta`：纯 Python
- `finta`
- 自己实现常用指标

### GPU

- 深度学习章节（Ch.17-22）可用 GPU
- TensorFlow GPU 版本或 PyTorch
- 强化学习建议 GPU

### 内存

- ITCH 数据解压后约 100GB（如果用全量）
- 推荐 16GB+ RAM
- 数据量大时建议用 SSD

## Notebooks 设计哲学

- **可重入**：每章独立，可跳过其他章节
- **数据缓存**：用 `.h5`/`.parquet` 加速 I/O
- **可视化**：每个 notebook 都有图
- **可调参**：开头显眼标 hardcode，方便实验
