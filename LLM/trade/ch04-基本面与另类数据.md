## 3.1 另类数据定义

非传统、与市场 / 基本面无关但能预测资产价格的数据：

```
人产生
├─ 社交媒体（推特、微博、雪球）
├─ 新闻（路透、彭博、自媒体）
├─ 财报电话会议（音频 + 文本）
├─ 招聘信息（LinkedIn）
└─ 公司公告 / 法律文书

过程产生
├─ 卫星图像（停车场、农田、储油罐）
├─ 物流（航运 GPS、卡车）
├─ 物联网传感器（生产计数）
├─ 网站流量（SimilarWeb）
└─ App 下载排行

交易产生
├─ 信用卡刷卡数据
├─ 发票 / 税务
├─ 银行流水
└─ 供应链发票
```

## 3.4 数据的几个性质

### 时效性

```
实时 / 近实时：推文、订单流
日级：        网站流量、新闻
周级：        卫星图（部分）
月级：        信用卡聚合
季度：        公司财报
```

### 频率 vs 信息量

- 高频不一定多信息
- 低频但独家高信息（如关键公司财报）

### 边缘信息

- 数据越冷门，alpha 越大（没人用）
- 越流行的数据，alpha 越低

## 3.6 数据的衰减

```
Year 0: 信号显著 (IC = 0.10)
Year 1: 减弱 (IC = 0.05)     ← 别人也开始用
Year 2: 消失 (IC = 0.01)     ← 拥挤
Year 3: 反向 (IC = -0.02)    ← 被挤出
```

另类数据的"alpha 半衰期"很短。

## 3.7 处理另类数据

```python
# 通用流程
def process_alt_data(raw_data):
    # 1. 清洗
    df = clean(raw_data)

    # 2. 标准化
    df['normalized'] = (
        (df['raw'] - df['raw'].mean()) / df['raw'].std()
    )

    # 3. 对齐到交易时间
    df = df.reindex(price_index).fillna(method='ffill')

    # 4. 滞后以避免前视偏差
    df['signal'] = df['normalized'].shift(1)

    # 5. 与资产匹配
    df['stock'] = map_to_stock(df['entity_id'])

    # 6. 多股票聚合
    panel = df.pivot(index='date', columns='stock', values='signal')

    return panel
```

## 3.8 数据质量评估

### 数据质量维度

| 维度 | 含义 |
|------|------|
| **覆盖率** | 多资产、多时间覆盖 |
| **频率** | 数据采集频率 |

## 3.11 案例：卫星图算沃尔玛停车场

```python
# 简化流程
import rasterio
import numpy as np
import torch
from torchvision import models, transforms

# 1. 加载图像
def load_image(path):
    with rasterio.open(path) as src:
        return src.read([3,2,1])  # RGB

# 2. CNN 估计车辆数
class CarCounterCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.backbone = models.resnet18(weights='DEFAULT')
        self.backbone.fc = torch.nn.Linear(512, 1)

    def forward(self, x):
        return self.backbone(x)

model = CarCounterCNN()
model.eval()

# 3. 推理
img = torch.from_numpy(load_image('walmart.tif')).float().unsqueeze(0)
car_count = model(img)

# 4. 关联到 WMT 收益
wmt = yf.download('WMT', start='2015-01-01')['Close']
```

## 3.12 关键 takeaway

- 另类数据是 alpha 的"前沿"
- 但 alpha 半衰期短（一旦广泛使用，alpha 消失）
- 评估流程：清洗 → IC 检验 → 分层回测
- 法律合规是底线
