## 7.1 学习任务定义

### 核心问题

把交易问题转换为 ML 任务：

```
输入 X（特征）
↓
模型
↓
输出 ŷ（预测）
```

### 关键决策

- **预测目标**：收益、方向、波动率
- **预测期**：1 天 / 5 天 / 1 月
- **数据集**：横截面 vs 时序
- **损失函数**：MSE / 分类损失

## 7.2 监督学习设置

### 回归（回归收益）

```python
# 标签 = 未来 N 天收益
df['label'] = df['returns'].shift(-5)
```

### 分类（方向）

```python
# 标签 = 上 / 下
df['label'] = np.sign(df['returns'].shift(-5))
df['label'] = df['label'].replace(0, 0)  # 平稳
```

### 多分类

```python
# 标签 = 三档（up / flat / down）
df['label'] = pd.cut(
    df['returns'].shift(-5),
    bins=[-np.inf, -0.01, 0.01, np.inf],
    labels=[0, 1, 2],
)
```

## 7.3 标签工程

### 收益 vs 价格

```python
# 用 log 收益（更稳定）
df['log_return'] = np.log(df['close'] / df['close'].shift(1))

# 用 forward return
df['fwd_ret_5'] = df['log_return'].shift(-5)
```

### 标准化

```python
# 横截面标准化（不同股票可比）
df['z_score'] = df.groupby('date')['returns'].transform(
    lambda x: (x - x.mean()) / x.std()
)
```

### 标签净化

```python
# 去除小波动（噪音）
threshold = 0.005
df['label_clean'] = np.where(
    df['fwd_ret'] > threshold, 1,
    np.where(df['fwd_ret'] < -threshold, -1, 0)
)
```

## 7.4 数据质量

### 检查项

| 项目 | 检查 |
|------|------|
| **缺失值** | `df.isnull().sum()` |
| **重复** | `df.duplicated().sum()` |
| **异常值** | `df.describe()` |
| **时序错位** | 时间戳 |
| **前瞻偏差** | 时间对齐 |
| **单位** | 一致性 |

```python
def data_quality_report(df):
    """数据质量报告。"""
    report = {
        'shape': df.shape,
        'missing_per_col': df.isnull().sum().to_dict(),
        'duplicates': df.duplicated().sum(),
        'unique_dates': df['date'].nunique(),
        'start_date': df['date'].min(),
        'end_date': df['date'].max(),
    }
    return report
```

## 7.5 标签对齐（防前瞻偏差）

```python
# 错误：在 t 日用 t 日收盘价 → t+1 日收益
df['label_wrong'] = df['close'].pct_change().shift(-1)  # 用了 t 日 close

# 正确：在 t 日用 t-1 日之前数据，预测 t+1 日收益
df['label_correct'] = df['close'].shift(-1) / df['close'] - 1  # t 日 close
```

## 7.6 信号评估

### IC（Information Coefficient）

```python
def information_coefficient(predictions, actuals):
    """皮尔森相关系数。"""
    return predictions.corr(actuals)

# 时序 IC
def rolling_ic(predictions, actuals, window=63):
    """滚动 IC。"""
    df = pd.concat([predictions, actuals], axis=1)
    return df.rolling(window).corr().iloc[0::2, -1]
```

### Rank IC

```python
def rank_ic(predictions, actuals):
    """斯皮尔曼相关系数。"""
    from scipy.stats import spearmanr
    return spearmanr(predictions, actuals)
```

### 十分位收益

```python
def quantile_returns(predictions, actuals, quantiles=10):
    """十分位收益分析。"""
    df = pd.DataFrame({'pred': predictions, 'act': actuals})
    df['quantile'] = pd.qcut(df['pred'], quantiles, labels=False)
    return df.groupby('quantile')['act'].mean()
```

## 7.7 IC IR

```python
def ic_ir(ic_series):
    """IC 信息比率。"""
    return ic_series.mean() / ic_series.std()
```

- IC IR > 0.5：好
- IC IR > 1.0：优秀

## 7.8 多步评估

```python
"""多 horizon 评估"""
def multi_horizon_eval(predictions, returns, multihorizon=[1, 5, 21]):
    results = {}
    for h in multi_horizon:
        fwd_ret = returns.rolling(h).mean().shift(-h)
        ic = predictions.corr(fwd_ret)
        results[f'horizon_{h}'] = ic
    return results
```

## 7.9 实战：完整学习任务

```python
"""定义完整学习任务"""
import pandas as pd
import numpy as np

# 1. 加载数据
prices = yf.download(['AAPL', 'MSFT', 'GOOGL'], start='2015-01-01')['Close']
returns = prices.pct_change()

# 2. 特征（用昨天 / 今天之前的数据）
features = pd.DataFrame()
for ticker in prices.columns:
    features[f'{ticker}_mom_5'] = prices[ticker].pct_change(5)
    features[f'{ticker}_vol_20'] = returns[ticker].rolling(20).std()

# 3. 标签（明天 / N 天后收益）
target_5d = prices.pct_change(5).shift(-5)  # 5 天后收益
target_dir = np.sign(target_5d)  # 方向

# 4. 对齐
data = features.copy()
data['target'] = target_5d.mean(axis=1)  # 跨股票平均
data = data.dropna()

# 5. 划分（时序）
train = data.loc['2015':'2020']
test = data.loc['2021':]

X_train = train.drop(columns=['target'])
y_train = train['target']
X_test = test.drop(columns=['target'])
y_test = test['target']

# 6. 训练 / 评估
from sklearn.ensemble import GradientBoostingRegressor

model = GradientBoostingRegressor()
model.fit(X_train, y_train)

pred = pd.Series(model.predict(X_test), index=y_test.index)

# IC
ic = pred.corr(y_test)
print(f"IC: {ic:.4f}")
```

## 7.11 标签漂移

### 概念

- 标签分布随时间变化
- 模型学到偏差

### 检测

```python
def label_drift_check(y_train, y_test):
    """标签分布检查。"""
    from scipy.stats import ks_2samp

    stat, p = ks_2samp(y_train, y_test)
    if p < 0.05:
        print("Warning: Label distribution differs significantly!")
    return stat, p
```
