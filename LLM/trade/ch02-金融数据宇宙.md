## 2.2 ITCH 数据格式

NASDAQ TotalView-ITCH 是行业标准的高频数据格式。

```
消息类型（每行一个）：
- 'A': Add Order (新增订单)
- 'D': Delete Order
- 'E': Execute Order
- 'F': Add Order with MPID Attribution
- 'H': Trade
- 'I': Net Order Imbalance Indicator
- 'Y': Market Segment
- 'S': System Event
- ...
```

### 解析 ITCH

```python
import struct
from datetime import datetime

def parse_itch_message(msg_type, raw_data):
    if msg_type == b'A':
        # 新增订单
        (stock_locate, tracking_number, timestamp,
         order_ref, buy_sell, shares, stock,
         price) = struct.unpack('>HHQqci6sI', raw_data[:36])
        return {
            'type': 'ADD',
            'order_ref': order_ref,
            'side': 'BUY' if buy_sell == b'B' else 'SELL',
            'shares': shares,
            'stock': stock_locate,  # 需查 map
            'price': price / 10000,
            'timestamp': timestamp,
        }
    elif msg_type == b'E':
        # 部分成交
        # ...
    elif msg_type == b'D':
        # 撤单
        # ...
```

## 2.3 重建订单簿（L3）

```python
class OrderBook:
    def __init__(self):
        self.bids = {}  # price -> {order_ref -> shares}
        self.asks = {}

    def add(self, side, price, order_ref, shares):
        book = self.bids if side == 'BUY' else self.asks
        book.setdefault(price, {})[order_ref] = shares

    def delete(self, order_ref):
        for book in [self.bids, self.asks]:
            for price, orders in book.items():
                if order_ref in orders:
                    del orders[order_ref]
                    if not orders:
                        del book[price]
                    return

    def execute(self, order_ref, executed_shares):
        for book in [self.bids, self.asks]:
            for price, orders in book.items():
                if order_ref in orders:
                    orders[order_ref] -= executed_shares
                    if orders[order_ref] <= 0:
                        del orders[order_ref]
                    return

    def best_bid_ask(self):
        best_bid = max(self.bids.keys()) if self.bids else None
        best_ask = min(self.asks.keys()) if self.asks else None
        return best_bid, best_ask
```

## 2.4 Bars：K 线重构

### 时间 Bars

传统 OHLCV。

```python
df['close'].resample('1H').ohlc()
df['volume'].resample('1H').sum()
```

### Tick Bars

每 N 次 tick 一根 bar：

```python
df['bar'] = (df.index // 1000)  # 每 1000 tick 一根
df.groupby('bar').agg({'price': 'ohlc', 'volume': 'sum'})
```

### Volume Bars

每成交 N 股一根：

```python
df['cum_vol'] = df['volume'].cumsum()
df['bar'] = df['cum_vol'] // 10000  # 每 10000 股
```

### Dollar Bars

每成交 $N 一根（**最重要**）：

```python
df['cum_dollar'] = (df['price'] * df['volume']).cumsum()
df['bar'] = df['cum_dollar'] // 100000  # 每 10 万美元
```

### 为什么 Dollar Bars 最好

```
时间 bars：受波动率影响（高波 → 少 tick，低波 → 多 tick）
Dollar bars：标准化信息量，更适合统计建模
```

详见 López de Prado *Advances in Financial Machine Learning*。

## 2.9 实战：ITTH tick 数据 ETL

```python
"""完整 ITCH → OrderBook → Bars 流水线"""
import struct
from collections import defaultdict
import pandas as pd
import numpy as np

def load_itch(filepath, stock='AAPL'):
    """简化版 ITCH 解析，返回 DataFrame."""
    messages = []
    stock_locate_to_ticker = {}

    with open(filepath, 'rb') as f:
        while True:
            header = f.read(1)
            if not header:
                break
            msg_type = header
            data = f.read(35)  # 假设每条 36 字节

            if msg_type == b'R':
                # Stock Directory
                (stock_locate, _, _, etf, _,
                 ticker, _) = struct.unpack('>HccB8s9sc', data[:23])
                stock_locate_to_ticker[stock_locate] = ticker.decode().strip()

            elif msg_type == b'A':
                # Add Order
                (stock_locate, _, _, order_ref, side, shares, _, price) = \
                    struct.unpack('>HHQqci6sI', data[:36])
                ticker = stock_locate_to_ticker.get(stock_locate)
                if ticker == stock:
                    messages.append({
                        'timestamp': None,  # 需 timestamp parse
                        'order_ref': order_ref,
                        'side': 'BUY' if side == b'B' else 'SELL',
                        'shares': shares,
                        'price': price / 10000,
                        'action': 'ADD',
                    })
            # 处理其他消息...

    return pd.DataFrame(messages)
```
