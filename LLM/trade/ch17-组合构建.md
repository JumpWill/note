## 5.1 投资组合理论

### 马科维茨均值-方差（1952）

给定期望收益 $\mu$ 与协方差 $\Sigma$，求：

$$
w^* = \arg\min_w \frac{1}{2} w^T \Sigma w - \lambda w^T \mu
$$

约束：$\sum w_i = 1$

解（解析）：

$$
w^* = \lambda \Sigma^{-1} \mu
$$

### 资本市场线（CML）

$$
E[R_p] = R_f + \frac{E[R_M] - R_f}{\sigma_M} \sigma_P
$$

最优组合位于 CML 上。

### CAPM

$$
E[R_i] = R_f + \beta_i (E[R_M] - R_f)
$$

## 5.2 实践：均值-方差优化

```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

def mean_variance_optimize(mu, sigma, risk_aversion=1.0, long_only=False):
    n = len(mu)
    w0 = np.ones(n) / n

    def objective(w):
        return 0.5 * w @ sigma @ w.T - mu @ w / risk_aversion

    constraints = [{'type': 'eq', 'fun': lambda w: w.sum() - 1}]

    bounds = [(0, 1)] * n if long_only else [(-w, w) for w in [1]*n]

    result = minimize(objective, w0,
                      constraints=constraints,
                      bounds=bounds,
                      method='SLSQP')
    return result.x

# 用历史估计 mu, sigma
returns = prices.pct_change().dropna()
mu = returns.mean() * 252
sigma = returns.cov() * 252

weights = mean_variance_optimize(mu.values, sigma.values, risk_aversion=2.0, long_only=True)
```

## 5.4 Black-Litterman

### 思想

综合**市场均衡收益**与**主观观点**：

$$
E[R] = [(\tau \Sigma)^{-1} + P^T \Omega^{-1} P]^{-1} [(\tau \Sigma)^{-1} \Pi + P^T \Omega^{-1} Q]
$$

- $\Pi$：市场隐含均衡收益
- $P, Q$：主观观点（资产 + 收益）
- $\Omega$：观点不确定度

### 实施

```python
# 假设 S&P 500 市值权重为市场组合
market_weights = ...  # 行业权重
implied_returns = delta * sigma @ market_weights  # 反问题

# 主观观点
# 视图："AAPL 未来会涨 5%"
P = np.array([[1, 0, 0, ...]])  # 哪些资产
Q = np.array([0.05])             # 预期收益
omega = np.array([[0.001]])      # 观点方差

# 后验
tau = 0.05
inv_tau_sigma = np.linalg.inv(tau * sigma)
M1 = inv_tau_sigma + P.T @ np.linalg.inv(omega) @ P
M2 = inv_tau_sigma @ implied_returns + P.T @ np.linalg.inv(omega) @ Q
mu_bl = np.linalg.solve(M1, M2)
```

## 5.5 风险平价 (Risk Parity)

### 思想

每个资产贡献**同等风险**到组合：

$$
w_i (\Sigma w)_i = \frac{w^T \Sigma w}{n}
$$

```python
def risk_parity(sigma):
    n = sigma.shape[0]
    w0 = np.ones(n) / n

    def objective(w):
        risk_contributions = w * (sigma @ w)
        target = w @ sigma @ w / n
        return np.sum((risk_contributions - target) ** 2)

    constraints = [{'type': 'eq', 'fun': lambda w: w.sum() - 1}]
    bounds = [(0.001, 1)] * n

    result = minimize(objective, w0, constraints=constraints,
                      bounds=bounds, method='SLSQP')
    return result.x
```

## 5.7 业绩评估指标

### 绝对收益

```python
def total_return(returns):
    return (1 + returns).prod() - 1

def annualized_return(returns, freq=252):
    return (1 + returns).prod() ** (freq / len(returns)) - 1

def annualized_vol(returns, freq=252):
    return returns.std() * np.sqrt(freq)
```

### 风险调整收益

```python
def sharpe_ratio(returns, rf=0, freq=252):
    excess = returns - rf / freq
    return excess.mean() / excess.std() * np.sqrt(freq)

def sortino_ratio(returns, rf=0, freq=252):
    excess = returns - rf / freq
    downside = excess[excess < 0].std()
    return excess.mean() / downside * np.sqrt(freq)

def calmar_ratio(returns, freq=252):
    ann_ret = annualized_return(returns, freq)
    max_dd = max_drawdown(returns)
    return ann_ret / abs(max_dd)
```

### 风险指标

```python
def max_drawdown(returns):
    cum = (1 + returns).cumprod()
    running_max = cum.cummax()
    dd = (cum - running_max) / running_max
    return dd.min()

def var(returns, alpha=0.05):
    return returns.quantile(alpha)

def cvar(returns, alpha=0.05):
    var_value = var(returns, alpha)
    return returns[returns <= var_value].mean()
```

### 主动管理

```python
def information_ratio(returns, benchmark):
    active_returns = returns - benchmark
    return active_returns.mean() / active_returns.std() * np.sqrt(252)

def tracking_error(returns, benchmark):
    active_returns = returns - benchmark
    return active_returns.std() * np.sqrt(252)
```

# 优化目标加交易成本
def objective_with_cost(w, current_w, returns, sigma, tc=0.001):
    portfolio_ret = (w * returns.mean()).sum()
    portfolio_risk = np.sqrt(w @ sigma @ w.T)
    turnover = np.abs(w - current_w).sum()
    return -(portfolio_ret - portfolio_risk / risk_aversion - tc * turnover)
