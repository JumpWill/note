## 4.1 什么是 Alpha 因子

Alpha 因子 = 预测资产未来收益的特征：

$$
E[R_{i,t+1} | \alpha_{i,t}] = f(\alpha_{i,t})
$$

经典四大类：
- **动量（Momentum）**：过去涨还会涨
- **价值（Value）**：便宜的会修复
- **质量（Quality）**：好的继续好
- **波动（Volatility）**：低波有时跑赢

## 4.2 基本因子

### 动量因子

```python
import pandas as pd

# 1 个月动量
mom_1m = close.pct_change(20)

# 12 个月动量（跳过最近一月）
mom_12m = close.pct_change(252) - close.pct_change(20)

# 截面动量
def cross_sectional_momentum(prices, window=252):
    """每天把所有股票的动量 z-score。"""
    returns = prices.pct_change(window)
    return (returns - returns.mean(axis=1).values.reshape(-1, 1)) / returns.std(axis=1).values.reshape(-1, 1)
```

### 价值因子

```python
# 需要基本面数据
# PE: 价格 / EPS
pe = price / earnings_per_share

# PB: 价格 / 每股净资产
pb = price / book_value_per_share

# PS: 价格 / 每股营收
ps = price / sales_per_share

# 行业中性 PE
pe_neutral = pe - pe.groupby(sector).transform('mean')
```

### 质量因子

```python
# ROE: 净利 / 股东权益
roe = net_income / equity

# ROA: 净利 / 总资产
roa = net_income / assets

# Profit Margin
pm = net_income / revenue

# Accruals（越小越健康）
accruals = (net_income - cash_flow_operations) / total_assets
```

### 波动因子

```python
# 历史波动率
vol_20d = close.pct_change().rolling(20).std()

# 偏度（极端收益）
skew = close.pct_change().rolling(60).skew()

# 最大回撤

```

## 4.4 因子组合 / 衍生

### 标准化

```python
def standardize_factor(factor, by_group=None):
    if by_group is not None:
        # 行业中性化
        return factor.groupby(by_group).transform(
            lambda x: (x - x.mean()) / x.std()
        )
    return (factor - factor.mean()) / factor.std()
```

### 排名 / 分数

```python
def rank_factor(factor):
    return factor.rank(pct=True)
```

### 缩尾

```python
def winsorize(factor, limits=(0.01, 0.99)):
    """缩尾：把极端值剪到分位数。"""
    lower = factor.quantile(limits[0])
    upper = factor.quantile(limits[1])
    return factor.clip(lower, upper)
```

### 中性化（对冲风险）

```python
# 中性化对市场、行业、市值
import statsmodels.api as sm

def neutralize(factor, features):
    features = sm.add_constant(features)
    model = sm.OLS(factor, features).fit()
    residual = model.resid
    return residual
```

## 4.5 卡尔曼滤波去噪

```python
from pykalman import KalmanFilter
import numpy as np

def kalman_smooth(prices, Q=0.01, R=1.0):
    """卡尔曼滤波去噪。"""
    kf = KalmanFilter(
        initial_state_mean=prices.iloc[0],
        n_dim_obs=1,
        transition_covariance=Q * np.eye(1),
        observation_covariance=R * np.eye(1),
    )
    state_means, _ = kf.smooth(prices.values)
    return pd.Series(state_means.flatten(), index=prices.index)

smooth_price = kalman_smooth(close)
signal = smooth_price.pct_change(20)
```

## 4.6 小波变换去噪

```python
import pywt

def wavelet_denoise(series, wavelet='db4', level=4, threshold_mode='soft'):
    coeffs = pywt.wavedec(series, wavelet, level=level)
    sigma = np.median(np.abs(coeffs[-1])) / 0.6745
    threshold = sigma * np.sqrt(2 * np.log(len(series)))
    coeffs[1:] = [pywt.threshold(c, threshold, threshold_mode) for c in coeffs[1:]]
    return pywt.waverec(coeffs, wavelet)[:len(series)]

denoised = wavelet_denoise(prices.values)
```

```python
# zipline-reloaded
from zipline.api import (
    order_target_percent, symbol, schedule_function,
    date_rules, time_rules, get_datetime,
)

def initialize(context):
    context.factor = 'momentum_20d'
    context.universe = [...]
    schedule_function(rebalance, date_rules.month_start())

def compute_alpha(context, data):
    hist = data.history(context.universe, 'price', 30, '1d')
    return hist.iloc[-1] / hist.iloc[0] - 1

def rebalance(context, data):
    alpha = compute_alpha(context, data)
    alpha = alpha.rank(pct=True)
    longs = alpha[alpha > 0.8].index
    shorts = alpha[alpha < 0.2].index

    for asset in longs:
        order_target_percent(asset, 0.025)  # 等权 + 杠杆
    for asset in shorts:
        order_target_percent(asset, -0.025)
```

## 4.10 因子衰减

```python
def factor_decay(factor_data, max_periods=10):
    """计算因子 IC 随持有期衰减。"""
    decays = {}
    for period in range(1, max_periods + 1):
        ic = alphalens.performance.factor_information_coefficient(
            factor_data, period
        )
        decays[period] = ic.mean()
    return pd.Series(decays)

# 衰减快 → 调仓频繁
# 衰减慢 → 长期持有
```

## 4.13 因子合成的陷阱

### 过拟合

- 100 个因子，10 个看起来有效（纯噪声）
- **多重检验**：需 Bonferroni 校正

### 前视偏差

- 用未来数据
- 解决：滚动计算

### 生存者偏差

- 用当前仍在的股票
- 解决：含已退市股票

### 数据窥探

- 反复看数据找模式
- 解决：样本外测试
