## 18.1 交易成本分类

### 主要类型

| 成本 | 描述 |
|------|------|
| **佣金** | 经纪商收取 |
| **买卖价差** | 即时成本 |
| **市场冲击** | 大单推动价格 |
| **机会成本** | 未成交 |
| **延迟成本** | 价格变动 |

### 总体公式

$$
\text{Total Cost} = \text{Commission} + \text{Spread} + \text{Impact} + \text{Delay}
$$

## 18.3 市场冲击模型

### Almgren-Chriss

```python
def almgren_chriss_impact(trade_size, daily_volume, volatility, eta=0.01):
    """Almgren-Chriss 临时冲击。"""
    X = trade_size
    V = daily_volume
    sigma = volatility

    # 临时冲击（与执行速率有关）
    temporary_impact = eta * sigma * np.sqrt(X / V)

    return temporary_impact
```

### 永久冲击

```python
def permanent_impact(trade_size, daily_volume, gamma=0.1):
    """永久冲击。"""
    X = trade_size
    V = daily_volume

    permanent = 0.01 * np.sqrt(X / V)
    return permanent
```

### 总冲击

```python
def total_impact(trade_size, daily_volume, volatility, eta=0.01, gamma=0.1):
    """总市场冲击。"""
    temp = almgren_chriss_impact(trade_size, daily_volume, volatility, eta)
    perm = permanent_impact(trade_size, daily_volume, gamma)

    return temp + perm
```

## 18.4 滑点估计

### 简单模型

```python
def estimate_slippage(order_size, daily_volume, spread):
    """估计滑点。"""
    participation_rate = order_size / daily_volume

    # 滑点 = 半个价差 + 冲击
    slippage = spread / 2 + 0.1 * spread * participation_rate

    return slippage
```

### 历史滑点

```python
def historical_slippage(trades):
    """从历史成交数据估计滑点。"""
    # trades: 包含 expected_price 和 actual_price
    slippage = trades['actual_price'] - trades['expected_price']

    # 按 size 分组
    trades['size_bucket'] = pd.qcut(trades['size'], 5)
    avg_slippage = trades.groupby('size_bucket').apply(
```

## 18.5 VWAP（成交量加权平均价）

### 思想

按历史成交量分布执行订单

```python
def vwap_execution(prices, volumes, target_size):
    """VWAP 执行。"""
    # 历史 VWAP
    hist_vwap = (prices * volumes).cumsum() / volumes.cumsum()

    # 当日目标 VWAP
    cum_volume = 0
    cumulative = []

    for i in range(len(volumes)):
        cum_volume += volumes.iloc[i]
        cumulative.append(cum_volume)

    # 按成交量分布
    target_cumulative = cumulative[-1] * (np.array(cumulative) / cum_volume)

    return target_cumulative
```

## 18.6 TWAP（时间加权平均价）

```python
def twap_execution(target_size, n_periods):
    """TWAP：均匀分配。"""
    slice_size = target_size / n_periods
    return [slice_size] * n_periods
```

## 18.7 Implementation Shortfall

```python
def implementation_shortfall(arrival_price, execution_prices, target_size):
    """实施缺口。"""
    # 用到达价作为基准
    total_cost = 0
    for i, price in enumerate(execution_prices):
        total_cost += (price - arrival_price) * (target_size[i] / target_size.sum())

    return total_cost / arrival_price
```

## 18.8 Almgren-Chriss 最优执行

```python
def almgren_chriss_optimal(X, V, T, sigma, eta, gamma, n_periods):
    """
    Almgren-Chriss 最优执行轨迹。
    X: 总订单量
    V: 总成交量
    T: 总执行时间
    sigma: 波动率
    eta: 临时冲击系数
    gamma: 永久冲击系数
    n_periods: 期数
    """
    tau = T / n_periods  # 每期时间

    # 最优参数
    kappa = np.sqrt(gamma / eta)  # |T| / (eta * kappa)

    # 持仓轨迹
    t = np.arange(n_periods + 1)
    trajectory = X * np.sinh(kappa * tau * (n_periods - t)) / np.sinh(kappa * tau * n_periods)

    return trajectory
```

## 18.9 实际回测考虑成本

```python
"""含实际成本的回测"""
def backtest_with_realistic_costs(prices, signals, daily_volume):
    """考虑交易成本的回测。"""
    positions = signals.shift(1).fillna(0)
    returns = prices.pct_change()
    trades = positions.diff().abs()

    # 1. 佣金
    commission = trades * 0.0005  # 5 bps

    # 2. 价差
    spread_cost = trades * 0.0005  # 5 bps

    # 3. 冲击
    impact = trades * daily_volume.apply(
        lambda v: 0.1 * np.sqrt(trades / v) if v > 0 else 0
    )

    # 总成本
    total_cost = commission + spread_cost + impact

    # 策略收益
    strategy_returns = positions * returns - total_cost

    return strategy_returns
```

## 18.10 成本优化策略

### 1. 减少换手

```python
# 信号平滑（减少换手）
def smooth_signal(signal, threshold=0.1):
    """平滑信号减少换手。"""
    smoothed = signal.copy()
    current = signal.iloc[0]

    for i in range(1, len(signal)):
        if abs(signal.iloc[i] - current) > threshold:
            current = signal.iloc[i]
        smoothed.iloc[i] = current

    return smoothed
```

### 2. 仓位限制

```python
def position_constraints(target_weights, current_weights, max_change=0.05):
    """限制每次仓位变化。"""
    new_weights = current_weights.copy()
    diff = target_weights − current_weights

    # 限制变化
    diff = np.clip(diff, -max_change, max_change)
    new_weights = current_weights + diff

    return new_weights
```

### 3. 分批执行

```python
def execute_in_batches(orders, prices, batch_size=100):
    """分批执行大订单。"""
    executed = []
    remaining = orders.copy()

    while remaining.abs().sum() > 0:
        # 每批只执行一部分
        batch = remaining.clip(-batch_size, batch_size)

        # 执行（用 VWAP）
        vwap_prices = compute_vwap(prices, batch)
        executed.append(vwap_prices)

        remaining -= batch

    return pd.DataFrame(executed).sum()
```

- 交易成本 = 价差 + 冲击 + 佣金

## 18.12 实战陷阱

### 假设错误

- 假设无限价差无滑点

### 量价关系

- 大订单冲击非线性

### 时机选择

- 开盘 / 收盘成本高

### 流动性差

- 紧急大单冲击更大
