## 7.1 线性模型与交易

### 为什么线性？

- **解释性强**：权重即因子暴露
- **稳健**：不易过拟合
- **快速**：训练 / 推理都快
- **监管友好**：模型可解释

### 主要场景

1. **风险因子模型**：Fama-French 三因子 / 五因子
2. **收益预测**：多因子 → 未来收益
4. **统计套利**：协整 + 残差预测
5. **特征选择**：Lasso 选出重要因子

## 7.3 正则化回归

### Ridge（L2 正则）

$$
L = \sum_i (y_i - \hat{y}_i)^2 + \lambda \sum_j \beta_j^2
$$

- 所有系数都保留
- 减少共线性影响
- 适合因子较多

```python
from sklearn.linear_model import Ridge

# 调 alpha
for alpha in [0.001, 0.01, 0.1, 1.0, 10.0]:
    model = Ridge(alpha=alpha)
    model.fit(X_train, y_train)
    score = model.score(X_val, y_val)
    print(f"alpha={alpha}: val_score={score:.4f}")
```

### Lasso（L1 正则）

$$
L = \sum_i (y_i - \hat{y}_i)^2 + \lambda \sum_j |\beta_j|
$$

- 把不重要的设为 0
- 自动特征选择
- 适合高维

```python
from sklearn.linear_model import Lasso

model = Lasso(alpha=0.001)
model.fit(X_train, y_train)

# 系数为 0 的特征
zero_coef_mask = model.coef_ == 0
print(f"Zeroed features: {X.columns[zero_coef_mask].tolist()}")
```

### ElasticNet（L1 + L2）

$$
L = \sum_i (y_i - \hat{y}_i)^2 + \lambda_1 \sum_j |\beta_j| + \lambda_2 \sum_j \beta_j^2
$$

```python
from sklearn.linear_model import ElasticNet

model = ElasticNet(alpha=0.001, l1_ratio=0.5)
```

## 7.5 滚动回归（时间序列）

### 滚动窗口预测

```python
def rolling_regression(prices, features, lookback=252):
    """每个时间点用过去 lookback 天训练，预测下一天。"""
    predictions = []
    for t in range(lookback, len(prices)):
        X_train = features.iloc[t - lookback:t]
        y_train = returns.iloc[t - lookback:t]
        X_test = features.iloc[t:t+1]

        model = Ridge(alpha=1.0)
        model.fit(X_train, y_train)
        pred = model.predict(X_test)
        predictions.append(pred[0])

    return pd.Series(predictions, index=prices.index[lookback:])
```

## 7.6 滚动预测 + 集成

```python
def rolling_ensemble_regression(X, y, models, retrain_every=21):
    """每个 retrain_every 天用多个模型重训，集成预测。"""
    predictions = []
    for t in range(252, len(X)):
        # 每 N 天重训
        if (t - 252) % retrain_every == 0:
            preds_t = []
            for name, model in models.items():
                model.fit(X.iloc[t-252:t], y.iloc[t-252:t])

        # 集成预测
        ens_pred = np.mean([m.predict(X.iloc[t:t+1])[0] for m in models.values()])
        predictions.append(ens_pred)

    return pd.Series(predictions, index=X.index[252:])
```

from sklearn.utils import resample

def bootstrap_coefficients(X, y, n=1000):
    coefs = []
    for _ in range(n):
        X_b, y_b = resample(X, y)
        model = Ridge(alpha=0.01)
        model.fit(X_b, y_b)
        coefs.append(model.coef_)
    return np.array(coefs)

coefs_boot = bootstrap_coefficients(X, y)
ci_low = np.percentile(coefs_boot, 2.5, axis=0)
ci_high = np.percentile(coefs_boot, 97.5, axis=0)

## 7.10 实战：从因子到收益预测

```python
"""完整线性模型交易系统"""
import yfinance as yf
import pandas as pd
import numpy as np
from sklearn.linear_model import Ridge, Lasso
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import TimeSeriesSplit
import alphalens

# 1. 数据
prices = yf.download(['AAPL', 'MSFT', 'GOOGL', 'AMZN', 'META'],
                     start='2015-01-01')['Close']

# 2. 特征
def build_features(close):
    features = pd.DataFrame()
    features['mom_5'] = close.pct_change(5)
    features['mom_20'] = close.pct_change(20)
    features['mom_60'] = close.pct_change(60)
    features['vol_20'] = close.pct_change().rolling(20).std()
    features['vol_60'] = close.pct_change().rolling(60).std()
    features['mean_rev_5'] = -close.pct_change(5)
    features['skew_60'] = close.pct_change().rolling(60).skew()
    return features

features_per_stock = {stock: build_features(prices[stock])
                      for stock in prices.columns}

X = pd.concat(features_per_stock, axis=1).dropna()
y = prices.pct_change().shift(-1).loc[X.index].dropna()
X, y = X.align(y, axis=0, join='inner')
X, y = X.dropna(), y.dropna()

# 3. 滚动预测
tscv = TimeSeriesSplit(n_splits=5, test_size=63)
predictions = []

for train_idx, test_idx in tscv.split(X):
    X_train, X_test = X.iloc[train_idx], X.iloc[test_idx]
    y_train, y_test = y.iloc[train_idx], y.iloc[test_idx]

    scaler = StandardScaler()
    X_train_s = scaler.fit_transform(X_train)
    X_test_s = scaler.transform(X_test)

    model = Ridge(alpha=1.0)
    model.fit(X_train_s, y_train)

    pred = model.predict(X_test_s)
    predictions.append(pd.DataFrame(pred, index=X_test.index, columns=y_test.columns))

# 4. IC 评估
pred_df = pd.concat(predictions)
ic = pred_df.corrwith(y, axis=1)
print(f"Mean IC: {ic.mean():.4f}")
print(f"IC std: {ic.std():.4f}")
```
