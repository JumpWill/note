## 11.3 VAE (Variational Autoencoder)

### 思想

学习**隐空间** $z$，采样 + 解码生成。

### 数学

ELBO：

$$
\log P(x) \geq \mathbb{E}_{q(z|x)}[\log p(x|z)] - \text{KL}(q(z|x) \| p(z))
$$

- $q(z|x)$：编码器（推断网络）
- $p(x|z)$：解码器（生成网络）
- $p(z)$：先验（标准正态）

### 重参数化技巧

$$
z = \mu + \sigma \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, 1)
$$

让采样可微。

### PyTorch 实现

```python
class VAE(nn.Module):
    def __init__(self, in_dim, latent_dim, hidden_dim=400):
        super().__init__()
        # 编码器
        self.encoder = nn.Sequential(
            nn.Linear(in_dim, hidden_dim), nn.ReLU(),
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)

        # 解码器
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, in_dim), nn.Sigmoid(),
        )

    def encode(self, x):
        h = self.encoder(x)
        return self.fc_mu(h), self.fc_logvar(h)

    def reparameterize(self, mu, logvar):
        std = (logvar * 0.5).exp()
        return mu + std * torch.randn_like(std)

    def decode(self, z):
        return self.decoder(z)

    def forward(self, x):
        mu, logvar = self.encode(x.view(-1, self.in_dim))
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

# 损失
def vae_loss(recon_x, x, mu, logvar):
    BCE = F.binary_cross_entropy(recon_x, x.view(-1, in_dim), reduction='sum')
    KLD = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return BCE + KLD
```

### 优缺点

**优点**：理论优雅、可嵌入下游
**缺点**：样本模糊、ELBO 不紧

### 变体

- **β-VAE**：加 $\beta \cdot \text{KL}$ 增强解耦
- **VQ-VAE**：离散隐空间
- **VQ-VAE-2**：分层
- **NVAE**：深度
- **Hierarchical VAE**

## 11.4 GAN (Generative Adversarial Network)

### 思想

两个网络对抗训练：
- **生成器 G**：噪声 → 假样本
- **判别器 D**：判真假

### 数学

$$
\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]
$$

### PyTorch 实现

```python
class Generator(nn.Module):
    def __init__(self, latent_dim=100, out_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(latent_dim, 256), nn.LeakyReLU(0.2),
            nn.Linear(256, 512), nn.LeakyReLU(0.2),
            nn.Linear(512, out_dim), nn.Tanh(),
        )

    def forward(self, z):
        return self.net(z)


class Discriminator(nn.Module):
    def __init__(self, in_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 512), nn.LeakyReLU(0.2),
            nn.Linear(512, 256), nn.LeakyReLU(0.2),
            nn.Linear(256, 1),
        )

    def forward(self, x):
        return self.net(x)


# 训练
for real, _ in dataloader:
    # 真实样本
    real_labels = torch.ones(batch_size, 1)
    fake_labels = torch.zeros(batch_size, 1)

    # 训练 D
    d_real = D(real)
    d_fake = D(G(z))
    d_loss = (F.binary_cross_entropy(d_real, real_labels) +
              F.binary_cross_entropy(d_fake, fake_labels))

    # 训练 G
    g_loss = F.binary_cross_entropy(D(G(z)), real_labels)
```

### 训练技巧

- **交替训练** G / D
- **标签平滑**：real 0.9 而非 1.0
- **TTUR**：D 比 G 小 LR
- **梯度惩罚 / Spectral Norm**

### 优缺点

**优点**：样本锐利、质量高
**缺点**：训练不稳、模式崩溃、多样性差

### GAN 变体

#### DCGAN

CNN + GAN。BatchNorm 关键。

#### WGAN (Wasserstein GAN)

Wasserstein 距离 + 梯度裁剪 / 梯度惩罚。

#### LSGAN

最小二乘损失，更稳。

#### CycleGAN

无配对图像翻译。

$$
L = L_{\text{GAN}}(G, D_Y, X, Y) + L_{\text{GAN}}(F, D_X, Y, X) + \lambda L_{\text{cyc}}(G, F)
$$

#### StyleGAN

Style-based 生成器，高质量人脸。

#### Conditional GAN

条件生成：

## 11.5 Diffusion Model (扩散模型) ⭐

### 思想

两个过程：
- **前向**：逐步加噪 → 纯高斯
- **反向**：逐步去噪 → 数据

### DDPM

#### 前向过程

$$
q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1 - \beta_t} x_{t-1}, \beta_t I)
$$

直接任意步：

$$
x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)
$$

#### 反向过程

$$
p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \Sigma_\theta(x_t, t))
$$

#### 简化损失

$$
L = \mathbb{E}_{t, x_0, \epsilon} \| \epsilon - \epsilon_\theta(\sqrt{\bar{\alpha}_t} x_0 + \sqrt{1-\bar{\alpha}_t} \epsilon, t) \|^2
$$

预测噪声 $\epsilon$。

### PyTorch 实现

```python
class DiffusionModel:
    def __init__(self, eps_model, n_steps=1000, beta_start=1e-4, beta_end=0.02):
        self.eps_model = eps_model
        self.betas = torch.linspace(beta_start, beta_end, n_steps)
        self.alphas = 1 - self.betas
        self.alpha_bars = torch.cumprod(self.alphas, dim=0)
        self.n_steps = n_steps

    def q_sample(self, x0, t, noise):
        sqrt_a_bar = self.alpha_bars[t].sqrt()[:, None, None, None]
        sqrt_one_minus = (1 - self.alpha_bars[t]).sqrt()[:, None, None, None]
        return sqrt_a_bar * x0 + sqrt_one_minus * noise

    def train_step(self, x0):
        B = x0.size(0)
        t = torch.randint(0, self.n_steps, (B,)).to(x0.device)
        noise = torch.randn_like(x0)
        x_t = self.q_sample(x0, t, noise)
        pred_noise = self.eps_model(x_t, t)
        return F.mse_loss(pred_noise, noise)

    @torch.no_grad()
    def sample(self, B, device, shape):
        x = torch.randn(B, *shape, device=device)
        for t in reversed(range(self.n_steps)):
            pred_noise = self.eps_model(x, torch.full((B,), t, device=device))
            beta_t = self.betas[t]
            alpha_t = self.alphas[t]
            alpha_bar_t = self.alpha_bars[t]
            mean = (1 / alpha_t.sqrt()) * (
                x - beta_t / (1 - alpha_bar_t).sqrt() * pred_noise
            )
            if t > 0:
                noise = torch.randn_like(x)
                sigma = beta_t.sqrt()
                x = mean + sigma * noise
            else:
                x = mean
        return x
```

            nn.Linear(1, time_dim), nn.SiLU(),

## 11.6 Flow 模型

### Normalizing Flow

通过可逆变换将简单分布映射到复杂分布：

$$
p_X(x) = p_Z(f^{-1}(x)) \left| \det \frac{\partial f^{-1}(x)}{\partial x} \right|
$$

### 主流

- **RealNVP**：仿射耦合层
- **Glow**：可逆 1x1 卷积
- **FFJORD**：连续 flow

### 优点

- 精确似然
- 可逆

### 缺点

- 计算量大

## 11.9 评估

### FID (Fréchet Inception Distance)

$$
\text{FID} = \|\mu_r - \mu_g\|^2 + \text{Tr}(\Sigma_r + \Sigma_g - 2(\Sigma_r \Sigma_g)^{1/2})
$$

越低越好。

### IS (Inception Score)

结合质量 + 多样性。

### LPIPS / SSIM / PSNR

像素级距离。

### 人类评估

最可靠但贵。
