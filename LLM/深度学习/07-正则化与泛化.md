# 07. 正则化与泛化

正则化（Regularization）减少过拟合，提升泛化能力。深度学习的核心挑战之一。

## 7.1 偏差-方差分解

期望误差：

$$
\mathbb{E}[(y - \hat{f}(x))^2] = \text{Bias}^2 + \text{Variance} + \text{Noise}
$$

| | 欠拟合 | 过拟合 | 好模型 |
|--|--------|--------|--------|
| Bias | **高** | 低 | 低 |
| Variance | 低 | **高** | 低 |

正则化的目标是 **在 bias-variance 之间找平衡**。

### Mixup

$$
\begin{aligned}
\tilde{x} &= \lambda x_i + (1-\lambda) x_j \\
\tilde{y} &= \lambda y_i + (1-\lambda) y_j
\end{aligned}
$$

```python
lam = np.random.beta(0.4, 0.4)
idx = torch.randperm(x.size(0))
x_mix = lam * x + (1 - lam) * x[idx]
y_mix = lam * y + (1 - lam) * y[idx]
loss = criterion(model(x_mix), y_mix)
```

### CutMix

$$
\tilde{x} = \text{Replace}(x_i, \text{patch from } x_j)
$$

```python
# timm 实现
from timm.data.mixup import Mixup

mixup_fn = Mixup(mixup_alpha=0.4, cutmix_alpha=1.0)
x, y = mixup_fn(x, y)
```

## 7.3 模型层面

### Dropout

训练时随机丢弃神经元：

```python
nn.Dropout(p=0.5)
```

$$
\tilde{a}^{(l)} = a^{(l)} \odot m, \quad m_i \sim \text{Bernoulli}(1-p)
$$

- 防止 co-adaptation
- 推理时关闭

**变体**：

- **DropConnect**：丢弃权重
- **SpatialDropout**：丢弃通道
- **DropBlock**：丢弃连续区域 (CV)
- **Stochastic Depth**：丢弃整层 (ResNet)

### 归一化

#### BatchNorm

```python
nn.BatchNorm2d(num_features)
```

$$
\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y = \gamma \hat{x} + \beta
$$

**优点**：缓解 internal covariate shift、加速收敛、轻微正则化

#### LayerNorm

```python
nn.LayerNorm(normalized_shape)
```

按特征归一化，NLP 默认（与 batch 无关）。

#### GroupNorm

```python
nn.GroupNorm(num_groups=32, num_channels=64)
```

分组归一化。检测 / 分割常用（batch 小的场景）。

#### InstanceNorm

```python
nn.InstanceNorm2d(num_features)
```

单样本单通道归一化。风格迁移常用。

#### RMSNorm

$$
y = \gamma \frac{x}{\sqrt{\text{mean}(x^2) + \epsilon}}
$$

LLM 加速版 LN（LLaMA）。

### 权重衰减 (Weight Decay)

$$
L_{\text{reg}} = L + \lambda \|W\|^2
$$

```python
# AdamW (推荐)
torch.optim.AdamW(params, lr=1e-3, weight_decay=1e-2)
# SGD
torch.optim.SGD(params, lr=1e-2, weight_decay=1e-4)
```

**注意**：不要对 BN/LayerNorm 的 $\gamma, \beta$、bias 做 weight decay。

```python
# 分组
decay_params = [p for n, p in model.named_parameters() if "bias" not in n and "bn" not in n]
no_decay_params = [p for n, p in model.named_parameters() if "bias" in n or "bn" in n]
optimizer = torch.optim.AdamW([
    {"params": decay_params, "weight_decay": 0.01},
    {"params": no_decay_params, "weight_decay": 0.0},
], lr=1e-3)
```

## 7.4 优化器层面

### Early Stopping

```python
patience = 10
best_loss = float('inf')
patience_counter = 0

for epoch in range(n_epochs):
    val_loss = evaluate(model, val_loader)
    if val_loss < best_loss:
        best_loss = val_loss
        torch.save(model.state_dict(), 'best.pt')
        patience_counter = 0
    else:
        patience_counter += 1
        if patience_counter >= patience:
            print("Early stopping")
            break
```

### 标签平滑 (Label Smoothing)

$$
y' = (1 - \epsilon) y + \frac{\epsilon}{K}
$$

```python
nn.CrossEntropyLoss(label_smoothing=0.1)
```

防止 overconfidence。

### 知识蒸馏 (KD)

软标签学习：

$$
L = \alpha T^2 \text{KL}(\text{softmax}(z_s/T) \| \text{softmax}(z_t/T)) + (1-\alpha) \text{CE}(z_s, y)
$$

## 7.5 训练技巧

### Stochastic Weight Averaging (SWA)

$$
\theta_{\text{SWA}} = \frac{1}{T}\sum_t \theta_t
$$

PyTorch 内置：`torch.optim.swa_utils`。

### Model Soups

简单平均多个微调 checkpoint（OpenAI 2022）。

## 7.6 隐式正则化

### 早停本身就是正则化

短训练 = 强正则。

### SGD 噪声 = 正则化

随机梯度 = 隐式正则化器。

### Batch Size 大小

小 batch → 噪声 → 隐式正则 → 泛化好。

### 信息瓶颈

深度学习隐式学最小充分表征 (Tishby, 2017)。

## 7.7 实用建议

| 场景 | 策略 |
|------|------|
| 视觉 | Data Aug + Dropout/BN + Mixup + Label Smoothing |
| LLM | Dropout + Label Smoothing + Weight Decay |
| 小数据 | 重数据增强 + 预训练 |
| 大数据 | 适度增强 + Weight Decay |
| 表格 | LightGBM/CatBoost 优先 |
| RL | Dropout + Reward Clipping |
