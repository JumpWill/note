# 14. 分布式训练

分布式训练解决**单卡显存不够 + 训练慢**的问题。深度学习大模型标配。

## 14.1 为什么需要分布式

### 单卡限制

- **显存**：A100 80GB 也不够 70B 模型训练
- **速度**：单卡训练大模型数月
- **吞吐量**：批训练需要大 batch

### 分布式策略

| 维度 | 数据并行 | 模型并行 | 流水线并行 |
|------|----------|----------|------------|
| 切什么 | 数据 | 模型 | 模型 |
| 通信 | 梯度同步 | 激活通信 | 微批次 |
| 显存省 | 0% | 高 | 高 |
| 实现难度 | 低 | 高 | 中 |

## 14.2 数据并行 (Data Parallel, DP / DDP)

### 思想

每 GPU 复制模型，分数据：

```
GPU 0: model, batch_0
GPU 1: model, batch_1
GPU 2: model, batch_2
GPU 3: model, batch_3
→ 梯度 AllReduce → 同步更新
```

### PyTorch DP (单进程)

```python
model = nn.DataParallel(model)  # 自动切
```

简单但慢（主 GPU 通信瓶颈）。

### PyTorch DDP (推荐)

```python
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

# 初始化
dist.init_process_group(backend='nccl')
local_rank = int(os.environ['LOCAL_RANK'])
torch.cuda.set_device(local_rank)

# 模型
model = Model().to(local_rank)
model = DDP(model, device_ids=[local_rank])

# DataLoader 用 DistributedSampler
sampler = DistributedSampler(dataset, shuffle=True)
loader = DataLoader(dataset, batch_size=B, sampler=sampler)

for epoch in range(n_epochs):
    sampler.set_epoch(epoch)
    for x, y in loader:
        ...
```

启动：

```bash
torchrun --nproc_per_node=4 train.py
# 或
python -m torch.distributed.launch --nproc_per_node=4 train.py
```

### 通信原语

- **AllReduce**：所有 GPU 同步梯度
- **Broadcast**：广播参数
- **AllGather**：收集所有
- **ReduceScatter**：分散到每个 GPU

后端：
- **NCCL**：GPU（默认）
- **Gloo**：CPU
- **MPI**：HPC

## 14.3 模型并行 (Model Parallel)

### 思想

模型切到多 GPU：

```
GPU 0: layer 0-10
GPU 1: layer 11-20
GPU 2: layer 21-30
```

### 手动

```python
class SplitModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.part1 = ModelPart1().to('cuda:0')
        self.part2 = ModelPart2().to('cuda:1')

    def forward(self, x):
        x = self.part1(x.to('cuda:0'))
        x = x.to('cuda:1')
        return self.part2(x)
```

### 朴素模型并行问题

- GPU 利用率低（顺序）
- 通信开销大
- 难平衡

## 14.4 流水线并行 (Pipeline Parallel)

### 思想

模型分阶段 + 微批次（micro-batch）：

```
Stage 0   Stage 1   Stage 2   Stage 3
  ↓          ↓          ↓          ↓
[mb1] → [mb1] → [mb1] → [mb1]
         [mb2] → [mb2] → [mb2]
                  [mb3] → [mb3]
                           [mb4]
```

### GPipe

- 微批次 + 同步
- 内存权衡：m 越大越省

```python
from torchgpipe import GPipe

model = nn.Sequential(...)
model = GPipe(model, balance=[2, 2, 2, 2], chunks=8)
```

### PipeDream

异步流水线，吞吐更高但实现复杂。

## 14.5 张量并行 (Tensor Parallel)

### 思想

单层切到多 GPU：

$$
Y = XW = X [W_1 | W_2] = [X W_1 | X W_2] = [Y_1 | Y_2]
$$

### 切分方式

#### 列并行

$$
Y_1 = X W_1, \quad Y_2 = X W_2
$$

输出拼接。

#### 行并行

$$
Y_1 = X_1 W_1, \quad Y_2 = X_2 W_2, \quad Y = Y_1 + Y_2
$$

输入切分 + 输出求和。

### 主流方案：Megatron-LM

```python
class ColumnParallelLinear(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.W = nn.Parameter(torch.randn(in_dim, out_dim // world_size))

    def forward(self, x):
        # 输入复制，每 GPU 算部分输出
        out = x @ self.W  # (B, L, out_dim/world_size)
        # All-Gather 输出
        return all_gather(out)
```

### Transformer 中应用

- **QKV 列并行**：每 GPU 算部分 head
- **FFN**：第一层列、第二层行
- **Attention**：输出 reduce-scatter

## 14.6 3D 并行

## 14.7 ZeRO (Zero Redundancy Optimizer)

### 思想

数据并行中，每 GPU 复制模型状态（参数、梯度、优化器状态），冗余。ZeRO 分片消除。

### 三阶段

- **ZeRO-1**：优化器状态分片
- **ZeRO-2**：+ 梯度分片
- **ZeRO-3**：+ 参数分片

```
                  ZeRO-1     ZeRO-2     ZeRO-3
Optimizer State    分片       分片       分片
Gradients          复制       分片       分片
Parameters         复制       复制       分片
```

### DeepSpeed

```python
import deepspeed

# config
ds_config = {
    "train_batch_size": 32,
    "gradient_accumulation_steps": 4,
    "fp16": {"enabled": True},
    "zero_optimization": {
        "stage": 3,
        "offload_optimizer": {
            "device": "cpu",
            "pin_memory": True,
        },
        "offload_param": {
            "device": "cpu",
            "pin_memory": True,
        },
    },
}

model_engine, optimizer, _, scheduler = deepspeed.initialize(
    model=model,
    model_parameters=model.parameters(),
    config=ds_config,
)

# 训练循环
for x, y in dataloader:
    loss = model_engine(x, y)
    model_engine.backward(loss)
    model_engine.step()
```

### ZeRO-3 + CPU Offload

模型参数可放 CPU，节省 GPU 显存。

## 14.8 FSDP (Fully Sharded Data Parallel)

PyTorch 原生 ZeRO-3。

```python
from torch.distributed.fsdp import FullyShardedDataParallel as FSDP
from torch.distributed.fsdp import MixedPrecision, BackwardPrefetch

model = Model()
model = FSDP(
    model,
    mixed_precision=MixedPrecision(
        param_dtype=torch.bfloat16,
        reduce_dtype=torch.bfloat16,
        buffer_dtype=torch.bfloat16,
    ),
    backward_prefetch=BackwardPrefetch.BACKWARD_PRE,
    device_id=torch.cuda.current_device(),
)
```

启动：

```bash
torchrun --nproc_per_node=8 fsdp_train.py
```

## 14.9 混合精度训练

### BF16 / FP16

- **FP16**：1+5+10 bit，范围小，易 overflow
- **BF16**：1+8+7 bit，范围大，LLM 首选

### AMP

```python
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
for x, y in dataloader:
    with autocast(dtype=torch.bfloat16):
        loss = model(x, y)

    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()
    optimizer.zero_grad()
```

### FSDP/DeepSpeed 自动混合精度

无需手动管理。

## 14.10 梯度累积

显存不够增大等效 batch：

```python
accum_steps = 8
for i, (x, y) in enumerate(loader):
    loss = model(x, y) / accum_steps
    loss.backward()

    if (i + 1) % accum_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

## 14.15 性能优化

### 通信优化

- **梯度压缩**：fp16 / 8-bit
- **Overlap**：通信与计算重叠
- **Large bucket**：减少通信次数

### 计算优化

- **torch.compile**：算子融合
- **Flash Attention**：内存高效 attention
- **混合精度**：加速

### 内存优化

- **Gradient Checkpointing**：时间换空间
- **CPU Offload**：分层存储
- **LoRA / QLoRA**：少训练参数

## 14.16 常见问题

| 问题 | 解决 |
|------|------|
| NCCL timeout | 加 timeout |
| OOM | 减小 batch / 启用 ZeRO |
| 速度慢 | 检查通信 / 用 torch.compile |
| 收敛不同步 | DDP 配 DistributedSampler |
| Loss 不下降 | 增大学习率 (sqrt 法则) |

### 经验法则

**大批量学习率**：

$$
\text{LR}_{\text{new}} = \text{LR}_{\text{old}} \times \sqrt{\frac{B_{\text{new}}}{B_{\text{old}}}}
$$

或线性缩放：

$$
\text{LR}_{\text{new}} = \text{LR}_{\text{old}} \times \frac{B_{\text{new}}}{B_{\text{old}}}
$$
