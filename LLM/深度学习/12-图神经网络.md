# 12. 图神经网络

图神经网络 (GNN) 处理**非欧几里得数据**：节点、边、图结构。社交网络、分子、推荐系统核心。

## 12.1 图数据

### 类型

- **链接预测**：预测节点之间是否存在边
- **图分类**：判断整个图的类别
- **社区发现**：聚类
- **图生成**：生成新图

### 例子

## 12.2 基础概念

### 图表示

- 邻接矩阵 $A \in \mathbb{R}^{N \times N}$
- 节点特征 $X \in \mathbb{R}^{N \times d}$
- 度矩阵 $D$
- 拉普拉斯 $L = D - A$

### 度

$$
\text{deg}(v) = |\{u : (u, v) \in E\}|
$$

### 同构 vs 异构

- **同构图**：节点 / 边同类型
- **异构图**：多种节点 / 边（如元路径）

## 12.3 核心思想：消息传递

每节点：

1. 从邻居聚合（aggregate）
2. 与自身特征组合（update）
3. 重复 K 轮（K-hop 邻居）

$$
h_v^{(k+1)} = \text{UPDATE}\left(h_v^{(k)}, \text{AGG}(\{h_u^{(k)} : u \in N(v)\})\right)
$$

## 12.4 主流 GNN

### GCN (Graph Convolutional Network)

Kipf & Welling, 2017

$$
H^{(l+1)} = \sigma\left(\tilde{D}^{-1/2} \tilde{A} \tilde{D}^{-1/2} H^{(l)} W^{(l)}\right)
$$

- $\tilde{A} = A + I$：加自环
- $\tilde{D}$：$\tilde{A}$ 度矩阵
- 对称归一化

```python
class GCNLayer(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.W = nn.Linear(in_dim, out_dim)

    def forward(self, H, A_hat):
        # A_hat: 归一化邻接
        return self.W(A_hat @ H)
```

### GraphSAGE (Hamilton et al., 2017)

$$
h_v^{(l+1)} = W \cdot \text{CONCAT}(h_v^{(l)}, \text{AGG}(\{h_u^{(l)}, u \in N(v)\}))
$$

三种聚合：

- Mean
- Max
- LSTM（顺序）

```python
class SAGEConv(nn.Module):
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.lin_self = nn.Linear(in_dim, out_dim)
        self.lin_neigh = nn.Linear(in_dim, out_dim)

    def forward(self, H, A):
        neigh = A @ H / (A.sum(dim=1, keepdim=True) + 1e-6)
        return self.lin_self(H) + self.lin_neigh(neigh)
```

### GAT (Graph Attention Network)

引入 attention 权重邻居重要性：

$$
\alpha_{ij} = \frac{\exp(\text{LeakyReLU}(a^T [Wh_i \| Wh_j]))}{\sum_k \exp(...)}
$$

$$
h_i' = \sigma\left(\sum_{j \in N(i)} \alpha_{ij} W h_j\right)
$$

多头：

```python
class GATConv(nn.Module):
    def __init__(self, in_dim, out_dim, heads=4):
        super().__init__()
        self.W = nn.Linear(in_dim, out_dim)
        self.att = nn.Parameter(torch.randn(1, heads, 2 * out_dim))
        self.heads = heads
        self.head_dim = out_dim // heads

    def forward(self, H, A):
        B, N, _ = H.shape
        H = self.W(H).view(B, N, self.heads, self.head_dim)
        # Attention 系数
        a_input = torch.cat([H.unsqueeze(2).repeat(1, 1, N, 1, 1),
                            H.unsqueeze(1).repeat(1, N, 1, 1, 1)], dim=-1)
        e = (a_input * self.att).sum(-1)  # (B, N, N, H)
        e = F.leaky_relu(e, 0.2)
        mask = (A == 0).unsqueeze(-1)
        e = e.masked_fill(mask, float('-inf'))
        alpha = e.softmax(dim=2)
        # 加权
        return (alpha.unsqueeze(-1) * H.unsqueeze(1)).sum(dim=2)
```

### GIN (Graph Isomorphism Network)

理论最强大：

$$
h_v^{(l+1)} = \text{MLP}^{(l)}\left((1 + \epsilon) h_v^{(l)} + \sum_{u \in N(v)} h_u^{(l)}\right)
$$

## 12.5 池化 (Pooling)

### TopK Pool

```python
class TopKPool(nn.Module):
    def forward(self, H, A, k):
        score = self.score(H)
        idx = score.topk(k).indices
        H_new = H[idx]
        A_new = A[idx][:, idx]
        return H_new, A_new
```

### SAGPool

### DiffPool

## 12.8 PyTorch Geometric (PyG)

主流 GNN 库。

```python
import torch
from torch_geometric.nn import GCNConv, SAGEConv, GATConv
from torch_geometric.datasets import Planetoid
from torch_geometric.data import Data

# 数据集
dataset = Planetoid(root='/tmp/Cora', name='Cora')
data = dataset[0]

# 模型
class GCN(nn.Module):
    def __init__(self, in_dim, hidden, out_dim):
        super().__init__()
        self.conv1 = GCNConv(in_dim, hidden)
        self.conv2 = GCNConv(hidden, out_dim)

    def forward(self, x, edge_index):
        x = F.relu(self.conv1(x, edge_index))
        x = F.dropout(x, p=0.5, training=self.training)
        return self.conv2(x, edge_index)

model = GCN(dataset.num_features, 16, dataset.num_classes)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)

for epoch in range(200):
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.cross_entropy(out[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()

    model.eval()
    pred = model(data.x, data.edge_index).argmax(dim=1)
    acc = (pred[data.test_mask] == data.y[data.test_mask]).float().mean()
    if epoch % 10 == 0:
        print(f"Epoch {epoch}: Loss {loss:.4f}, Acc {acc:.4f}")
```

## 12.11 图 Transformer

### Graphormer / GraphGPS / GATv2

把 Transformer 应用到图。

```python
class GraphTransformerLayer(nn.Module):
    def __init__(self, dim, heads):
        super().__init__()
        self.attn = nn.MultiheadAttention(dim, heads)
        self.ff = FeedForward(dim)
        self.ln1 = nn.LayerNorm(dim)
        self.ln2 = nn.LayerNorm(dim)

    def forward(self, x, attn_bias=None):
        # attn_bias: 包含图结构信息
        h, _ = self.attn(self.ln1(x), self.ln1(x), self.ln1(x),
                         attn_mask=attn_bias)
        x = x + h
        x = x + self.ff(self.ln2(x))
        return x
```

### Graphormer

- 中心性编码
- 空间编码
- 边编码
