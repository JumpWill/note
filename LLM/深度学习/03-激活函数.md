# 03. 激活函数

激活函数引入**非线性**，让神经网络能拟合复杂函数。没有激活函数，多层网络等价于单层。

## 3.1 为什么需要非线性

组合线性变换：

$$
W_2 (W_1 x + b_1) + b_2 = (W_2 W_1) x + (W_2 b_1 + b_2)
$$

仍是线性 → 多层 = 单层。

只有**非线性激活**才让深度有意义。

## 3.2 激活函数性质

| 性质 | 含义 |
|------|------|
| **非线性** | 让网络能拟合非线性 |
| **可微** | 梯度计算 |
| **单调** | 优化容易 |
| **零中心** | 梯度更新对称 |
| **饱和性** | 极端值梯度小 |
| **计算便宜** | 训练快 |

## 3.3 Sigmoid

$$
\sigma(x) = \frac{1}{1 + e^{-x}}
$$

$$
\sigma'(x) = \sigma(x)(1 - \sigma(x))
```

### 性质

- 输出 ∈ (0, 1)
- 二分类输出层经典选择
- **梯度消失**（饱和区梯度接近 0）
- 输出不以 0 为中心 → 梯度更新偏锯齿
- exp 计算贵

### 代码

```python
import torch
x = torch.linspace(-5, 5, 100)
y = torch.sigmoid(x)
```

### 适用

- 输出层（二分类）
- LSTM 门控

## 3.4 Tanh

$$
\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}
$$

### 性质

- 输出 ∈ (-1, 1)
- **零中心**（比 sigmoid 好）
- 仍有梯度消失

### 代码

```python
y = torch.tanh(x)
```

### 适用

- RNN 隐藏层
- 隐藏层（一般情况比 sigmoid 好）

## 3.5 ReLU (Rectified Linear Unit)

$$
\text{ReLU}(x) = \max(0, x)
$$

### 性质

- 简单：分段线性
- **正区间梯度 = 1**（不消失）
- 负区间梯度 = 0（**Dead ReLU 问题**）
- 输出非零中心
- 计算便宜（仅 max）

### 优点

- 收敛快 6x（vs sigmoid/tanh）
- 梯度不饱和（正区间）
- 稀疏激活（约 50% 神经元死亡）

### 缺点

- Dead ReLU（学习率大、负偏置 → 神经元永远不激活）
- 输出非零中心

### 代码

```python
import torch.nn as nn
nn.ReLU()
nn.ReLU(inplace=True)  # 原地操作省内存
```

### 适用

- **CNN 隐藏层默认**
- MLP 隐藏层
- 大多数前馈网络

## 3.6 Leaky ReLU

$$
\text{LReLU}(x) = \max(\alpha x, x), \quad \alpha = 0.01
$$

### 性质

- 负区间有小梯度（避免 Dead ReLU）

```python
nn.LeakyReLU(negative_slope=0.01)
```

### 变体

**PReLU**：$\alpha$ 也学
**RReLU**：训练时随机 $\alpha$

## 3.7 GELU (Gaussian Error Linear Unit)

$$
\text{GELU}(x) = x \cdot \Phi(x)
$$

$\Phi$ = 标准正态 CDF。

近似：

$$
\text{GELU}(x) \approx 0.5 x (1 + \tanh(\sqrt{2/\pi}(x + 0.044715 x^3)))
$$

### 性质

- 平滑非线性
- **概率上**激活（input × 概率门控）
- Transformer / BERT 默认
- 在 NLP 任务表现好

### 代码

```python
nn.GELU()  # 精确计算
nn.GELU(approximate='tanh')  # 近似
```

## 3.8 SiLU / Swish

$$
\text{SiLU}(x) = x \cdot \sigma(x)
$$

与 GELU 类似但更简单。Google Brain 提出 (2017)。

```python
nn.SiLU()
```

**h-SiLU**：x * sigmoid(x)，Stable Diffusion / YOLO 等用。

## 3.9 SwiGLU

$$
\text{SwiGLU}(x) = \text{SiLU}(W_1 x) \odot W_2 x
$$

**门控线性单元 (GLU)** + Swish：

- LLaMA / PaLM 等大模型默认
- 比 ReLU/GELU 略好
- 参数更多（额外 W）

```python
class SwiGLU(nn.Module):
    def __init__(self, dim, hidden_dim):
        super().__init__()
        self.w1 = nn.Linear(dim, hidden_dim)
        self.w2 = nn.Linear(dim, hidden_dim)
        self.w3 = nn.Linear(hidden_dim, dim)

    def forward(self, x):
        return self.w3(F.silu(self.w1(x)) * self.w2(x))
```

LLaMA 风格的 FFN：

```python
class LlamaFFN(nn.Module):
    def __init__(self, dim, hidden_dim):
        super().__init__()
        self.gate = nn.Linear(dim, hidden_dim)
        self.up = nn.Linear(dim, hidden_dim)
        self.down = nn.Linear(hidden_dim, dim)

    def forward(self, x):
        return self.down(F.silu(self.gate(x)) * self.up(x))
```

## 3.10 Mish

$$
\text{Mish}(x) = x \cdot \tanh(\text{softplus}(x)) = x \cdot \tanh(\ln(1 + e^x))
$$

- YOLO v5 默认
- 平滑、自门控

```python
# 没有内置，需要自己实现
def mish(x):
    return x * torch.tanh(F.softplus(x))
```

## 3.11 Maxout

$$
\text{Maxout}(x) = \max_{j \in [1, k]} (W_j^T x + b_j)
$$

- 可学凸分段线性
- 表达能力比 ReLU 强
- 参数 × k

## 3.12 Softplus

$$
\text{Softplus}(x) = \ln(1 + e^x)
$$

- ReLU 的平滑版本
- 输出 > 0

## 3.13 ELU / SELU

### ELU

$$
\text{ELU}(x) = \begin{cases} x & x > 0 \\ \alpha (e^x - 1) & x \leq 0 \end{cases}
$$

```python
nn.ELU(alpha=1.0)
```

### SELU

ELU + 缩放，自归一化（SNN）：

```python
nn.SELU()
```

## 3.14 激活函数选择

| 场景 | 推荐 |
|------|------|
| CNN 默认 | ReLU |
| CNN 改进 | SiLU / Mish |
| Transformer / LLM | **GELU / SwiGLU** |
| RNN / LSTM | Tanh |
| 二分类输出 | Sigmoid |
| 多分类输出 | Softmax |
| 回归输出 | Identity |

## 3.15 Softmax

多分类输出层：

$$
\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$

```python
nn.Softmax(dim=-1)
```

### 数值稳定：

```python
def softmax(x):
    x_max = x.max(dim=-1, keepdim=True).values
    e = (x - x_max).exp()
    return e / e.sum(dim=-1, keepdim=True)
```

## 3.16 实际建议

1. **先试 ReLU**：简单有效
3. **LLM 用 GELU 或 SwiGLU**
4. **Dead ReLU**：调小学习率、用 Leaky ReLU
5. **不能用 sigmoid/tanh 作隐藏层**（梯度消失）
6. **输出层激活**：根据任务选

## 3.17 代码：完整激活对比

```python
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

activations = {
    'sigmoid': nn.Sigmoid(),
    'tanh': nn.Tanh(),
    'relu': nn.ReLU(),
    'leaky_relu': nn.LeakyReLU(0.1),
    'gelu': nn.GELU(),
    'silu': nn.SiLU(),
}

x = torch.linspace(-3, 3, 200)
fig, axes = plt.subplots(1, 6, figsize=(15, 3))
for ax, (name, fn) in zip(axes, activations.items()):
    y = fn(x)
    dy = torch.autograd.grad(y.sum(), x, create_graph=True)[0]
    ax.plot(x, y, label='y')
    ax.plot(x, dy, label="y'", linestyle='--')
    ax.set_title(name)
    ax.legend()
    ax.grid()

plt.tight_layout()
plt.show()
```

## 3.18 进阶话题

### 自适应激活

- **PReLU**：$\alpha$ 可学
- **Maxout**：分段凸
- **APL** (Adaptive Piecewise Linear)：可学激活

### 稀疏激活

- ReLU 天然稀疏
- **Top-K ReLU**：每层只激活 top K
- **SparseMixer**：Google 稀疏 FFN

### 激活分布

监控激活分布判断是否健康：

```python
def hook(module, input, output):
    global activations
    activations = output.detach()

model.layer1.register_forward_hook(hook)
```
