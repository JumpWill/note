# 13. 预训练与微调

预训练-微调 (Pretrain-Finetune) 是当代深度学习的标准范式。在大规模数据上学通用知识，在小数据上微调。

## 13.1 范式演进

### 监督学习时代 (2012-2017)

每个任务独立训练，标注成本高。

### 预训练 + 微调 (2018-)

- BERT / GPT 预训练
- 下游任务微调
- 减少标注需求

### 大模型时代 (2020-)

- LLM 涌现能力
- Prompt Engineering
- 少样本 / 零样本

### 指令微调 + RLHF (2022-)

- InstructGPT / ChatGPT
- InstructGPT 三阶段

## 13.2 自监督预训练

### 语言模型

#### Causal LM (GPT)

$$
L = -\sum_t \log p(x_t | x_{<t})
$$

从左到右预测。

#### Masked LM (BERT)

15% token 替换为 [MASK] 或随机词：

$$
L = -\sum_{t \in \text{masked}} \log p(x_t | x_{\text{context}})
$$

#### Span Corruption (T5)

连续 span 替换为 sentinel：

```
"I have a cute cat." → "I have a [S1] cat." → output " [S1] cute"
```

#### ELECTRA

替换 token 检测（RTD）：判别器区分真实 / 替换。

#### DeBERTa

解耦相对位置。

### 视觉预训练

#### SimCLR / MoCo

对比学习：

$$
L = -\log \frac{\exp(s_i \cdot s_j / \tau)}{\sum_k \exp(s_i \cdot s_k / \tau)}
$$

#### MAE (Masked Autoencoder)

```python
class MAE(nn.Module):
    def __init__(self, encoder, decoder, mask_ratio=0.75):
        super().__init__()
        self.encoder = encoder
        self.decoder = decoder
        self.mask_ratio = mask_ratio

    def forward(self, x):
        # 随机 mask 75% patches
        x_masked, mask = self.random_masking(x)
        # 仅编码可见
        latent = self.encoder(x_masked)
        # 重建所有
        pred = self.decoder(latent)
        loss = (pred - x) ** 2
        loss = loss.mean(-1)  # 每 patch
        loss = (loss * mask).sum() / mask.sum()
        return loss
```

#### DINO

自监督 ViT。

### 多模态

#### CLIP

```python
class CLIP(nn.Module):
    def __init__(self, image_enc, text_enc, dim=512):
        super().__init__()
        self.image_enc = image_enc
        self.text_enc = text_enc
        self.image_proj = nn.Linear(image_enc_dim, dim)
        self.text_proj = nn.Linear(text_enc_dim, dim)

    def forward(self, image, text):
        img_feat = F.normalize(self.image_proj(self.image_enc(image)), dim=-1)
        txt_feat = F.normalize(self.text_proj(self.text_enc(text)), dim=-1)

        # 对比学习
        logits = img_feat @ txt_feat.T / self.temperature
        labels = torch.arange(len(logits))
        loss = (F.cross_entropy(logits, labels) +
                F.cross_entropy(logits.T, labels)) / 2
        return loss
```

## 13.4 参数高效微调 (PEFT)

### LoRA (Low-Rank Adaptation)

低秩矩阵注入：

$$
W' = W + \Delta W = W + BA
$$

$A \in \mathbb{R}^{d \times r}, B \in \mathbb{R}^{r \times d}, r \ll d$

```python
from peft import LoraConfig, get_peft_model

config = LoraConfig(
    r=16, lora_alpha=32,
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
)
model = get_peft_model(base_model, config)
model.print_trainable_parameters()
# trainable params: 1.5M || all params: 7B || trainable%: 0.02%
```

**优点**：少训练参数、原模型不动、可合并。

### QLoRA

LoRA + 4-bit 量化基础模型：

```python
from transformers import BitsAndBytesConfig

bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.float16,
)
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3-8B",
    quantization_config=bnb_config,
)
# 套 LoRA
```

65B 模型可在 48GB GPU 上微调。

### Adapter Tuning

中间插入小型网络：

```python
class Adapter(nn.Module):
    def __init__(self, dim, bottleneck=64):
        super().__init__()
        self.down = nn.Linear(dim, bottleneck)
        self.up = nn.Linear(bottleneck, dim)

    def forward(self, x):
        return x + self.up(F.relu(self.down(x)))
```

### Prefix Tuning

在 K/V 前拼接可训前缀。

### Prompt Tuning

仅学软 token embedding。

### IA³

低秩向量缩放激活：

```python
class IA3(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.l = nn.Parameter(torch.ones(dim))

    def forward(self, x):
        return x * self.l
```

### 对比

| 方法 | 参数量 | 性能 |
|------|--------|------|
| Full FT | 100% | **基线** |
| Adapter | 1-5% | 95-99% |
| Prefix | 0.1-1% | 95-99% |
| Prompt | 0.01% | 90-95% |
| **LoRA** | 0.1-5% | **99%** |
| QLoRA | 0.1-5% + 量化 | 95-98% |

## 13.6 RLHF (Reinforcement Learning from Human Feedback)

### 三阶段

```
1. SFT: 预训练模型 + 指令数据 → SFT 模型
2. RM: 人类排序数据 → 奖励模型
3. PPO: SFT 模型 + RM 信号 → RLHF 模型
```

### 完整流程

```python
# 1. SFT
from trl import SFTTrainer
sft_trainer = SFTTrainer(model=base_model, train_dataset=sft_data, ...)
sft_trainer.train()

# 2. Reward Model
from trl import RewardTrainer
rm_trainer = RewardTrainer(model=rm_model, train_dataset=rm_data, ...)
rm_trainer.train()

# 3. PPO
from trl import PPOTrainer, PPOConfig
ppo_config = PPOConfig(...)
ppo_trainer = PPOTrainer(config=ppo_config, model=sft_model, ref_model=ref_model, ...)
ppo_trainer.train()
```

### DPO (Direct Preference Optimization)

跳过奖励模型：

$$
L_{\text{DPO}} = -\log \sigma\left(\beta \log \frac{\pi_\theta(y_w | x)}{\pi_{\text{ref}}(y_w | x)} - \beta \log \frac{\pi_\theta(y_l | x)}{\pi_{\text{ref}}(y_l | x)}\right)
$$

- $y_w$：优选响应
- $y_l$：劣势响应

```python
from trl import DPOTrainer, DPOConfig

config = DPOConfig(beta=0.1, ...)
trainer = DPOTrainer(model, ref_model, train_dataset=dpo_data, args=config)
trainer.train()
```

**优点**：稳定、简单、无需 RM。

### GRPO

## 13.7 迁移学习 (Transfer Learning)

### 思路

源域大数据 → 目标域小数据。

### 场景

- 大语种 → 小语种

5. 渐进解冻

## 13.8 多任务学习

### 共享 Backbone

```python
class MultiTaskModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.backbone = SharedBackbone()
        self.task1_head = HeadA()
        self.task2_head = HeadB()

    def forward(self, x, task_id):
        feat = self.backbone(x)
        if task_id == 0:
            return self.task1_head(feat)
        else:
            return self.task2_head(feat)

loss = sum(task_losses)
```

## 13.9 持续学习 (Continual Learning)

### 问题

- **灾难性遗忘**：学新任务忘旧任务
- 数据 / 计算限制

### 方法

#### Replay

保留旧数据。

#### EWC (Elastic Weight Consolidation)

对重要参数加正则：

$$
L = L_{\text{new}} + \lambda \sum_i F_i (\theta_i - \theta_i^*)^2
$$

#### LoRA / Adapter

冻结基础模型，加新模块。

#### Progressive Networks

新任务加新列。
