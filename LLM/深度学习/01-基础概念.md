# 01. 基础概念

## 1.1 深度学习定义

深度学习使用**多层神经网络**自动学习数据的多层次抽象表征，模型参数以梯度下降方式端到端训练。

```
数据 (像素/词/...) 
    ↓
层 1: 低层特征 (边缘、词向量)
    ↓
层 2: 中层特征 (纹理、词组)
    ↓
层 3: 高层特征 (物体部件、语义)
    ↓
层 4: 任务输出 (分类、回归、生成)
```

## 1.2 为什么深

### 层次化表征

深度网络能学到从低级到高级的层次化特征。

以图像为例：

```
输入像素
  → 边缘检测
    → 纹理
      → 部件（眼睛、鼻子）
        → 物体（人脸）
```

### 函数复杂度

通用数感知网络可证明：足够宽 + 1 层可逼近任意函数。但**深度更经济**：用更少参数逼近更复杂函数。

### 数据效率

深度网络层次化共享特征 → 数据效率高。

## 1.3 关键术语

| 术语 | 含义 |
|------|------|
| **神经元 (Neuron)** | 仿生单元，输出 = 激活函数(W·x + b) |
| **层 (Layers)** | 神经元的集合 |
| **输入层** | 接收原始数据 |
| **隐藏层** | 中间层 |
| **输出层** | 产生预测 |
| **前馈 (Feed-forward)** | 信息单向流动 |
| **权重 (Weights)** | 学习参数 W |
| **偏置 (Bias)** | 学习参数 b |
| **激活函数 (Activation)** | 引入非线性 |
| **损失函数 (Loss)** | 衡量预测误差 |
| **梯度 (Gradient)** | 损失对参数的导数 |
| **学习率 (LR)** | 参数更新步长 |
| **Epoch** | 全量数据过一遍 |
| **Batch** | 一次梯度更新的样本子集 |
| **Iteration / Step** | 一次参数更新 |
| **推理 (Inference)** | 用模型预测 |

## 1.4 与传统 ML 区别

| 维度 | 传统 ML | 深度学习 |

## 1.5 监督学习范式

### 训练流程

```
1. 数据准备 (X, y)
2. 模型定义 (网络结构)
3. 损失函数 (L(y, y_pred))
4. 优化器选择 (SGD/Adam)
5. 训练循环:
   for epoch:
       for batch:
           前向: y_pred = model(X)
           损失: L = loss(y_pred, y)
           反向: grads = backward(L)
           更新: params -= lr * grads
6. 评估 / 部署
```

### 损失驱动学习

深度学习是**梯度下降 + 反向传播**驱动的：

$$
\theta^{(n+1)} = \theta^{(n)} - \eta \nabla_\theta L(\theta)
$$

## 1.8 批训练 (Batching)

### 概念

把数据集分成若干 batch，每次迭代更新用一批：

```
数据: [x1, x2, ..., xN]
Batch 1: x1, ..., x32
Batch 2: x33, ..., x64
...
```

### Batch Size 选择

| Batch Size | 效果 |
|------------|------|
| 1 (SGD) | 噪声大、泛化好、慢 |
| 中 (32-256) | 平衡 |
| 大 (1K-64K) | 稳定、快、需要大显存 |

### 术语

- **mini-batch**：常用 batch size
- **full-batch**：N = batch size
- **online (SGD)**：batch = 1

## 1.9 Epoch 与 Step

- **Epoch**：全部数据过一遍 = N / batch_size 个 step
- **Step / Iteration**：一次参数更新

```python
for epoch in range(n_epochs):
    for X_batch, y_batch in dataloader:
        # 一次 step
        y_pred = model(X_batch)
        loss = criterion(y_pred, y_batch)
        loss.backward()
        optimizer.step()
```

## 1.10 学习率

### 重要性

学习率是深度学习**最重要的超参**：

- 太大 → 不收敛 / 震荡
- 太小 → 慢 / 卡在局部最优
- 适中 → 平滑下降

### 学习率衰减

```python
# 指数衰减
scheduler = torch.optim.lr_scheduler.ExponentialLR(optimizer, gamma=0.95)

# Cosine 衰减
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs)

# Warmup + Cosine
scheduler = torch.optim.lr_scheduler.LambdaLR(
    optimizer, lambda step: min((step+1)/warmup, 0.5*(1+cos((step-warmup)/(total-warmup)*pi)))
)
```

## 1.11 梯度消失与爆炸

### 现象

- **梯度消失**：梯度 → 0，浅层参数不更新
- **梯度爆炸**：梯度 → ∞，参数震荡

### 原因

反向传播链式法则：

$$
\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial a_n} \prod_i \frac{\partial a_i}{\partial a_{i-1}} \frac{\partial a_{i-1}}{\partial W_1}
$$

如果 $|w| > 1$ 链上 → 指数爆炸
如果 $|w| < 1$ 链上 → 指数消失

### 解决

- 适当的激活函数 (ReLU, GELU)
- 权重初始化 (He, Xavier)
- BatchNorm / LayerNorm
- 残差连接 (ResNet)
- 梯度裁剪 (Gradient Clipping)

## 1.13 欠拟合 vs 过拟合

### 诊断

| 现象 | 训练集 | 验证集 | 原因 |
|------|--------|--------|------|
| 欠拟合 | 差 | 差 | 模型简单 / 训练不足 |
| 过拟合 | **好** | 差 | 模型复杂 / 数据不足 / 训练过头 |
| 理想 | 好 | **好** | - |

### 解决

**欠拟合**：加层、加神经元、改架构、加特征、训练更久
**过拟合**：加数据、增强、正则化、降复杂度、Dropout、Early Stop

详见 [07-正则化与泛化](07-正则化与泛化.md)。

## 1.15 常见误区

### 数据

- ❌ 训练前忘了打乱数据
- ❌ 测试集参与了训练
- ❌ 用未来信息 (look-ahead)

### 模型

- ❌ 网络过大 / 数据过小
- ❌ 没用正则化
- ❌ 激活函数不当

### 训练

- ❌ 学习率未调
- ❌ 不做 Early Stopping
- ❌ 训练时间不足 / 过长

### 部署

- ❌ 训练 / 推理预处理不一致
- ❌ 不考虑推理延迟
- ❌ 模型太大无法部署

## 1.16 关键公式

### 前向传播

$$
a^{(l)} = \sigma(W^{(l)} a^{(l-1)} + b^{(l)})
$$

### 损失

$$
L = \frac{1}{N} \sum_{i} L_i(\hat{y}_i, y_i)
$$

### 反向传播

$$
\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial a^{(L)}} \prod_{k=l+1}^{L} \frac{\partial a^{(k)}}{\partial a^{(k-1)}} \cdot \frac{\partial a^{(l)}}{\partial W^{(l)}}
$$

### 梯度更新

$$
W^{(l)} \leftarrow W^{(l)} - \eta \frac{\partial L}{\partial W^{(l)}}
$$
