## 16.5 显著性图 (Saliency)

### Vanilla Gradient

$$
\text{saliency} = \left| \frac{\partial y^c}{\partial x} \right|
$$

```python
x = torch.randn(1, 3, 224, 224, requires_grad=True)
y = model(x)
y[0, class_idx].backward()
saliency = x.grad.abs().max(dim=1)[0]
```

### SmoothGrad

加噪平均梯度：

```python
def smooth_grad(model, x, n=50, std=0.15):
    grads = []
    for _ in range(n):
        x_noisy = x + std * torch.randn_like(x)
        x_noisy.requires_grad_(True)
        y = model(x_noisy)
        y[0, class_idx].backward()
        grads.append(x_noisy.grad.abs())
    return torch.stack(grads).mean(0)
```

### Integrated Gradients

沿路径积分：

$$
\text{IG}_i(x) = (x_i - x_i') \int_0^1 \frac{\partial F(x' + \alpha(x - x'))}{\partial x_i} d\alpha
$$

```python
from captum.attr import IntegratedGradients

ig = IntegratedGradients(model)
attribution = ig.attribute(x, target=class_idx)
```

## 16.6 Grad-CAM / Grad-CAM++

### 思想

梯度加权的类激活图：

$$
L_{\text{Grad-CAM}}^c = \text{ReLU}\left(\sum_k \alpha_k^c A^k\right)
$$

$$
\alpha_k^c = \frac{1}{Z}\sum_{i,j} \frac{\partial y^c}{\partial A_{ij}^k}
$$

```python
class GradCAM:
    def __init__(self, model, target_layer):
        self.model = model
        self.target_layer = target_layer
        self.activations = None
        self.gradients = None
        target_layer.register_forward_hook(self.save_activation)
        target_layer.register_full_backward_hook(self.save_gradient)

    def save_activation(self, module, input, output):
        self.activations = output

    def save_gradient(self, module, grad_input, grad_output):
        self.gradients = grad_output[0]

    def __call__(self, x, class_idx):
        self.model.zero_grad()
        output = self.model(x)
        output[0, class_idx].backward()

        weights = self.gradients.mean(dim=[2, 3], keepdim=True)
        cam = (weights * self.activations).sum(dim=1, keepdim=True)
        cam = F.relu(cam)

        # 上采样到输入尺寸
        cam = F.interpolate(cam, size=x.shape[2:], mode='bilinear')
        return cam.squeeze().detach().cpu().numpy()
```

## 16.12 不确定性估计

### MC Dropout

```python
def mc_dropout_predict(model, x, n=20):
    model.train()  # 保持 dropout
    preds = torch.stack([model(x) for _ in range(n)])
    return preds.mean(0), preds.std(0)  # mean, uncertainty
```
