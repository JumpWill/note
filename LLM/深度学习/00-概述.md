# 深度学习总览

## 什么是深度学习

深度学习 (Deep Learning, DL) 是机器学习的一个分支，使用**多层神经网络**自动学习数据的层次化表征，无需手工特征工程。

```
传统机器学习:
数据 → [人工特征工程] → [分类器] → 输出

深度学习:
数据 → [神经网络多层自动提取特征 + 分类] → 输出
```

关键概念：
- **深度**：多层（10-1000+ 层）网络
- **表示学习**：模型自动学表征
- **端到端**：从原始输入到最终输出

## 发展历史

| 时期 | 关键事件 |
|------|----------|
| 1940s | McCulloch-Pitts 神经元 |
| 1958 | Perceptron (Rosenblatt) |
| 1969 | Perceptron 局限 (Minsky) |
| 1986 | BP 算法 (Rumelhart) |
| 1989 | CNN (LeNet, LeCun) |
| 2006 | Deep Belief Nets (Hinton) |
| 2012 | AlexNet (ImageNet) |
| 2014 | GAN / VGG / Inception |
| 2015 | ResNet / BatchNorm |
| 2017 | Transformer |
| 2018 | BERT / GPT-1 |
| 2020 | GPT-3 / Vision Transformer |
| 2022 | Stable Diffusion / ChatGPT |
| 2023 | GPT-4 / Multimodal |
| 2024 | Sora / Llama 3 / 多模态融合 |

## 与传统 ML 的对比

| 维度 | 传统 ML | 深度学习 |
|------|--------|----------|
| 特征工程 | 手工 | **自动** |
| 数据需求 | 万级 | **百万+** |
| 算力 | CPU 即可 | **GPU/TPU** |
| 解释性 | **强** | 弱 |
| 调参 | 简单 | 复杂 |
| 小数据 | **强** | 弱 |
| 大数据 | 中 | **强** |
| 表格数据 | 强 | 中 |
| 图像/语音/文本 | 弱 | **强** |
