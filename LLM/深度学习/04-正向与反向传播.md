# 04. 正向与反向传播

正向传播 (Forward) 计算预测，反向传播 (Backward) 计算梯度。深度学习自动化的核心。

## 4.1 正向传播 (Forward Pass)

### 流程

输入 $x$ → 逐层计算 → 输出 $\hat{y}$

```
x → h_1 = σ(W_1 x + b_1) → h_2 = σ(W_2 h_1 + b_2) → ... → ŷ
```

### 数学

$$
h^{(l)} = f^{(l)}(W^{(l)} h^{(l-1)} + b^{(l)})
$$

### PyTorch

```python
model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 10),
)
x = torch.randn(32, 784)
y_pred = model(x)  # 正向
```

### 内存占用

保存每层的输入（或激活）以备反向使用：

- Batch 大、序列长 → OOM 风险
- 解决：**Gradient Checkpointing**（见 [17](17-训练技巧与调优.md)）

## 4.2 损失函数

正向传播结束后算损失：

$$
L = \frac{1}{N}\sum_{i=1}^{N} \ell(y_i, \hat{y}_i)
$$

```python
criterion = nn.CrossEntropyLoss()
loss = criterion(y_pred, y_true)
```

详见 [05-损失函数](05-损失函数.md)。

## 4.3 反向传播 (Backward Pass)

### 数学基础：链式法则

$$
\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial h^{(l)}} \cdot \frac{\partial h^{(l)}}{\partial W^{(l)}}
$$

从输出层向输入层反向累积梯度。

### 流程

```
loss → ∂L/∂ŷ → ∂L/∂h_{L-1} → ... → ∂L/∂h_1 → ∂L/∂W_1, ∂L/∂b_1
```

每层只需计算：

- 前向的导数（局部梯度）
- 反向传过来的梯度

### 反向传播通用公式

设 $z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$，$a^{(l)} = \sigma(z^{(l)})$。

输出层：

$$
\delta^{(L)} = \nabla_{a^{(L)}} L \odot \sigma'(z^{(L)})
$$

隐藏层：

$$
\delta^{(l)} = ((W^{(l+1)})^T \delta^{(l+1)}) \odot \sigma'(z^{(l)})
$$

梯度：

$$
\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T, \quad
\frac{\partial L}{\partial b^{(l)}} = \delta^{(l)}
$$

## 4.4 自动微分 (Autograd)

现代框架**自动**构建计算图并反向求导：

### PyTorch Autograd

```python
import torch

x = torch.randn(2, 3, requires_grad=True)
W = torch.randn(3, 5, requires_grad=True)

# 前向（构建计算图）
y = x @ W
loss = y.sum()

# 反向（自动求导）
loss.backward()

# 梯度
print(W.grad)
print(x.grad)
```

### 计算图

节点：tensor，边：操作

```
x ─┐
   ├──> matmul ─> y ─> sum ─> loss
W ─┘
```

### backward() 限制

- 标量 → 梯度（必须先 sum 或 mean）
- 非标量 → 加 `gradient` 参数

```python
y = model(x)
y.backward(torch.ones_like(y))  # 或 loss.backward()
```

### 关闭 autograd

```python
with torch.no_grad():
    y_pred = model(x)

# 或
model.eval()
```

## 4.5 计算图类型

### 静态图 (Static Graph)

- 定义图 → 编译 → 运行
- 优化机会多
- TensorFlow 1.x、Theano
- 调试难

### 动态图 (Dynamic Graph)

- 运行时构建图
- Pythonic、易调试
- PyTorch、TensorFlow 2.x (Eager)、JAX
- 现代默认

## 4.6 计算图优化

### Operator Fusion

合并小操作减少内存访问：

```python
# 不优化
a = x + 1
b = a * 2
c = b - 1

# 融合
c = (x + 1) * 2 - 1  # 等价但更高效
```

框架支持：PyTorch 2.0+ `torch.compile()`、TensorRT。

### Gradient Checkpointing

用时间换空间：

```python
from torch.utils.checkpoint import checkpoint

def forward(self, x):
    # 只保存部分激活
    x = checkpoint(self.layer1, x)
    x = checkpoint(self.layer2, x)
    return x
```

显存省 O(N) → O(√N)，计算略增。

### 混合精度

```python
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
with autocast():
    y_pred = model(x)
    loss = criterion(y_pred, y)

scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()
```

## 4.7 梯度消失与爆炸

详见 [01-基础概念](01-基础概念.md) §1.11。

### 监控

```python
# 检查梯度范数
for name, param in model.named_parameters():
    if param.grad is not None:
        grad_norm = param.grad.norm().item()
        if grad_norm > 100 or grad_norm < 1e-6:
            print(f"{name}: grad_norm = {grad_norm}")
```

### 解决

| 方法 | 说明 |
|------|------|
| **梯度裁剪** | `torch.nn.utils.clip_grad_norm_` |
| **合适的初始化** | He / Xavier |
| **合适的激活** | ReLU / GELU (避免 Sigmoid/Tanh) |
| **BN / LN** | 归一化输入 |
| **残差连接** | 让梯度短路 |
| **学习率 warmup** | 慢慢加大学习率 |

### 梯度裁剪

```python
# L2 裁剪
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

# 按值裁剪
torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=0.5)
```

## 4.8 检查梯度

### 数值梯度 vs 解析梯度

```python
def numerical_gradient(f, x, eps=1e-5):
    return (f(x + eps) - f(x - eps)) / (2 * eps)

# 验证解析梯度
analytic_grad = x.grad
numeric_grad = numerical_gradient(lambda x: (x * W).sum(), x)
assert torch.allclose(analytic_grad, numeric_grad, atol=1e-5)
```

### 检测 NaN / Inf

```python
for name, param in model.named_parameters():
    if torch.isnan(param.grad).any() or torch.isinf(param.grad).any():
        print(f"⚠️ NaN/Inf in {name}.grad")
```

## 4.9 自定义 autograd

```python
class MyFunction(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)
        return x ** 2

    @staticmethod
    def backward(ctx, grad_output):
        x, = ctx.saved_tensors
        return grad_output * 2 * x

# 使用
y = MyFunction.apply(x)
y.sum().backward()
```

## 4.10 完整示例

```python
import torch
import torch.nn as nn
import torch.optim as optim

# 模型
model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 10),
)

# 数据
x = torch.randn(32, 784)
y = torch.randint(0, 10, (32,))

# 前向
y_pred = model(x)
loss = nn.CrossEntropyLoss()(y_pred, y)

# 反向
loss.backward()

# 检查梯度
for name, param in model.named_parameters():
    print(f"{name}: grad_norm = {param.grad.norm():.4f}")

# 更新
optimizer = optim.SGD(model.parameters(), lr=0.01)
optimizer.step()
optimizer.zero_grad()
```

## 4.11 自定义训练循环

```python
def train_step(model, x, y, criterion, optimizer):
    model.train()

    # 前向
    y_pred = model(x)
    loss = criterion(y_pred, y)

    # 反向
    optimizer.zero_grad()
    loss.backward()

    # 梯度裁剪
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

    # 更新
    optimizer.step()

    return loss.item()

# 多 epoch
for epoch in range(n_epochs):
    for x_batch, y_batch in dataloader:
        loss = train_step(model, x_batch, y_batch, criterion, optimizer)
```

## 4.15 常见错误

| 错误 | 表现 | 解决 |
|------|------|------|
| **忘了 zero_grad** | 梯度累积 | `optimizer.zero_grad()` |
| **Backward 在 no_grad 内** | 报错 | 移除 `torch.no_grad()` |
| **inplace 操作** | 报错 | `x = x + 1` 而非 `x += 1` |
| **输入需要梯度** | 报错 | `input.requires_grad=False` |
| **叶子节点** | 改不到 | 用 Parameter |
