## 17.2 学习率

### 重要性

**最关键超参**。学习率太大不收敛；太小学不到；适中才平滑。

### LR Range Test

```python
# Leslie Smith
def lr_range_test(model, train_loader, criterion, optimizer,
                  start_lr=1e-7, end_lr=1, n_steps=200):
    model.train()
    lrs = np.logspace(np.log10(start_lr), np.log10(end_lr), n_steps)
    losses = []

    for i, (x, y) in enumerate(train_loader):
        if i >= n_steps:
            break

        # 调整 LR
        for pg in optimizer.param_groups:
            pg['lr'] = lrs[i]

        optimizer.zero_grad()
        y_pred = model(x)
        loss = criterion(y_pred, y)
        loss.backward()
        optimizer.step()

        losses.append(loss.item())

    return lrs, losses

# 画图找拐点
plt.plot(lrs, losses)
plt.xscale('log')
plt.xlabel('LR')
plt.ylabel('Loss')
plt.show()
```

### 调度策略

```python
# 1. Cosine + Warmup (LLM 标准)
import math
def lr_schedule(step, warmup, total, base_lr, min_lr=0):
    if step < warmup:
        return base_lr * step / warmup
    progress = (step - warmup) / (total - warmup)
    return min_lr + 0.5 * (base_lr - min_lr) * (1 + math.cos(math.pi * progress))

# 2. Linear Warmup + Linear Decay
# 3. Step Decay
# 4. Plateau Decay (ReduceLROnPlateau)
```

### 大 batch 法则

```python
# Linear Scaling Rule
lr_new = lr_base * batch_new / batch_base

# sqrt scaling (更稳)
lr_new = lr_base * (batch_new / batch_base) ** 0.5
```

## 17.5 Normalization

### BatchNorm

- CNN 默认
- 训练时用 batch 统计，推理用 running mean/var
- ❌ batch 小 (< 8) 差

### LayerNorm

- Transformer 默认
- 与 batch 无关
- 单样本可计算

### RMSNorm

- LN 简化版，LLaMA 用
- 少算一个均值

```python
class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))
        self.eps = eps

    def forward(self, x):
        rms = x.pow(2).mean(-1, keepdim=True).sqrt() + self.eps
        return x / rms * self.weight
```

## 17.8 训练技巧

### EMA (Exponential Moving Average)

```python
class EMA:
    def __init__(self, model, decay=0.999):
        self.decay = decay
        self.shadow = {k: v.clone().detach() for k, v in model.state_dict().items()}

    def update(self, model):
        for k, v in model.state_dict().items():
            self.shadow[k] = self.decay * self.shadow[k] + (1 - self.decay) * v

    def apply_to(self, model):
        model.load_state_dict(self.shadow)
```

提升泛化（Vision Transformer 默认用）。

### Gradient Checkpointing

显存省 O(√N)，计算略增：

```python
from torch.utils.checkpoint import checkpoint

class Block(nn.Module):
    def forward(self, x):
        x = checkpoint(self.subblock1, x, use_reentrant=False)
        x = checkpoint(self.subblock2, x, use_reentrant=False)
        return x
```

LLM 训练必备。

### Stochastic Depth

```python
class StochasticDepth(nn.Module):
    def __init__(self, p=0.1):
        super().__init__()
        self.p = p

    def forward(self, x):
        if self.training and torch.rand(1) < self.p:
            return x  # skip
        return x
```

ResNet / Swin Transformer 用。

## 17.10 损失工程

### Loss 形状

```python
# 加权 (类别不平衡)
weights = torch.tensor([1.0, 5.0, 1.0])

# Focal Loss (难样本)
def focal_loss(logits, targets, gamma=2):
    ce = F.cross_entropy(logits, targets, reduction='none')
    pt = torch.exp(-ce)
    return ((1 - pt) ** gamma * ce).mean()
```
