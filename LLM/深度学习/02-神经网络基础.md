# 02. 神经网络基础

## 2.1 神经元

### 生物神经元 vs 人工神经元

```
生物:                              人工:
树突 (输入) →                     x_1   x_2   x_3
        ↓                          ↓     ↓     ↓
细胞体 (加权和)                   w_1   w_2   w_3
        ↓                          ↘   ↓   ↙
轴突 (激活) →                       Σ + b → σ → a
        ↓
突触 (输出)
```

### 数学模型

$$
a = \sigma(W^T x + b) = \sigma\left(\sum_{j=1}^{d} w_j x_j + b\right)
$$

- $x = [x_1, \ldots, x_d]$：输入
- $W = [w_1, \ldots, w_d]$：权重
- $b$：偏置
- $\sigma$：激活函数

## 2.2 感知机 (Perceptron)

最简单的神经网络单元：

$$
a = \text{sign}(W^T x + b)
$$

只能解决**线性可分**问题（XOR 不可解）。

```python
# sklearn 单隐藏层
from sklearn.linear_model import Perceptron
model = Perceptron(max_iter=1000)
model.fit(X_train, y_train)
```

## 2.3 多层感知机 (MLP)

### 结构

```
输入层       隐藏层       隐藏层       输出层
  x_1 ────── h_1 ────── h_1 ────── o_1
  x_2 ────── h_2 ────── h_2 ────── o_2
  x_3 ────── h_3 ────── h_3
              ↓
            激活函数
```

### 数学

$$
\begin{aligned}
h^{(1)} &= \sigma(W^{(1)} x + b^{(1)}) \\
h^{(2)} &= \sigma(W^{(2)} h^{(1)} + b^{(2)}) \\
o &= W^{(3)} h^{(2)} + b^{(3)}
\end{aligned}
$$

### Universal Approximation Theorem

> 一个仅含单个隐藏层（足够宽）的神经网络能以任意精度逼近任意连续函数（在紧集上）。

**但**：宽度指数级增长 → 实际用深度更经济。

## 2.4 PyTorch 实现

### 简单 MLP

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, in_dim, hidden_dim, out_dim, n_layers=3):
        super().__init__()
        layers = []
        prev_dim = in_dim
        for _ in range(n_layers - 1):
            layers.append(nn.Linear(prev_dim, hidden_dim))
            layers.append(nn.ReLU())
            prev_dim = hidden_dim
        layers.append(nn.Linear(prev_dim, out_dim))
        self.net = nn.Sequential(*layers)

    def forward(self, x):
        return self.net(x)

model = MLP(in_dim=784, hidden_dim=256, out_dim=10, n_layers=3)
```

### PyTorch 关键概念

#### nn.Module

所有神经网络的基类：

```python
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer = nn.Linear(10, 5)

    def forward(self, x):
        return self.layer(x)
```

#### Parameter vs Buffer

- `nn.Parameter`：会被优化器更新
- `register_buffer`：不会被更新（如 BN 的 running mean）

#### nn.Sequential

顺序容器：

```python
model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 10),
)
```

### 参数初始化

```python
import torch.nn.init as init

# Xavier / Glorot
init.xavier_uniform_(layer.weight)
init.xavier_normal_(layer.weight)

# He / Kaiming (ReLU 友好)
init.kaiming_uniform_(layer.weight, nonlinearity='relu')
init.kaiming_normal_(layer.weight, nonlinearity='relu')

# 偏置
init.zeros_(layer.bias)
```

## 2.5 网络结构

### 前馈网络 (FFN)

$$
y = f(W_L \cdots \sigma(W_2 \sigma(W_1 x + b_1) + b_2) \cdots + b_L)
$$

- 信息单向流动
- 无循环

### 卷积网络 (CNN)

卷积 + 池化：

```
Conv → ReLU → Pool
Conv → ReLU → Pool
FC → ReLU → FC
```

详见 [08-CNN](08-CNN-卷积神经网络.md)。

### 循环网络 (RNN)

$$
h_t = f(W_x x_t + W_h h_{t-1} + b)
$$

详见 [09-RNN](09-RNN与序列模型.md)。

### Transformer

Self-Attention + FFN：

```
Multi-Head Attention → Add & Norm
FFN → Add & Norm
```

详见 [10-Transformer](10-Transformer详解.md)。

## 2.7 张量形状约定

### 图像

- BCHW: `(batch, channels, height, width)` - PyTorch
- BHWC: `(batch, height, width, channels)` - TensorFlow

```python
# 1 batch, 3 channels, 32x32 image
img = torch.randn(1, 3, 32, 32)
```

### 文本

- `(B, L)`：B=batch, L=sequence length
- `(B, L, D)`：含嵌入

```python
tokens = torch.randint(0, 10000, (32, 50))     # 32 句，128 tokens
embedding = torch.randn(32, 50, 768)             # 32 句，768 dim
```

### 时间序列

类似文本 + 1=时间。

## 2.8 参数计算

### Linear 层

$$
\text{params} = in \times out + out
$$

### Conv 层

$$
\text{params} = k \times k \times c_{in} \times c_{out} + c_{out}
$$

### Transformer Block

$$
\text{params} \approx 4 d^2 + 4 d \cdot d_{ff} + 2 d \cdot d_{ff}
$$

$d$ = hidden dim, $d_{ff}$ = FFN dim

## 2.10 模型尺寸计算

```python
def count_params(model):
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

print(f"参数量: {count_params(model):,}")
print(f"约 {count_params(model) / 1e6:.1f}M")
```

## 2.11 完整训练示例

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset

# 数据 (示例)
X_train = torch.randn(1000, 784)
y_train = torch.randint(0, 10, (1000,))
train_dataset = TensorDataset(X_train, y_train)
train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)

# 模型
model = MLP(784, 256, 10)
print(f"参数量: {count_params(model):,}")

# 损失 + 优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=1e-3)

# 训练
for epoch in range(10):
    model.train()
    total_loss = 0
    for X_batch, y_batch in train_loader:
        # 前向
        y_pred = model(X_batch)
        loss = criterion(y_pred, y_batch)

        # 反向
        optimizer.zero_grad()
        loss.backward()

        # 更新
        optimizer.step()

        total_loss += loss.item()

    print(f"Epoch {epoch+1}: Loss = {total_loss / len(train_loader):.4f}")

# 评估
model.eval()
with torch.no_grad():
    y_pred = model(X_train)
    acc = (y_pred.argmax(1) == y_train).float().mean()
    print(f"Train Acc = {acc:.4f}")
```

## 2.12 网络设计原则

1. **从简到繁**：先简单，再加复杂
2. **可分离**：先 downsample，再 process
3. **跨层短路**：ResNet 残差
4. **Normalize**：BN / LN
6. **通道翻倍 + 分辨 1/2**：经典设计
7. **末端 1x1 Conv**：降维
8. **末端 GAP**：替代 FC

## 2.13 优缺点

### 优点

- 自动特征工程
- 处理高维 / 非结构化数据
- 表达力强
- 大数据下性能优
- GPU 加速

### 缺点

- 数据需求大
- 算力需求高
- 调参复杂
- 难解释
- 小数据易过拟合
- 部署复杂

## 2.14 何时用神经网络 vs 经典 ML

详见 [机器学习/19-选型](../机器学习/19-选型速查与数据集.md)。

### 用神经网络

- 图像、语音、文本
- 大数据 (> 100K)
- 复杂非线性
- 端到端学习

### 用经典 ML

- 表格数据
- 小数据 (< 10K)
- 可解释性优先
- 资源受限
