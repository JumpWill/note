# 知识库（可私有化）

Confluence / Notion / 各种 Wiki 替代品。覆盖企业文档协作、知识沉淀、共享笔记、团队 Wiki、本地优先笔记。

## 一、Notion 替代思路

Notion 之所以受欢迎，主要三点：

1. **Block 模型**：每段（文本/列表/图片/页面）都是 block，灵活组合
2. **Database**：表格 + 多视图 + Filter/Sort
3. **AI 加持**：自动摘要 / 自动分类

私有化替代品的目标：

- Local-first / 数据自托管
- 类似 Block 数据库的体验
- 可自部署或自同步

## 二、AppFlowy

### 1. 定位

- 国产 / 国际开源，Rust + Flutter
- 100% Notion 替代定位
- 端到端可自部署
- AI 一等公民

### 2. 架构

```text
┌────────────────────────────────────┐
│ Client (Flutter Desktop / Mobile /  │
│           Web)                      │
└─────────────────┬──────────────────┘
                  │ WebSocket / HTTP
                  ▼
┌────────────────────────────────────┐
│ AppFlowy Server (Rust + Actix)      │
│   - Document sync (Yrs CRDT)        │
│   - Workspace / Auth / Payment      │
└──────┬───────────────┬─────────────┘
       │               │
       ▼               ▼
 PostgreSQL         Object Storage
                    (Local / S3 / MinIO)
```

- 基于 Yjs CRDT，客户端实时同步
- 后台只负责存储 + 协作 + 备份

### 3. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| Block 模型 | 完整 / 嵌套 |
| Database | Grid / Board / Calendar |
| Page 嵌套 | 无限深度 |
| Markdown 双向 | 导入 / 导出 |
| 富文本 | H1–H3 / Bold / Code 等 |
| Local-first | 数据优先本地，同步靠 cloud |
| E2EE | 中 |

### 4. 部署

```bash
docker compose up -d
```

需要 PostgreSQL + Redis + MinIO（默认配置）。

### 5. AI

AppFlowy AI 自托管：

- 接入 OpenAI / Claude / 自定义 LLM
- 工作流 / 模板 / 自动化
- RAG 集成业务知识

### 6. 适合场景

- 团队 Notion 替代
- 看重本地优先 + 自部署
- Block 化创作

## 三、SiYuan（思源笔记）

### 1. 定位

- 国产开源（个人 / 商业双版本）
- 块级（block） + 双链 + 数据库
- Notion / Obsidian / Logseq 风格综合
- 完全本地优先，自同步（V3）支持 P2P 同步

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| Block 编辑器 | 内容块嵌套 |
| 双链 | Block 间引用 |
| 反向链接 | 自动汇总 |
| YAML 标签 | 类似 Obsidian |
| Database | 表格 / 看板 |
| PDF 阅读 | 内嵌批注 |
| 闪卡 / 看板 / 时序图 / 流程图 | 全能 |
| 块属性面板 | 灵活 |

### 3. 存储模型

```text
工作空间
   ├── notebooks/
   ├── documents/
   ├── blocks/
   ├── assets/
   └── database (.sqlite + WAL)
```

- 默认：本地 SQLite
- 自部署：云端方案（V3）

### 4. 部署

| 模式 | 含义 |
| ---- | ---- |
| **本地** | 桌面端 / 移动端 / Docker |
| **自同步**（V3+） | 云端同步（自托管） |
| **P2P 同步** | 端对端加密同步 |

### 5. 与 Obsidian 对比

| 维度 | SiYuan | Obsidian |
| ---- | ------ | -------- |
| 自部署同步 | ✔ V3 | 商业 Obsidian Sync 或 iCloud / Git |
| 数据库 | ✔ | ❌ / Limited |
| Database Views | Grid / Kanban | ❌ |
| 块引用 | ✔ | ✔ |
| AI | ✔（思源助手） | Plugin |
| 完全离线 | ✔ | ✔ |

## 四、AFFiNE

### 1. 定位

- 开源 Notion + Miro 综合
- Block 模型 + 实时协作
- 多模式编辑：Page / Database / Whiteboard
- Toeverything 团队维护
- 端对端可本地 / 同步

### 2. 架构

```text
┌────────────────────────────────────┐
│ AFFiNE Client (Electron / Web)     │
└─────────────────┬──────────────────┘
                  │ 自定义 Protocol
                  ▼
┌────────────────────────────────────┐
│ AFFiNE Server (NestJS)              │
│   - doc-sync (Octobase)            │
│   - workspace / user / permissions  │
└──────┬───────────────┬─────────────┘
       │               │
       ▼               ▼
 PostgreSQL        S3 / MinIO
```

- Novi / BlockSuite（编辑器内核）
- 数据同步基于 Octobase CRDT

### 3. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| Block | Notion 级嵌套 |
| Database | 多视图 |
| Whiteboard | Miro / Excalidraw 风格 |
| Local-first | ✔ |
| AI | Native AI modules |
| 自托管 | ✔ |

### 4. 部署

```bash
docker run -d --name affine \
  -e DATABASE_URL=postgres://... \
  affine
```

### 5. 适合

- 想要 Notion + Miro 一体
- 本地优先 + 跨设备同步

## 五、Outline

### 1. 定位

- 团队知识库（Notion 风格）
- React + Node.js + Postgres
- 商业（SaaS）+ 自部署 License

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| Markdown 编辑 | 强，富文本 + Markdown |
| Collection | 嵌套文档 |
| Search | Postgres 全文检索 |
| 权限 | 共享 / 私有 / 团队 |
| Slack import | 保留 Slack 历史 |
| API | 公开 API |

### 3. 部署

```bash
docker run outlinewiki/outline:0.78 \
  --name outline
```

需要：

- PostgreSQL
- Redis
- Object Storage (S3 / MinIO)
- OIDC / Slack / Google login

### 4. 与 Notion 对比

- Outline：更紧凑，更适合团队文档 / Wiki
- Notion：Block 数据库能力更广

## 十四、最佳实践

- **数据自托管**：本地优先 + 加密同步
- **备份**：日记 / 周记 / 项目文档双重备份
- **权限**：与 SSO / OIDC 统一
- **协作**：实时多人编辑需要 CRDT
- **AI 能力**：RAG + LLM 必备
- **搜索**：Postgres FTS / Meilisearch / Elasticsearch
- **导出**：避免 vendor lock-in（Markdown 导出）
