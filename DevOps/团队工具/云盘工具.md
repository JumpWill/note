# 云盘工具（可私有化）

企业级 / 个人级文件同步、分享、协作平台。区别于对象存储的"机器存储"，云盘是给"人用"的私有 Google Drive / Dropbox 替代。

## 一、Nextcloud

### 1. 定位

- AGPL v3 开源自部署
- 跨平台同步盘 + Office 协作
- 应用市场 100+ 官方应用
- 既是云盘也是协作平台

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| **文件同步** | Windows / macOS / Linux / iOS / Android |
| **Web 文件管理** | 拖拽、上传、版本、回收站 |
| **Nextcloud Office** | OnlyOffice / Collabora 内嵌编辑 |
| **日历 / 联系人** | CalDAV / CardDAV |
| **邮件** | 集成 / 自部署 |
| **Talk** | 视频会议 + 聊天（基于 WebRTC） |
| **联邦** | 跨实例联邦同步 |
| **AI** | 本地 LLM 助手（Nextcloud Assistant） |
| **应用市场** | 100+ 应用：相册、密码、任务、看板、白板 |

### 3. 架构

```text
┌────────────────────────────────────┐
│ Nextcloud Server (PHP)             │
│   - 路由                            │
│   - WebDAV                          │
│   - OCS / Opendesktop API          │
│   - App 加载                         │
└────┬───────────────────┬───────────┘
     │                   │
     ▼                   ▼
  PostgreSQL /         Object Storage
  MariaDB              (Local FS / S3 / MinIO)
```

- 单一 PHP 应用 + App 扩展
- 数据规模大后可通过 `occ` 命令做 sharding
- 用户管理 / 共享 / 通知全在内部

### 4. 部署

```bash
# Docker
docker run -d --name nextcloud \
  -v /var/nextcloud:/var/www/html \
  -e POSTGRES_HOST=db \
  nextcloud:31
```

也可以：

- LAMP / LNMP
- K8s Helm
- UCS Univention 企业版

### 5. Federation（联邦共享）

```text
nextcloud.example.com  ⇄  partner.example.com
   │ 用户 alice            │ 用户 bob
   └─ 通过联邦 token 交换
```

满足跨组织共享，但都能保持自家域名。

### 6. 文件加密 (E2EE)

应用市场安装 "End-to-End Encryption"：

```text
客户端生成密钥   → server 只看到密文
                  → 上传前加密
                  → 苹果和 web 端支持
```

### 7. 自带 AI

v28+：

```text
Nextcloud Assistant / Local LLM
   ├── 文本生成 / 摘要 / 翻译
   ├── 自带 Ollama 接入
   ├── 与文本、文件深度集成
   └── 完全本地化
```

### 8. 与 Seafile / ownCloud 对比

| 维度 | Nextcloud | Seafile | ownCloud |
| ---- | --------- | ------- | -------- |
| 协作能力 | 强（含 Talk / Office） | 较强（Wiki / Doc） | 中 |
| 客户端 | 全平台 | 全平台（更轻） | 全平台 |
| 数据库 | PG / MariaDB | MySQL/MariaDB | PG |
| Office | Collabora / OnlyOffice | 内置 docx / Wiki | OnlyOffice |
| 性能 | 中 | 较快（C 存储） | 中 |
| AI | 内置 Assistant | ❌ | ❌ |
| 联邦 | ✔ | ✔ | ✔ |
| 许可证 | AGPL v3 | AGPL v3 / Commercial | AGPL v3 / Commercial |

### 9. 典型部署规模

- 个人：单 SSD + PG
- 部门：100 用户 / 几 TB / 单实例 + Redis
- 企业：1000+ 用户 / 多实例 + MinIO 后端

## 二、Seafile

### 1. 定位

- 国产开源（团队在清华起家）
- 多平台同步 + 文档协作
- C 实现底层，性能好
- 自带 Wiki / Doc 协作

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| **Block 同步** | Block-level 增量上传，与 Dropbox 类似 |
| **端到端加密** | Library-level 加密 |
| **Doc / Wiki** | Markdown + 富文本协作 |
| **WebDAV** | 标准协议 |
| **DRM** | 防截屏 + 数字水印（专业版） |
| **多租户** | 多机构场景 |

### 3. 部署

```bash
docker run -d --name seafile \
  -v /seafile-data:/shared \
  -e SEAFILE_ADMIN_EMAIL=admin@org.com \
  -e SEAFILE_ADMIN_PASSWORD=... \
  seafileltd/seafile:11.0
```

### 4. 与 Nextcloud 对比

- 性能更好（特别是大文件）
- 客户端体验更接近 Dropbox
- UI 更"云盘"，而非协作平台

## 三、ownCloud

### 1. 定位

- Nextcloud 的前身
- 同样 AGPL v3 / 商业版
- 与 Nextcloud 互补，更稳但 UI 更老

### 2. 架构

```text
ownCloud Server (PHP)
   ├── WebDAV / OCS
   ├── OAuth2 / OpenID Connect
   └── Storage Backend (Local / S3 / SMB / etc.)
```

### 3. 当前状态

- 由 ownCloud GmbH 维护，更新较慢
- 适合"只需要文件同步，不需要丰富应用"场景
- 商业版（ownCloud Enterprise）含文件生命周期管理

## 四、Cloudreve

### 1. 定位

- 国产开源（Go 实现）
- 支持多云存储后端
- 既能本地，也能聚合 OSS / S3 / OneDrive / GDrive / 坚果云 / 阿里云盘

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| 多云 | S3 / OSS / COS / COS-V5 / OneDrive / GDrive / 阿里云盘 |
| 离线下载 | BT / 磁链 / HTTP / 直连 |
| 视频播放 | 在线转码 / 流式播放 |
| 分享 | 公开 / 私密 / 加密 |
| 用户 / 群组 | 多用户 + 容量配额 |
| 主题 | Web 主题切换 + 移动端 |

### 3. 部署

```bash
docker run -d --name cloudreve \
  -v /cloudreve/data:/cloudreve/data \
  -p 5212:5212 \
  cloudreve/cloudreve:3
```

数据库：MySQL / PostgreSQL / SQL Server / SQLite。

### 4. 适合场景

- 个人 / 工作室，希望聚合多云
- 资源分享站
- 学习 / 离线下载

### 5. 局限

- 不擅长企业协作 / 文件编辑

## 五、MinIO

### 1. 定位

- 高性能 S3 兼容对象存储
- Go 实现
- 不是给"人用"的云盘，但是后台首选

### 2. 核心能力

- 完全 S3 API 兼容
- 纠删码 EC 数据保护
- 多盘、多节点
- 版本 / 生命周期 / Bucket Replication
- KMS / SSO / 审计

### 3. 部署

```bash
docker run -d --name minio \
  -p 9000:9000 -p 9001:9001 \
  -e MINIO_ROOT_USER=admin \
  -e MINIO_ROOT_PASSWORD=... \
  -v /minio/data:/data \
  quay.io/minio/minio server /data --console-address ":9001"
```

集群 / K8s Operator：

```bash
helm repo add minio https://charts.min.io
helm install minio minio/minio
```

### 4. 客户端

- `mc` CLI
- S3 Browser / Cyberduck / WinSCP 等 GUI
- API 完全兼容 AWS S3（boto3 / aws-sdk）

### 5. 适合

- 数据中台 / 数据湖后端
- 文件持久层（替代 Ceph）
- AI/ML 数据集
- 备份 / 灾难恢复

## 六、Garage

### 1. 定位

- 法国 CNRS / Inria 出品
- 轻量级 S3 兼容对象存储
- 适合集群（Write Quorum）

### 2. 特点

- Rust 实现
- 单二进制
- 完全地理分布式
- 适合小型（边缘）部署

### 3. 与 MinIO 对比

| 维度 | Garage | MinIO |
| ---- | ------ | ----- |
| 资源占用 | 极低 | 中等 |
| 大规模 | 适中 | 强 |
| 集群协议 | 自研（CRDT） | Raft |
| 地理分布 | 设计目标 | 需多集群 |
| 适合 | 边缘 / 中小规模 | 万节点 |

## 十、最佳实践

- **存储后端**：业务数据盘 / 对象存储分层
- **加密**：客户端加密 + 服务器端 KMS
- **备份**：定期快照到第二层（如 S3 / 异地）
- **审计**：操作日志走 SIEM
- **大规模**：Nextcloud 用 occ + 多实例 + Redis + MinIO 后端
- **合规**：开启 GDPR / SOC2 审计
