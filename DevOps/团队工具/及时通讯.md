# 及时通讯（可私有化）

Slack / Teams / Discord 替代品。私有 IM / 实时协作 / 端到端加密都覆盖。

## 一、Mattermost

### 1. 定位

- 团队聊天平台（Slack 替代）
- Slack 兼容 API / webhook / bot
- 多客户端（iOS / Android / Desktop / Web）
- 自部署：单二进制 / Docker / K8s
- AGPL v3 / 商业双版本
- 三种部署模式：
  - **Mattermost Free**（Slack 替代）
  - **Mattermost Professional**（付费）
  - **Mattermost Enterprise**（含 LDAP / SAML / Compliance Export）

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| **Channels** | Public / Private / Direct / Group |
| **Threads** | 回复线程 |
| **Calls** | 语音 / 视频通话 (v6+，基于 RTC) |
| **Playbooks** | 流程化协作（v7+） |
| **Boards** | Kanban（自部署） |
| **Agents & Integrations** | Webhook / Slash Command / Bot |
| **AD / LDAP / SAML** | 企业身份集成 |
| **Compliance Export** | 合规导出 |
| **Custom Theme** | 自定义品牌 |
| **Custom Workflow** | 自定义工作流（v8+） |
| **OAuth 2.0** | 第三方 App 接入 |

### 3. 架构

```text
┌──────────────────────────────────────┐
│ Mattermost Server (Go)                │
│   - HTTP REST API                     │
│   - WS (WebSocket)                    │
│   - Plugin Framework                  │
└──────┬───────────┬────────────────────┘
       │           │
       ▼           ▼
  PostgreSQL   File Storage
  （DB）        （Local / S3 / NFS）
```

- 单一 Go 应用，部署简单
- DB 用 PG 也支持 MySQL
- Plugin：Pythons / Go 均可

### 4. 部署

```bash
docker run -d --name mattermost \
  -e MM_USERNAME=admin \
  -e MM_PASSWORD=... \
  -e MM_SQLSETTINGS_DATASOURCE=postgres://... \
  -v /mattermost/data:/mattermost/data \
  mattermost/mattermost-enterprise-edition:9.x
```

K8s Operator：

```bash
helm repo add mattermost https://charts.mattermost.com
helm install mattermost mattermost/mattermost-team-edition
```

### 5. Slack 兼容 / Bot

- Incoming Webhook
- Slash Command
- Outgoing Webhook（v6+ 默认已弃）
- Slack import tool（迁移 Slack 频道到 Mattermost）
- Bot 可用 Matterbot / 自建

```python
from mattermostdriver import Driver
bot = Driver({"url":"http://mm","token":"xxx","login_id":"bot"})
bot.login()
bot.posts.create_post({"channel_id":"abc","message":"hi"})
```

### 6. Calls

v6+ 开始原生支持 calls：

- 1:1 / 小型群通话
- 基于 LiveKit / 默认为自部署 Pion
- 可连 SIP / RTMP

### 7. 集成

- GitHub / GitLab webhook 推送
- Jenkins / Argo
- Prometheus Alertmanager 转发告警
- Mirrors：Jira / Zendesk

### 8. Playbooks（流程化协作）

```text
Playbook: "故障响应"
   Step 1: 通知 on-call
   Step 2: 创建 Zoom / Call
   Step 3: 制定 PR / 修复
   Step 4: 发送事后总结
```

适合 SRE / NOC / 客户支持团队。

### 9. 合规 / 审计

- Audit Log
- Compliance Export（Enterprise）：SIEM / E-Discovery
- Custom retention policy
- Granular permission role

### 10. 与 Rocket.Chat / Element 对比

| 维度 | Mattermost | Rocket.Chat | Element |
| ---- | --------- | ----------- | ------ |
| 协议 | 自有协议 / Bot | Hubot | Matrix |
| 客户端 | 全平台 | 全平台 | 全平台 |
| 联邦 | 支持 Enterprise / 工作空间 | ❌ | ✔（联邦协议） |
| E2EE | 部分（截止 v9） | ❌ | ✔ end-to-end |
| 性能 | 好 | 中 | 中 |
| 视频通话 | 内置 Calls | 第三方 LiveKit | 内置 / Jitsi |
| 适合 | 企业自部署 | 开源社区 / 跨行业 | 隐私 / 跨组织 |

## 二、Element（Matrix）

### 1. 定位

- 基于 Matrix 协议的现代 IM
- 端到端加密（Olm / Megolm）
- 联邦：跨服务器互联互通
- 客户端：Element Web / iOS / Android / Desktop

### 2. Matrix 协议

```text
Synapse / Dendrite (Server)
   │
   ▼
Matrix Federation
   │
   ├── Server A ↔ Server B ↔ Server C
   │
   ▼
Clients (Element / SchildiChat / Nheko / FluffyChat)
```

- 去中心化联邦
- 房间与服务器解耦

### 3. 服务器

| Server | 实现 | 特点 |
| ------ | ---- | ---- |
| **Synapse** | Python / Twisted | 主流，官方推荐 |
| **Dendrite** | Go | 新一代，ReWrite |
| **Conduit** | Rust | 极简 alpha |

### 4. Synapse 部署

```yaml
# docker-compose.yml
services:
  homeserver:
    image: matrixdotorg/synapse:latest
    volumes:
      - ./data:/data
    environment:
      - SYNAPSE_SERVER_NAME=example.com
      - SYNAPSE_CONFIG_PATH=/data/homeserver.yaml
```

需要：

- PostgreSQL
- Redis
- Reverse proxy（Nginx）for TLS
- Federation 开放：443 / 8448

### 5. 关键功能

| 功能 | 含义 |
| ---- | ---- |
| E2EE | 端到端加密（Olm） |
| Federation | 跨服务器同步 |
| 房间 | Public / Private / Encrypted |
| 历史可见性 | 自定义 |
| 客户端 | 多平台 |
| 自带 Bridge | WhatsApp / Telegram / Slack / Discord / Signal |
| 推送 | Unified Push / APNs / FCM |

### 6. Bridge

```text
maubot / matrix-appservice-*
   ├── Discord
   ├── Slack
   ├── GitHub
   ├── Email
   ├── WhatsApp（外部）
   └── Telegram（外部）
```

自带 mautrix-aws 或 matrix-hookshot 提供 webhook。

### 7. 与 Slack / Teams 对比

| 维度 | Element | Slack | Teams |
| ---- | ------ | ----- | ----- |
| E2EE | 强 | ❌ | ❌ |
| 联邦 | 跨服务器 | ❌ | ❌ |
| 自部署 | ✔ | ❌ | ❌ |
| 视频 | Jitsi 集成 | 内置 | 内置 |
| 集成 | 自部署 | 庞大市场 | Microsoft 生态 |
| 适合 | 安全 / 隐私 / 多组织 | 通用 | 企业 |

### 8. 规模参考

- 政府 / 国防：欧洲多国部署（法国 / Germany）
- 沙箱：sch.chat
- 中小规模：Synapse 单实例
- 大规模：Dendrite / 集群

## 三、Rocket.Chat

### 1. 定位

- 团队 IM，Hubot 协议
- 全功能 Web / Desktop / Mobile
- 集成 Hubot bot 框架
- Slack / Mattermost 替代

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| Channels | Public / Private |
| Threads | 线程回复 |
| Omnichannel | 客户对话集成 |
| Apps | App Engine / Marketplace |
| Federation | ❌（仅企业云） |
| Video Calls | Jitsi 集成 |
| Bot | Hubot |

### 3. 部署

```bash
docker run -d --name rocketchat \
  -e MONGO_URL=mongodb://mongo:27017/rocketchat \
  -e MONGO_OPLOG_URL=mongodb://mongo:27017/local \
  rocket.chat:6
```

### 4. Omnichannel

适合客服工单场景：

- 自动分配
- SLA / 监控
- 跨渠道（WhatsApp / 邮件 / LiveChat）

### 5. Apps

- Marketplace 上百 Apps
- 自定义 Apps（类似 Slack App）
- Webhook / OAuth

### 6. 客户

- Homeland Security
- Pfizer / Airbus
- 中小企业自部署常见

## 四、Zulip

### 1. 定位

- 团队协作 IM，主题分组（streams / topics）
- 类似邮件列表 + IM 混合
- Python + Django

### 2. 主题模型

```text
Stream: 设计
   Topic: 2024-09 logo 讨论
       ├── alice: 先 eval 一下 …
       ├── bob: draft 先发一版
       └── charlie: 周三 review
```

主题让长会话不混乱。

### 3. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| Streams / Topics | 二级分类 |
| 表情回复 | ✔ |
| 集成 | GitHub / Jira / GitLab / CI |
| 跨组织 | ❌（仅单租户） |
| Webhook | ✔ 强 |

### 4. 客户端

- Web / Desktop / Mobile
- API

### 5. 应用场景

- 研发团队
- 开源 / 邮件列表式讨论
- 学术协作

### 6. 与其他 IM 对比

| 维度 | Zulip | Slack | Mattermost |
| ---- | ----- | ----- | ---------- |
| 模型 | Stream + Topic | Channel | Channel |
| 邮件思维 | 强 | 弱 | 弱 |
| 搜索 | 强 | 中 | 中 |
| SLA / 商业 | ✔ | ✔ | ✔ |

## 十、选型速查

| 场景 | 推荐 |
| ---- | ---- |
| 企业通用 Slack 替代 | Mattermost |
| 多组织 / 联邦 / 安全 | Element (Matrix) |
| 客服 / Omnichannel | Rocket.Chat |
| 长期讨论 / 邮件列表 | Zulip |

## 十一、最佳实践

- **身份统一**：与 SSO (Keycloak / Authing) 集成
- **审计 / Compliance**：Mattermost Enterprise 合规导出
- **E2EE**：Element 默认开启（注意备份不便）
- **存储**：附件走对象存储（S3 / MinIO）
- **联邦**：Element 默认开启；Mattermost Enterprise 提供工作空间联邦
- **Webhook / Bot**：标准化 API
- **视频 / 通话**：集成 LiveKit / Jitsi
- **高可用**：DB 集群 + Redis + 反向代理
