# 项目管理（可私有化）

Jira / Trello / Asana / Linear / Monday 自部署替代品。覆盖敏捷 Scrum、看板、缺陷跟踪、路线图、产品需求、OKR 等场景。

## 一、Redmine

### 1. 定位

- 老牌 Ruby on Rails 项目管理
- 缺陷 / 任务 / 文档 / 论坛 / Wiki 全合一
- 高度可定制（通过 Plugin）

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| 项目 | 多项目 / 子项目 |
| 问题 | Task / Bug / Feature + 自定义字段 |
| 工作流 | 自定义状态流转 |
| Gantt / 燃尽 | 甘特图 / 进度 |
| 时间跟踪 | 计时器 / 工时 |
| 通知 | 邮件 / Webhook |
| 版本 / 里程碑 | 版本管理 |
| Wiki | 内置文档 |
| SVN / Git | 仓库集成 |
| LDAP / SAML | 企业认证 |

### 3. 部署

```bash
docker run -d --name redmine \
  -v /redmine/data:/usr/src/redmine/files \
  -e REDMINE_DB_MYSQL=mysql \
  -e REDMINE_DB_DATABASE=redmine \
  -e REDMINE_DB_USERNAME=redmine \
  -e REDMINE_DB_PASSWORD=... \
  redmine
```

### 4. Plugin 生态

- Agile 插件（Scum 看板）
- Checklists
- People（用户管理）
- 自定义 Plugin（Ruby）

### 5. 适合

- 传统企业
- 软件研发 + 综合
- 长期生产可用（15+ 年）

## 二、OpenProject

### 1. 定位

- Ruby on Rails + Angular
- 综合项目管理：Scrum + Kanban + 路线图 + 资源
- 替代 Jira

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| Work Packages | 任务聚合 |
| Agile | Scrum 看板 / Burndown |
| Roadmap | 里程碑 / 路线图 |
| Gantt | 资源甘特 / 依赖 |
| Wiki | 内置文档 |
| Forem | 论坛 |
| Time | 时间成本 |
| Workflows | 工作流 |
| LDAP / OIDC / SAML | 企业集成 |

### 3. 部署

```bash
docker run -d --name openproject \
  -e OPENPROJECT_DB_POSTGRES_USERNAME=openproject \
  -e OPENPROJECT_DB_POSTGRES_PASSWORD=... \
  openproject/openproject:15
```

支持 Docker / K8s / Omnibus。

### 4. 适合

- 中大型企业
- 综合规划型项目管理
- 不喜欢 Atlassian Jira 的收费

## 四、Plane

### 1. 定位

- 现代开源 Linear 替代品
- React + Node.js + PG
- 国产 / 国际团队均活跃
- 模块化、模块之间解耦

### 2. 核心能力

| 能力 | 含义 |
| ---- | ---- |
| Workspace | 多项目聚合 |
| Cycles | 周期性 Sprint |
| Modules | 模块化子项目 |
| Views | List / Board / Calendar / Triage |
| Work items | Issue / Task |
| Issues | 进度 / 工时 |
| Pages | 富文本 / Markdown |
| Analytics | 燃尽图 / Charts |

### 3. 部署

```bash
docker run -d --name plane \
  -v plane_data:/data \
  -e DATABASE_URL=... \
  makeplane/plane
```

需要 PG + Redis + S3 + 邮件。

### 4. 适合

- 创业 / SaaS
- 喜欢 Linear 体验但不想订阅
- 现代 React UI

### 5. 与 Linear 对比

| 维度 | Plane | Linear |
| ---- | ----- | ------ |
| 开源 | ✔ MPL 2.0 | ❌ |
| 客户端 | Web / Desktop | Web / Desktop / Mobile |
| 路线图 | ✔ | ✔ |
| 自部署 | ✔ | ❌ |
| 集成 | 自定 / GitHub / Slack | 丰富 |

## 十八、最佳实践

- **标准化**：自定义字段、状态、工作流统一
- **Webhook**：与 Git / CI / IM 集成
- **权限**：与 SSO 对接
- **数据导出**：避免 vendor lock-in
- **导出周期**：定期导出 Confluence / Jira / Redmine
- **审计**：变更日志进 SIEM
- **海外团队 / 数据合规**：自部署
- **结合 AI**：自动摘要 / 任务分派 / 决策建议
